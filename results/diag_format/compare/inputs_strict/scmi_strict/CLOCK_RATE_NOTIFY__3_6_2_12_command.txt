3.6.2.12 CLOCK_RATE_NOTIFY command
               Requests notifications from the platform when the rate of a specific clock device changes. The platform sends these notifications as CLOCK_RATE_CHANGED messages (Section 3.6.4.1). This command is optional. Use PROTOCOL_MESSAGE_ATTRIBUTES to discover whether it is implemented. The notifications are disabled by default during initial boot of the platform.
               3.6.2.12.1 Interface
               3.6.2.12.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                Message identifier, value 0x9
        protocol_id         Header       -           UInt32                                Protocol identifier, value 0x14
        clock_id            Payload[0]   31:0        UInt32                                Identifier for the clock device
        notify_enable       Payload[1]   31:1        UInt32                                Reserved, must be zero
                                         0                                                 Notify enable: 0 = the platform does not send CLOCK_RATE_CHANGED messages to the calling agent; 1 = the platform sends CLOCK_RATE_CHANGED messages to the calling agent when the clock rate for the clock device changes
               3.6.2.12.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              Payload[0]   31:0        Int32                                 status: command return status (see Section 3.1.4)
               3.6.2.12.2 Failure conditions
  ID                          Condition
  clock_id                    pre: !IsValidClockDevice(clock_id)
                              post: ResultEqual(result, NOT_FOUND)
  notify_enable               pre: !IsValidNotifyEnable(notify_enable)
                              post: ResultEqual(result, INVALID_PARAMETERS)
               3.6.2.12.2.1   Failure condition ordering
               The CLOCK_RATE_NOTIFY command does not have any failure condition orderings.
               3.6.2.12.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SUCCESS)
  notify_on                   post: Bits(notify_enable, 0, 0) == 1 ==> ClockRateNotifyEnabled(CallingAgent(), clock_id)
  notify_off                  post: Bits(notify_enable, 0, 0) == 0 ==> !ClockRateNotifyEnabled(CallingAgent(), clock_id)
               3.6.2.12.4 Footprint
    ID                        Value
    notify                    ClockRateNotifyEnabled(CallingAgent(), clock_id)
