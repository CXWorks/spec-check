3.3.2.1 PROTOCOL_VERSION command
               Returns the Protocol version.
               3.3.2.1.1 Interface
               3.3.2.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          -            -           UInt32                                Message identifier, value 0x0
        protocol_id         -            -           UInt32                                Protocol identifier, value 0x11
               3.3.2.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              -            -           Int32                                 Command return status. Status codes are defined in Section 3.1.4
        version             -            -           UInt32                                Protocol version. For this revision of the specification, the value must be 0x30001
               3.3.2.1.2 Failure conditions
               The PROTOCOL_VERSION command does not have any failure conditions.
               3.3.2.1.2.1   Failure condition ordering
               The PROTOCOL_VERSION command does not have any failure condition orderings.
               3.3.2.1.3 Success conditions
  ID                          Condition
  status                      post: IsSuccessStatus(status)
  version                     post: version == 0x30001
               3.3.2.1.4 Footprint
               The PROTOCOL_VERSION command does not modify any state.
