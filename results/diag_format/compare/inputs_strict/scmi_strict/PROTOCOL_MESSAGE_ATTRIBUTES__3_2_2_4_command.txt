3.2.2.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details associated with a specific message in this protocol.
               This command is mandatory.
               3.2.2.4.1 Interface
               3.2.2.4.1.1   Input values
        Name                Register             Bits        Type                                  Description
        msg_header_id       Message header       -           UInt                                  message_id of this command, value 0x2
        msg_header_proto    Message header       -           UInt                                  protocol_id of this command, value 0x10
        message_id          Payload word 0       31:0        UInt32                                message_id of the message
               3.2.2.4.1.2   Output values
        Name                Register             Bits        Type                                  Description
        status              Payload word 0       31:0        Int32                                 Command return status (see Section 3.1.4)
        attributes          Payload word 1       31:0        UInt32                                Flags associated with the specified command in the protocol
               3.2.2.4.2 Failure conditions
  ID                          Condition
  msg_not_found               pre: !IsMessageImplemented(0x10, message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.2.2.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.2.2.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  msg_available               post: IsMessageImplemented(0x10, message_id) && IsMessageAvailable(0x10, message_id)
  attributes                  post: attributes == 0
               3.2.2.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not modify any state.
