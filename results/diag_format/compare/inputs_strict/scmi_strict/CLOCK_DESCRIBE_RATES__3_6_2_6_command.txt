3.6.2.6 CLOCK_DESCRIBE_RATES command
               Returns the valid rates to which a clock can be set. Rates are returned either as a list of discrete rates or as one segment {lowest rate, highest rate, step size}. Several calls may be needed to retrieve the whole list. The response reports how many rates remain.
               message_id: 0x4, protocol_id: 0x14. This command is mandatory.
               3.6.2.6.1 Interface
               3.6.2.6.1.1   Input values
        Name                Register        Bits        Type                                  Description
        clock_id            Payload[0]      31:0        UInt32                                Identifier for the clock device
        rate_index          Payload[1]      31:0        UInt32                                Index of the first rate value to describe in the returned rate array
               3.6.2.6.1.2   Output values
        Name                Register        Bits        Type                                  Description
        status              Payload[0]      31:0        Int32                                 Command return status
        num_rates_flags     Payload[1]      31:0        UInt32                                Descriptor for the rates this clock supports:
                                                                                              Bits[31:16] number of remaining rates;
                                                                                              Bits[15:13] reserved, must be zero;
                                                                                              Bit[12] return format (1 = segment triplet, 0 = discrete rates);
                                                                                              Bits[11:0] number of rates returned by this call
        rates[N]            Payload[2..]    63:0        {UInt32, UInt32}                      Rate Array. N is Bits[11:0] of num_rates_flags.
                                                                                              If Bit[12] is 0, each entry is one discrete physical rate in Hertz:
                                                                                              the lower word holds the lower 32 bits and the upper word holds the upper 32 bits.
                                                                                              If Bit[12] is 1, the entries form one segment:
                                                                                              rates[0] is the lowest rate, rates[1] is the highest rate and rates[2] is the step size.
               3.6.2.6.2 Failure conditions
  ID                          Condition
  clock_id                    pre: !ClockExists(clock_id)
                              post: ResultEqual(status, NOT_FOUND)
  rate_index                  pre: !IsValidRateIndex(clock_id, rate_index)
                              post: ResultEqual(status, OUT_OF_RANGE)
               3.6.2.6.2.1   Failure condition ordering
  [clock_id] < [rate_index]
               3.6.2.6.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  reserved                    post: Bits(num_rates_flags, 15, 13) == 0
  segment_count               post: Bits(num_rates_flags, 12, 12) == 1 ==> Bits(num_rates_flags, 11, 0) == 3
  segment_remaining           post: Bits(num_rates_flags, 12, 12) == 1 ==> Bits(num_rates_flags, 31, 16) == 0
  segment_rates               post: Bits(num_rates_flags, 12, 12) == 1 ==> IsClockRateSegment(clock_id, LowestRate(rates), HighestRate(rates), StepSize(rates))
  discrete_rates              post: Bits(num_rates_flags, 12, 12) == 0 ==> (forall|i: UInt32| i < Bits(num_rates_flags, 11, 0) ==> IsClockPhysicalRate(clock_id, RateHz(rates, i)))
  discrete_first              post: Bits(num_rates_flags, 12, 12) == 0 ==> RateHz(rates, 0) == ClockRateAtIndex(clock_id, rate_index)
  discrete_remaining          post: Bits(num_rates_flags, 12, 12) == 0 ==> Bits(num_rates_flags, 31, 16) == NumRemainingRates(clock_id, rate_index, Bits(num_rates_flags, 11, 0))
  ascending                   post: forall|i: UInt32| i + 1 < Bits(num_rates_flags, 11, 0) && Bits(num_rates_flags, 12, 12) == 0 ==> RateHz(rates, i) < RateHz(rates, i + 1)
  array_size                  post: Bits(num_rates_flags, 11, 0) <= MaxTransportReturnRates()
               3.6.2.6.4 Footprint
               The CLOCK_DESCRIBE_RATES command does not modify any state.
