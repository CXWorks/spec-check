3.10.3.13 POWERCAP_DOMAIN_NAME_GET command
               Returns the extended name of a power capping domain.
               This command is mandatory only if extended power capping domain names are supported. They are supported when Bit[28] of the attributes field returned by POWERCAP_DOMAIN_ATTRIBUTES is set to 1 (see Section 3.10.3.5).
               3.10.3.13.1 Interface
               3.10.3.13.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           UInt                                  Message ID, value 0x8
        protocol_id         Header       —           UInt                                  Protocol ID, value 0x18
        domain_id           Payload[0]   31:0        UInt32                                Identifier for the power capping domain
               3.10.3.13.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status (see Section 3.1.4)
        flags               Payload[1]   31:0        UInt32                                Reserved, must be zero
        name                Payload[2]   511:0       UInt8[64]                             Null-terminated ASCII string of up to 64 bytes giving the extended name of the power capping domain
               3.10.3.13.2 Failure conditions
  ID                          Condition
  domain_exists               pre: !PowercapDomainExists(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.10.3.13.2.1   Failure condition ordering
               The POWERCAP_DOMAIN_NAME_GET command does not have any failure condition orderings.
               3.10.3.13.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  flags                       post: flags == 0
  name_term                   post: IsNullTerminatedAscii(name, 64)
  name_value                  post: IsPowercapDomainExtendedName(name, domain_id)
               3.10.3.13.4 Footprint
               The POWERCAP_DOMAIN_NAME_GET command does not modify any state.
