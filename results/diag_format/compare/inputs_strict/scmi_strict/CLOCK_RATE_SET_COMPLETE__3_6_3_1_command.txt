3.6.3.1 CLOCK_RATE_SET_COMPLETE command
               Delayed response that the platform sends to the agent when the clock rate changes, if the agent changed the clock rate asynchronously through CLOCK_RATE_SET. This command is optional.
               3.6.3.1.1 Interface
               3.6.3.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          —            —           UInt32                                Message ID, value 0x5
        protocol_id         —            —           UInt32                                Protocol ID, value 0x14
               3.6.3.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              —            31:0        Int32                                 Command return status
        clock_id            —            31:0        UInt32                                Identifier for the clock device
        rate[0]             —            31:0        UInt32                                Lower 32 bits of the physical rate in Hertz that the clock transitioned to
        rate[1]             —            31:0        UInt32                                Upper 32 bits of the physical rate in Hertz that the clock transitioned to
               3.6.3.1.2 Failure conditions
  ID                          Condition
  clock_denied                pre: ClockHasOtherUsers(clock_id)
                              post: ResultEqual(status, DENIED)
               3.6.3.1.2.1   Failure condition ordering
               The CLOCK_RATE_SET_COMPLETE command does not have any failure condition orderings.
               3.6.3.1.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  clock_rate                  post: ClockRate(clock_id) == rate[0] + rate[1] * 4294967296
               3.6.3.1.4 Footprint
    ID                        Value
    clock_rate                ClockRate(clock_id)
