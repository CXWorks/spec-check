3.12.4.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details of a specific message in this protocol. It can be used to check whether optional commands are supported.
               3.12.4.4.1 Interface
               3.12.4.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           UInt                                  Message identifier of this command, value 0x2
        protocol_id         Header       —           UInt                                  Protocol identifier, value 0x1B
        message_id          Param 0      31:0        UInt32                                message_id of the message being queried
               3.12.4.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Return 0     31:0        Int32                                 Command return status
        attributes          Return 1     31:0        UInt32                                Flags associated with the queried command in the protocol
               3.12.4.4.2 Failure conditions
  ID                          Condition
  msg_not_found               pre: !IsValidMessageId(message_id) || !IsMessageImplemented(message_id) || !IsMessageAvailableToAgent(message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.12.4.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.12.4.4.3 Success conditions
  ID                          Condition
  msg_supported               post: ResultEqual(status, SUCCESS)
  msg_attributes              post: attributes == 0
               3.12.4.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not modify any state.
