3.8.2.3 PROTOCOL_ATTRIBUTES command
               Returns the implementation details associated with this protocol.
               This command is mandatory.
               3.8.2.3.1 Interface
               3.8.2.3.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          —            —           UInt32                                Message ID, value 0x1
        protocol_id         —            —           UInt32                                Protocol ID, value 0x16
               3.8.2.3.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              —            31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions.
        attributes          —            31:16       UInt32                                Reserved, must be zero
                                         15:0                                              Number of reset domains
               3.8.2.3.2 Failure conditions
               The PROTOCOL_ATTRIBUTES command does not have any failure conditions.
               3.8.2.3.2.1   Failure condition ordering
               The PROTOCOL_ATTRIBUTES command does not have any failure condition orderings.
               3.8.2.3.3 Success conditions
  ID                          Condition
  attr_reserved               post: Bits(attributes, 31, 16) == 0
  attr_num_domains            post: Bits(attributes, 15, 0) == NumResetDomains()
               3.8.2.3.4 Footprint
               The PROTOCOL_ATTRIBUTES command does not modify any state.
