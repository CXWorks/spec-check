3.6.2.16 CLOCK_PARENT_GET command
               Gets the current parent of a clock device.
               This command is mandatory if, for any clock device, Bit[28] of the attributes field returned by the CLOCK_ATTRIBUTES command is set to 1.
               3.6.2.16.1 Interface
               3.6.2.16.1.1   Input values
        Name                Register          Bits        Type                                  Description
        message_id          Header            -           UInt                                  Message identifier, value 0xE
        protocol_id         Header            -           UInt                                  Protocol identifier, value 0x14
        clock_id            Payload word 0    31:0        UInt32                                Identifier for the clock device
               3.6.2.16.1.2   Output values
        Name                Register          Bits        Type                                  Description
        status              Payload word 0    31:0        Int32                                 Command return status (see Section 3.1.4)
        parent_id           Payload word 1    31:0        UInt32                                Identifier for the parent clock device
               3.6.2.16.2 Failure conditions
  ID                          Condition
  clock_exists                pre: !ClockExists(clock_id)
                              post: ResultEqual(status, NOT_FOUND)
  supported                   pre: !IsClockParentGetSupported(clock_id)
                              post: ResultEqual(status, NOT_SUPPORTED)
  permission                  pre: !IsAgentAllowedToGetClockParent(CallingAgent(), clock_id)
                              post: ResultEqual(status, DENIED)
               3.6.2.16.2.1   Failure condition ordering
               The CLOCK_PARENT_GET command does not have any failure condition orderings.
               3.6.2.16.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  parent                      post: parent_id == ClockParent(clock_id)
               3.6.2.16.4 Footprint
               The CLOCK_PARENT_GET command does not have a footprint.
