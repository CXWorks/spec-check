3.9.2.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details of a specific message in this protocol (protocol_id 0x17, message_id 0x2). This command is mandatory.
               3.9.2.4.1 Interface
               3.9.2.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Payload[0]   31:0        UInt32                                message_id of the message being queried
               3.9.2.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status (see Section 3.1.4)
        attributes          Payload[1]   31:0        UInt32                                Flags associated with the queried command in the protocol
               3.9.2.4.2 Failure conditions
  ID                          Condition
  msg_not_found               pre: !IsValidMessageId(message_id) || !IsMessageImplemented(message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.9.2.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.9.2.4.3 Success conditions
  ID                          Condition
  msg_status                  post: ResultEqual(status, SUCCESS)
  msg_attributes              post: attributes == 0
               3.9.2.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not modify any state.
