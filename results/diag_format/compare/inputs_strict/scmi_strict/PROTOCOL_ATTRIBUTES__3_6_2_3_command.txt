3.6.2.3 PROTOCOL_ATTRIBUTES command
               Returns the implementation details associated with this protocol.
               This command is mandatory.
               3.6.2.3.1 Interface
               3.6.2.3.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       7:0         UInt8                                 Message ID, value 0x1
        protocol_id         Header       17:10       UInt8                                 Protocol ID, value 0x14
               3.6.2.3.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        int32                                 Command return status. See Section 3.1.4 for status code definitions.
        attributes          Payload[1]   31:0        uint32                                Bits[31:24]: Reserved, must be zero.
                                                                                           Bits[23:16]: Maximum number of pending asynchronous clock rate changes supported by the platform.
                                                                                           Bits[15:0]: Number of clocks.
               3.6.2.3.2 Failure conditions
               The PROTOCOL_ATTRIBUTES command does not have any failure conditions.
               3.6.2.3.2.1   Failure condition ordering
               The PROTOCOL_ATTRIBUTES command does not have any failure condition orderings.
               3.6.2.3.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attr_reserved               post: Bits(attributes, 31, 24) == 0
  attr_max_pending            post: Bits(attributes, 23, 16) == MaxPendingAsyncClockRateChanges()
  attr_num_clocks             post: Bits(attributes, 15, 0) == NumClocks()
               3.6.2.3.4 Footprint
               The PROTOCOL_ATTRIBUTES command does not modify any state.
