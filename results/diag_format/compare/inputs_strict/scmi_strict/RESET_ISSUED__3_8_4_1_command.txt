3.8.4.1 RESET_ISSUED command
               The platform sends this notification to an agent that has registered to receive notifications when the reset domain identified by domain_id has been reset. The agent might not receive the notification if the reset affects that agent. This command is optional.
               3.8.4.1.1 Interface
               3.8.4.1.1.1   Input values
        Name                Register             Bits        Type                                  Description
        message_id          Message header       —           UInt                                  Message identifier, value 0x0
        protocol_id         Message header       —           UInt                                  Protocol identifier, value 0x16
        agent_id            Payload word 0       31:0        UInt32                                Identifier of the agent that caused the reset of the domain
        domain_id           Payload word 1       31:0        UInt32                                Identifier of the reset domain
        reset_state         Payload word 2       31:0        UInt32                                Reset state issued on the domain, in the format given in Table 22
               3.8.4.1.1.2   Output values
               The RESET_ISSUED command does not have any output values.
               3.8.4.1.2 Failure conditions
               The RESET_ISSUED command does not have any failure conditions.
               3.8.4.1.2.1   Failure condition ordering
               The RESET_ISSUED command does not have any failure condition orderings.
               3.8.4.1.3 Success conditions
  ID                          Condition
  domain_reset                post: ResetDomainHasBeenReset(domain_id, reset_state)
  agent_registered            post: AgentRegisteredForResetNotifications(recipient_agent, domain_id)
  reset_cause                 post: ResetCausedByAgent(domain_id, agent_id)
               3.8.4.1.4 Footprint
               The RESET_ISSUED command does not modify any state.
