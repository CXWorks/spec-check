3.7.2.1 PROTOCOL_VERSION command
               Returns the version of this protocol. For this version of the specification, the version is 3.1.
               This command is mandatory.
               3.7.2.1.1 Interface
               3.7.2.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                Message identifier, value 0x0
        protocol_id         Header       -           UInt32                                Protocol identifier, value 0x15
               3.7.2.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions.
        version             Payload[1]   31:0        UInt32                                Protocol version. For this revision of the specification, this value must be 0x30001.
               3.7.2.1.2 Failure conditions
               The PROTOCOL_VERSION command does not have any failure conditions.
               3.7.2.1.2.1   Failure condition ordering
               The PROTOCOL_VERSION command does not have any failure condition orderings.
               3.7.2.1.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  version                     post: version == 0x30001
               3.7.2.1.4 Footprint
               The PROTOCOL_VERSION command does not modify any state.
