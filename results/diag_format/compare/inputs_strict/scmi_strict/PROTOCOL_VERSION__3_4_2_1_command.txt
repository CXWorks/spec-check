3.4.2.1 PROTOCOL_VERSION command
               Returns the version of this protocol. This command is mandatory.
               3.4.2.1.1 Interface
               3.4.2.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          header       -           UInt                                  Message ID, value 0x0
        protocol_id         header       -           UInt                                  Protocol ID, value 0x12
               3.4.2.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              payload      31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions.
        version             payload      31:0        UInt32                                Protocol version. For this revision of the specification, this must be 0x20001 (version 2.1).
               3.4.2.1.2 Failure conditions
               The PROTOCOL_VERSION command does not have any failure conditions.
               3.4.2.1.2.1   Failure condition ordering
               The PROTOCOL_VERSION command does not have any failure condition orderings.
               3.4.2.1.3 Success conditions
  ID                          Condition
  version                     post: version == 0x20001
               3.4.2.1.4 Footprint
               The PROTOCOL_VERSION command does not modify any state.
