3.10.3.6 POWERCAP_CPC_ATTRIBUTES command
               Returns the CPC attributes for a power capping domain as an array of CPLi descriptors. One call might not return every descriptor, so the caller can make several calls. Each call also reports how many descriptors remain. The transport determines how many descriptors one call can return. The CPL Identifiers in the returned array should be in ascending numeric order. Section 3.5.6.8 shows an example of this kind of API.
               This command is mandatory if CPC is supported for any domain.
               3.10.3.6.1 Interface
               3.10.3.6.1.1   Input values
        Name                Register        Bits        Type                                  Description
        protocol_id         Message header  -           UInt                                  Protocol identifier, value 0x18
        message_id          Message header  -           UInt                                  Message identifier, value 0xD
        domain_id           Parameter 0     31:0        UInt32                                Identifier for the power capping domain
        desc_index          Parameter 1     31:0        UInt32                                Index of the first CPLi descriptor to return in the CPLi descriptor array. This is not the CPL Identifier.
               3.10.3.6.1.2   Output values
        Name                Register        Bits        Type                                  Description
        status              Return 0        31:0        Int32                                 Command return status
        num_cpl             Return 1        31:16       UInt32                                Number of remaining CPLi descriptors
        num_cpl             Return 1        15:0        UInt32                                Number of CPLi descriptors returned by this call
        desc[N]             Return 2..      -           CPLi_DESC[N]                          Array of CPLi descriptors, in the CPLi Descriptor format
               3.10.3.6.1.3   CPLi Descriptor
        Name                Bits            Type                                  Description
        cpli                31:0            UInt32                                Integer identifier of the concurrent power limit
        flags               31:1            UInt32                                Reserved, must be zero
        flags               0               UInt32                                Power cap configuration support. 1: this CPLi supports changing power caps. 0: this CPLi does not support changing power caps.
        min_power_cap       31:0            UInt32                                Minimum power value that can be set as the power cap for this CPLi. Must not be zero.
        max_power_cap       31:0            UInt32                                Maximum power value that can be set as the power cap for this CPLi. Must not be zero.
        power_cap_step      31:0            UInt32                                Step size between two consecutive supported power cap values
        min_cai             31:0            UInt32                                Minimum supported power capping averaging interval (CAI), in microseconds. Zero if the platform does not report this value.
        max_cai             31:0            UInt32                                Maximum supported CAI, in microseconds. Zero if the platform does not report this value.
        cai_step            31:0            UInt32                                Step size between two consecutive supported CAI values
        name                8 x 16          UInt8[16]                             Null-terminated ASCII string of up to 16 bytes describing the CPLi. Table 26 gives the recommended naming convention.
               3.10.3.6.2 Failure conditions
  ID                          Condition
  cmd_support                 pre: !IsCommandSupported(protocol_id, message_id)
                              post: ResultEqual(status, NOT_SUPPORTED)
  domain                      pre: !IsValidPowercapDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  cpc_support                 pre: !DomainSupportsCpc(domain_id)
                              post: ResultEqual(status, NOT_SUPPORTED)
  desc_range                  pre: !IsValidCpliDescIndex(domain_id, desc_index)
                              post: ResultEqual(status, OUT_OF_RANGE)
               3.10.3.6.2.1   Failure condition ordering
  [domain] < [cpc_support]
  [domain] < [desc_range]
               The valid range of desc_index belongs to a specific domain. The domain_id check therefore comes before the desc_index range check and the CPC support check.
               3.10.3.6.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  num_returned                post: Bits(num_cpl, 15, 0) == N
  num_returned_bound          post: Bits(num_cpl, 15, 0) <= MaxCpliDescsPerTransport()
  num_remaining               post: Bits(num_cpl, 31, 16) == NumCpliDescs(domain_id) - desc_index - Bits(num_cpl, 15, 0)
  desc_content                post: forall|i: UInt32| i < N ==> desc[i] == CpliDescriptor(domain_id, desc_index + i)
  desc_order                  post: forall|i: UInt32| i + 1 < N ==> desc[i].cpli < desc[i + 1].cpli
  flags_rsvd                  post: forall|i: UInt32| i < N ==> Bits(desc[i].flags, 31, 1) == 0
  flags_cap_cfg               post: forall|i: UInt32| i < N ==> (Bits(desc[i].flags, 0, 0) == 1) == CpliSupportsPowerCapChange(domain_id, desc[i].cpli)
  min_cap_nonzero             post: forall|i: UInt32| i < N ==> desc[i].min_power_cap != 0
  max_cap_nonzero             post: forall|i: UInt32| i < N ==> desc[i].max_power_cap != 0
  cap_not_cfg                 post: forall|i: UInt32| i < N ==> (desc[i].min_power_cap == desc[i].max_power_cap ==> !IsPowerCapConfigurable(domain_id, desc[i].cpli))
  cap_step                    post: forall|i: UInt32| i < N ==> (desc[i].min_power_cap != desc[i].max_power_cap ==> desc[i].power_cap_step != 0)
  cai_not_cfg                 post: forall|i: UInt32| i < N ==> (desc[i].min_cai == desc[i].max_cai ==> !IsCaiConfigurable(domain_id, desc[i].cpli))
  cai_step                    post: forall|i: UInt32| i < N ==> (desc[i].min_cai != desc[i].max_cai ==> desc[i].cai_step != 0)
  cai_unreported              post: forall|i: UInt32| i < N ==> (!PlatformReportsCai(domain_id, desc[i].cpli) ==> desc[i].min_cai == 0 && desc[i].max_cai == 0)
  name                        post: forall|i: UInt32| i < N ==> IsNullTerminatedAscii(desc[i].name, 16)
               3.10.3.6.4 Footprint
               The POWERCAP_CPC_ATTRIBUTES command does not modify any state.
