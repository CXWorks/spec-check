3.4.2.7 SYSTEM_POWER_STATE_NOTIFY command
               Requests notification of system power state requests. The OSPM can use it to receive notifications of graceful system power state requests. A management agent or a privileged agent can use it to be notified that the OSPM requested a forceful transition. On initial boot of an agent, these notifications are disabled by default for that agent. This command is mandatory in an OSPM view implementation.
               3.4.2.7.1 Interface
               3.4.2.7.1.1   Input values
        Name                Register        Bits        Type                Description
        message_id          Message header  -           UInt32              Message ID, value 0x5
        protocol_id         Message header  -           UInt32              Protocol ID, value 0x12
        notify_enable       Payload word 0  31:0        UInt32              Bits[31:1]: reserved, must be zero. Bit[0]: notify enable. 0: the platform does not send SYSTEM_POWER_STATE_NOTIFIER messages to the calling agent. 1: the platform sends SYSTEM_POWER_STATE_NOTIFIER messages to the calling agent. See Section 3.4.3.1.
               3.4.2.7.1.2   Output values
        Name                Register        Bits        Type                Description
        status              Payload word 0  31:0        Int32               Command return status. See Section 3.1.4.
               3.4.2.7.2 Failure conditions
  ID                          Condition
  notify_supported            pre: !SystemPowerStateNotifySupported(caller)
                              post: ResultEqual(status, NOT_SUPPORTED)
  notify_enable_valid         pre: Bits(notify_enable, 31, 1) != 0 || !IsPermissibleNotifyEnable(caller, notify_enable)
                              post: ResultEqual(status, INVALID_PARAMETERS)
               3.4.2.7.2.1   Failure condition ordering
               The SYSTEM_POWER_STATE_NOTIFY command does not have any failure condition orderings.
               3.4.2.7.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  notify_on                   post: Bits(notify_enable, 0, 0) == 1 ==> SystemPowerStateNotifyEnabled(caller)
  notify_off                  post: Bits(notify_enable, 0, 0) == 0 ==> !SystemPowerStateNotifyEnabled(caller)
