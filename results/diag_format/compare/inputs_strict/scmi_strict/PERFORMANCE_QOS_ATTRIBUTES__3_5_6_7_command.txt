3.5.6.7 PERFORMANCE_QOS_ATTRIBUTES command
               Returns the name and attributes of a QoS capability.
               message_id: 0xE, protocol_id: 0x13.
               This command is mandatory if the platform supports QoS capabilities.
               3.5.6.7.1 Interface
               3.5.6.7.1.1   Input values
        Name                Register        Bits        Type                                  Description
        domain_id           Payload[0]      31:0        UInt32                                Identifier for the performance domain
        capability          Payload[1]      31:0        UInt32                                QoS capability, as described by Table 14. Only one QoS capability Type bit can be set. At most one QoS capability Subtype bit can be set.
               3.5.6.7.1.2   Output values
        Name                Register        Bits        Type                                  Description
        status              Payload[0]      31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions.
        qos_attribute_1     Payload[1]      31:0        UInt32                                First attribute of the specified QoS capability of this domain. See Section 3.5.4.1 for the attribute details of each QoS capability Type.
        name                Payload[2..5]   127:0       UInt8[16]                             Null-terminated ASCII string, up to 16 bytes long, giving the name of the QoS capability
               3.5.6.7.2 Failure conditions
  ID                          Condition
  domain_valid                pre: !IsValidPerformanceDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  capability_valid            pre: !IsValidQosCapability(domain_id, capability)
                              post: ResultEqual(status, NOT_FOUND)
  type_bits                   pre: QosCapabilityTypeBitCount(capability) > 1
                              post: ResultEqual(status, INVALID_PARAMETERS)
  subtype_bits                pre: QosCapabilitySubtypeBitCount(capability) > 1
                              post: ResultEqual(status, INVALID_PARAMETERS)
               3.5.6.7.2.1   Failure condition ordering
               The PERFORMANCE_QOS_ATTRIBUTES command does not have any failure condition orderings.
               3.5.6.7.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  qos_attribute_1             post: qos_attribute_1 == QosCapabilityFirstAttribute(domain_id, capability)
  name                        post: QosCapabilityNameEqual(name, domain_id, capability)
  name_terminated             post: IsNullTerminatedAscii(name, 16)
               3.5.6.7.4 Footprint
               The PERFORMANCE_QOS_ATTRIBUTES command only returns information, so it has no footprint.
