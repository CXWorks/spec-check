3.10.4.1 POWERCAP_CAP_SET_COMPLETE command
               Delayed response that the platform sends to the agent when a power cap setting request made asynchronously through POWERCAP_CAP_SET has completed.
               This command is optional if no domain supports asynchronously setting the power cap.
               3.10.4.1.1 Interface
               3.10.4.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt                                  Message ID, value 0x5
        protocol_id         Header       -           UInt                                  Protocol ID, value 0x18
               3.10.4.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload      31:0        Int32                                 Command return status: SUCCESS, or another status code (see Section 3.1.4), including vendor-specific errors
        domain_id           Payload      31:0        UInt32                                Identifier for the power capping domain
        power_cap           Payload      31:0        UInt32                                The power cap set for the domain
        cpli                Payload      31:0        UInt32                                Concurrent power limit identifier
               3.10.4.1.2 Failure conditions
               The section names no specific failure conditions. Depending on the implementation, other vendor-specific errors can also be returned.
               3.10.4.1.2.1   Failure condition ordering
               The POWERCAP_CAP_SET_COMPLETE command does not have any failure condition orderings.
               3.10.4.1.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  cap_set                     post: PowerCapRequestCompleted(domain_id, power_cap)
  cpli_zero                   post: !DomainSupportsCpc(domain_id) ==> cpli == 0
               3.10.4.1.4 Footprint
    ID                        Value
    cap_set                   PowerCap(domain_id)
