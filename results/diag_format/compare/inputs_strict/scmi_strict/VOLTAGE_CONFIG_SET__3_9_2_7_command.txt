3.9.2.7 VOLTAGE_CONFIG_SET command

               Sets the configuration of a voltage domain, which enables or disables the domain.
               This command is mandatory.

               3.9.2.7.1 Interface

               3.9.2.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                Message identifier, value 0x5
        protocol_id         Header       -           UInt32                                Protocol identifier, value 0x17
        domain_id           Payload[0]   31:0        UInt32                                Identifier for the voltage domain
        config              Payload[1]   31:4        UInt32                                Reserved, must be zero
                            Payload[1]   3:0         UInt32                                Mode: the operating mode to set the voltage domain to, as described in Table 24

               3.9.2.7.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status. See Section 3.1.4 for more status code definitions

               3.9.2.7.2 Failure conditions
  ID                          Condition
  domain_exists               pre: !VoltageDomainExists(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  config_supported            pre: !VoltageDomainSupportsMode(domain_id, Bits(config, 3, 0))
                              post: ResultEqual(status, INVALID_PARAMETERS)
  request_supported           pre: !IsRequestSupported(VOLTAGE_CONFIG_SET)
                              post: ResultEqual(status, NOT_SUPPORTED)
  agent_permission            pre: !AgentMaySetVoltageConfig(CallingAgent(), domain_id)
                              post: ResultEqual(status, DENIED)

               3.9.2.7.2.1   Failure condition ordering
               The VOLTAGE_CONFIG_SET command does not have any failure condition orderings.

               3.9.2.7.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  domain_mode                 post: VoltageDomain(domain_id).mode == Bits(config, 3, 0)

               3.9.2.7.4 Footprint
    ID                        Value
    domain_mode               VoltageDomain(domain_id).mode
