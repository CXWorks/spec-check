3.8.2.1 PROTOCOL_VERSION command
               Returns the version of this protocol. This command is mandatory.
               3.8.2.1.1 Interface
               3.8.2.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          -            -           UInt                                  Message ID, value 0x0
        protocol_id         -            -           UInt                                  Protocol ID, value 0x16
               3.8.2.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              -            31:0        int32                                 Command return status. See Section 3.1.4 for status code definitions.
        version             -            31:0        uint32                                Version of this protocol. For this revision of the specification, this must be 0x30001.
               3.8.2.1.2 Failure conditions
               The PROTOCOL_VERSION command does not have any failure conditions.
               3.8.2.1.2.1   Failure condition ordering
               The PROTOCOL_VERSION command does not have any failure condition orderings.
               3.8.2.1.3 Success conditions
  ID                          Condition
  status                      post: IsSuccessStatus(status)
  version                     post: version == 0x30001
  version_num                 post: ProtocolVersionIs(version, 3, 1)
               3.8.2.1.4 Footprint
               The PROTOCOL_VERSION command does not modify any state.
