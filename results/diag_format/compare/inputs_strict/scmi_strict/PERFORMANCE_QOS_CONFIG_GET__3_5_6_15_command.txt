3.5.6.15 PERFORMANCE_QOS_CONFIG_GET command
               Gets the current QoS configuration for a performance domain, for one of the domain's supported QoS capabilities.
               This command is mandatory if the platform supports QoS capabilities.
               The returned qos_value may already be stale when the command completes, because another QoS value change request could have started and finished in the meantime.
               3.5.6.15.1 Interface
               3.5.6.15.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       7:0         UInt8                                 Message identifier, value 0x21
        protocol_id         Header       17:10       UInt8                                 Protocol identifier, value 0x13
        domain_id           Payload[0]   31:0        UInt32                                Identifier for the performance domain
        capability          Payload[1]   31:0        UInt32                                QoS capability, as described by Table 14. Only one QoS capability Type bit can be set. At most one QoS capability Subtype bit can be set.
               3.5.6.15.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
        qos_value           Payload[1]   31:0        UInt32                                QoS configuration of the performance domain for the given QoS capability
               3.5.6.15.2 Failure conditions
  ID                          Condition
  domain_valid                pre: !IsValidPerformanceDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  capability_valid            pre: !IsValidQosCapabilityOfDomain(domain_id, capability)
                              post: ResultEqual(status, NOT_FOUND)
  capability_type_bits        pre: QosCapabilityTypeBitCount(capability) > 1
                              post: ResultEqual(status, INVALID_PARAMETERS)
  capability_subtype_bits     pre: QosCapabilitySubtypeBitCount(capability) > 1
                              post: ResultEqual(status, INVALID_PARAMETERS)
               3.5.6.15.2.1   Failure condition ordering
               The PERFORMANCE_QOS_CONFIG_GET command does not have any failure condition orderings.
               3.5.6.15.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  qos_value                   post: qos_value == CurrentQosConfig(domain_id, capability)
               3.5.6.15.4 Footprint
               The PERFORMANCE_QOS_CONFIG_GET command does not have any footprint.
