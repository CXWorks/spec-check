3.9.2.9 VOLTAGE_LEVEL_SET command
               Sets the voltage level of a voltage domain.
               3.9.2.9.1 Interface
               3.9.2.9.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                Message ID, value 0x7
        protocol_id         Header       -           UInt32                                Protocol ID, value 0x17
        domain_id           Payload[0]   31:0        UInt32                                Identifier for the voltage domain
        flags               Payload[1]   31:0        UInt32                                Bits[31:1]: Reserved, must be zero. Bit[0]: Async flag. 1 = set the voltage level asynchronously; the call is completed with a VOLTAGE_LEVEL_SET_COMPLETE message. 0 = set the voltage level synchronously; the call returns when the voltage level has been set.
        voltage_level       Payload[2]   31:0        Int32                                 Voltage level to set the domain to, in microvolts (uV)
               3.9.2.9.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
               3.9.2.9.2 Failure conditions
  ID                          Condition
  domain_exists               pre: !VoltageDomainExists(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  level_supported             pre: !IsSupportedVoltageLevel(domain_id, voltage_level)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  request_supported           pre: !IsVoltageLevelSetRequestSupported(domain_id, flags, voltage_level)
                              post: ResultEqual(status, NOT_SUPPORTED)
  agent_permission            pre: !AgentMaySetVoltageLevel(calling_agent, domain_id)
                              post: ResultEqual(status, DENIED)
               3.9.2.9.2.1   Failure condition ordering
               The VOLTAGE_LEVEL_SET command does not have any failure condition orderings.
               3.9.2.9.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  level_sync                  post: Bits(flags, 0, 0) == 0 ==> VoltageLevel(domain_id) == voltage_level
  level_async_queued          post: Bits(flags, 0, 0) == 1 ==> VoltageLevelSetQueued(domain_id, voltage_level)
  level_async_complete        post: Bits(flags, 0, 0) == 1 ==> CompletesWithVoltageLevelSetCompleteMessage(domain_id)
               3.9.2.9.4 Footprint
    ID                        Value
    level                     VoltageLevel(domain_id)
