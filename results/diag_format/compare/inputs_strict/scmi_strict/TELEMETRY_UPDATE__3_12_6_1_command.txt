3.12.6.1 TELEMETRY_UPDATE command
               Notifies an agent that requested continuous update notifications through TELEMETRY_CONFIG_SET that it should read telemetry data. The notification also carries the telemetry payload lines for DEs that are enabled but are not available over SHMTI or FastChannels.
               3.12.6.1.1 Interface
               3.12.6.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          -            -           UInt32                                Message ID, value 0x0
        protocol_id         -            -           UInt32                                Protocol ID, value 0x1B
               3.12.6.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        agent_id            -            31:0        UInt32                                Agent that caused this event. Set to 0 to show that the platform generates all telemetry notification events
        status              -            31:0        Int32                                 Status code, as described in Section 3.1.4
        num_dwords          -            31:0        UInt32                                Size of the returned array in DWORDS (one DWORD is 4 bytes)
        array               -            -           UInt32[N]                             Telemetry payload section without prologue or epilogue. N is given by num_dwords
               3.12.6.1.2 Failure conditions
  ID                          Condition
  de_hw_fault                 pre: DeHardwareFaultDetected()
                              post: ResultEqual(status, HARDWARE_ERROR)
  partial_data                pre: SomeTelemetryDataNotCollected()
                              post: ResultEqual(status, PARTIAL_ERROR)
               3.12.6.1.2.1   Failure condition ordering
               The TELEMETRY_UPDATE command does not have any failure condition orderings.
               3.12.6.1.3 Success conditions
  ID                          Condition
  status                      post: status == 0
  agent_id                    post: agent_id == 0
  dwords_even                 post: num_dwords % 2 == 0
  dwords_none                 post: AllEnabledDesOnShmtiOrFastChannels() ==> num_dwords == 0
  array_len                   post: ArrayLength(array) == num_dwords
  array_lines                 post: ArrayHoldsEnabledDesNotOnShmtiOrFastChannels(array)
  latest_values               post: ProvidesLatestDeValues(array)
  rate                        post: AverageNotificationPeriod() >= ConfiguredSamplingPeriod()
               3.12.6.1.4 Footprint
               The TELEMETRY_UPDATE command does not have a footprint.
