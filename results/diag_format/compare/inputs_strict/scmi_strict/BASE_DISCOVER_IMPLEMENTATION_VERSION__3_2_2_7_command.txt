3.2.2.7 BASE_DISCOVER_IMPLEMENTATION_VERSION command
               Returns a vendor-specific 32-bit implementation version. The version number format is vendor-specific. Version numbers must strictly increase, so a higher number means a more recent implementation.
               This command is mandatory.
               3.2.2.7.1 Interface
               3.2.2.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt                                  Message ID, value 0x5
        protocol_id         Header       -           UInt                                  Protocol ID, value 0x10
               3.2.2.7.1.2   Output values
        Name                     Register     Bits        Type          Description
        status                   Payload      31:0        int32         Status code; see Section 3.1.4 for status code definitions
        implementation_version   Payload      31:0        uint32        Implementation version; format is vendor specific
               3.2.2.7.2 Failure conditions
               The BASE_DISCOVER_IMPLEMENTATION_VERSION command does not have any failure conditions.
               3.2.2.7.2.1   Failure condition ordering
               The BASE_DISCOVER_IMPLEMENTATION_VERSION command does not have any failure condition orderings.
               3.2.2.7.3 Success conditions
  ID                          Condition
  impl_version                post: implementation_version == VendorImplementationVersion()
  impl_monotonic              post: forall|v: UInt32| IsEarlierImplementationVersion(v) ==> v < implementation_version
               3.2.2.7.4 Footprint
               The BASE_DISCOVER_IMPLEMENTATION_VERSION command does not modify any state.
