3.6.2.2 NEGOTIATE_PROTOCOL_VERSION command
               The agent uses this command to negotiate which protocol version it will use if it does not support the version returned by the PROTOCOL_VERSION command.
               The agent can attempt any number of negotiations. All commands, responses and notifications must comply with the protocol version that was last negotiated successfully. If the agent uses a protocol version other than the one returned by PROTOCOL_VERSION without a successful negotiation, the platform handles it on a best-effort basis and functionality is not guaranteed.
               This command is optional. It is strongly recommended for platforms that intend to support agents compliant with older versions of this protocol.
               3.6.2.2.1 Interface
               3.6.2.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt                                  Message ID, value 0x10
        protocol_id         Header       -           UInt                                  Protocol ID, value 0x14
        version             Payload      31:0        UInt32                                The negotiated protocol version the agent intends to use
               3.6.2.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload      31:0        Int32                                 Command return status
               3.6.2.2.2 Failure conditions
  ID                          Condition
  version_supported           pre: !PlatformSupportsProtocolVersion(version)
                              post: ResultEqual(status, NOT_SUPPORTED)
               3.6.2.2.2.1   Failure condition ordering
               The NEGOTIATE_PROTOCOL_VERSION command does not have any failure condition orderings.
               3.6.2.2.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  negotiated_version          post: NegotiatedProtocolVersion(agent) == version
  compliance                  post: AllSubsequentMessagesComplyWithVersion(agent, version)
               3.6.2.2.4 Footprint
    ID                        Value
    negotiated_version        NegotiatedProtocolVersion(agent)
