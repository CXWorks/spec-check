3.8.2.5 RESET_DOMAIN_ATTRIBUTES command
               Returns attributes of the reset domain specified in the command.
               This command is mandatory.
               3.8.2.5.1 Interface
               3.8.2.5.1.1   Input values
        Name                Register        Bits        Type                  Description
        message_id          Header          -           UInt32                Message ID, value 0x3
        protocol_id         Header          -           UInt32                Protocol ID, value 0x16
        domain_id           Payload[0]      31:0        UInt32                Identifier for the reset domain
               3.8.2.5.1.2   Output values
        Name                Register        Bits        Type                  Description
        status              Payload[0]      31:0        Int32                 Command return status
        attributes          Payload[1]      31:0        UInt32                Reset domain attributes. Bit[31]: asynchronous reset support. Bit[30]: reset notifications support. Bit[29]: extended reset domain name. Bits[28:0]: reserved, must be zero
        latency             Payload[2]      31:0        UInt32                Maximum time in microseconds required for the reset to take effect on the domain. 0xFFFFFFFF if the platform does not support this field
        name                Payload[3..6]   127:0       UInt8[16]             Null-terminated ASCII string of up to 16 bytes describing the reset domain name
               3.8.2.5.2 Failure conditions
  ID                          Condition
  domain_exists               pre: !IsValidResetDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.8.2.5.2.1   Failure condition ordering
               The RESET_DOMAIN_ATTRIBUTES command does not have any failure condition orderings.
               3.8.2.5.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(status, SUCCESS)
  attr_async                  post: (Bits(attributes, 31, 31) == 1) == ResetDomainSupportsAsyncReset(domain_id)
  attr_notify                 post: (Bits(attributes, 30, 30) == 1) == ResetDomainSupportsResetNotifications(domain_id)
  attr_ext_name               post: (Bits(attributes, 29, 29) == 1) ==> ResetDomainNameLength(domain_id) > 16
  attr_reserved               post: Bits(attributes, 28, 0) == 0
  latency_supported           post: ResetLatencySupported(domain_id) ==> latency == MaxResetLatencyUs(domain_id)
  latency_unsupported         post: !ResetLatencySupported(domain_id) ==> latency == 0xFFFFFFFF
  name_format                 post: IsNullTerminatedAsciiString(name, 16)
  name_value                  post: (Bits(attributes, 29, 29) == 0) ==> name == ResetDomainName(domain_id)
  name_ext_value              post: (Bits(attributes, 29, 29) == 1) ==> name == NullTerminatedPrefix(ResetDomainName(domain_id), 15)
               3.8.2.5.4 Footprint
               The RESET_DOMAIN_ATTRIBUTES command does not modify any state.
