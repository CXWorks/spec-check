3.2.3.1 BASE_ERROR_EVENT command
               Notifies registered agents of a fatal or non-fatal platform error. This notification is optional.
               3.2.3.1.1 Interface
               3.2.3.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                Message ID, value 0x0
        protocol_id         Header       -           UInt32                                Protocol ID, value 0x10
        agent_id            Payload[0]   31:0        UInt32                                Identifier of the agent that caused this notification
        error_status        Payload[1]   31          UInt32                                Fatal. Set if the error is fatal and the platform cannot continue. Cleared if the error is non-fatal but commands have failed
                                         30:10                                             Reserved, must be zero
                                         9:0                                               Command count: number of commands in the command list. Zero is possible if the error cannot be attributed
        command_list        Payload[2..] -           {UInt32 message_header, UInt32 status}[N]   Each entry is the message header of a command and the error status code associated with that command. The command count sub-field gives the number of entries
               3.2.3.1.1.2   Output values
               The BASE_ERROR_EVENT command does not have any output values.
               3.2.3.1.2 Failure conditions
               The BASE_ERROR_EVENT command does not have any failure conditions.
               3.2.3.1.2.1   Failure condition ordering
               The BASE_ERROR_EVENT command does not have any failure condition orderings.
               3.2.3.1.3 Success conditions
  ID                          Condition
  notif_recipient             post: NotificationSentTo(agent) ==> (IsRegisteredForBaseErrorNotifications(agent) && PlatformImplementsBaseErrorNotifications())
  notif_boot_default          post: IsInitialBoot(agent) ==> !BaseErrorNotificationsEnabled(agent)
  status_fatal                post: Bits(error_status, 31, 31) == 1 ==> !PlatformCanProcessCommands()
  status_non_fatal            post: Bits(error_status, 31, 31) == 0 ==> (PlatformIsOperational() && SomeCommandsFailed())
  status_reserved             post: Bits(error_status, 30, 10) == 0
  status_count                post: Bits(error_status, 9, 0) == N
  list_entries                post: forall|i: UInt32| i < Bits(error_status, 9, 0) ==> IsFailedCommandEntry(command_list, i)
               3.2.3.1.4 Footprint
               The BASE_ERROR_EVENT command does not have a footprint.
