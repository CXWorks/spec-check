3.10.5.1 POWERCAP_CAP_CHANGED command
               Notifies a subscribing agent that the power cap or the power capping averaging interval (CAI) of a power capping domain has changed. The platform sends this notification only to agents that have registered for power cap or CAI change notifications for the domain identified by domain_id. The change can come from another agent or entity in the system, including the platform itself. The platform sends the notification after the power cap or CAI transition has completed. The notification carries the latest power cap and CAI settings for the domain, whichever of the two changed. This command is optional if no domain supports power cap and CAI change notifications.
               3.10.5.1.1 Interface
               3.10.5.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          header       -           UInt                                  Message identifier, value 0x0
        protocol_id         header       -           UInt                                  Protocol identifier, value 0x18
        agent_id            -            31:0        UInt32                                Identifier of the agent that caused the power cap and CAI change
        domain_id           -            31:0        UInt32                                Identifier for the power capping domain
        power_cap           -            31:0        UInt32                                The power cap set for the domain
        cai                 -            31:0        UInt32                                The power capping averaging interval set for the domain
        cpli                -            31:0        UInt32                                Concurrent power limit identifier for the power capping domain. Must be 0 if the domain does not support CPC
               3.10.5.1.1.2   Output values
               The POWERCAP_CAP_CHANGED notification does not have any output values.
               3.10.5.1.2 Failure conditions
               The POWERCAP_CAP_CHANGED notification does not have any failure conditions.
               3.10.5.1.2.1   Failure condition ordering
               The POWERCAP_CAP_CHANGED notification does not have any failure condition orderings.
               3.10.5.1.3 Success conditions
  ID                          Condition
  subscribed                  pre: AgentRegisteredForCapChangeNotification(recipient, domain_id)
                              post: NotificationSent(recipient, domain_id)
  transition_done             post: PowerCapTransitionCompleted(domain_id)
  agent                       post: agent_id == AgentCausingChange(domain_id)
  power_cap                   post: power_cap == DomainPowerCap(domain_id)
  cai                         post: cai == DomainCai(domain_id)
  cpli                        post: !DomainSupportsCpc(domain_id) ==> cpli == 0
               3.10.5.1.4 Footprint
               The POWERCAP_CAP_CHANGED notification does not modify any state.
