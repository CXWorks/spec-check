3.5.6.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details for one message in this protocol. It can be used to check whether the platform supports performance level or limit change notifications, and whether FastChannels are supported for the message given by message_id.
               This command is mandatory.
               3.5.6.4.1 Interface
               3.5.6.4.1.1   Input values
        Name                   Register     Bits        Type        Description
        header.protocol_id     Header       -           UInt32      Protocol identifier, value 0x13
        header.message_id      Header       -           UInt32      Message identifier, value 0x2
        message_id             Payload      31:0        UInt32      message_id of the message
               3.5.6.4.1.2   Output values
        Name                   Register     Bits        Type        Description
        status                 Payload      31:0        Int32       Command return status
        attributes             Payload      31:0        UInt32      Flags for the message given by message_id
               3.5.6.4.2 Failure conditions
  ID                          Condition
  msg_invalid                 pre: !IsValidMessageId(message_id) || !IsMessageImplemented(message_id)
                              post: ResultEqual(status, NOT_FOUND)
  notify_unavail              pre: (message_id == PERFORMANCE_NOTIFY_LEVEL || message_id == PERFORMANCE_NOTIFY_LIMITS) && (!IsNotificationImplemented(message_id) || !IsNotificationAvailableToAgent(message_id, calling_agent))
                              post: ResultEqual(status, NOT_FOUND)
               3.5.6.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.5.6.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attr_reserved               post: Bits(attributes, 31, 1) == 0
  attr_fc_set                 post: HasDedicatedFastChannel(message_id) ==> Bits(attributes, 0, 0) == 1
  attr_fc_clear               post: !HasDedicatedFastChannel(message_id) ==> Bits(attributes, 0, 0) == 0
               3.5.6.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not modify any state.
