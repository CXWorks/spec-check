3.11.2.3 PROTOCOL_ATTRIBUTES command
               Returns the implementation details associated with this protocol.
               This command is mandatory.
               3.11.2.3.1 Interface
               3.11.2.3.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt                                  Message ID, value 0x1
        protocol_id         Header       -           UInt                                  Protocol ID, value 0x19
               3.11.2.3.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Return[0]    31:0        int32                                 Command return status (see Section 3.1.4 for status code definitions)
        attributes_low      Return[1]    31:0        uint32                                Bits[31:16]: Number of pin groups. Bits[15:0]: Number of pins
        attributes_high     Return[2]    31:0        uint32                                Bits[31:16]: Reserved, must be zero. Bits[15:0]: Number of functions
               3.11.2.3.2 Failure conditions
               The PROTOCOL_ATTRIBUTES command does not have any failure conditions.
               3.11.2.3.2.1   Failure condition ordering
               The PROTOCOL_ATTRIBUTES command does not have any failure condition orderings.
               3.11.2.3.3 Success conditions
  ID                          Condition
  num_groups                  post: Bits(attributes_low, 31, 16) == NumPinGroups()
  num_pins                    post: Bits(attributes_low, 15, 0) == NumPins()
  high_reserved               post: Bits(attributes_high, 31, 16) == 0
  num_functions               post: Bits(attributes_high, 15, 0) == NumFunctions()
               3.11.2.3.4 Footprint
               The PROTOCOL_ATTRIBUTES command does not modify any state.
