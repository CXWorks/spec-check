3.5.6.14 PERFORMANCE_QOS_CONFIG_SET command
               Sets or resets the QoS configuration for one domain or a group of domains, for a specified QoS capability.
               This command is mandatory if the platform supports QoS capabilities.
               3.5.6.14.1 Interface
               3.5.6.14.1.1   Input values
        Name                Register        Bits        Type                                  Description
        message_id          header          7:0         UInt8                                 Message ID, value 0x20
        protocol_id         header          17:10       UInt8                                 Protocol ID, value 0x13
        domain_id           payload[0]      31:0        UInt32                                Identifier for the performance domain
        capability          payload[1]      31:0        UInt32                                QoS capability descriptor (Table 14). Only one QoS capability Type bit can be set. At most one QoS capability Subtype bit can be set.
        flags               payload[2]      31:0        UInt32                                Bits[31:5]: Reserved, must be zero. Bit[4]: Platform QoS configuration reset. Bit[3]: Sibling domains QoS configuration reset. Bit[2]: Domain QoS configuration reset. Bit[1]: Async flag. Bit[0]: Ignore delayed response.
        qos_value           payload[3]      31:0        UInt32                                Requested QoS value for the specified QoS capability. Ignored if Bit[2], Bit[3] or Bit[4] of flags is set to 1.
               3.5.6.14.1.2   Output values
        Name                Register        Bits        Type                                  Description
        status              payload[0]      31:0        Int32                                 Command return status
               3.5.6.14.2 Failure conditions
  ID                          Condition
  domain_invalid              pre: Bits(flags, 4, 4) == 0 && !IsValidPerfDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  capability_invalid          pre: !IsValidQosCapability(domain_id, capability)
                              post: ResultEqual(status, NOT_FOUND)
  capability_multi_type       pre: PopCount(Bits(capability, 23, 16)) > 1
                              post: ResultEqual(status, INVALID_PARAMETERS)
  capability_multi_subtype    pre: PopCount(Bits(capability, 7, 0)) > 1
                              post: ResultEqual(status, INVALID_PARAMETERS)
  flags_invalid               pre: !IsValidQosConfigFlags(flags)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  value_unsupported           pre: Bits(flags, 4, 2) == 0 && !IsSupportedQosValue(domain_id, capability, qos_value)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  access_denied               pre: !CallerMayConfigureQos(domain_id, capability)
                              post: ResultEqual(status, DENIED)
               3.5.6.14.2.1   Failure condition ordering
               The PERFORMANCE_QOS_CONFIG_SET command does not have any failure condition orderings.
               3.5.6.14.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  qos_set                     post: Bits(flags, 1, 1) == 0 && Bits(flags, 4, 2) == 0 ==> QosValue(domain_id, capability) == qos_value
  qos_domain_reset            post: Bits(flags, 1, 1) == 0 && Bits(flags, 2, 2) == 1 ==> QosValue(domain_id, capability) == PlatformDefaultQos(domain_id, capability)
  qos_sibling_reset           post: Bits(flags, 1, 1) == 0 && Bits(flags, 3, 3) == 1 ==> (forall|d: PerfDomain| (d == domain_id || IsSiblingDomain(d, domain_id)) ==> QosValue(d, capability) == PlatformDefaultQos(d, capability))
  qos_platform_reset          post: Bits(flags, 1, 1) == 0 && Bits(flags, 4, 4) == 1 ==> (forall|d: PerfDomain| QosValue(d, capability) == PlatformDefaultQos(d, capability))
  async_queued                post: Bits(flags, 1, 1) == 1 ==> QosConfigRequestQueued(domain_id, capability, flags, qos_value)
  async_delayed_response      post: Bits(flags, 1, 1) == 1 && Bits(flags, 0, 0) == 0 ==> CompletesWithDelayedResponse(PERFORMANCE_QOS_CONFIG_COMPLETE)
  async_no_delayed_response   post: Bits(flags, 1, 1) == 1 && Bits(flags, 0, 0) == 1 ==> !SendsDelayedResponse(PERFORMANCE_QOS_CONFIG_COMPLETE)
               3.5.6.14.4 Footprint
    ID                        Value
    qos_values                forall|d: PerfDomain| QosValue(d, capability)
