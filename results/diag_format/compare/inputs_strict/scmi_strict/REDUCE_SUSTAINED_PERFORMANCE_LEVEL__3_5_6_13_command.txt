3.5.6.13 REDUCE_SUSTAINED_PERFORMANCE_LEVEL command
               Asks the platform to lower the sustained performance level of a performance domain below the level the platform specifies. This command is optional.
               3.5.6.13.1 Interface
               3.5.6.13.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           UInt                                  Message ID, value 0xF
        protocol_id         Header       —           UInt                                  Protocol ID, value 0x13
        domain_id           Payload[0]   31:0        uint32                                Identifier for the performance domain
        sustained_level     Payload[1]   31:0        uint32                                Requested sustained performance level, or level index
               3.5.6.13.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        int32                                 Command return status
               3.5.6.13.2 Failure conditions
  ID                          Condition
  cmd_supported               pre: !IsCommandSupported(REDUCE_SUSTAINED_PERFORMANCE_LEVEL)
                              post: ResultEqual(status, NOT_SUPPORTED)
  domain_valid                pre: !IsValidPerfDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  agent_permitted             pre: !AgentPermittedToReduceSustainedLevel(agent, domain_id)
                              post: ResultEqual(status, DENIED)
  level_range                 pre: !IsInAllowedSustainedRange(domain_id, LevelOrIndex(domain_id, sustained_level))
                              post: ResultEqual(status, OUT_OF_RANGE)
               3.5.6.13.2.1   Failure condition ordering
               The REDUCE_SUSTAINED_PERFORMANCE_LEVEL command does not have any failure condition orderings.
               3.5.6.13.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  accepted                    post: ReducedSustainedLevelScheduled(domain_id, LevelOrIndex(domain_id, sustained_level))
  attr_unchanged              post: PerfDomainAttributes(domain_id).sustained_perf_level == PlatformSustainedPerfLevel(domain_id)
               3.5.6.13.4 Footprint
    ID                        Value
    accepted                  PerfDomain(domain_id).provisioned_sustained_level
