3.10.3.10 POWERCAP_MAI_SET command
               Sets the power measurement averaging interval (MAI) for a power capping domain. This command is mandatory if any domain supports configuring the MAI.
               3.10.3.10.1 Interface
               3.10.3.10.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       7:0         UInt8                                 Message ID, value 0x7
        protocol_id         Header       17:10       UInt8                                 Protocol ID, value 0x18
        domain_id           Payload[0]   31:0        UInt32                                Identifier for the power capping domain
        flags               Payload[1]   31:0        UInt32                                Reserved, must be zero
        mai                 Payload[2]   31:0        UInt32                                Power measurement averaging interval to set for the domain. Must not be zero
               3.10.3.10.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
               3.10.3.10.2 Failure conditions
  ID                          Condition
  domain_exists               pre: !PowercapDomainExists(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  request_supported           pre: !IsMaiSetSupported(domain_id)
                              post: ResultEqual(status, NOT_SUPPORTED)
  mai_supported               pre: !IsSupportedMai(domain_id, mai)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  flags_valid                 pre: !AreValidMaiSetFlags(flags)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  agent_permitted             pre: !AgentMaySetMai(calling_agent, domain_id)
                              post: ResultEqual(status, DENIED)
               3.10.3.10.2.1   Failure condition ordering
               The POWERCAP_MAI_SET command does not have any failure condition orderings.
               3.10.3.10.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  mai_set                     post: PowercapDomainMai(domain_id) == mai
               3.10.3.10.4 Footprint
    ID                        Value
    mai_set                   PowercapDomainMai(domain_id)
