3.3.2.3 PROTOCOL_ATTRIBUTES command
               Returns the implementation details associated with this protocol.
               This command is mandatory.
               3.3.2.3.1 Interface
               3.3.2.3.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       7:0         UInt8                                 Message ID, value 0x1
        protocol_id         Header       17:10       UInt8                                 Protocol ID, value 0x11
               3.3.2.3.1.2   Output values
        Name                      Register     Bits        Type                  Description
        status                    Payload[0]   31:0        Int32                 Command return status (see Section 3.1.4)
        attributes                Payload[1]   31:0        UInt32                Bits[31:16]: reserved, must be zero
                                                                                 Bits[15:0]: number of power domains
        statistics_address_low    Payload[2]   31:0        UInt32                Lower 32 bits of the PA of the statistics shared memory region
        statistics_address_high   Payload[3]   31:0        UInt32                Upper 32 bits of the PA of the statistics shared memory region
        statistics_len            Payload[4]   31:0        UInt32                Length in bytes of the statistics shared memory region
               3.3.2.3.2 Failure conditions
               The PROTOCOL_ATTRIBUTES command does not have any failure conditions.
               3.3.2.3.2.1   Failure condition ordering
               The PROTOCOL_ATTRIBUTES command does not have any failure condition orderings.
               3.3.2.3.3 Success conditions
  ID                          Condition
  attr_reserved               post: Bits(attributes, 31, 16) == 0
  attr_num_domains            post: Bits(attributes, 15, 0) == NumPowerDomains()
  stats_unsupported           post: (statistics_len == 0) == !PlatformSupportsStatisticsRegion()
  stats_len                   post: statistics_len != 0 ==> statistics_len == StatisticsRegionLength()
  stats_addr                  post: statistics_len != 0 ==> statistics_address_high * 4294967296 + statistics_address_low == StatisticsRegionAddress()
  stats_addr_map              post: statistics_len != 0 ==> IsInCallerMemoryMap(statistics_address_high * 4294967296 + statistics_address_low)
               3.3.2.3.4 Footprint
               The PROTOCOL_ATTRIBUTES command does not modify any state.
               Note: Statistics capability has been marked for deprecation and is being replaced by system telemetry.
