3.9.2.3 PROTOCOL_ATTRIBUTES command
               Returns the implementation details associated with this protocol. This command is mandatory.
               3.9.2.3.1 Interface
               3.9.2.3.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          -            -           UInt                                  Message ID, value 0x1
        protocol_id         -            -           UInt                                  Protocol ID, value 0x17
               3.9.2.3.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              -            31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions.
        attributes          -            31:0        UInt32                                Bits[31:16]: Reserved, must be zero. Bits[15:0]: Number of voltage domains.
               3.9.2.3.2 Failure conditions
               The PROTOCOL_ATTRIBUTES command does not have any failure conditions.
               3.9.2.3.2.1   Failure condition ordering
               The PROTOCOL_ATTRIBUTES command does not have any failure condition orderings.
               3.9.2.3.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attr_reserved               post: Bits(attributes, 31, 16) == 0
  attr_num_domains            post: Bits(attributes, 15, 0) == NumVoltageDomains()
               3.9.2.3.4 Footprint
               The PROTOCOL_ATTRIBUTES command does not modify any state.
