3.5.6.1 PROTOCOL_VERSION command
               Returns the version of this protocol.
               3.5.6.1.1 Interface
               3.5.6.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        protocol_id         Header       -           UInt                                  Protocol identifier, value 0x13
        message_id          Header       -           UInt                                  Message identifier, value 0x0
               3.5.6.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions.
        version             Payload[1]   31:0        UInt32                                Protocol version. For this revision of the specification, this must be 0x40001.
               3.5.6.1.2 Failure conditions
               The PROTOCOL_VERSION command does not have any failure conditions.
               3.5.6.1.2.1   Failure condition ordering
               The PROTOCOL_VERSION command does not have any failure condition orderings.
               3.5.6.1.3 Success conditions
  ID                          Condition
  status                      post: StatusIsSuccess(status)
  version                     post: version == 0x40001
               3.5.6.1.4 Footprint
               The PROTOCOL_VERSION command does not modify any state.
