3.5.6.11 PERFORMANCE_LEVEL_SET command
               Sets the performance level of a performance domain. If Level Indexing Mode is used, the level must be given as a level index rather than as a performance level. The command can return before the domain has moved to the requested performance level. The platform only has to acknowledge that it received the command. To find out whether a performance transition has taken place, the agent can register for performance level notifications (see Section 3.5.8.2). This command is mandatory if Bit [23] of the attributes field of the PERFORMANCE_DOMAIN_ATTRIBUTES command is set to 0 for any domain.
               3.5.6.11.1 Interface
               3.5.6.11.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                Message ID, value 0x7
        protocol_id         Header       -           UInt32                                Protocol ID, value 0x13
        domain_id           Payload[0]   31:0        UInt32                                Identifier for the performance domain
        performance_level   Payload[1]   31:0        UInt32                                Requested performance level, or level index. If this field is a performance level and is set to 0, platform policy determines the performance level of this domain
               3.5.6.11.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status (see Section 3.1.4)
               3.5.6.11.2 Failure conditions
  ID                          Condition
  domain_valid                pre: !IsValidPerformanceDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  level_range                 pre: !IsWithinAllowedPerformanceRange(domain_id, performance_level)
                              post: ResultEqual(status, OUT_OF_RANGE)
  agent_permitted             pre: !AgentPermittedToSetPerformanceLevel(calling_agent, domain_id)
                              post: ResultEqual(status, DENIED)
               3.5.6.11.2.1   Failure condition ordering
               The PERFORMANCE_LEVEL_SET command does not have any failure condition orderings.
               3.5.6.11.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  scheduled                   post: PerformanceLevelRequestScheduled(domain_id, performance_level)
  policy_level                post: (!LevelIndexingModeInUse(domain_id) && performance_level == 0) ==> PlatformPolicyDeterminesPerformanceLevel(domain_id)
               3.5.6.11.4 Footprint
    ID                        Value
    scheduled                 PerformanceDomain(domain_id).requested_level
