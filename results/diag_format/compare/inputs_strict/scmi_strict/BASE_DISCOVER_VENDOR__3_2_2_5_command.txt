3.2.2.5 BASE_DISCOVER_VENDOR command
               Returns a vendor identifier ASCII string. This command is mandatory.
               3.2.2.5.1 Interface
               3.2.2.5.1.1   Input values
        Name                Register        Bits        Type                                  Description
        message_id          Message header  -           UInt                                  Message ID, value 0x3
        protocol_id         Message header  -           UInt                                  Protocol ID, value 0x10
               3.2.2.5.1.2   Output values
        Name                Register        Bits        Type                                  Description
        status              Return payload  31:0        Int32                                 Command return status, as defined in Section 3.1.4
        vendor_identifier   Return payload  -           UInt8[16]                             Vendor identifier ASCII string
               3.2.2.5.2 Failure conditions
               The BASE_DISCOVER_VENDOR command does not have any failure conditions.
               3.2.2.5.2.1   Failure condition ordering
               The BASE_DISCOVER_VENDOR command does not have any failure condition orderings.
               3.2.2.5.3 Success conditions
  ID                          Condition
  vendor_id                   post: IsAsciiString(vendor_identifier)
               3.2.2.5.4 Footprint
               The BASE_DISCOVER_VENDOR command does not modify any state.
