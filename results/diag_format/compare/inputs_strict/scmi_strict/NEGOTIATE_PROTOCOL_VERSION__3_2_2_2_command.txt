3.2.2.2 NEGOTIATE_PROTOCOL_VERSION command
               Negotiates the protocol version that the agent intends to use if the agent does not support the version that PROTOCOL_VERSION returns.
               This command is optional. It is strongly recommended for platforms that intend to support agents compliant with older versions of this protocol.
               The agent can attempt any number of negotiations. All commands, responses and notifications must comply with the protocol version that was last negotiated successfully.
               3.2.2.2.1 Interface
               3.2.2.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt                                  Message ID, value 0x10
        protocol_id         Header       -           UInt                                  Protocol ID, value 0x10
        version             Payload      31:0        uint32                                Negotiated protocol version that the agent intends to use
               3.2.2.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload      31:0        int32                                 Command return status
               3.2.2.2.2 Failure conditions
  ID                          Condition
  version_supp                pre: !IsPlatformSupportedProtocolVersion(version)
                              post: ResultEqual(status, NOT_SUPPORTED)
               3.2.2.2.2.1   Failure condition ordering
               The NEGOTIATE_PROTOCOL_VERSION command does not have any failure condition orderings.
               3.2.2.2.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  neg_version                 post: NegotiatedProtocolVersion() == version
               3.2.2.2.4 Footprint
    ID                        Value
    neg_version               NegotiatedProtocolVersion()
