3.3.2.10 POWER_DOMAIN_NAME_GET command
               Returns the extended name associated with a specific power domain.
               This command is mandatory only if extended power domain name is supported. Extended power domain name is supported when Bit[27] of the attributes field of the POWER_DOMAIN_ATTRIBUTES command is set to 1.
               3.3.2.10.1 Interface
               3.3.2.10.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       7:0         UInt8                                 Message ID, value 0x8
        protocol_id         Header       17:10       UInt8                                 Protocol ID, value 0x11
        domain_id           Payload[0]   31:0        UInt32                                Identifier for the power domain
               3.3.2.10.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
        flags               Payload[1]   31:0        UInt32                                Reserved, must be zero
        ext_name            Payload[2]   511:0       UInt8[64]                             Null-terminated ASCII string of up to 64 bytes describing the power domain extended name
               3.3.2.10.2 Failure conditions
  ID                          Condition
  domain_exists               pre: !PowerDomainExists(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.3.2.10.2.1   Failure condition ordering
               The POWER_DOMAIN_NAME_GET command does not have any failure condition orderings.
               3.3.2.10.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  flags                       post: flags == 0
  ext_name                    post: ext_name == PowerDomainExtendedName(domain_id)
  ext_name_fmt                post: IsNullTerminatedAscii(ext_name, 64)
               3.3.2.10.4 Footprint
               The POWER_DOMAIN_NAME_GET command does not modify any state.
