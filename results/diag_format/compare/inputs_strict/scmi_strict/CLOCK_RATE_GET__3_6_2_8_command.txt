3.6.2.8 CLOCK_RATE_GET command
               Gets the current rate of a clock device. If the clock is disabled, the command returns the rate the clock would run at once it is enabled again.
               Note: If the clock rate is set asynchronously, the returned rate might be stale by the time the command completes.
               This command is mandatory.
               3.6.2.8.1 Interface
               3.6.2.8.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                Message identifier, value 0x6
        protocol_id         Header       -           UInt32                                Protocol identifier, value 0x14
        clock_id            Payload[0]   31:0        UInt32                                Identifier for the clock device
               3.6.2.8.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status (see Section 3.1.4)
        rate_low            Payload[1]   31:0        UInt32                                Lower 32 bits of the physical rate in Hertz (rate[0])
        rate_high           Payload[2]   31:0        UInt32                                Upper 32 bits of the physical rate in Hertz (rate[1])
               3.6.2.8.2 Failure conditions
  ID                          Condition
  clock_exists                pre: !ClockExists(clock_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.6.2.8.2.1   Failure condition ordering
               The CLOCK_RATE_GET command does not have any failure condition orderings.
               3.6.2.8.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  rate_enabled                post: !ClockIsDisabled(clock_id) ==> rate_low + rate_high * 4294967296 == ClockCurrentRate(clock_id)
  rate_disabled               post: ClockIsDisabled(clock_id) ==> rate_low + rate_high * 4294967296 == ClockRateOnReenable(clock_id)
               3.6.2.8.4 Footprint
               The CLOCK_RATE_GET command does not modify any state.
