3.10.3.2 NEGOTIATE_PROTOCOL_VERSION command
               Negotiates the protocol version that the agent intends to use, if the agent does not support the version returned by the PROTOCOL_VERSION command.
               3.10.3.2.1 Interface
               3.10.3.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                Message ID, value 0x10
        protocol_id         Header       -           UInt32                                Protocol ID, value 0x18
        version             Payload[0]   31:0        UInt32                                The negotiated protocol version the agent intends to use
               3.10.3.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
               3.10.3.2.2 Failure conditions
  ID                          Condition
  version_supp                pre: !PlatformSupportsProtocolVersion(protocol_id, version)
                              post: ResultEqual(status, NOT_SUPPORTED)
               3.10.3.2.2.1   Failure condition ordering
               The NEGOTIATE_PROTOCOL_VERSION command does not have any failure condition orderings.
               3.10.3.2.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  neg_version                 post: AgentNegotiatedProtocolVersion(protocol_id) == version
               3.10.3.2.4 Footprint
    ID                        Value
    neg_version               AgentNegotiatedProtocolVersion(protocol_id)
