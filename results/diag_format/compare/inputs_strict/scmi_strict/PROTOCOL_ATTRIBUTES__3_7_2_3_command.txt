3.7.2.3 PROTOCOL_ATTRIBUTES command
               Returns the implementation details associated with this protocol. This command is mandatory.
               3.7.2.3.1 Interface
               3.7.2.3.1.1   Input values
        Name                      Register     Bits        Type        Description
        message_id                Header       -           UInt32      Message identifier, value 0x1
        protocol_id               Header       -           UInt32      Protocol identifier, value 0x15
               3.7.2.3.1.2   Output values
        Name                      Register     Bits        Type        Description
        status                    Payload      31:0        Int32       Status code (see Section 3.1.4)
        attributes                Payload      31:0        UInt32      Bits[31:24]: Reserved, must be zero
                                                                       Bits[23:16]: Maximum number of outstanding asynchronous commands supported by the platform
                                                                       Bits[15:0]: Number of sensors present
        sensor_reg_address_low    Payload      31:0        UInt32      Lower 32 bits of the physical address of the sensor shared memory region; invalid if sensor_reg_len is 0
        sensor_reg_address_high   Payload      31:0        UInt32      Upper 32 bits of the physical address of the sensor shared memory region; invalid if sensor_reg_len is 0
        sensor_reg_len            Payload      31:0        UInt32      Length in bytes of the sensor shared memory region; 0 means the platform does not implement the sensor shared memory
               3.7.2.3.2 Failure conditions
               The PROTOCOL_ATTRIBUTES command does not have any failure conditions.
               3.7.2.3.2.1   Failure condition ordering
               The PROTOCOL_ATTRIBUTES command does not have any failure condition orderings.
               3.7.2.3.3 Success conditions
  ID                          Condition
  attr_reserved               post: Bits(attributes, 31, 24) == 0
  attr_max_async              post: Bits(attributes, 23, 16) == PlatformMaxOutstandingAsyncCommands()
  attr_num_sensors            post: Bits(attributes, 15, 0) == NumSensorsPresent()
  shmem_absent                post: (sensor_reg_len == 0) == !PlatformImplementsSensorSharedMemory()
  shmem_len                   post: sensor_reg_len != 0 ==> sensor_reg_len == SensorSharedMemoryLength()
  shmem_addr                  post: sensor_reg_len != 0 ==> (sensor_reg_address_high * 4294967296 + sensor_reg_address_low) == SensorSharedMemoryBase()
  shmem_align                 post: sensor_reg_len != 0 ==> sensor_reg_address_low % 8 == 0
  shmem_map                   post: sensor_reg_len != 0 ==> IsInCallingAgentMemoryMap(sensor_reg_address_high * 4294967296 + sensor_reg_address_low)
               3.7.2.3.4 Footprint
               The PROTOCOL_ATTRIBUTES command does not modify any state.

               Note: Statistics capability has been marked for deprecation and is being replaced by system telemetry. The sensor shared memory region is described in Section 3.7.5.
