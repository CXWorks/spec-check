3.6.4.1 CLOCK_RATE_CHANGED command
               Notifies a subscribed agent that the rate of a clock device has changed.
               message_id: 0x0, protocol_id: 0x14. This command is optional.
               3.6.4.1.1 Interface
               3.6.4.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       7:0         UInt8                                 Message identifier, value 0x0
        protocol_id         Header       17:10       UInt8                                 Protocol identifier, value 0x14
        agent_id            Payload[0]   31:0        UInt32                                Identifier of the agent that caused the clock rate change
        clock_id            Payload[1]   31:0        UInt32                                Identifier of the clock device
        rate                Payload[2:3] 63:0        UInt32[2]                             Rate the clock has transitioned to. rate[0]: lower 32 bits of the physical rate in Hertz. rate[1]: upper 32 bits of the physical rate in Hertz.
               3.6.4.1.1.2   Output values
               The CLOCK_RATE_CHANGED command does not have any output values.
               3.6.4.1.2 Failure conditions
               The CLOCK_RATE_CHANGED command does not have any failure conditions.
               3.6.4.1.2.1   Failure condition ordering
               The CLOCK_RATE_CHANGED command does not have any failure condition orderings.
               3.6.4.1.3 Success conditions
  ID                          Condition
  subscribed                  post: IsRegisteredForClockRateChangeNotification(RecipientAgent(), clock_id)
  other_cause                 post: ClockRateChangedByOtherAgentOrPlatform(agent_id, RecipientAgent())
  transition_done             post: ClockRateTransitionCompleted(clock_id)
  rate_value                  post: ClockRate(clock_id) == RateLow(rate) + RateHigh(rate) * 4294967296
               3.6.4.1.4 Footprint
               The CLOCK_RATE_CHANGED command does not modify any state.
