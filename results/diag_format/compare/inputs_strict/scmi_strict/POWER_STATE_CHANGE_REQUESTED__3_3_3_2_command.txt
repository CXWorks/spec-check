3.3.3.2 POWER_STATE_CHANGE_REQUESTED command
               The platform sends this notification to an agent that registered through POWER_STATE_CHANGE_REQUESTED_NOTIFY. It is sent when the platform receives a request from a different agent to change the power state of a power domain.
               This command is optional. For more details on how POWER_STATE_CHANGE_REQUESTED notifications can be used, see Section 3.3.2.9.
               3.3.3.2.1 Interface
               3.3.3.2.1.1   Input values
        Name                Register             Bits        Type                                  Description
        message_id          Message header       -           UInt32                                Message identifier, value 0x1
        protocol_id         Message header       -           UInt32                                Protocol identifier, value 0x11
        agent_id            Payload word 0       31:0        UInt32                                Identifier of the agent that requested the power transition
        domain_id           Payload word 1       31:0        UInt32                                Identifier of the power domain whose power state change is being requested
        power_state         Payload word 2       31:0        UInt32                                The power state requested
               3.3.3.2.1.2   Output values
               The POWER_STATE_CHANGE_REQUESTED command does not have any output values.
               3.3.3.2.2 Failure conditions
               The POWER_STATE_CHANGE_REQUESTED command does not have any failure conditions.
               3.3.3.2.2.1   Failure condition ordering
               The POWER_STATE_CHANGE_REQUESTED command does not have any failure condition orderings.
               3.3.3.2.3 Success conditions
  ID                          Condition
  notify_reg                  post: IsRegisteredForPowerStateChangeRequested(recipient_agent)
  notify_other                post: agent_id != recipient_agent
  notify_req                  post: PlatformReceivedPowerStateChangeRequest(agent_id, domain_id, power_state)
               3.3.3.2.4 Footprint
               The POWER_STATE_CHANGE_REQUESTED command does not have a footprint.
