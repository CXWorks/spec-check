3.9.2.8 VOLTAGE_CONFIG_GET command
               Requests the configuration of a voltage domain. This command is mandatory.
               3.9.2.8.1 Interface
               3.9.2.8.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt                                  Message identifier, value 0x6
        protocol_id         Header       -           UInt                                  Protocol identifier, value 0x17
        domain_id           Parameter    31:0        uint32                                Identifier for the voltage domain
               3.9.2.8.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Return       31:0        int32                                 Command return status
        config              Return       31:0        uint32                                Bits[31:4]: Reserved, must be zero. Bits[3:0]: Mode, the operating mode of the voltage domain, as described in Table 24
               3.9.2.8.2 Failure conditions
  ID                          Condition
  domain_valid                pre: !IsValidVoltageDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  request_supported           pre: !IsRequestSupported(message_id, protocol_id)
                              post: ResultEqual(status, NOT_SUPPORTED)
  agent_permitted             pre: !AgentMayGetVoltageConfig(calling_agent, domain_id)
                              post: ResultEqual(status, DENIED)
               3.9.2.8.2.1   Failure condition ordering
               The VOLTAGE_CONFIG_GET command does not have any failure condition orderings.
               3.9.2.8.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  config_reserved             post: Bits(config, 31, 4) == 0
  config_mode                 post: Bits(config, 3, 0) == VoltageDomainMode(domain_id)
               3.9.2.8.4 Footprint
               The VOLTAGE_CONFIG_GET command does not modify any state.
