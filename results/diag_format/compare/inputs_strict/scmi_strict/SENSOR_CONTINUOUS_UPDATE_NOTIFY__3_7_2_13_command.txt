3.7.2.13 SENSOR_CONTINUOUS_UPDATE_NOTIFY command
               Requests the platform to send SENSOR_UPDATE notifications to the agent when the sensor has values to report.
               3.7.2.13.1 Interface
               3.7.2.13.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                Message identifier, value 0xB
        protocol_id         Header       -           UInt32                                Protocol identifier, value 0x15
        sensor_id           Payload[0]   31:0        UInt32                                Identifier for the sensor
        notify_enable       Payload[1]   31:1        UInt32                                Reserved, must be zero
                            Payload[1]   0           UInt32                                Notify enable: 0 = do not send SENSOR_UPDATE notifications to the agent, 1 = send SENSOR_UPDATE notifications to the agent
               3.7.2.13.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
               3.7.2.13.2 Failure conditions
  ID                          Condition
  sensor_valid                pre: !IsValidSensor(sensor_id)
                              post: ResultEqual(status, NOT_FOUND)
  sensor_support              pre: !SensorSupportsContinuousUpdateNotify(sensor_id)
                              post: ResultEqual(status, NOT_SUPPORTED)
  notify_param                pre: !IsSupportedNotifyEnable(notify_enable)
                              post: ResultEqual(status, INVALID_PARAMETERS)
               3.7.2.13.2.1   Failure condition ordering
  [sensor_valid] < [sensor_support]
               3.7.2.13.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(status, SUCCESS)
  notify_state                post: SensorUpdateNotifyEnabled(sensor_id, agent) == (Bits(notify_enable, 0, 0) == 1)
               3.7.2.13.4 Footprint
    ID                        Value
    notify_state              SensorUpdateNotifyEnabled(sensor_id, agent)
