5.14 MEM_PROTECT command
               Enables or disables memory protection against cold reboot attacks, and returns the previous protection state. Introduced in PSCI1.1. This function is optional.
               5.14.1 Interface
               5.14.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           63:0        UInt64                                FID of MEM_PROTECT
        enable              X1           63:0        UInt64                                Non-zero value enables memory protection, 0 disables memory protection
               5.14.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 Previous memory protection state (0 = disabled, 1 = enabled), or NOT_SUPPORTED
               5.14.2 Failure conditions
  ID                          Condition
  not_impl                    pre: !MemProtectImplemented()
                              post: ResultEqual(result, NOT_SUPPORTED)
               5.14.2.1   Failure condition ordering
               The MEM_PROTECT command does not have any failure condition orderings.
               5.14.3 Success conditions
  ID                          Condition
  prev_disabled               post: !Old(MemProtectEnabled()) ==> ResultEqual(result, 0)
  prev_enabled                post: Old(MemProtectEnabled()) ==> ResultEqual(result, 1)
  prot_state                  post: MemProtectEnabled() == (enable != 0)
  check_range                 post: MemProtectCheckRangeImplemented()
  overwrite                   post: MemProtectEnabled() ==> AllCallerAccessibleVolatileMemoryOverwrittenOnNextNonWarmResetBoot()
  warm_reset                  post: MemProtectEnabled() ==> CallerMemoryPreservedOnSystemWarmReset()
  boot_disable                post: MemProtectDisabledBeforeOsBootLoaderHandover()
               5.14.4 Footprint
    ID                        Value
    prot_state                MemProtectEnabled()
