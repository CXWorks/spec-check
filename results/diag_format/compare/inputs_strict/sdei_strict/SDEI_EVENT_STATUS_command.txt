5.1.9 SDEI_EVENT_STATUS command
               Retrieve the status of an event.
               5.1.9.1 Interface
               5.1.9.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           31:0        UInt32                                FID, value 0xC4000028
        event               X1           31:0        Int32                                 Event number
               5.1.9.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 On success, the event status (Bits[63:3] must be zero, Bit[2] Running, Bit[1] Enable, Bit[0] Register); on error, the error code
               5.1.9.2 Failure conditions
  ID                          Condition
  not_supported               pre: !SdeiIsSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
  event_invalid               pre: !IsKnownEventNumber(event)
                              post: ResultEqual(result, INVALID_PARAMETERS)
               5.1.9.2.1   Failure condition ordering
               The SDEI_EVENT_STATUS command does not have any failure condition orderings.
               5.1.9.3 Success conditions
  ID                          Condition
  status_mbz                  post: Bits(result, 63, 3) == 0
  status_running              post: (Bits(result, 2, 2) == 1) == EventHandlerIsRunning(event)
  status_enabled              post: (Bits(result, 1, 1) == 1) == EventHandlerIsEnabled(event)
  status_registered           post: (Bits(result, 0, 0) == 1) == EventHandlerIsRegistered(event)
  status_state                post: EventStatusMapsToHandlerState(result, event)
               5.1.9.4 Footprint
               The SDEI_EVENT_STATUS command does not modify any state.
