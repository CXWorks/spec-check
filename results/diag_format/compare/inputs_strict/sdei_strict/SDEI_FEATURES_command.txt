5.1.17 SDEI_FEATURES command
               Lists the SDEI features that the system implements.
               5.1.17.1 Interface
               5.1.17.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           31:0        UInt32                                FID, value 0xC4000030
        feature             X1           31:0        UInt32                                Feature being queried: 0 = BIND_SLOTS, 1 = RELATIVE_MODE. All other values are reserved
               5.1.17.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 On success, the requested feature information. On error, the error code
               5.1.17.2 Failure conditions
  ID                          Condition
  sdei_supported              pre: !SdeiIsSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
  feature_valid               pre: !IsDefinedSdeiFeature(feature)
                              post: ResultEqual(result, INVALID_PARAMETERS)
               5.1.17.2.1   Failure condition ordering
               The SDEI_FEATURES command does not have any failure condition orderings.
               5.1.17.3 Success conditions
  ID                          Condition
  bind_slots_rsvd             post: feature == BIND_SLOTS ==> Bits(result, 63, 32) == 0
  bind_slots_shared           post: feature == BIND_SLOTS ==> Bits(result, 31, 16) == SharedEventSlotCount()
  bind_slots_private          post: feature == BIND_SLOTS ==> Bits(result, 15, 0) == PrivateEventSlotCount()
  relative_mode_supp          post: (feature == RELATIVE_MODE && RelativeModeSupported()) ==> result == 1
  relative_mode_unsupp        post: (feature == RELATIVE_MODE && !RelativeModeSupported()) ==> result == 0
               5.1.17.4 Footprint
               The SDEI_FEATURES command does not modify any state.
