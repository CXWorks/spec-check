5.1.18 SDEI_PRIVATE_RESET command
               Resets private SDEI data of the calling PE.
               5.1.18.1 Interface
               5.1.18.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           31:0        UInt32                                Function ID, value 0xC4000031
               5.1.18.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 Command return status
               5.1.18.2 Failure conditions
  ID                          Condition
  sdei_support                pre: !SdeiIsSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
  handler_running             pre: exists|e: SdeiEvent| IsPrivateEvent(e) && EventOwnerPe(e) == CallingPe() && HandlerRunning(e)
                              post: ResultEqual(result, DENIED)
               5.1.18.2.1   Failure condition ordering
               The SDEI_PRIVATE_RESET command does not have any failure condition orderings.
               5.1.18.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SUCCESS)
  priv_unreg                  post: forall|e: SdeiEvent| (IsPrivateEvent(e) && EventOwnerPe(e) == CallingPe() && !HandlerRunning(e)) ==> EventIsUnregistered(e)
  priv_pending                post: forall|e: SdeiEvent| (IsPrivateEvent(e) && EventOwnerPe(e) == CallingPe() && HandlerRunning(e)) ==> HandlerUnregisterPending(e)
  priv_aux                    post: PrivateEventAuxInfoReset(CallingPe())
  shared_unchanged            post: forall|e: SdeiEvent| IsSharedEvent(e) ==> EventStateUnchanged(e)
               5.1.18.4 Footprint
    ID                        Value
    priv_reg                  PrivateEventRegistrations(CallingPe())
    priv_handler_state        PrivateEventHandlerStates(CallingPe())
    priv_aux                  PrivateEventAuxInfo(CallingPe())
