5.1.3 SDEI_EVENT_ENABLE command
               Enables the specified event.
               5.1.3.1 Interface
               5.1.3.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           31:0        UInt32                                FID, value 0xC4000022
        event               X1           31:0        Int32                                 Event number
               5.1.3.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 Command return status
               5.1.3.2 Failure conditions
  ID                          Condition
  sdei_support                pre: !SdeiIsSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
  event_valid                 pre: !IsKnownEventNumber(event)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  event_registered            pre: !IsEventRegisteredByClient(event, CallingClient())
                              post: ResultEqual(result, DENIED)
  handler_state               pre: EventHandlerState(event, CallingClient()) == HANDLER_UNREGISTER_PENDING
                              post: ResultEqual(result, DENIED)
               5.1.3.2.1   Failure condition ordering
               The SDEI_EVENT_ENABLE command does not have any failure condition orderings.
               5.1.3.3 Success conditions
  ID                          Condition
  result_success              post: ResultEqual(result, SUCCESS)
  private_enable              post: IsPrivateEvent(event) ==> IsEventEnabledForPe(event, CallingPe())
  shared_enable               post: IsSharedEvent(event) ==> IsEventEnabledForClient(event, CallingClient())
  pending_delivery            post: IsEventPending(event) ==> EventDeliveredWhenEnabled(event, CallingClient())
               5.1.3.4 Footprint
    ID                        Value
    handler_state             EventHandlerState(event, CallingClient())
    private_enable            EventEnableState(event, CallingPe())
    shared_enable             EventEnableState(event, CallingClient())
