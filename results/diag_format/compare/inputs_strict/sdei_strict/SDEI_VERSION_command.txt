5.1.1 SDEI_VERSION command
               Returns the version of the SDEI implementation.
               5.1.1.1 Interface
               5.1.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           31:0        UInt32                                Function ID, value 0xC4000020
               5.1.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 SDEI version number on success, or error code on failure
               5.1.1.2 Failure conditions
  ID                          Condition
  sdei_supp                   pre: !SdeiIsSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
               5.1.1.2.1   Failure condition ordering
               The SDEI_VERSION command does not have any failure condition orderings.
               5.1.1.3 Success conditions
  ID                          Condition
  ver_bit63                   post: Bits(result, 63, 63) == 0
  ver_major                   post: Bits(result, 62, 48) == 1
  ver_minor                   post: Bits(result, 47, 32) == 1
  ver_vendor                  post: Bits(result, 31, 0) == VendorDefinedVersion()
  ver_calls                   post: SdeiImplementsAllCalls()
               5.1.1.4 Footprint
               The SDEI_VERSION command does not modify any state.
