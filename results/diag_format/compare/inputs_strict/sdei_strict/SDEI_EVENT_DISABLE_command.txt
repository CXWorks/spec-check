5.1.4 SDEI_EVENT_DISABLE command
               Disables the specified event for the client.
               5.1.4.1 Interface
               5.1.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           31:0        UInt32                                FID, value 0xC4000023
        event               X1           31:0        Int32                                 Event number
               5.1.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 Command return status
               5.1.4.2 Failure conditions
  ID                          Condition
  sdei_support                pre: !SdeiIsSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
  event_valid                 pre: !IsValidEventNumber(event)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  event_registered            pre: !IsEventRegisteredByClient(event, CallingClient())
                              post: ResultEqual(result, DENIED)
  handler_state               pre: EventHandlerState(event) == HANDLER_UNREGISTER_PENDING
                              post: ResultEqual(result, DENIED)
               5.1.4.2.1   Failure condition ordering
               The SDEI_EVENT_DISABLE command does not have any failure condition orderings.
               5.1.4.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SUCCESS)
  event_private               post: IsPrivateEvent(event) ==> !IsEventEnabledForPe(event, CallingPe())
  event_shared                post: IsSharedEvent(event) ==> !IsEventEnabledForClient(event, CallingClient())
  handler_running             post: RunningEventHandlerUnaffected(event)
  pending_retained            post: TriggeredEventsStayPendingUntilEnabled(event)
               5.1.4.4 Footprint
    ID                        Value
    handler_state             EventHandlerState(event)
    event_enable              EventEnableState(event)
