8.7 sbi_remote_hfence_vvma command
               Instructs the remote harts to execute one or more HFENCE.VVMA instructions. The instructions cover the range of guest virtual addresses from start_addr to start_addr + size, for the current VMID (in the hgatp CSR) of the calling hart.
               8.7.1 Interface
               8.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 6
        hart_mask           a0           XLEN-1:0    unsigned long                         Mask of target harts, relative to hart_mask_base
        hart_mask_base      a1           XLEN-1:0    unsigned long                         Base hartid from which hart_mask is applied
        start_addr          a2           XLEN-1:0    unsigned long                         Start of the guest virtual address range
        size                a3           XLEN-1:0    unsigned long                         Size of the guest virtual address range
               8.7.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              a0           XLEN-1:0    sbiret.error                          Command return status
               8.7.2 Failure conditions
  ID                          Condition
  not_supported               pre: !RemoteHfenceVvmaImplemented() || (exists|h: HartId| IsTargetHart(h, hart_mask, hart_mask_base) && !HartSupportsHypervisorExtension(h))
                              post: ResultEqual(result, SBI_ERR_NOT_SUPPORTED)
  invalid_address             pre: !IsValidAddress(start_addr) || !IsValidSize(start_addr, size)
                              post: ResultEqual(result, SBI_ERR_INVALID_ADDRESS)
  invalid_param               pre: exists|h: HartId| IsTargetHart(h, hart_mask, hart_mask_base) && (!HartEnabledByPlatform(h) || !HartAvailableToSupervisor(h))
                              post: ResultEqual(result, SBI_ERR_INVALID_PARAM)
  failed                      pre: RequestFailedForUnspecifiedReason()
                              post: ResultEqual(result, SBI_ERR_FAILED)
               8.7.2.1   Failure condition ordering
               The sbi_remote_hfence_vvma command does not have any failure condition orderings.
               8.7.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SBI_SUCCESS)
  ipi_sent                    post: forall|h: HartId| IsTargetHart(h, hart_mask, hart_mask_base) ==> IpiSent(h)
  hfence_vvma                 post: forall|h: HartId| IsTargetHart(h, hart_mask, hart_mask_base) ==> HfenceVvmaExecuted(h, start_addr, start_addr + size, HgatpVmid(CallingHart()))
               8.7.4 Footprint
    ID                        Value
    hfence_vvma               GuestTlbState(h), for each h where IsTargetHart(h, hart_mask, hart_mask_base)
