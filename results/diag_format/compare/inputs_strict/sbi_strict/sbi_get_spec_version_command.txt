4.1 sbi_get_spec_version command
               Returns the current SBI specification version.
               4.1.1 Interface
               4.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 0
               4.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           XLEN-1:0    Int                                   Command return status (struct sbiret.error)
        value               a1           XLEN-1:0    UInt                                  Encoded SBI specification version (struct sbiret.value)
               4.1.2 Failure conditions
               The sbi_get_spec_version command does not have any failure conditions.
               4.1.2.1   Failure condition ordering
               The sbi_get_spec_version command does not have any failure condition orderings.
               4.1.3 Success conditions
  ID                          Condition
  success                     post: CallSucceeded(error)
  minor                       post: Bits(value, 23, 0) == SbiSpecMinorVersion()
  major                       post: Bits(value, 30, 24) == SbiSpecMajorVersion()
  rsvd_31                     post: Bits(value, 31, 31) == 0
  rsvd_high                   post: XLEN > 32 ==> Bits(value, XLEN - 1, 32) == 0
               4.1.4 Footprint
               The sbi_get_spec_version command does not have any footprint.
