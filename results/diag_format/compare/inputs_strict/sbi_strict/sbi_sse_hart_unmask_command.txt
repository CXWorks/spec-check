17.15 sbi_sse_hart_unmask command
               Starts receiving (unmasks) software events on the calling hart, so that the calling hart is ready to receive software events from the SBI implementation. Software events are masked initially on all harts, so supervisor software must explicitly unmask software events on the relevant harts at boot time.
               17.15.1 Interface
               17.15.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           63:0        UInt64                                FID, value 8
               17.15.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              a0           63:0        SbiErrorCode                          Error code (sbiret.error)
               17.15.2 Failure conditions
  ID                          Condition
  already_started             pre: SseHartUnmasked(CurrentHart())
                              post: ResultEqual(result, SBI_ERR_ALREADY_STARTED)
  failed                      pre: SseUnspecifiedFailure(CurrentHart())
                              post: ResultEqual(result, SBI_ERR_FAILED)
               17.15.2.1   Failure condition ordering
               The sbi_sse_hart_unmask command does not have any failure condition orderings.
               17.15.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SBI_SUCCESS)
  hart_unmasked               post: SseHartUnmasked(CurrentHart())
               17.15.4 Footprint
    ID                        Value
    hart_unmasked             SseHartMaskState(CurrentHart())
