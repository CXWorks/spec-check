8.6 sbi_remote_hfence_vvma_asid command
               Instructs the remote harts to execute one or more HFENCE.VVMA instructions. These cover the guest virtual addresses from start_addr to start_addr + size for the given ASID and the current VMID.
               8.6.1 Interface
               8.6.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    unsigned long                         FID, value 5
        hart_mask           a0           XLEN-1:0    unsigned long                         Mask of the target remote harts
        hart_mask_base      a1           XLEN-1:0    unsigned long                         Base hart ID that hart_mask is relative to
        start_addr          a2           XLEN-1:0    unsigned long                         Start of the guest virtual address range
        size                a3           XLEN-1:0    unsigned long                         Size of the guest virtual address range
        asid                a4           XLEN-1:0    unsigned long                         ASID that the fence applies to
               8.6.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           XLEN-1:0    long                                  sbiret.error: command return status
        value               a1           XLEN-1:0    long                                  sbiret.value
               8.6.2 Failure conditions
               The section does not define any failure conditions for the sbi_remote_hfence_vvma_asid command.
               8.6.2.1   Failure condition ordering
               The sbi_remote_hfence_vvma_asid command does not have any failure condition orderings.
               8.6.3 Success conditions
  ID                          Condition
  hfence_exec                 post: RemoteHartsExecutedHfenceVvma(hart_mask, hart_mask_base, start_addr, start_addr + size, asid, CurrentVmid())
               8.6.4 Footprint
    ID                        Value
    hfence_exec               GuestTlbState(hart_mask, hart_mask_base)
