6.1 sbi_set_timer command
               Programs the clock for the next event after stime_value time. stime_value is in absolute time.
               6.1.1 Interface
               6.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           63:0        UInt64                                FID, value 0
        stime_value         a0           63:0        UInt64                                Absolute time of the next timer event
               6.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           63:0        SbiReturnCode                         Command return status (sbiret.error)
               6.1.2 Failure conditions
               The sbi_set_timer command does not have any failure conditions.
               6.1.2.1   Failure condition ordering
               The sbi_set_timer command does not have any failure condition orderings.
               6.1.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(error, SBI_SUCCESS)
  timer_event                 post: NextTimerEventTime() == stime_value
  timer_pending               post: stime_value > CurrentTime() ==> !TimerInterruptPending()
               6.1.4 Footprint
    ID                        Value
    timer_event               NextTimerEventTime()
    timer_pending             TimerInterruptPending()
