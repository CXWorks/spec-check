8.1 sbi_remote_fence_i command
               Instructs remote harts to execute FENCE.I instruction.
               8.1.1 Interface
               8.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           63:0        UInt64                                FID, value 0
        hart_mask           a0           63:0        UInt64                                Mask of target harts, relative to hart_mask_base
        hart_mask_base      a1           63:0        UInt64                                Base hartid from which hart_mask is applied
               8.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           63:0        SbiErrorCode                          Command return status (sbiret.error)
               8.1.2 Failure conditions
  ID                          Condition
  hart_invalid                pre: exists|h: HartId| IsTargetedHart(hart_mask, hart_mask_base, h) && (!IsHartEnabledByPlatform(h) || !IsHartAvailableToSupervisor(h))
                              post: ResultEqual(error, SBI_ERR_INVALID_PARAM)
  failed                      pre: RequestFailedForUnspecifiedReason(hart_mask, hart_mask_base)
                              post: ResultEqual(error, SBI_ERR_FAILED)
               8.1.2.1   Failure condition ordering
               The sbi_remote_fence_i command does not have any failure condition orderings.
               8.1.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(error, SBI_SUCCESS)
  ipi_sent                    post: forall|h: HartId| IsTargetedHart(hart_mask, hart_mask_base, h) ==> FenceIIpiSent(h)
               8.1.4 Footprint
    ID                        Value
    ipi_sent                  FenceIIpiSent(h)
