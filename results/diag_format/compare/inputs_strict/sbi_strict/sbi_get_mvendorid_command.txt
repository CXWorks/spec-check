4.5 sbi_get_mvendorid command
               Returns a value that is legal for the mvendorid CSR.
               4.5.1 Interface
               4.5.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           63:0        UInt64                                FID, value 4
               4.5.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           63:0        Int64                                 Command return status
        value               a1           63:0        UInt64                                A value that is legal for the mvendorid CSR
               4.5.2 Failure conditions
               The sbi_get_mvendorid command does not have any failure conditions.
               4.5.2.1   Failure condition ordering
               The sbi_get_mvendorid command does not have any failure condition orderings.
               4.5.3 Success conditions
  ID                          Condition
  value_legal                 post: IsLegalMvendoridValue(value)
               4.5.4 Footprint
               The sbi_get_mvendorid command does not have any footprint.
