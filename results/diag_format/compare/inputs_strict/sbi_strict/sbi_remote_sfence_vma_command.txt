8.2 sbi_remote_sfence_vma command
               Instructs the remote harts to execute one or more SFENCE.VMA instructions, covering the range of virtual addresses between start_addr and start_addr + size.
               8.2.1 Interface
               8.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 1
        hart_mask           a0           XLEN-1:0    unsigned long                         Mask of the target harts
        hart_mask_base      a1           XLEN-1:0    unsigned long                         Base hart ID from which hart_mask is applied
        start_addr          a2           XLEN-1:0    unsigned long                         Start of the virtual address range
        size                a3           XLEN-1:0    unsigned long                         Size of the virtual address range
               8.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           XLEN-1:0    SbiErrorCode                          Command return status (sbiret.error)
               8.2.2 Failure conditions
  ID                          Condition
  addr_valid                  pre: !IsValidAddressRange(start_addr, size)
                              post: ResultEqual(error, SBI_ERR_INVALID_ADDRESS)
               8.2.2.1   Failure condition ordering
               The sbi_remote_sfence_vma command does not have any failure condition orderings.
               8.2.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(error, SBI_SUCCESS)
  ipi_sent                    post: forall|h: HartId| IsTargetedHart(hart_mask, hart_mask_base, h) ==> IpiSent(h)
  sfence_vma                  post: forall|h: HartId| IsTargetedHart(hart_mask, hart_mask_base, h) ==> SfenceVmaExecuted(h, start_addr, start_addr + size)
               8.2.4 Footprint
    ID                        Value
    sfence_vma                forall|h: HartId| IsTargetedHart(hart_mask, hart_mask_base, h) ==> AddressTranslationCache(h)
