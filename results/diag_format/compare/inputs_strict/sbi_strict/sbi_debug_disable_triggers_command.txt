19.8 sbi_debug_disable_triggers command
               Disables a set of debug triggers on the calling hart.
               19.8.1 Interface
               19.8.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    unsigned long                         FID, value 7
        trig_idx_base       a0           XLEN-1:0    unsigned long                         Starting trigger index of the set of debug triggers
        trig_idx_mask       a1           XLEN-1:0    unsigned long                         Bitmask of the triggers, relative to trig_idx_base, to disable
               19.8.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              a0           XLEN-1:0    long                                  Command return status (sbiret.error)
               19.8.2 Failure conditions
  ID                          Condition
  trig_invalid                pre: exists|trig_idx: UInt64| TriggerInSet(trig_idx_base, trig_idx_mask, trig_idx) && (!IsMappedToHwTrigger(trig_idx) || trig_idx >= TrigMax())
                              post: ResultEqual(result, SBI_ERR_INVALID_PARAM)
               19.8.2.1   Failure condition ordering
               The sbi_debug_disable_triggers command does not have any failure condition orderings.
               19.8.3 Success conditions
  ID                          Condition
  result_ok                   post: ResultEqual(result, SBI_SUCCESS)
  trig_vs                     post: forall|trig_idx: UInt64| TriggerInSet(trig_idx_base, trig_idx_mask, trig_idx) ==> MappedHwTrigger(trig_idx).vs == 0
  trig_vu                     post: forall|trig_idx: UInt64| TriggerInSet(trig_idx_base, trig_idx_mask, trig_idx) ==> MappedHwTrigger(trig_idx).vu == 0
  trig_s                      post: forall|trig_idx: UInt64| TriggerInSet(trig_idx_base, trig_idx_mask, trig_idx) ==> MappedHwTrigger(trig_idx).s == 0
  trig_u                      post: forall|trig_idx: UInt64| TriggerInSet(trig_idx_base, trig_idx_mask, trig_idx) ==> MappedHwTrigger(trig_idx).u == 0
               19.8.4 Footprint
    ID                        Value
    trig_vs                   MappedHwTrigger(trig_idx).vs, for each trig_idx in the set
    trig_vu                   MappedHwTrigger(trig_idx).vu, for each trig_idx in the set
    trig_s                    MappedHwTrigger(trig_idx).s, for each trig_idx in the set
    trig_u                    MappedHwTrigger(trig_idx).u, for each trig_idx in the set
