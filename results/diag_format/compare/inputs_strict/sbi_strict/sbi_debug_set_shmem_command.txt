19.2 sbi_debug_set_shmem command
               Sets and enables, or disables, the shared memory for debug trigger configuration on the calling hart.
               19.2.1 Interface
               19.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 1
        shmem_phys_lo       a0           XLEN-1:0    unsigned long                         Lower XLEN bits of the shared memory physical base address, or all-ones bitwise to disable
        shmem_phys_hi       a1           XLEN-1:0    unsigned long                         Upper XLEN bits of the shared memory physical base address, or all-ones bitwise to disable
        flags               a2           XLEN-1:0    unsigned long                         Reserved for future use, MUST be zero
               19.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           XLEN-1:0    long                                  Command return status (sbiret.error)
               19.2.2 Failure conditions
  ID                          Condition
  flags_nonzero               pre: flags != 0
                              post: ResultEqual(error, SBI_ERR_INVALID_PARAM)
  shmem_align                 pre: !IsDisableRequest(shmem_phys_lo, shmem_phys_hi) && (shmem_phys_lo % (XLEN / 8)) != 0
                              post: ResultEqual(error, SBI_ERR_INVALID_PARAM)
  shmem_addr                  pre: !IsDisableRequest(shmem_phys_lo, shmem_phys_hi) && !ShmemSatisfiesSection3_2Requirements(PhysAddr(shmem_phys_hi, shmem_phys_lo), TrigMax() * (XLEN / 2))
                              post: ResultEqual(error, SBI_ERR_INVALID_ADDRESS)
  unspecified                 pre: RequestFailedForUnspecifiedReason()
                              post: ResultEqual(error, SBI_ERR_FAILED)
               19.2.2.1   Failure condition ordering
               The sbi_debug_set_shmem command does not have any failure condition orderings.
               19.2.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(error, SBI_SUCCESS)
  shmem_enable                post: !IsDisableRequest(shmem_phys_lo, shmem_phys_hi) ==> DebugShmemEnabled(CallingHart()) && DebugShmemBase(CallingHart()) == PhysAddr(shmem_phys_hi, shmem_phys_lo) && DebugShmemSize(CallingHart()) == TrigMax() * (XLEN / 2)
  shmem_disable               post: IsDisableRequest(shmem_phys_lo, shmem_phys_hi) ==> !DebugShmemEnabled(CallingHart())
               19.2.4 Footprint
    ID                        Value
    shmem_enable              DebugShmemEnabled(CallingHart())
    shmem_base                DebugShmemBase(CallingHart())
    shmem_size                DebugShmemSize(CallingHart())
