14.4 sbi_cppc_write command
               Writes the value in val to the CPPC register selected by cppc_reg_id.
               14.4.1 Interface
               14.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           63:0        UInt64                                FID, value 3
        cppc_reg_id         a0           31:0        UInt32                                Identifier of the target CPPC register
        val                 a1           63:0        UInt64                                Value to write to the CPPC register
               14.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              a0           63:0        SbiError                              Command return status (sbiret.error)
               14.4.2 Failure conditions
  ID                          Condition
  reg_reserved                pre: CppcRegIsReserved(cppc_reg_id)
                              post: ResultEqual(result, SBI_ERR_INVALID_PARAM)
  reg_not_impl                pre: !CppcRegIsImplemented(cppc_reg_id)
                              post: ResultEqual(result, SBI_ERR_NOT_SUPPORTED)
               14.4.2.1   Failure condition ordering
               The sbi_cppc_write command does not have any failure condition orderings.
               14.4.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SBI_SUCCESS)
  reg_value                   post: CppcRegValue(cppc_reg_id) == val
               14.4.4 Footprint
    ID                        Value
    reg_value                 CppcRegValue(cppc_reg_id)
