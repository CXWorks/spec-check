9.1 sbi_hart_start command
               Requests the SBI implementation to start executing the target hart in supervisor-mode, at the address
               9.1.1 Interface
               9.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 -            -           unsigned long                         FID, value 0
        hartid              -            -           unsigned long                         Target hart
        start_addr          -            -           unsigned long                         Address at which the target hart starts executing
        opaque              -            -           unsigned long                         Opaque parameter
               9.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        ret                 -            -           struct sbiret                         Command return value
               9.1.2 Failure conditions
               The sbi_hart_start command does not have any failure conditions.
               9.1.2.1   Failure condition ordering
               The sbi_hart_start command does not have any failure condition orderings.
               9.1.3 Success conditions
  ID                          Condition
  hart_start                  post: HartStartRequestedInSupervisorMode(hartid, start_addr)
               9.1.4 Footprint
    ID                        Value
    hart_start                HartAt(hartid)
