14.1 sbi_cppc_probe command
               Probes whether the CPPC register given by cppc_reg_id is implemented by the platform.
               14.1.1 Interface
               14.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 —            —           UInt                                  FID, value 0
        cppc_reg_id         —            31:0        uint32_t                              Identifier of the CPPC register to probe
               14.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              —            —           sbiret.error                          Error code
        value               —            —           sbiret.value                          Register width if the register is implemented, otherwise 0
               14.1.2 Failure conditions
  ID                          Condition
  reg_reserved                pre: IsReservedCppcRegId(cppc_reg_id)
                              post: ResultEqual(result, SBI_ERR_INVALID_PARAM)
  probe_failed                pre: CppcProbeFailed(cppc_reg_id)
                              post: ResultEqual(result, SBI_ERR_FAILED)
               14.1.2.1   Failure condition ordering
               The sbi_cppc_probe command does not have any failure condition orderings.
               14.1.3 Success conditions
  ID                          Condition
  result_success              post: ResultEqual(result, SBI_SUCCESS)
  reg_implemented             post: IsCppcRegImplemented(cppc_reg_id) ==> value == CppcRegWidth(cppc_reg_id)
  reg_not_implemented         post: !IsCppcRegImplemented(cppc_reg_id) ==> value == 0
               14.1.4 Footprint
               The sbi_cppc_probe command does not modify any state.
