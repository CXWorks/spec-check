18.1 sbi_fwft_set command
               Sets a firmware feature (Firmware Features Set, FID #0).
               18.1.1 Interface
               18.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 0
        feature             a0           31:0        UInt32                                Firmware feature to set
        value               a1           XLEN-1:0    unsigned long                         Requested feature value. Supported values for each feature are given in Table 93
        flags               a2           XLEN-1:0    unsigned long                         Set flags, as described in Table 94. BIT[0]: LOCK. BIT[XLEN-1:1]: reserved for future use and must be zero
               18.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        ret                 a0, a1       XLEN-1:0    struct sbiret                         Command return status
               18.1.2 Failure conditions
               This section does not define any failure conditions or error codes for the sbi_fwft_set command.
               18.1.2.1   Failure condition ordering
               The sbi_fwft_set command does not have any failure condition orderings.
               18.1.3 Success conditions
  ID                          Condition
  feat_value                  post: FeatureValue(feature) == value
  feat_same                   post: FeatureValueAtEntry(feature) == value ==> IsSuccessfulReturn(ret)
  feat_lock                   post: Bits(flags, 0, 0) == 1 ==> FeatureIsLocked(feature)
  feat_lock_local             post: FeatureIsLocked(feature) && FeatureHasLocalScope(feature) ==> FeatureValueImmutableUntilHartReset(feature)
  feat_lock_global            post: FeatureIsLocked(feature) && FeatureHasGlobalScope(feature) ==> FeatureValueImmutableUntilSystemReset(feature)
               18.1.4 Footprint
    ID                        Value
    feat_value                FeatureValue(feature)
    feat_lock                 FeatureIsLocked(feature)
