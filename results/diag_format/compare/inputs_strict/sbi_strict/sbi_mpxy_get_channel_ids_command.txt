20.7 sbi_mpxy_get_channel_ids command
               Gets the channel IDs of the message channels that the supervisor software can access. The IDs are written to the calling hart's shared memory.
               20.7.1 Interface
               20.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 2
        start_index         a0           31:0        UInt32                                Array index of the first channel ID to return in the shared memory
               20.7.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              a0           XLEN-1:0    SbiErrorCode                          sbiret.error: command return status
        uvalue              a1           XLEN-1:0    UInt                                  sbiret.uvalue: always zero
               20.7.2 Failure conditions
  ID                          Condition
  invalid_param               pre: !IsValidChannelIdStartIndex(start_index)
                              post: ResultEqual(result, SBI_ERR_INVALID_PARAM)
  no_shmem                    pre: !MpxyShmemEnabled(CallingHart())
                              post: ResultEqual(result, SBI_ERR_NO_SHMEM)
  denied                      pre: !GetChannelIdsAllowed(CallingHart())
                              post: ResultEqual(result, SBI_ERR_DENIED)
  failed                      pre: UnspecifiedFailure(CallingHart())
                              post: ResultEqual(result, SBI_ERR_FAILED)
               20.7.2.1   Failure condition ordering
               The sbi_mpxy_get_channel_ids command does not have any failure condition orderings.
               20.7.3 Success conditions
  ID                          Condition
  success                     post: ResultEqual(result, SBI_SUCCESS)
  uvalue_zero                 post: uvalue == 0
  returned                    post: ShmemReturned(CallingHart()) == NumChannelIdsWritten(CallingHart())
  remaining                   post: RemainingCountsChannelIdsAfterReturned(CallingHart(), start_index, ShmemRemaining(CallingHart()))
  channel_ids                 post: forall|i: UInt32| i < ShmemReturned(CallingHart()) ==> ShmemChannelId(CallingHart(), i) == AccessibleChannelId(CallingHart(), start_index + i)
               20.7.4 Footprint
    ID                        Value
    shmem_remaining           ShmemRemaining(CallingHart())
    shmem_returned            ShmemReturned(CallingHart())
    shmem_channel_ids         ShmemChannelIdArray(CallingHart())
