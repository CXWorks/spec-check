15.7 sbi_nacl_sync_csr command
               Synchronizes CSRs in the nested acceleration shared memory. This is an optional function. It is available only if the SBI_NACL_FEAT_SYNC_CSR feature is available.
               15.7.1 Interface
               15.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 2
        csr_num             a0           XLEN-1:0    unsigned long                         Set of RISC-V H-extension CSRs to synchronize
               15.7.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           XLEN-1:0    long                                  sbiret.error: command return status (Table 72)
               15.7.2 Failure conditions
               Table 72 lists the error codes that sbiret.error can return. This section does not reproduce the contents of Table 72, so no failure conditions are listed here.
               15.7.2.1   Failure condition ordering
               The sbi_nacl_sync_csr command does not have any failure condition orderings.
               15.7.3 Success conditions
  ID                          Condition
  sync_all                    post: (csr_num == AllOnes()) ==> AllImplementedHCsrsSynchronized()
  sync_one                    post: (((csr_num & 0x300) == 0x200) && (csr_num < 0x1000)) ==> HCsrSynchronized(csr_num)
               15.7.4 Footprint
    ID                        Value
    shmem_csrs                NaclSharedMemoryCsrArea()
    h_csrs                    ImplementedHCsrs()
