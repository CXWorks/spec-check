8.5 sbi_remote_hfence_gvma command
               Instructs the remote harts to execute one or more HFENCE.GVMA instructions. These cover the range of guest physical addresses between start_addr and start_addr + size, for all guests. This function call is only valid for harts that implement the hypervisor extension.
               8.5.1 Interface
               8.5.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           63:0        UInt64                                FID, value 4
        hart_mask           a0           63:0        UInt64                                Mask of target harts, relative to hart_mask_base
        hart_mask_base      a1           63:0        UInt64                                Base hartid from which hart_mask is applied
        start_addr          a2           63:0        Address                               Start of the guest physical address range
        size                a3           63:0        UInt64                                Size of the guest physical address range
               8.5.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              a0           63:0        SbiErrorCode                          Command return status (sbiret.error)
               8.5.2 Failure conditions
  ID                          Condition
  not_supported               pre: !IsFunctionImplemented(fid) || (exists|h: HartId| IsTargetHart(h, hart_mask, hart_mask_base) && !HartSupportsHypervisorExtension(h))
                              post: ResultEqual(result, SBI_ERR_NOT_SUPPORTED)
  invalid_address             pre: !IsValidAddressRange(start_addr, size)
                              post: ResultEqual(result, SBI_ERR_INVALID_ADDRESS)
  invalid_param               pre: exists|h: HartId| IsTargetHart(h, hart_mask, hart_mask_base) && (!IsHartEnabledByPlatform(h) || !IsHartAvailableToSupervisor(h))
                              post: ResultEqual(result, SBI_ERR_INVALID_PARAM)
  failed                      pre: RequestFailedForOtherReason(hart_mask, hart_mask_base, start_addr, size)
                              post: ResultEqual(result, SBI_ERR_FAILED)
               8.5.2.1   Failure condition ordering
               The sbi_remote_hfence_gvma command does not have any failure condition orderings.
               8.5.3 Success conditions
  ID                          Condition
  result_success              post: ResultEqual(result, SBI_SUCCESS)
  ipi_sent                    post: forall|h: HartId| IsTargetHart(h, hart_mask, hart_mask_base) ==> IpiSentToHart(h)
  hfence_gvma                 post: forall|h: HartId| IsTargetHart(h, hart_mask, hart_mask_base) ==> HfenceGvmaExecuted(h, start_addr, start_addr + size)
               8.5.4 Footprint
    ID                        Value
    hfence_gvma               forall|h: HartId| IsTargetHart(h, hart_mask, hart_mask_base) ==> GuestPhysicalTranslationState(h, start_addr, start_addr + size)
