17.16 sbi_sse_hart_mask command
               Masks software events on the calling hart, so that it stops receiving them from the SBI implementation.
               17.16.1 Interface
               17.16.1.1   Input values
        Name                Register     Bits        Type                                  Description
        eid                 a7           XLEN-1:0    UInt                                  SSE extension ID
        fid                 a6           XLEN-1:0    UInt                                  FID, value 9
               17.16.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              a0           XLEN-1:0    SbiErrorCode                          Command return status (struct sbiret.error)
               17.16.2 Failure conditions
  ID                          Condition
  already_stopped             pre: SseEventsMasked(current_hart)
                              post: ResultEqual(result, SBI_ERR_ALREADY_STOPPED)
  failed                      pre: RequestFailedForUnspecifiedReason(current_hart)
                              post: ResultEqual(result, SBI_ERR_FAILED)
               17.16.2.1   Failure condition ordering
               The sbi_sse_hart_mask command does not have any failure condition orderings.
               17.16.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SBI_SUCCESS)
  hart_masked                 post: SseEventsMasked(current_hart)
  hart_not_ready              post: !SseHartReadyToReceiveEvents(current_hart)
               17.16.4 Footprint
    ID                        Value
    hart_masked               SseHartMaskState(current_hart)
