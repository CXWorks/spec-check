19.1 sbi_debug_num_triggers command
               Gets the number of triggers.
               19.1.1 Interface
               19.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           63:0        UInt64                                FID, value 0
        trig_tdata1         a0           63:0        UInt64                                Trigger tdata1 value used to select the triggers to count
               19.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result.error        a0           63:0        Int64                                 Command return status
        result.value        a1           63:0        UInt64                                Number of triggers
               19.1.2 Failure conditions
               The sbi_debug_num_triggers command does not have any failure conditions.
               19.1.2.1   Failure condition ordering
               The sbi_debug_num_triggers command does not have any failure condition orderings.
               19.1.3 Success conditions
  ID                          Condition
  num_trig                    post: result.value == NumTriggers(trig_tdata1)
               19.1.4 Footprint
               The sbi_debug_num_triggers command does not have any footprint.
