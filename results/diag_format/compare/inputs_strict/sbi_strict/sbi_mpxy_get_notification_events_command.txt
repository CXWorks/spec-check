20.12 sbi_mpxy_get_notification_events command
               Gets the message protocol specific notification events on the MPXY channel given by channel_id. Each message protocol specification defines its own events.
               20.12.1 Interface
               20.12.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 7
        channel_id          a0           31:0        uint32_t                              ID of the target MPXY channel
               20.12.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           XLEN-1:0    long                                  sbiret.error, command return status
        value               a1           XLEN-1:0    long                                  sbiret.value
               20.12.2 Failure conditions
               The sbi_mpxy_get_notification_events section does not define any failure conditions.
               20.12.2.1   Failure condition ordering
               The sbi_mpxy_get_notification_events command does not have any failure condition orderings.
               20.12.3 Success conditions
  ID                          Condition
  events_data                 post: ShmemHoldsProtocolNotificationEvents(channel_id)
  state_cap                   post: EventsStateEnabled(channel_id) ==> ChannelCapabilityEventsStateSet(channel_id)
  state_remaining             post: EventsStateEnabled(channel_id) ==> ShmemWord32(channel_id, 0x0) == EventsRemaining(channel_id)
  state_returned              post: EventsStateEnabled(channel_id) ==> ShmemWord32(channel_id, 0x4) == EventsReturned(channel_id)
  state_lost                  post: EventsStateEnabled(channel_id) ==> ShmemWord32(channel_id, 0x8) == EventsLost(channel_id)
  state_reserved              post: EventsStateEnabled(channel_id) ==> IsReservedField(channel_id, 0xC)
  state_data_offset           post: EventsStateEnabled(channel_id) ==> NotificationEventsDataStartsAt(channel_id, 0x10)
               20.12.4 Footprint
    ID                        Value
    events_data               ChannelShmem(channel_id)
    events_state              EventsState(channel_id)
