13.14 FFA_ABORT command
               Invoked by a partition execution context to enter the aborted state when it encounters a fatal error. An invocation of this command does not complete.
               13.14.1 Interface
               13.14.1.1   Input values
        Name                      Register     Bits        Type        Description
        fid                       W0           31:0        UInt32      FID, value 0x84000090 or 0xC4000090
        reserved_1                W1/X1        63:0        UInt64      Reserved (SBZ)
        impdef                    W2/X2        63:0        UInt64      IMPLEMENTATION DEFINED value
        reserved_3_7              W3-W7        31:0        UInt32      Reserved (SBZ)
        reserved_3_17             X3-X17       63:0        UInt64      Reserved (SBZ)
               13.14.1.2   Output values
               The FFA_ABORT command has no output values because an invocation of this command does not complete.
               13.14.1.3   Valid instances and conduits
        Config No.    FF-A instance        Valid conduits
        1             Secure physical      SMC
        2             Secure virtual       SMC, HVC, SVC
               13.14.2 Failure conditions
               The FFA_ABORT command does not have any failure conditions.
               13.14.2.1   Failure condition ordering
               The FFA_ABORT command does not have any failure condition orderings.
               13.14.3 Success conditions
  ID                          Condition
  ec_aborted                  post: ExecutionContextIsAborted(CallerExecutionContext())
  no_complete                 post: !InvocationCompletes(fid)
               13.14.4 Footprint
    ID                        Value
    ec_aborted                CallerExecutionContext().state
