14.5 FFA_NORMAL_WORLD_RESUME command
               Asks the SPMD to resume Normal world execution on the current PE once the exception that preempted the Normal world has been handled. The SPMC in S-EL2 or S-EL1 uses this command. It is valid at the Secure physical FF-A instance, through the SMC conduit.
               14.5.1 Interface
               14.5.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 W0           31:0        UInt32                                Function ID, value 0x8400007C or 0xC400007C
        reserved            W1-W7        31:0        UInt32                                Reserved (SBZ)
        reserved            X1-X17       63:0        UInt64                                Reserved (SBZ)
               14.5.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              W2           31:0        Int32                                 Error code, returned through FFA_ERROR
               14.5.2 Failure conditions
  ID                          Condition
  instance                    pre: !IsSecurePhysicalInstance(ffa_instance)
                              post: ResultEqual(result, NOT_SUPPORTED)
  not_preempted               pre: IsSecurePhysicalInstance(ffa_instance) && !NormalWorldWasPreempted(current_pe)
                              post: ResultEqual(result, DENIED)
               14.5.2.1   Failure condition ordering
               The FFA_NORMAL_WORLD_RESUME command does not have any failure condition orderings.
               14.5.3 Success conditions
  ID                          Condition
  nw_resume                   post: NormalWorldResumed(current_pe)
  pe_state                    post: PeState(current_pe) == SavedNormalWorldPeState(current_pe)
  completion                  post: CompletedByFfaFunctionInvocationViaEret(current_pe)
               14.5.4 Footprint
    ID                        Value
    pe_state                  PeState(current_pe)
