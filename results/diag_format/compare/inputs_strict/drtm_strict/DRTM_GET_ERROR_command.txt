3.7 DRTM_GET_ERROR command
               Returns an error code from the previous DRTM dynamic launch.
               3.7.1 Interface
               3.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 W0           31:0        UInt32                                Function ID, value 0xC4000116
               3.7.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 Command return status
        error_code          X1           63:0        Int64                                 Error code from the previous launch, valid only if result == SUCCESS. See the error encoding in section 3.12
               3.7.2 Failure conditions
  ID                          Condition
  drtm_support                pre: !IsDrtmSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
  err_not_found               pre: !IsRecordedLaunchErrorCodeFound()
                              post: ResultEqual(result, NOT_FOUND)
               3.7.2.1   Failure condition ordering
               The DRTM_GET_ERROR command does not have any failure condition orderings.
               3.7.3 Success conditions
  ID                          Condition
  result_ok                   post: ResultEqual(result, SUCCESS)
  err_value                   post: error_code == RecordedLaunchErrorCode()
  err_preserved               post: RecordedLaunchErrorCodeUnchanged()
               3.7.4 Footprint
               The DRTM_GET_ERROR command does not modify any state.
