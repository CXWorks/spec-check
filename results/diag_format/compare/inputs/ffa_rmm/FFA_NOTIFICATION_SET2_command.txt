16.9 FFA_NOTIFICATION_SET2 command
               Requests the partition manager to signal the notifications in the Notification bitmap to the Receiver endpoint. This command is used by an FF-A component that supports Extended notifications.
               An endpoint can invoke it at a virtual FF-A instance with the SMC, HVC or SVC conduits. The Hypervisor can invoke it at the Non-secure physical FF-A instance with the SMC conduit. In that case the SPMC signals VM notifications to the SP given in the Receiver endpoint ID, on behalf of the VM given in the Sender endpoint ID.
               Valid FF-A instances and conduits:
        Config No.          FF-A instance                Valid conduits
        1                   Non-secure virtual           SMC, HVC
        2                   Secure virtual               SMC, HVC, SVC
        3                   Non-secure physical          SMC
        4                   Secure physical              ERET
               16.9.1 Interface
               16.9.1.1   Input values
        Name                Register     Bits        Type          Description
        fid                 w0           31:0        UInt32        Function ID, value 0xC4000096
        sender_id           w1           31:16       UInt16        Sender endpoint ID
        receiver_id         w1           15:0        UInt16        Receiver endpoint ID
        per_vcpu            x2           0           Bits1         Per-vCPU notification flag. b'1: all notifications in the bitmap are per-vCPU notifications, each signaled to the vCPU given in receiver_vcpu_id. b'0: all notifications in the bitmap are global notifications.
        delay_sri           x2           1           Bits1         Delay Schedule Receiver interrupt flag
        reserved            x2           15:2        Bits14        Reserved, MBZ
        receiver_vcpu_id    x2           63:16       UInt48        Receiver vCPU ID when per_vcpu is b'1. MBZ when per_vcpu is b'0.
        bitmap              x3-x8        b:0         Bits384       Notification bitmap with one or more set bits. Bit i set: signal notification i to the Receiver. Bit i clear: do not signal it. Bit i = Bit[i % 64] of x((i / 64) + 3). b = number of supported notifications - 1, with 63 <= b <= 383. Bits for unimplemented notification IDs MBZ.
        reserved            x9-x17       63:0        Bits64        Reserved, SBZ
               16.9.1.2   Output values
        Name                Register        Bits        Type          Description
        result              Not specified   -           FF-A function Returned function: FFA_SUCCESS (with no further parameters) or FFA_ERROR
        error_code          w2              31:0        Int32         Error code when result is FFA_ERROR
               16.9.2 Failure conditions
  ID                          Condition
  not_supported               pre: !IsImplementedAtInstance(FFA_NOTIFICATION_SET2, ffa_instance)
                              post: ResultEqual(result, NOT_SUPPORTED)
  part_id                     pre: !IsRecognizedPartitionId(sender_id) || !IsRecognizedPartitionId(receiver_id)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  flags_valid                 pre: !IsValidFlags(flags)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  global_vcpu_id              pre: per_vcpu == '0' && receiver_vcpu_id != 0
                              post: ResultEqual(result, INVALID_PARAMETERS)
  global_has_per_vcpu         pre: per_vcpu == '0' && BitmapContainsPerVcpuNotification(receiver_id, bitmap)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  per_vcpu_has_global         pre: per_vcpu == '1' && BitmapContainsGlobalNotification(receiver_id, bitmap)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  per_vcpu_unsupported        pre: per_vcpu == '1' && !PerVcpuNotificationsSupported()
                              post: ResultEqual(result, INVALID_PARAMETERS)
  bitmap_range                pre: BitmapExceedsSupportedNotifications(bitmap)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  bitmap_empty                pre: IsEmptyBitmap(bitmap)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  sender_perm                 pre: !SenderPermittedToSignalAll(sender_id, receiver_id, bitmap)
                              post: ResultEqual(result, DENIED)
  receiver_support            pre: !SupportsNotificationReceipt(receiver_id)
                              post: ResultEqual(result, DENIED)
  receiver_aborted            pre: HasAborted(receiver_id)
                              post: ResultEqual(result, ABORTED)
               16.9.2.1   Failure condition ordering
               The FFA_NOTIFICATION_SET2 command does not have any failure condition orderings.
               16.9.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, FFA_SUCCESS)
  global_signaled             post: per_vcpu == '0' ⇒ for each i where bitmap[i] == '1', NotificationSignaled(receiver_id, i)
  per_vcpu_signaled           post: per_vcpu == '1' ⇒ for each i where bitmap[i] == '1', NotificationSignaled(receiver_id, receiver_vcpu_id, i)
