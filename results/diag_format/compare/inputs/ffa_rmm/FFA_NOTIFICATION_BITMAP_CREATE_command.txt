16.1 FFA_NOTIFICATION_BITMAP_CREATE command
               Requests the SPMC to create the SP and SPM framework notifications bitmap for the VM specified in the VM ID input parameter. The Hypervisor invokes it at the Non-secure physical FF-A instance through the SMC conduit. The valid instance and conduit pairs are Non-secure physical with SMC, and Secure physical with ERET. See also 10.3 Notification bitmap setup.
               16.1.1 Interface
               16.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 W0           31:0        UInt32                                Function ID, value 0x8400007D
        vm_id               W1           15:0        UInt32                                ID of VM for which a bitmap must be created in the Secure world to enable SPs to send notifications to this VM
                            W1           31:16       UInt32                                Reserved (MBZ)
        vcpu_count          W2           31:0        UInt32                                Number of vCPUs implemented by the VM
        notification_count  W3           8:0         UInt32                                Number of SP notifications i requested for the VM, where total notification count = i + 64
                            W3           32:9        UInt32                                Reserved (SBZ)
        -                   W4-W7        31:0        -                                     Reserved (SBZ)
               16.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              -            -           -                                     Returned function: FFA_SUCCESS or FFA_ERROR
        notification_count  W2           8:0         UInt32                                FFA_SUCCESS: number of SP notifications i allocated for the VM, where total notification count = i + 64
                            W2           32:9        UInt32                                FFA_SUCCESS: Reserved (SBZ)
        error_code          W2           31:0        Int32                                 FFA_ERROR: error code
               16.1.2 Failure conditions
  ID                          Condition
  vm_id                       pre: !IsRecognizedVmId(vm_id)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  not_impl                    pre: !IsImplementedAtInstance(FFA_NOTIFICATION_BITMAP_CREATE, instance)
                              post: ResultEqual(result, NOT_SUPPORTED)
  bitmap_exists               pre: NotificationBitmapExists(vm_id)
                              post: ResultEqual(result, DENIED)
  no_memory                   pre: !CanAllocateNotificationBitmap(vm_id)
                              post: ResultEqual(result, NO_MEMORY)
               16.1.2.1   Failure condition ordering
               The FFA_NOTIFICATION_BITMAP_CREATE command does not have any failure condition orderings.
               16.1.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, FFA_SUCCESS)
  bitmap_created              post: NotificationBitmapExists(vm_id)
  notif_count                 post: TotalNotificationCount(NotificationBitmap(vm_id)) == notification_count[8:0] + 64
               16.1.4 Footprint
    ID                        Value
    bitmap                    NotificationBitmap(vm_id)
