12.2 FFA_ERROR command
               Returns an error code in response to a previous invocation of an FF-A function.
               12.2.1 Interface
               12.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 W0           31:0        UInt32                                FID, value 0x84000060 or 0xC4000060. 0xC4000060 is used by callers that only implement SMC64 FIDs, as described in 11.1.2 Parameter Register Preservation.
        target_id           W1           31:16       UInt16                                ID of the target SP/VM. Valid only when the SMC conduit is used at the Non-secure virtual FF-A instance. MBZ otherwise.
        target_vcpu         W1           15:0        UInt16                                ID of the vCPU of the target SP/VM to deliver the error to. Valid only when the SMC conduit is used at the Non-secure virtual FF-A instance. MBZ otherwise.
        error_code          W2           31:0        Int32                                 FF-A function-specific error code. The definition of each function lists the error codes that apply to it.
        reserved            W3-W7        31:0        -                                     Reserved, SBZ
               12.2.1.2   Output values
               The section does not define any output values for FFA_ERROR.
               12.2.1.3   Error status codes
               All values are 32-bit signed integers.
        Status code         Name
        -1                  NOT_SUPPORTED
        -2                  INVALID_PARAMETERS
        -3                  NO_MEMORY
        -4                  BUSY
        -5                  INTERRUPTED
        -6                  DENIED
        -7                  RETRY
        -8                  ABORTED
        -9                  NO_DATA
        -10                 NOT_READY
               12.2.1.4   Instances and conduits
        Config No.          FF-A instance                              Valid conduits
        1                   Secure and Non-secure physical             SMC, ERET
        2                   Non-secure virtual                         SMC, HVC, ERET
        3                   Secure virtual                             SMC, ERET
               12.2.2 Failure conditions
               The section does not define any failure conditions for FFA_ERROR.
               12.2.2.1   Failure condition ordering
               The FFA_ERROR command does not have any failure condition orderings.
               12.2.3 Success conditions
  ID                          Condition
  err_return                  post: ErrorCodeReturnedToPreviousCaller(error_code)
  err_target                  pre: IsNonSecureVirtualInstance() && ConduitIs(SMC)
                              post: ErrorCodeDeliveredTo(target_id, target_vcpu, error_code)
               12.2.4 Footprint
               The section does not define any state that FFA_ERROR modifies.
