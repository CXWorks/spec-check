3.10.3.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details for a specific message in this protocol.
               This command can be used to check whether power cap and CAI change notifications are supported, by passing the POWERCAP_CAP_NOTIFY message identifier. It can also be used to check whether MAI and power measurements change notifications are supported, by passing the POWERCAP_MEASUREMENTS_NOTIFY message identifier. The notification commands are described in Section 3.10.3.15 and Section 3.10.3.16.
               This command is mandatory.
               3.10.3.4.1 Interface
               3.10.3.4.1.1   Input values
        Name                Register             Bits        Type                                  Description
        protocol_id         Message header       -           UInt                                  Protocol identifier, value 0x18
        message_id (hdr)    Message header       -           UInt                                  Message identifier of this command, value 0x2
        message_id          Parameter 0          31:0        UInt32                                message_id of the message being queried
               3.10.3.4.1.2   Output values
        Name                Register             Bits        Type                                  Description
        status              Return value 0       31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions
        attributes          Return value 1       31:0        UInt32                                Flags associated with the queried message
                                                 31:1                                              Reserved, must be zero
                                                 0                                                 FastChannel Support: 1 if at least one dedicated FastChannel is available for this message; 0 if no FastChannels are available for this message
               3.10.3.4.2 Failure conditions
  ID                          Condition
  msg_impl                    pre: !IsMessageImplemented(message_id)
                              post: ResultEqual(status, NOT_FOUND)
  notify_avail                pre: (message_id == POWERCAP_CAP_NOTIFY || message_id == POWERCAP_MEASUREMENTS_NOTIFY)
                                   && !IsNotificationAvailableToAgent(message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.10.3.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.10.3.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attr_rsvd                   post: attributes[31:1] == 0
  attr_fastch                 post: attributes[0] == (HasDedicatedFastChannel(message_id) ? 1 : 0)
  notify_supp                 post: (message_id == POWERCAP_CAP_NOTIFY || message_id == POWERCAP_MEASUREMENTS_NOTIFY)
                                    ==> IsNotificationSupported(message_id)
               3.10.3.4.4 Footprint
               The section does not list any state that the PROTOCOL_MESSAGE_ATTRIBUTES command modifies.
