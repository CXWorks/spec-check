3.10.3.15 POWERCAP_CAP_NOTIFY command
               Requests notifications from the platform when the power cap or CAI changes for a specific power capping domain. The platform sends these notifications using the POWERCAP_CAP_CHANGED notification, described in Section 3.10.5.1.
               Notification support is optional. PROTOCOL_MESSAGE_ATTRIBUTES must be used to discover whether this command is implemented.
               This command is mandatory if any domain supports power cap or CAI change notifications.
               These notifications must be disabled by default during initial boot of the platform.
               3.10.3.15.1 Interface
               3.10.3.15.1.1   Input values
        Name                Register             Bits        Type        Description
        message_id          Message header       -           -           Message ID, value 0xA
        protocol_id         Message header       -           -           Protocol ID, value 0x18
        domain_id           Parameter word 0     31:0        uint32      Identifier for the power capping domain
        notify_enable       Parameter word 1     31:1        uint32      Reserved, must be zero
                                                 0                       Notify enable:
                                                                         0: the platform does not send any POWERCAP_CAP_CHANGED messages to the calling agent.
                                                                         1: the platform sends POWERCAP_CAP_CHANGED messages to the calling agent when the power cap or CAI for the domain is changed.
               3.10.3.15.1.2   Output values
        Name                Register             Bits        Type        Description
        status              Return word 0        31:0        int32       Command return status. See Section 3.1.4 for status code definitions.
               3.10.3.15.2 Failure conditions
  ID                          Condition
  domain_valid                pre: !IsValidPowercapDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  notify_enable_valid         pre: !IsValidNotifyEnable(notify_enable)
                              post: ResultEqual(status, INVALID_PARAMETERS)
               The status values listed here are not exhaustive.
               3.10.3.15.2.1   Failure condition ordering
               The POWERCAP_CAP_NOTIFY command does not have any failure condition orderings.
               3.10.3.15.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  notify_state                post: PowercapCapNotifyEnabled(domain_id, calling_agent) == notify_enable[0]
               3.10.3.15.4 Footprint
    ID                        Value
    notify_state              PowercapCapNotifyEnabled(domain_id, calling_agent)
