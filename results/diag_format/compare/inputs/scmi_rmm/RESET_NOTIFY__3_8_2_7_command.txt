3.8.2.7 RESET_NOTIFY command
               Asks the platform to send RESET_ISSUED notifications to the calling agent when a reset domain has been reset. If the reset was explicitly signaled, the platform sends the notification when the reset signal has been asserted. Notification support is optional. Use PROTOCOL_MESSAGE_ATTRIBUTES to find out whether this command is implemented. Notifications must be disabled by default during initial boot of the platform.
               3.8.2.7.1 Interface
               3.8.2.7.1.1   Input values
        Name                Register        Bits        Type        Description
        message_id          Header          —           —           Message identifier, value 0x5
        protocol_id         Header          —           —           Protocol identifier, value 0x16
        domain_id           Parameter 0     31:0        uint32      Identifier for the reset domain
        notify_enable       Parameter 1     31:1        uint32      Reserved, must be zero
        notify_enable       Parameter 1     0           uint32      Notify enable. 1: the platform should send RESET_ISSUED notifications to the calling agent when the domain is reset. 0: the platform should not send any RESET_ISSUED notifications to the calling agent
               3.8.2.7.1.2   Output values
        Name                Register        Bits        Type        Description
        status              Return 0        31:0        int32       Command return status
               3.8.2.7.2 Failure conditions
  ID                          Condition
  domain_valid                pre: !IsValidResetDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  notify_enable_valid         pre: !IsValidNotifyEnable(notify_enable)
                              post: ResultEqual(status, INVALID_PARAMETERS)
               3.8.2.7.2.1   Failure condition ordering
               The RESET_NOTIFY command does not have any failure condition orderings.
               3.8.2.7.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  notify_state                post: ResetNotifyEnabled(domain_id, calling_agent) == (notify_enable[0] == 1)
               3.8.2.7.4 Footprint
    ID                        Value
    notify_state              ResetNotifyEnabled(domain_id, calling_agent)
