3.12.4.9 TELEMETRY_DE_ENABLED_LIST command
               Lists the DEs or event groups that have been enabled.
               This command is mandatory.
               3.12.4.9.1 Interface
               3.12.4.9.1.1   Input values
        Name                Register     Bits        Type                                  Description
        protocol_id         Header       -           UInt32                                Protocol ID, value 0x1B
        message_id          Header       -           UInt32                                Message ID, value 0x7
        index               Payload[0]   31:0        UInt32                                Index of the first enabled element to be described in the return array
        flags               Payload[1]   31:1        UInt32                                Reserved, must be zero
        selector            Payload[1]   0           UInt1                                 Whether index refers to a DE or an event group: 0 = DE (including DEs associated with event groups), 1 = event group
               3.12.4.9.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
        num_remaining       Payload[1]   31:16       UInt16                                Number of remaining enabled DE array elements
        num_returned        Payload[1]   15:0        UInt16                                Number of DE array elements returned by this call (N)
        array[N].entry[0]   Payload[2+2i] 31:0       UInt32                                DE or event group ID
        array[N].entry[1]   Payload[3+2i] 31:2       UInt32                                Reserved, must be zero
        array[N].mode       Payload[3+2i] 1:0        UInt2                                 Mode: 1 = enabled without timestamps, 2 = enabled with timestamps, all other values reserved
               3.12.4.9.2 Failure conditions
  ID                          Condition
  index_range                 pre: !IsValidEnabledListIndex(index, selector)
                              post: ResultEqual(status, OUT_OF_RANGE)
               3.12.4.9.2.1   Failure condition ordering
               The TELEMETRY_DE_ENABLED_LIST command does not have any failure condition orderings.
               3.12.4.9.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  array_len                   post: Length(array) == num_returned
  array_kind                  post: (selector == 0 && AllEntriesAreEnabledDes(array)) || (selector == 1 && AllEntriesAreEnabledEventGroups(array))
  array_mode                  post: ForAll(array, e => e.mode == 1 || e.mode == 2)
               3.12.4.9.4 Footprint
               The TELEMETRY_DE_ENABLED_LIST command does not modify any state.
               For an example of using this kind of API, see Section 3.5.6.8.
