3.5.8.1 PERFORMANCE_LIMITS_CHANGED command
               The platform sends this notification to an agent when the performance limits change for the domain identified by domain_id. It is sent only if the agent has registered for limit change notifications for that domain.
               This command is optional.
               3.5.8.1.1 Interface
               3.5.8.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          —            —           UInt                                  Message identifier, value 0x0
        protocol_id         —            —           UInt                                  Protocol identifier, value 0x13
               3.5.8.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        agent_id            —            31:0        UInt32                                Identifier for the agent that caused the performance limit change
        domain_id           —            31:0        UInt32                                Identifier for the performance domain whose limit was changed
        range_max           —            31:0        UInt32                                Maximum allowed performance level, or level index when Level Indexing Mode is used
        range_min           —            31:0        UInt32                                Minimum allowed performance level, or level index when Level Indexing Mode is used
               3.5.8.1.2 Failure conditions
               The PERFORMANCE_LIMITS_CHANGED command does not have any failure conditions.
               3.5.8.1.2.1   Failure condition ordering
               The PERFORMANCE_LIMITS_CHANGED command does not have any failure condition orderings.
               3.5.8.1.3 Success conditions
  ID                          Condition
  notify_sent                 pre: IsRegisteredForLimitChangeNotification(agent, domain_id) && PerformanceLimitsChanged(domain_id)
                              post: NotificationSentToAgent(agent, PERFORMANCE_LIMITS_CHANGED)
  limit_agent                 post: agent_id == IdOfAgentCausingLimitChange(domain_id)
  limit_max                   post: range_max == PerformanceLimitMax(domain_id)
  limit_min                   post: range_min == PerformanceLimitMin(domain_id)
               3.5.8.1.4 Footprint
               The PERFORMANCE_LIMITS_CHANGED command does not have a footprint.
