3.10.3.2 NEGOTIATE_PROTOCOL_VERSION command
               Negotiates the protocol version that the agent intends to use when it does not support the version returned by the PROTOCOL_VERSION command.
               The agent may attempt any number of negotiations. All commands, responses and notifications must comply with the protocol version that was last negotiated successfully. If the agent uses a protocol version other than the one returned by PROTOCOL_VERSION without a successful negotiation, the result is best effort and functionality is not guaranteed.
               This command is optional. It is strongly recommended for platforms that intend to support agents compliant with older versions of this protocol.
               3.10.3.2.1 Interface
               3.10.3.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           UInt                                  Message ID, value 0x10
        protocol_id         Header       —           UInt                                  Protocol ID, value 0x18
        version             Payload[0]   31:0        UInt32                                The negotiated protocol version the agent intends to use
               3.10.3.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status (see Section 3.1.4)
               3.10.3.2.2 Failure conditions
  ID                          Condition
  version_supp                pre: !IsSupportedProtocolVersion(version)
                              post: ResultEqual(status, NOT_SUPPORTED)
               3.10.3.2.2.1   Failure condition ordering
               The NEGOTIATE_PROTOCOL_VERSION command does not have any failure condition orderings.
               3.10.3.2.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  neg_version                 post: NegotiatedProtocolVersion() == version
  compliance                  post: All subsequent commands, responses and notifications comply with NegotiatedProtocolVersion()
