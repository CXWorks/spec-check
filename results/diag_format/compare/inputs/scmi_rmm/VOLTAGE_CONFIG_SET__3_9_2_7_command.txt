3.9.2.7 VOLTAGE_CONFIG_SET command
               Sets the configuration of a voltage domain. Use it to enable or disable the domain.
               This command is mandatory.
               3.9.2.7.1 Interface
               3.9.2.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt                                  Message identifier, value 0x5
        protocol_id         Header       -           UInt                                  Protocol identifier, value 0x17
        domain_id           Param[0]     31:0        UInt32                                Identifier for the voltage domain
        config.reserved     Param[1]     31:4        UInt32                                Reserved, must be zero
        config.mode         Param[1]     3:0         UInt32                                Mode: the operating mode the voltage domain should be set to, as described in Table 24
               3.9.2.7.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Ret[0]       31:0        Int32                                 Command return status. See Section 3.1.4 for more status code definitions
               3.9.2.7.2 Failure conditions
  ID                          Condition
  domain_exists               pre: !VoltageDomainExists(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  config_supported            pre: !VoltageDomainSupportsConfig(domain_id, config)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  request_supported           pre: !IsRequestSupported()
                              post: ResultEqual(status, NOT_SUPPORTED)
  agent_permitted             pre: !AgentMaySetVoltageConfig(caller, domain_id)
                              post: ResultEqual(status, DENIED)
               3.9.2.7.2.1   Failure condition ordering
               The VOLTAGE_CONFIG_SET command does not have any failure condition orderings.
               3.9.2.7.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  domain_config               post: VoltageDomain(domain_id).mode == config.mode
               3.9.2.7.4 Footprint
    ID                        Value
    domain_config             VoltageDomain(domain_id).mode
