3.9.2.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details for a specific message in this protocol.
               This command is mandatory.
               3.9.2.4.1 Interface
               3.9.2.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                message_id of this command, value 0x2
        protocol_id         Header       -           UInt32                                protocol_id of this command, value 0x17
        message_id          Payload[0]   31:0        UInt32                                message_id of the message being queried
               3.9.2.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions
        attributes          Payload[1]   31:0        UInt32                                Flags associated with the queried command in the protocol. Always 0 in the current version of the specification
               3.9.2.4.2 Failure conditions
  ID                          Condition
  msg_invalid                 pre: !IsValidMessageId(message_id) || !IsMessageImplemented(message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.9.2.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.9.2.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  msg_available               post: IsMessageImplemented(message_id) && IsMessageAvailable(message_id)
  attributes                  post: attributes == 0
               3.9.2.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not modify any state.
