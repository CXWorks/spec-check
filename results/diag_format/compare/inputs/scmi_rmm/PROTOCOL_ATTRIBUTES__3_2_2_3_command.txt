3.2.2.3 PROTOCOL_ATTRIBUTES command
               Returns the implementation details associated with this protocol.
               This command is mandatory.
               3.2.2.3.1 Interface
               3.2.2.3.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           UInt                                  Message ID, value 0x1
        protocol_id         Header       —           UInt                                  Protocol ID, value 0x10
               3.2.2.3.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Return       31:0        int32                                 Command return status. See Section 3.1.4 for status code definitions.
        attributes          Return       31:0        uint32                                Protocol attributes:
                                                                                           Bits[31:16]: Reserved, must be zero.
                                                                                           Bits[15:8]: Number of agents in the system.
                                                                                           Bits[7:0]: Number of protocols implemented, excluding the Base protocol.
               3.2.2.3.2 Failure conditions
               The PROTOCOL_ATTRIBUTES command does not have any failure conditions.
               3.2.2.3.2.1   Failure condition ordering
               The PROTOCOL_ATTRIBUTES command does not have any failure condition orderings.
               3.2.2.3.3 Success conditions
  ID                          Condition
  attr_reserved               post: attributes[31:16] == 0
  attr_num_agents             post: attributes[15:8] == NumAgentsInSystem()
  attr_num_protocols          post: attributes[7:0] == NumImplementedProtocolsExcludingBase()
  attr_no_discovery           pre: !PlatformSupportsAgentDiscovery()
                              post: attributes[15:8] == 0
               If the platform does not support agent discovery, all notifications carry a zero in the agent_id field.
               3.2.2.3.4 Footprint
               The section does not describe any state that the PROTOCOL_ATTRIBUTES command modifies.
