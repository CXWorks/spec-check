3.12.4.12 TELEMETRY_RESET command
               Resets the entire telemetry infrastructure, including all configuration and accumulated DE data.
               This command is mandatory if Bit[17] of the attributes_1 field in the PROTOCOL_ATTRIBUTES command is set to 1.
               3.12.4.12.1 Interface
               3.12.4.12.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          header       -           -                                     Message ID, value 0xA
        protocol_id         header       -           -                                     Protocol ID, value 0x1B
        flags               payload[0]   31:0        int32                                 Reserved, must be zero
               3.12.4.12.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              payload[0]   31:0        int32                                 Command return status
               3.12.4.12.2 Failure conditions
  ID                          Condition
  flags_reserved              pre: flags != 0
                              post: ResultEqual(status, INVALID_PARAMETERS)
  agent_permission            pre: !IsAgentPermittedTelemetryReset(calling_agent)
                              post: ResultEqual(status, DENIED)
               3.12.4.12.2.1   Failure condition ordering
               The TELEMETRY_RESET command does not have any failure condition orderings.
               3.12.4.12.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  telemetry_config            post: TelemetryConfigurationIsReset()
  telemetry_de_data           post: TelemetryAccumulatedDeDataIsReset()
               3.12.4.12.4 Footprint
    ID                        Value
    telemetry_config          TelemetryConfiguration()
    telemetry_de_data         TelemetryAccumulatedDeData()
