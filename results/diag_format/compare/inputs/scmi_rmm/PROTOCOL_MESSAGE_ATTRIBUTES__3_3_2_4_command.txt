3.3.2.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details of a specific message in this protocol.
               This command can check whether power state change notifications are supported: pass the POWER_STATE_NOTIFY or POWER_STATE_CHANGE_REQUESTED_NOTIFY message identifier. SUCCESS means the platform supports power state change notifications. NOT_FOUND means notifications are not implemented, or are not available to the calling agent. Section 3.3.2.8 and Section 3.3.3.1 describe the notification commands.
               This command is mandatory.
               3.3.2.4.1 Interface
               3.3.2.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           -                                     Message identifier, value 0x2
        protocol_id         Header       -           -                                     Protocol identifier, value 0x11
        message_id          Payload      31:0        UInt32                                message_id of the message being queried
               3.3.2.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload      31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions
        attributes          Payload      31:0        UInt32                                Flags associated with the specified command in the protocol. Always 0 in the current version of the specification
               3.3.2.4.2 Failure conditions
  ID                          Condition
  msg_valid                   pre: !IsValidMessageId(message_id) || !IsMessageImplemented(message_id)
                              post: ResultEqual(status, NOT_FOUND)
  notify_avail                pre: IsPowerStateNotifyMessage(message_id) && !IsNotificationAvailableToAgent(message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.3.2.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.3.2.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attributes                  post: attributes == 0
               3.3.2.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not modify any state.
