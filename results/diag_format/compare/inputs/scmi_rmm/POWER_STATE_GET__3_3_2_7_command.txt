3.3.2.7 POWER_STATE_GET command
               Requests the current power state of a power domain.
               Note: The power_state value this command returns can be out of date by the time the command completes. Another state change request may have been started and completed in the meantime.
               This command is mandatory.
               3.3.2.7.1 Interface
               3.3.2.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          —            —           UInt                                  Message identifier, value 0x5
        protocol_id         —            —           UInt                                  Protocol identifier, value 0x11
        domain_id           —            31:0        UInt32                                Identifier for the power domain
               3.3.2.7.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              —            31:0        Int32                                 Command return status (see Section 3.1.4 for status code definitions)
        power_state         —            31:0        UInt32                                Platform-specific parameter identifying the power state of this domain. For device power domains, encoded as described in Table 6
               3.3.2.7.2 Failure conditions
  ID                          Condition
  domain_id                   pre: !IsValidPowerDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.3.2.7.2.1   Failure condition ordering
               The POWER_STATE_GET command does not have any failure condition orderings.
               3.3.2.7.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  power_state                 post: power_state == PowerDomainAt(domain_id).power_state
  device_encoding             pre: IsDevicePowerDomain(domain_id)
                              post: power_state is encoded as described in Table 6
               3.3.2.7.4 Footprint
               The POWER_STATE_GET command does not modify any state.
