3.7.2.2 NEGOTIATE_PROTOCOL_VERSION command
               Negotiates the protocol version that the agent intends to use, if the agent does not support the version returned by the PROTOCOL_VERSION command.
               3.7.2.2.1 Interface
               3.7.2.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           UInt32                                Message ID, value 0x10
        protocol_id         Header       —           UInt32                                Protocol ID, value 0x15
        version             Payload      31:0        UInt32                                Protocol version the agent intends to use
               3.7.2.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload      31:0        Int32                                 Command return status
               3.7.2.2.2 Failure conditions
  ID                          Condition
  version_supp                pre: !PlatformSupportsProtocolVersion(version)
                              post: ResultEqual(status, NOT_SUPPORTED)
               3.7.2.2.2.1   Failure condition ordering
               The NEGOTIATE_PROTOCOL_VERSION command does not have any failure condition orderings.
               3.7.2.2.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(status, SUCCESS)
  neg_version                 post: NegotiatedProtocolVersion == version
               3.7.2.2.4 Footprint
    ID                        Value
    neg_version               NegotiatedProtocolVersion
