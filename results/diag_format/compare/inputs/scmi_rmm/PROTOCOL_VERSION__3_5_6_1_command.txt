3.5.6.1 PROTOCOL_VERSION command
               Returns the version of this protocol. This command is mandatory.
               3.5.6.1.1 Interface
               3.5.6.1.1.1   Input values
        Name                Register          Bits        Type                                  Description
        message_id          Message header    —           —                                     Message ID, value 0x0
        protocol_id         Message header    —           —                                     Protocol ID, value 0x13
               3.5.6.1.1.2   Output values
        Name                Register          Bits        Type                                  Description
        status              —                 —           int32                                 Command return status. See Section 3.1.4 for status code definitions.
        version             —                 —           uint32                                Protocol version. For this revision of the specification, this must be 0x40001.
               3.5.6.1.2 Failure conditions
               The PROTOCOL_VERSION command does not have any failure conditions defined in this section.
               3.5.6.1.2.1   Failure condition ordering
               The PROTOCOL_VERSION command does not have any failure condition orderings.
               3.5.6.1.3 Success conditions
  ID                          Condition
  status                      post: StatusIndicatesSuccess(status)
  version                     post: version == 0x40001
               3.5.6.1.4 Footprint
               The PROTOCOL_VERSION command does not modify any state.
