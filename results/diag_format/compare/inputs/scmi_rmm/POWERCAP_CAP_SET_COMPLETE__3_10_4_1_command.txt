3.10.4.1 POWERCAP_CAP_SET_COMPLETE command
               This is a delayed response from the platform to the agent. The platform sends it when a power cap request that the agent made asynchronously through POWERCAP_CAP_SET has completed.
               This command is optional if no domain supports setting the power cap asynchronously.
               3.10.4.1.1 Interface
               3.10.4.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          header       —           UInt32                                Message identifier, value 0x5
        protocol_id         header       —           UInt32                                Protocol identifier, value 0x18
               3.10.4.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              payload[0]   31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions
        domain_id           payload[1]   31:0        UInt32                                Identifier for the power capping domain
        power_cap           payload[2]   31:0        UInt32                                The power cap set for the domain
        cpli                payload[3]   31:0        UInt32                                Concurrent power limit identifier. Must be 0 if the domain does not support CPC
               3.10.4.1.2 Failure conditions
               The section does not specify any failure conditions. The status codes it lists are "not limited to" SUCCESS. Implementations can also return other vendor-specific errors.
               3.10.4.1.2.1   Failure condition ordering
               The POWERCAP_CAP_SET_COMPLETE command does not have any failure condition orderings.
               3.10.4.1.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  cap_set                     post: PowerCapDomain(domain_id).power_cap == power_cap
  cpli_no_cpc                 pre: !DomainSupportsCpc(domain_id)
                              post: cpli == 0
               3.10.4.1.4 Footprint
    ID                        Value
    cap_set                   PowerCapDomain(domain_id).power_cap
