3.5.6.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details for one message in this protocol. Use it to check whether the platform supports performance level change notifications (PERFORMANCE_NOTIFY_LEVEL, Section 3.5.6.16) or performance limit change notifications (PERFORMANCE_NOTIFY_LIMITS, Section 3.5.6.17). It also reports whether FastChannels are supported for the message given by message_id.
               message_id: 0x2
               protocol_id: 0x13
               This command is mandatory.
               3.5.6.4.1 Interface
               3.5.6.4.1.1   Input values
        Name                Register            Bits        Type          Description
        message_id          Parameter word 0    31:0        UInt32        message_id of the message
               3.5.6.4.1.2   Output values
        Name                Register            Bits        Type          Description
        status              Return word 0       31:0        Int32         Command return status (see Section 3.1.4)
        attributes          Return word 1       31:0        UInt32        Flags associated with the specified message
                                                31:1                      Reserved, must be zero
                                                0                         FastChannel Support
               3.5.6.4.2 Failure conditions
  ID                          Condition
  msg_invalid                 pre: !IsValidMessage(message_id) || !IsImplementedMessage(message_id)
                              post: ResultEqual(status, NOT_FOUND)
  notify_unavailable          pre: IsPerformanceNotifyMessage(message_id) &&
                                   (!NotificationsImplemented(message_id) ||
                                    !NotificationsAvailableToAgent(message_id, calling_agent))
                              post: ResultEqual(status, NOT_FOUND)
               3.5.6.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.5.6.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attr_reserved               post: attributes[31:1] == 0
  attr_fastchannel            post: attributes[0] == (HasDedicatedFastChannel(message_id) ? 1 : 0)
               3.5.6.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have a footprint.
