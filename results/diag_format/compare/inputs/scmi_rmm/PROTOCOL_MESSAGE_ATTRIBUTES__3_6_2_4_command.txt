3.6.2.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details of a specific message in this protocol. You can use it to check whether clock rate change notifications are supported by passing the CLOCK_RATE_NOTIFY or CLOCK_RATE_CHANGE_REQUESTED_NOTIFY message identifier. SUCCESS means the platform supports clock rate change notifications. NOT_FOUND means notifications are not implemented or are not available to the calling agent.
               This command is mandatory.
               3.6.2.4.1 Interface
               3.6.2.4.1.1   Input values
        Name                  Register     Bits        Type                                  Description
        header.message_id     -            -           UInt32                                Message identifier, value 0x2
        header.protocol_id    -            -           UInt32                                Protocol identifier, value 0x14
        message_id            -            31:0        UInt32                                message_id of the message being queried
               3.6.2.4.1.2   Output values
        Name                  Register     Bits        Type                                  Description
        status                -            31:0        Int32                                 Command return status (see Section 3.1.4)
        attributes            -            31:0        UInt32                                Flags associated with the queried command in the protocol
               3.6.2.4.2 Failure conditions
  ID                          Condition
  msg_impl                    pre: !IsMessageImplemented(protocol_id, message_id)
                              post: ResultEqual(status, NOT_FOUND)
  msg_avail                   pre: !IsMessageAvailableToAgent(protocol_id, message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.6.2.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.6.2.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attributes                  post: attributes == 0
               3.6.2.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not modify any state.
