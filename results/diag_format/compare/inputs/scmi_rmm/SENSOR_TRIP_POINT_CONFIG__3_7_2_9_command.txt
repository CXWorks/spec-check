3.7.2.9 SENSOR_TRIP_POINT_CONFIG command
               Selects and configures a trip point on a sensor. On success, the platform generates the SENSOR_TRIP_POINT_EVENT event each time the sensor value crosses the programmed trip point value. This happens only if trip-point notifications are enabled globally with the SENSOR_TRIP_POINT_NOTIFY command. A sensor that reports values along several axes can support trip points only if all its axes report the same sensor units. For such a sensor, the event is generated when any axis crosses the configured threshold.
               This command is mandatory if at least one of the platform's sensors supports trip points.
               3.7.2.9.1 Interface
               3.7.2.9.1.1   Input values
        Name                  Register             Bits        Type                     Description
        message_id            Header               -           UInt                     Message identifier, value 0x5
        protocol_id           Header               -           UInt                     Protocol identifier, value 0x15
        sensor_id             Payload[0]           31:0        UInt32                   Identifier for the sensor
        trip_point_ev_ctrl    Payload[1]           31:12       Reserved                 Reserved
                              Payload[1]           11:4        UInt8                    trip_point_id: Identifier for the selected trip point. Must be equal to or less than the number of trip points that the sensor's descriptor advertises
                              Payload[1]           3:2         Reserved                 Reserved for future use
                              Payload[1]           1:0         UInt2                    Event control for the trip point:
                                                                                        0: disable event generation for this trip point (default)
                                                                                        1: enable event generation when the value is reached or crossed in a positive direction
                                                                                        2: enable event generation when the value is reached or crossed in a negative direction
                                                                                        3: enable event generation when the value is reached or crossed in either direction
        trip_point_val_low    Payload[2]           31:0        UInt32                   Lower 32 bits of the sensor value for this trip point. Default value is 0
        trip_point_val_high   Payload[3]           31:0        UInt32                   Higher 32 bits of the sensor value for this trip point. Default value is 0
               3.7.2.9.1.2   Output values
        Name                  Register             Bits        Type                     Description
        status                Payload[0]           31:0        Int32                    Command return status (see Section 3.1.4)
               3.7.2.9.2 Failure conditions
  ID                          Condition
  sensor_exists               pre: !SensorExists(sensor_id)
                              post: ResultEqual(status, NOT_FOUND)
  trip_id                     pre: trip_point_id > NumTripPoints(sensor_id)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  params                      pre: !AreLegalTripPointParams(sensor_id, trip_point_ev_ctrl, trip_point_val_low, trip_point_val_high)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  trip_supported              pre: !SensorSupportsTripPointEvents(sensor_id)
                              post: ResultEqual(status, NOT_SUPPORTED)
               3.7.2.9.2.1   Failure condition ordering
               [sensor_exists] < [trip_id, params, trip_supported]
               3.7.2.9.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  trip_value                  post: TripPoint(sensor_id, trip_point_id).value == (trip_point_val_high << 32) | trip_point_val_low
  trip_ev_ctrl                post: TripPoint(sensor_id, trip_point_id).ev_ctrl == trip_point_ev_ctrl[1:0]
               3.7.2.9.4 Footprint
    ID                        Value
    trip_value                TripPoint(sensor_id, trip_point_id).value
    trip_ev_ctrl              TripPoint(sensor_id, trip_point_id).ev_ctrl
