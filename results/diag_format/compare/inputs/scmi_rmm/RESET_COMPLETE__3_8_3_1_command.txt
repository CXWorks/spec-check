3.8.3.1 RESET_COMPLETE command
               Delayed response the platform sends to a caller that requested an asynchronous reset of the specified reset domain. This command is optional.
               3.8.3.1.1 Interface
               3.8.3.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           UInt32                                Message identifier, value 0x4
        protocol_id         Header       —           UInt32                                Protocol identifier, value 0x16
               3.8.3.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload      31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions. The implementation can also return vendor-specific errors.
        domain_id           Payload      31:0        UInt32                                Identifier for the reset domain
               3.8.3.1.2 Failure conditions
  ID                          Condition
  domain_users                pre: ResetDomainHasOtherUsers(domain_id)
                              post: ResultEqual(status, GENERIC_ERROR)
  domain_quiesce              pre: !ResetDomainCanBeQuiesced(domain_id)
                              post: ResultEqual(status, GENERIC_ERROR)
               3.8.3.1.2.1   Failure condition ordering
               The RESET_COMPLETE command does not have any failure condition orderings.
               3.8.3.1.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  domain_reset                post: ResetDomainWasReset(domain_id)
               3.8.3.1.4 Footprint
    ID                        Value
    domain_reset              ResetDomainAt(domain_id).state
