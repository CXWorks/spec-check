3.4.2.3 PROTOCOL_ATTRIBUTES command
               Returns the implementation details associated with this protocol.
               This command is mandatory.
               3.4.2.3.1 Interface
               3.4.2.3.1.1   Input values
        Name                Register          Bits        Type                                  Description
        message_id          Message header    —           —                                     Message identifier, value 0x1
        protocol_id         Message header    —           —                                     Protocol identifier, value 0x12
               3.4.2.3.1.2   Output values
        Name                Register          Bits        Type                                  Description
        status              Return value      —           int32                                 Command return status. See Section 3.1.4 for status code definitions.
        attributes          Return value      31:0        uint32                                Reserved, must be zero.
               3.4.2.3.2 Failure conditions
               The PROTOCOL_ATTRIBUTES command does not have any failure conditions.
               3.4.2.3.2.1   Failure condition ordering
               The PROTOCOL_ATTRIBUTES command does not have any failure condition orderings.
               3.4.2.3.3 Success conditions
  ID                          Condition
  attr_rsvd                   post: attributes[31:0] == 0
               3.4.2.3.4 Footprint
               The PROTOCOL_ATTRIBUTES command does not have any footprint.
