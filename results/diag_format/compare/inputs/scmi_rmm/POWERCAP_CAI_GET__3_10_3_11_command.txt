3.10.3.11 POWERCAP_CAI_GET command
               Gets the currently enforced power capping measurement averaging interval (CAI) for a domain.
               The CAI value returned may be stale by the time the command completes, because another CAI change request could have been started and completed in the meantime.
               This command is mandatory if any domain supports reading the CAI.
               3.10.3.11.1 Interface
               3.10.3.11.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt32                                Message identifier, value 0xE
        protocol_id         Header       -           UInt32                                Protocol identifier, value 0x18
        domain_id           Payload[0]   31:0        UInt32                                Identifier for the power capping domain
        cpli                Payload[1]   31:0        UInt32                                Concurrent power limit identifier. Must be set to 0 if the domain does not support CPC
               3.10.3.11.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status (see Section 3.1.4)
        cai                 Payload[1]   31:0        UInt32                                The power capping averaging interval set for the domain and cpli
               3.10.3.11.2 Failure conditions
  ID                          Condition
  domain_valid                pre: !IsValidPowercapDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  cpli_valid                  pre: !IsValidCpli(domain_id, cpli)
                              post: ResultEqual(status, NOT_FOUND)
  supported                   pre: !IsRequestSupported(domain_id, cpli)
                              post: ResultEqual(status, NOT_SUPPORTED)
               3.10.3.11.2.1   Failure condition ordering
               The POWERCAP_CAI_GET command does not have any failure condition orderings.
               3.10.3.11.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  cai_value                   post: cai == EnforcedCai(domain_id, cpli)
               3.10.3.11.4 Footprint
               The POWERCAP_CAI_GET command does not modify any state.
