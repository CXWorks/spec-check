3.4.2.2 NEGOTIATE_PROTOCOL_VERSION command
               Negotiates the protocol version that the agent intends to use, if the agent does not support the version returned by the PROTOCOL_VERSION command.
               3.4.2.2.1 Interface
               3.4.2.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           UInt                                  Message ID, value 0x10
        protocol_id         Header       —           UInt                                  Protocol ID, value 0x12
        version             Payload      31:0        UInt32                                The negotiated protocol version the agent intends to use
               3.4.2.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload      31:0        Int32                                 Command return status. See Section 3.1.4 for status code definitions
               3.4.2.2.2 Failure conditions
  ID                          Condition
  version_supp                pre: !IsPlatformSupportedProtocolVersion(version)
                              post: ResultEqual(status, NOT_SUPPORTED)
               3.4.2.2.2.1   Failure condition ordering
               The NEGOTIATE_PROTOCOL_VERSION command does not have any failure condition orderings.
               3.4.2.2.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  neg_version                 post: NegotiatedProtocolVersion(agent) == version
               3.4.2.2.4 Footprint
    ID                        Value
    neg_version               NegotiatedProtocolVersion(agent)
