3.9.2.1 PROTOCOL_VERSION command
               Returns the protocol version. For this version of the specification, the version is 0x20001, which corresponds to version 2.1.
               This command is mandatory.
               3.9.2.1.1 Interface
               3.9.2.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        protocol_id         —            —           UInt                                  Protocol identifier, value 0x17
        message_id          —            —           UInt                                  Message identifier, value 0x0
               3.9.2.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              —            —           int32                                 Command return status. See Section 3.1.4 for status code definitions.
        version             —            —           uint32                                Protocol version. For this revision of the specification, this value must be 0x20001.
               3.9.2.1.2 Failure conditions
               The PROTOCOL_VERSION command does not have any failure conditions.
               3.9.2.1.2.1   Failure condition ordering
               The PROTOCOL_VERSION command does not have any failure condition orderings.
               3.9.2.1.3 Success conditions
  ID                          Condition
  status                      post: StatusIsSuccess(status)
  version                     post: version == 0x20001
               3.9.2.1.4 Footprint
               The PROTOCOL_VERSION command does not modify any state.
