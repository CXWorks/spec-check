3.6.2.14 CLOCK_POSSIBLE_PARENTS_GET command
               Gets the possible parents of a clock device. Only one parent can be active for a clock device at any time. If transport size limits prevent returning the full list in one call, the agent can make several calls.
               3.6.2.14.1 Interface
               3.6.2.14.1.1   Input values
        Name                Register        Bits        Type        Description
        message_id          Header          —           UInt32      Message identifier, value 0xC
        protocol_id         Header          —           UInt32      Protocol identifier, value 0x14
        clock_id            Parameter 0     31:0        UInt32      Identifier for the clock device
        skip_parents        Parameter 1     31:0        UInt32      Number of parents to skip before the first possible parent in the returned parent array
               3.6.2.14.1.2   Output values
        Name                Register        Bits        Type        Description
        status              Return 0        31:0        Int32       Command return status
        flags               Return 1        31:24       UInt32      Number of remaining parents
                                            23:8                    Reserved, must be zero
                                            7:0                     Number of parent clock identifiers returned by this call
        possible_parents    Return 2..N+1   31:0 each   UInt32[N]   Array of possible parent clocks in ascending numeric order of their identifiers. N is given by flags[7:0]
               3.6.2.14.2 Failure conditions
  ID                          Condition
  clock_exists                pre: !ClockExists(clock_id)
                              post: ResultEqual(status, NOT_FOUND)
  skip_range                  pre: !IsValidParentSkip(clock_id, skip_parents)
                              post: ResultEqual(status, OUT_OF_RANGE)
  parents_supported           pre: !IsPossibleParentsQuerySupported(clock_id)
                              post: ResultEqual(status, NOT_SUPPORTED)
  agent_permission            pre: !AgentMayGetPossibleParents(calling_agent, clock_id)
                              post: ResultEqual(status, DENIED)
               3.6.2.14.2.1   Failure condition ordering
               The CLOCK_POSSIBLE_PARENTS_GET command does not have any failure condition orderings.
               3.6.2.14.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  num_returned                post: flags[7:0] == N
  num_remaining               post: flags[31:24] == RemainingPossibleParents(clock_id, skip_parents, N)
  reserved                    post: flags[23:8] == 0
  parents_skip                post: possible_parents[0] == PossibleParents(clock_id)[skip_parents]
  parents_order               post: IsAscendingOrder(possible_parents[0..N-1])
               3.6.2.14.4 Footprint
               The section does not say that the CLOCK_POSSIBLE_PARENTS_GET command modifies any state.
