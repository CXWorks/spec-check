3.4.2.7 SYSTEM_POWER_STATE_NOTIFY command
               Requests notification of system power state requests to the calling agent. This command is mandatory in an OSPM view implementation.
               3.4.2.7.1 Interface
               3.4.2.7.1.1   Input values
        Name                Register             Bits        Type                                  Description
        message_id          Message header       -           UInt                                  Message ID, value 0x5
        protocol_id         Message header       -           UInt                                  Protocol ID, value 0x12
        notify_enable       Payload word 0       31:1        UInt32                                Reserved, must be zero
                                                 0                                                 Notify enable: 0 = platform does not send SYSTEM_POWER_STATE_NOTIFIER messages to the calling agent; 1 = platform sends SYSTEM_POWER_STATE_NOTIFIER messages to the calling agent (see Section 3.4.3.1)
               3.4.2.7.1.2   Output values
        Name                Register             Bits        Type                                  Description
        status              Payload word 0       31:0        Int32                                 Command return status (see Section 3.1.4)
               3.4.2.7.2 Failure conditions
  ID                          Condition
  notify_support              pre: !NotificationsSupportedForAgent(caller)
                              post: ResultEqual(status, NOT_SUPPORTED)
  notify_param                pre: !IsValidNotifyEnable(notify_enable)
                              post: ResultEqual(status, INVALID_PARAMETERS)
               3.4.2.7.2.1   Failure condition ordering
               The SYSTEM_POWER_STATE_NOTIFY command does not have any failure condition orderings.
               3.4.2.7.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  notify_state                post: SystemPowerStateNotifyEnabled(caller) == (notify_enable[0] == 1)
               3.4.2.7.4 Footprint
    ID                        Value
    notify_state              SystemPowerStateNotifyEnabled(caller)
