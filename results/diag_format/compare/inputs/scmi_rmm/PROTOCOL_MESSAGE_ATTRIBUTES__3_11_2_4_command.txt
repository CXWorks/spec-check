3.11.2.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details of a specific message in this protocol. It can be used to check whether optional commands are supported: SUCCESS means the platform supports the command; NOT_FOUND means the command is not implemented or not available to the calling agent.
               Message identification: message_id 0x2, protocol_id 0x19.
               This command is mandatory.
               3.11.2.4.1 Interface
               3.11.2.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          -            31:0        UInt32                                message_id of the message being queried
               3.11.2.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              -            31:0        Int32                                 Command return status. See Section 3.1.4 for more status code definitions
        attributes          -            31:0        UInt32                                Flags associated with the queried command in the protocol
               3.11.2.4.2 Failure conditions
  ID                          Condition
  msg_impl                    pre: !IsValidMessageId(message_id) || !IsMessageImplemented(message_id)
                              post: ResultEqual(status, NOT_FOUND)
  msg_avail                   pre: !IsMessageAvailableToAgent(message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.11.2.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.11.2.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attributes                  post: attributes == 0
               3.11.2.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not modify any state.
