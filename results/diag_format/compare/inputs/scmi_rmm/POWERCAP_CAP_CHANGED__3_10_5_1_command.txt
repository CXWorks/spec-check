3.10.5.1 POWERCAP_CAP_CHANGED command
               The platform sends this notification to an agent that has registered for power cap or CAI change notifications on the power capping domain identified by domain_id. It is sent when the power cap or CAI of that domain is changed by a different agent or entity in the system, including the platform itself. For example, the platform might change the power cap on its own to apply thermal or other constraints. The notification is sent after the power cap or CAI transition has completed. When either value changes, the notification carries the latest power cap and the latest CAI for the domain.
               This command is optional if no domain supports power cap and CAI change notifications.
               3.10.5.1.1 Interface
               3.10.5.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           —                                     Message identifier, value 0x0
        protocol_id         Header       —           —                                     Protocol identifier, value 0x18
        agent_id            Payload      31:0        UInt32                                Identifier of the agent that caused the power cap and CAI change
        domain_id           Payload      31:0        UInt32                                Identifier for the power capping domain
        power_cap           Payload      31:0        UInt32                                The power cap set for the domain
        cai                 Payload      31:0        UInt32                                The power capping averaging interval set for the domain
        cpli                Payload      31:0        UInt32                                Concurrent power limit identifier for the power capping domain. Must be set to 0 if the domain does not support CPC
               3.10.5.1.1.2   Output values
               The POWERCAP_CAP_CHANGED command does not have any output values.
               3.10.5.1.2 Failure conditions
               The POWERCAP_CAP_CHANGED command does not have any failure conditions.
               3.10.5.1.2.1   Failure condition ordering
               The POWERCAP_CAP_CHANGED command does not have any failure condition orderings.
               3.10.5.1.3 Success conditions
  ID                          Condition
  subscribed                  pre: IsRegisteredForPowerCapNotification(recipient, domain_id)
                              post: NotificationSent(recipient, POWERCAP_CAP_CHANGED)
  trigger                     pre: PowerCapChanged(domain_id) || CaiChanged(domain_id)
                              post: NotificationSent(recipient, POWERCAP_CAP_CHANGED)
  after_transition            post: TransitionCompleted(domain_id)
  cap_latest                  post: power_cap == DomainPowerCap(domain_id)
  cai_latest                  post: cai == DomainCai(domain_id)
  cpli_no_cpc                 pre: !DomainSupportsCpc(domain_id)
                              post: cpli == 0
               3.10.5.1.4 Footprint
               The POWERCAP_CAP_CHANGED command does not modify any state.
