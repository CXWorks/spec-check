3.11.2.11 PINCTRL_NAME_GET command
               Returns the extended name associated with a pin, group, or function.
               This command is mandatory only if extended name is supported. Extended name is supported when Bit[31] of the attributes field in the PINCTRL_ATTRIBUTES response is set to 1.
               3.11.2.11.1 Interface
               3.11.2.11.1.1   Input values
        Name                Register     Bits        Type                                  Description
        protocol_id         Header       -           UInt32                                Protocol identifier, value 0x19
        message_id          Header       -           UInt32                                Message identifier, value 0x9
        identifier          Payload[0]   15:0        UInt16                                Identifier for the pin, group, or function
        identifier_ignored  Payload[0]   31:16       -                                     Ignored by the platform
        selector            Payload[1]   1:0         UInt2                                 Selects the kind of identifier: 0 = Pin, 1 = Group, 2 = Function. All other values are reserved for future use
        flags_reserved      Payload[1]   31:2        -                                     Reserved, must be zero
               3.11.2.11.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
        flags               Payload[1]   31:0        UInt32                                Reserved, must be zero
        name                Payload[2:17] -          UInt8[64]                             Null-terminated ASCII string of up to 64 bytes giving the extended name of the pin, group, or function
               3.11.2.11.2 Failure conditions
  ID                          Condition
  ident_exists                pre: !PinctrlEntityExists(selector, identifier)
                              post: ResultEqual(status, NOT_FOUND)
               3.11.2.11.2.1   Failure condition ordering
               The PINCTRL_NAME_GET command does not have any failure condition orderings.
               3.11.2.11.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  name                        post: name == PinctrlExtendedName(selector, identifier)
  name_term                   post: IsNullTerminatedAscii(name, 64)
  flags                       post: flags == 0
               3.11.2.11.4 Footprint
               The PINCTRL_NAME_GET command does not modify any state.
