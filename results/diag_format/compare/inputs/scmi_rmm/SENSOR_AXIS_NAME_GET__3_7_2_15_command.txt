3.7.2.15 SENSOR_AXIS_NAME_GET command
               Returns the extended names of a sensor's axes, as an array of axis name descriptors (see Axis Name Descriptor). One call might not return every descriptor, because the array size depends on how many return values the transport can carry. The caller can make further calls, and each response gives the number of descriptors still remaining. Descriptors should be reported in the normative order of axes. For example, a triaxial accelerometer reports x, then y, then z.
               This command is mandatory only if extended sensor axis names are supported. Support is indicated when Bit[9] of the axis_attributes_low field returned by SENSOR_AXIS_DESCRIPTION_GET is set to 1 (see Section 3.7.2.6).
               3.7.2.15.1 Interface
               3.7.2.15.1.1   Input values
        Name                Register      Bits        Type                                  Description
        protocol_id         Header        -           UInt                                  Protocol identifier, value 0x15
        message_id          Header        -           UInt                                  Message identifier, value 0xD
        sensor_id           Payload[0]    31:0        UInt32                                Identifier for the sensor
        axis_id             Payload[1]    31:0        UInt32                                Index of the first sensor axis to be read in the sensor axis name descriptor array
               3.7.2.15.1.2   Output values
        Name                Register      Bits        Type                                  Description
        status              Payload[0]    31:0        Int32                                 Command return status (see Section 3.1.4)
        flags               Payload[1]    31:26       UInt32                                Number of remaining axis name descriptors
                                          25:6                                              Reserved, must be zero
                                          5:0                                               Number of axis name descriptors returned by this call
        desc                Payload[2..]  -           AXIS_NAME_DESC[N]                     Array of axis name descriptors
               3.7.2.15.1.3   AXIS_NAME_DESC structure
        Name                Type          Description
        axis_id             UInt32        Identifier for the axis of the sensor
        name                UInt8[64]     NULL-terminated UTF-8 string of up to 64 bytes describing the axis extended name. It is recommended that the name ends with '_' followed by the sensor axis in uppercase, for example "acc_X" or "_X" for the x-axis of a triaxial accelerometer
               3.7.2.15.2 Failure conditions
  ID                          Condition
  sensor_valid                pre: !IsValidSensor(sensor_id)
                              post: ResultEqual(status, NOT_FOUND)
  axis_valid                  pre: !IsValidSensorAxis(sensor_id, axis_id)
                              post: ResultEqual(status, NOT_FOUND)
  axis_support                pre: !SensorReportsAxisValues(sensor_id)
                              post: ResultEqual(status, NOT_SUPPORTED)
               3.7.2.15.2.1   Failure condition ordering
               The SENSOR_AXIS_NAME_GET command does not have any failure condition orderings.
               3.7.2.15.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  num_returned                post: flags[5:0] == NumDescriptors(desc)
  num_remaining               post: flags[31:26] == NumRemainingAxisNameDescriptors(sensor_id, axis_id, flags[5:0])
  reserved                    post: flags[25:6] == 0
               3.7.2.15.4 Footprint
               The SENSOR_AXIS_NAME_GET command does not modify any state.
