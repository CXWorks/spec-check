3.7.3.1 SENSOR_READING_COMPLETE command
               The delayed response to an asynchronous SENSOR_READING_GET command issued by an agent. This response is mandatory. The platform generates it if the caller used the asynchronous method to read the sensor.
               3.7.3.1.1 Interface
               3.7.3.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          —            —           UInt                                  Message identifier, value 0x6
        protocol_id         —            —           UInt                                  Protocol identifier, value 0x15
               3.7.3.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              —            31:0        int32                                 An appropriate status code, as described in Section 3.1.4
        sensor_id           —            31:0        uint32                                Identifier for the sensor
        readings            —            —           SENSOR_READING[N]                     Array of sensor readings in the format given by the Sensor Reading Descriptor, where N is the number of sensor axes
               3.7.3.1.2 Failure conditions
  ID                          Condition
  sensor_hw_fault             pre: SensorHasHardwareFault(sensor_id)
                              post: ResultEqual(status, HARDWARE_ERROR)
               Section 3.1.4 lists the other errors, which apply to the interface itself.
               3.7.3.1.2.1   Failure condition ordering
               The SENSOR_READING_COMPLETE command does not have any failure condition orderings.
               3.7.3.1.3 Success conditions
  ID                          Condition
  readings_count              post: Length(readings) == NumSensorAxes(sensor_id)
  readings_order              post: ReadingsReportedInAxisOrder(readings, sensor_id)
               3.7.3.1.4 Footprint
               This section does not say which state, if any, the SENSOR_READING_COMPLETE command modifies.
