3.7.2.12 SENSOR_READING_GET command
               Requests the current value of the sensor identified by sensor_id. The command is mandatory.
               3.7.2.12.1 Interface
               3.7.2.12.1.1   Input values
        Name                Register        Bits        Type                                  Description
        protocol_id         Header          31:0        UInt32                                Protocol identifier, value 0x15
        message_id          Header          31:0        UInt32                                Message identifier, value 0x6
        sensor_id           Param[0]        31:0        UInt32                                Identifier of the sensor to be read
        flags.reserved      Param[1]        31:1        Bits31                                Reserved
        flags.async         Param[1]        0           Bool                                  Async flag: 1 to read asynchronously, 0 to read synchronously
               3.7.2.12.1.2   Output values
        Name                Register        Bits        Type                                  Description
        status              Return[0]       31:0        Int32                                 Command return status
        readings[N]         Return[1..4N]   31:0        SENSOR_READING[N]                     Array of sensor readings. N is 1 for sensors that measure scalar values, or the number of sensor axes for sensors that report values along axes, with all axes reported in order
               3.7.2.12.1.3   SENSOR_READING structure
        Name                Word            Bits        Type                                  Description
        sensor_value_low    0               31:0        Int32                                 Lower 32 bits of the sensor value. Invalid if an error status is returned
        sensor_value_high   1               31:0        Int32                                 Higher 32 bits of the sensor value. Invalid if an error status is returned
        timestamp_low       2               31:0        UInt32                                Lower 32 bits of the timestamp when the sample was captured. 0 if no timestamp is collected
        timestamp_high      3               31:0        UInt32                                Higher 32 bits of the timestamp when the sample was captured. 0 if no timestamp is collected
               3.7.2.12.2 Failure conditions
  ID                          Condition
  sensor_exists               pre: !SensorExists(sensor_id)
                              post: ResultEqual(status, NOT_FOUND)
  flags_valid                 pre: !IsValidReadingFlags(flags)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  sensor_enabled              pre: !SensorIsEnabled(sensor_id)
                              post: ResultEqual(status, PROTOCOL_ERROR)
  sensor_hw_fault             pre: flags.async == 0 && SensorHasHardwareFault(sensor_id)
                              post: ResultEqual(status, HARDWARE_ERROR)
               For an asynchronous request, status applies only to the command itself. Any error that occurs during the
               actual sensor read operation is reported later in the SENSOR_READING_COMPLETE delayed response.
               Other status codes that relate to the interface itself are defined in Section 3.1.4.
               3.7.2.12.2.1   Failure condition ordering
  [sensor_exists] < [sensor_enabled]
               3.7.2.12.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  sync_reading                pre: flags.async == 0
                              post: readings == CurrentSensorReadings(sensor_id)
  sync_count                  pre: flags.async == 0
                              post: N == (SensorIsAxial(sensor_id) ? SensorNumAxes(sensor_id) : 1)
  sync_timestamp              pre: flags.async == 0 && !SensorCollectsTimestamp(sensor_id)
                              post: readings[i].timestamp_low == 0 && readings[i].timestamp_high == 0
  async_enqueued              pre: flags.async == 1
                              post: AsyncReadingRequestEnqueued(sensor_id)
               For an asynchronous request, the platform returns the sensor value in the SENSOR_READING_COMPLETE delayed
               response.
               3.7.2.12.4 Footprint
    ID                        Value
    async_enqueued            AsyncReadingRequestQueue(sensor_id)
