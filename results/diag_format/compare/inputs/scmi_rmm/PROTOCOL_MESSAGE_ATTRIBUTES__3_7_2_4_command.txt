3.7.2.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details of a specific message in this protocol. This lets calling agents work out which commands the platform supports and configure themselves to match. The command is mandatory.
               3.7.2.4.1 Interface
               3.7.2.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        protocol_id         Header       -           UInt32                                Protocol identifier, value 0x15
        message_id          Header       -           UInt32                                Message identifier, value 0x2
        message_id          Payload[0]   31:0        UInt32                                message_id of the message being queried
               3.7.2.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
        attributes          Payload[1]   31:0        UInt32                                Attributes of the message specified by message_id
               3.7.2.4.2 Failure conditions
  ID                          Condition
  msg_supported               pre: !IsMessageImplemented(message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.7.2.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.7.2.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attributes                  post: attributes == 0
               3.7.2.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not modify any state.
