3.8.2.2 NEGOTIATE_PROTOCOL_VERSION command
               Negotiates the protocol version that the agent intends to use if the agent does not support the version that the PROTOCOL_VERSION command returns.
               The agent can attempt any number of negotiations. All commands, responses and notifications must comply with the protocol version that was last negotiated successfully. If the agent uses a protocol version other than the one that PROTOCOL_VERSION returns without a successful negotiation, it does so on a best-effort basis and functionality is not guaranteed.
               This command is optional. Platforms that intend to support agents compliant with older versions of this protocol are strongly recommended to implement it.
               3.8.2.2.1 Interface
               3.8.2.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          —            —           UInt32                                Message ID, value 0x10
        protocol_id         —            —           UInt32                                Protocol ID, value 0x16
        version             —            31:0        UInt32                                The negotiated protocol version the agent intends to use
               3.8.2.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              —            31:0        Int32                                 status: command return status. See Section 3.1.4 for status code definitions
               3.8.2.2.2 Failure conditions
  ID                          Condition
  version_supported           pre: !PlatformSupportsProtocolVersion(version)
                              post: ResultEqual(result, NOT_SUPPORTED)
               3.8.2.2.2.1   Failure condition ordering
               The NEGOTIATE_PROTOCOL_VERSION command does not have any failure condition orderings.
               3.8.2.2.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SUCCESS)
  negotiated_version          post: NegotiatedProtocolVersion() == version
