3.8.2.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               On success, returns the implementation details associated with a specific message in this protocol.
               message_id: 0x2, protocol_id: 0x16. This command is mandatory.
               3.8.2.4.1 Interface
               3.8.2.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Payload[0]   31:0        UInt32                                message_id of the message
               3.8.2.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status (see Section 3.1.4 for status code definitions)
        attributes          Payload[1]   31:0        UInt32                                Reserved, must be zero
               3.8.2.4.2 Failure conditions
  ID                          Condition
  msg_not_found               pre: !IsMessageImplemented(message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.8.2.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.8.2.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attributes                  post: attributes == 0
               3.8.2.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have a footprint.
