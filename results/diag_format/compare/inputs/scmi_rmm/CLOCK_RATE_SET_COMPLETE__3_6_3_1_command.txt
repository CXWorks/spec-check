3.6.3.1 CLOCK_RATE_SET_COMPLETE command
               If the agent changed the clock rate asynchronously through CLOCK_RATE_SET, the platform sends this delayed response to the agent when the clock rate changes.
               This command is optional.
               3.6.3.1.1 Interface
               3.6.3.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           UInt                                  Message identifier, value 0x5
        protocol_id         Header       —           UInt                                  Protocol identifier, value 0x14
               3.6.3.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
        clock_id            Payload[1]   31:0        UInt32                                Identifier for the clock device
        rate[0]             Payload[2]   31:0        UInt32                                Lower 32 bits of the physical rate, in Hertz, that the clock transitioned to
        rate[1]             Payload[3]   31:0        UInt32                                Upper 32 bits of the physical rate, in Hertz, that the clock transitioned to
               3.6.3.1.2 Failure conditions
  ID                          Condition
  clock_denied                pre: ClockHasOtherUsers(clock_id)
                              post: ResultEqual(status, DENIED)
               Other vendor-specific errors can also be generated depending on the implementation. See Section 3.1.4 for more status code definitions.
               3.6.3.1.2.1   Failure condition ordering
               The CLOCK_RATE_SET_COMPLETE command does not have any failure condition orderings.
               3.6.3.1.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  clock_rate                  post: ClockAt(clock_id).rate == (rate[1] << 32) | rate[0]
               3.6.3.1.4 Footprint
    ID                        Value
    clock_rate                ClockAt(clock_id).rate
