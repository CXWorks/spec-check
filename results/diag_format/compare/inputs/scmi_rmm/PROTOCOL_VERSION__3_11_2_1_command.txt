3.11.2.1 PROTOCOL_VERSION command
               Returns the protocol version. This command is mandatory.
               3.11.2.1.1 Interface
               3.11.2.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          —            —           —                                     Message ID, value 0x0
        protocol_id         —            —           —                                     Protocol ID, value 0x19
               3.11.2.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              —            —           int32                                 Command return status. See Section 3.1.4 for status code definitions.
        version             —            —           uint32                                Protocol version. For this revision of the specification, this value must be 0x10000.
               3.11.2.1.2 Failure conditions
               The PROTOCOL_VERSION command does not have any failure conditions.
               3.11.2.1.2.1   Failure condition ordering
               The PROTOCOL_VERSION command does not have any failure condition orderings.
               3.11.2.1.3 Success conditions
  ID                          Condition
  status                      post: StatusIsSuccess(status)
  version                     post: version == 0x10000
               3.11.2.1.4 Footprint
               The PROTOCOL_VERSION command does not have any footprint.
