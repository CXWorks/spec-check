3.3.2.3 PROTOCOL_ATTRIBUTES command
               Returns the implementation details associated with the Power domain management protocol. This command is mandatory.
               3.3.2.3.1 Interface
               3.3.2.3.1.1   Input values
        Name                        Register            Bits        Type        Description
        message_id                  Message header      —           UInt        Message identifier, value 0x1
        protocol_id                 Message header      —           UInt        Protocol identifier, value 0x11
               3.3.2.3.1.2   Output values
        Name                        Register            Bits        Type        Description
        status                      Return payload      31:0        Int32       Command return status. See Section 3.1.4 for status code definitions.
        attributes                  Return payload      31:16       UInt32      Reserved, must be zero
                                                        15:0                    Number of power domains
        statistics_address_low      Return payload      31:0        UInt32      Lower 32 bits of the PA of the statistics shared memory region (described in Section 3.3.4). Should be 64-bit aligned. Must be in the memory map of the calling agent. Invalid and must be ignored if statistics_len is 0.
        statistics_address_high     Return payload      31:0        UInt32      Upper 32 bits of the PA of the statistics shared memory region (described in Section 3.3.4). Must be in the memory map of the calling agent. Invalid and must be ignored if statistics_len is 0.
        statistics_len              Return payload      31:0        UInt32      Length in bytes of the statistics shared memory region. 0 indicates that the platform does not support the statistics shared memory region.
               3.3.2.3.2 Failure conditions
               The PROTOCOL_ATTRIBUTES command does not have any failure conditions.
               3.3.2.3.2.1   Failure condition ordering
               The PROTOCOL_ATTRIBUTES command does not have any failure condition orderings.
               3.3.2.3.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attr_reserved               post: attributes[31:16] == 0
  num_domains                 post: attributes[15:0] == NumPowerDomains()
  stats_unsupported           post: (statistics_len == 0) == !PlatformSupportsStatisticsRegion()
  stats_addr_valid            post: statistics_len != 0 ==> StatisticsRegionAddr(statistics_address_high, statistics_address_low) == StatisticsRegionBase()
  stats_addr_map              post: statistics_len != 0 ==> IsInCallerMemoryMap(StatisticsRegionAddr(statistics_address_high, statistics_address_low))
  stats_len                   post: statistics_len != 0 ==> statistics_len == StatisticsRegionSize()
               3.3.2.3.4 Footprint
               The PROTOCOL_ATTRIBUTES command does not modify any state.

               Note: The statistics capability has been marked for deprecation and is being replaced by system telemetry.
