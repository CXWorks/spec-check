3.2.2.4 PROTOCOL_MESSAGE_ATTRIBUTES command
               Returns the implementation details for one message in this protocol.
               message_id: 0x2, protocol_id: 0x10. This command is mandatory.
               3.2.2.4.1 Interface
               3.2.2.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          —            31:0        uint32                                message_id of the queried message
               3.2.2.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              —            31:0        int32                                 Command return status (see Section 3.1.4)
        attributes          —            31:0        uint32                                Flags for the queried command in the protocol
               3.2.2.4.2 Failure conditions
  ID                          Condition
  msg_impl                    pre: !IsMessageImplemented(message_id)
                              post: ResultEqual(status, NOT_FOUND)
               3.2.2.4.2.1   Failure condition ordering
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not have any failure condition orderings.
               3.2.2.4.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  attributes                  post: attributes == 0
               3.2.2.4.4 Footprint
               The PROTOCOL_MESSAGE_ATTRIBUTES command does not modify any state.
