3.6.2.7 CLOCK_RATE_SET command
               Selects the clock rate of a clock, synchronously or asynchronously. The command returns when the clock rate has been changed. If the clock is disabled, the new rate takes effect when the clock is re-enabled.
               This command is mandatory.
               3.6.2.7.1 Interface
               3.6.2.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          header       -           UInt                                  Message ID, value 0x5
        protocol_id         header       -           UInt                                  Protocol ID, value 0x14
        flags               param[0]     31:0        uint32                                Bits[31:4]: Reserved, must be zero.
                                                                                           Bits[3:2]: Round up/down. If Bit[3] == 1, the platform rounds up or down autonomously to the physical rate closest to the requested rate, and Bit[2] is ignored. If Bit[3] == 0, the platform rounds up if Bit[2] == 1 and rounds down if Bit[2] == 0.
                                                                                           Bit[1]: Ignore delayed response. If Bit[0] == 1 and Bit[1] == 1, the platform does not send a CLOCK_RATE_SET delayed response. If Bit[0] == 1 and Bit[1] == 0, the platform sends a CLOCK_RATE_SET delayed response. If Bit[0] == 0, this bit is ignored.
                                                                                           Bit[0]: Async flag. 1: the clock rate is set asynchronously; if Bit[1] == 0 the call is completed with a CLOCK_RATE_SET_COMPLETE message (see Section 3.6.3.1). 0: the clock rate is set synchronously and the call returns when the clock rate setting has been completed.
        clock_id            param[1]     31:0        uint32                                Identifier for the clock device
        rate[0]             param[2]     31:0        uint32                                Lower 32 bits of the physical rate in Hertz
        rate[1]             param[3]     31:0        uint32                                Upper 32 bits of the physical rate in Hertz
               3.6.2.7.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              ret[0]       31:0        int32                                 Command return status (see Section 3.1.4)
               3.6.2.7.2 Failure conditions
  ID                          Condition
  clock_exists                pre: !ClockExists(clock_id)
                              post: ResultEqual(status, NOT_FOUND)
  rate_supported              pre: !ClockSupportsRate(clock_id, rate)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  flags_valid                 pre: !IsValidClockRateSetFlags(flags)
                              post: ResultEqual(status, INVALID_PARAMETERS)
  async_pending               pre: flags[0] == 1 && PendingAsyncClockRateChanges() >= MaxPendingAsyncClockRateChanges()
                              post: ResultEqual(status, BUSY)
  dependencies                pre: ClockRateBlockedByDependencies(clock_id)
                              post: ResultEqual(status, DENIED)
               3.6.2.7.2.1   Failure condition ordering
               The CLOCK_RATE_SET command does not have any failure condition orderings.
               Note: the status codes listed are not exhaustive. See Section 3.1.4 for more status code definitions. MaxPendingAsyncClockRateChanges() is the value reported by the PROTOCOL_ATTRIBUTES command.
               3.6.2.7.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  sync_rate                   post: flags[0] == 0 implies ClockRate(clock_id) == RoundRate(clock_id, rate, flags[3:2])
  disabled_rate               post: flags[0] == 0 && !ClockEnabled(clock_id) implies the new rate takes effect when the clock is re-enabled
  async_queued                post: flags[0] == 1 implies CommandQueued(CLOCK_RATE_SET, clock_id, rate)
  async_response              post: flags[0] == 1 && flags[1] == 0 implies the platform sends CLOCK_RATE_SET_COMPLETE on completion
  async_no_response           post: flags[0] == 1 && flags[1] == 1 implies the platform does not send a CLOCK_RATE_SET delayed response
