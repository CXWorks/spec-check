3.10.5.2 POWERCAP_MEASUREMENTS_CHANGED command
               Notifies a registered agent of a change in the MAI or power measurement of a power capping domain. This notification is optional if no domain supports MAI and power measurements change notifications.
               3.10.5.2.1 Interface
               3.10.5.2.1.1   Input values
               The POWERCAP_MEASUREMENTS_CHANGED notification is generated by the platform and has no agent-supplied input values.
               3.10.5.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        message_id          Header       —           UInt                                  Message identifier, value 0x1
        protocol_id         Header       —           UInt                                  Protocol identifier, value 0x18
        agent_id            Payload      31:0        UInt32                                Identifier of the agent that caused this change event. For the current version of the specification, set to 0 to indicate that the platform generates all power consumption change events
        domain_id           Payload      31:0        UInt32                                Identifier for the power capping domain
        power               Payload      31:0        UInt32                                Average power consumption of the domain when either the upper or the lower power threshold was breached, or, if the notification was sent because the MAI changed, when the MAI changed
        mai                 Payload      31:0        UInt32                                Power measurement averaging interval set for the domain
               3.10.5.2.2 Failure conditions
               The POWERCAP_MEASUREMENTS_CHANGED notification does not have any failure conditions.
               3.10.5.2.2.1   Failure condition ordering
               The POWERCAP_MEASUREMENTS_CHANGED notification does not have any failure condition orderings.
               3.10.5.2.3 Success conditions
  ID                          Condition
  notify_registered           pre: IsRegisteredForMeasurementsChangeNotification(agent, domain_id)
                              post: NotificationSentTo(agent)
  notify_trigger              post: MaiChanged(domain_id)
                                    || AveragePowerOverMai(domain_id) < LowerPowerThreshold(agent, domain_id)
                                    || AveragePowerOverMai(domain_id) > UpperPowerThreshold(agent, domain_id)
  agent_id                    post: agent_id == 0
  power_threshold             pre: !MaiChanged(domain_id)
                              post: power == AveragePowerOverMai(domain_id) at threshold breach
  power_mai                   pre: MaiChanged(domain_id)
                              post: power == AveragePowerOverMai(domain_id) at MAI change
  mai                         post: mai == DomainMai(domain_id)
               3.10.5.2.4 Footprint
               The section does not identify any state that the POWERCAP_MEASUREMENTS_CHANGED notification modifies.
