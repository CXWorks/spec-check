3.9.2.8 VOLTAGE_CONFIG_GET command
               Requests the configuration of a voltage domain.
               This command is mandatory.
               3.9.2.8.1 Interface
               3.9.2.8.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           UInt                                  Message ID, value 0x6
        protocol_id         Header       -           UInt                                  Protocol ID, value 0x17
        domain_id           Payload[0]   31:0        UInt32                                Identifier for the voltage domain
               3.9.2.8.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload[0]   31:0        Int32                                 Command return status
        config              Payload[1]   31:0        UInt32                                Voltage domain configuration
        config.reserved     Payload[1]   31:4        UInt28                                Reserved, must be zero
        config.mode         Payload[1]   3:0         UInt4                                 Operating mode of the voltage domain, as described in Table 24
               3.9.2.8.2 Failure conditions
  ID                          Condition
  domain_valid                pre: !IsValidVoltageDomain(domain_id)
                              post: ResultEqual(status, NOT_FOUND)
  request_supported           pre: !IsRequestSupported()
                              post: ResultEqual(status, NOT_SUPPORTED)
  agent_permitted             pre: !AgentMayGetVoltageConfig(calling_agent, domain_id)
                              post: ResultEqual(status, DENIED)
               3.9.2.8.2.1   Failure condition ordering
               The VOLTAGE_CONFIG_GET command does not have any failure condition orderings.
               3.9.2.8.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  config_reserved             post: config[31:4] == 0
  config_mode                 post: config[3:0] == VoltageDomain(domain_id).mode
               3.9.2.8.4 Footprint
               The VOLTAGE_CONFIG_GET command does not have a footprint.
