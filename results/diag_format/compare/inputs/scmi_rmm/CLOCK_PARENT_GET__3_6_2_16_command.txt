3.6.2.16 CLOCK_PARENT_GET command

Gets the current parent of a clock device.

This command is mandatory if Bit[28] of the attributes field returned by the CLOCK_ATTRIBUTES command is set to 1 for any clock device.

3.6.2.16.1 Interface

3.6.2.16.1.1 Input values

| Name | Register | Bits | Type | Description |
|---|---|---|---|---|
| message_id | Message header | — | UInt | Message identifier, value 0xE |
| protocol_id | Message header | — | UInt | Protocol identifier, value 0x14 |
| clock_id | Parameters | 31:0 | uint32 | Identifier for the clock device |

3.6.2.16.1.2 Output values

| Name | Register | Bits | Type | Description |
|---|---|---|---|---|
| status | Return values | 31:0 | int32 | Command return status. Section 3.1.4 defines further status codes. |
| parent_id | Return values | 31:0 | uint32 | Identifier for the parent clock device |

3.6.2.16.2 Failure conditions

| ID | Condition |
|---|---|
| clock_exists | pre: !ClockExists(clock_id) |
| | post: ResultEqual(status, NOT_FOUND) |
| req_supported | pre: !IsRequestSupported(clock_id) |
| | post: ResultEqual(status, NOT_SUPPORTED) |
| agent_permitted | pre: !AgentMayGetClockParent(calling_agent, clock_id) |
| | post: ResultEqual(status, DENIED) |

The status list in the section says "One of, but not limited to", so the command may return other status codes too.

3.6.2.16.2.1 Failure condition ordering

The CLOCK_PARENT_GET command does not have any failure condition orderings.

3.6.2.16.3 Success conditions

| ID | Condition |
|---|---|
| status | post: ResultEqual(status, SUCCESS) |
| parent | post: parent_id == ClockParent(clock_id) |

3.6.2.16.4 Footprint

The CLOCK_PARENT_GET command does not change any state.
