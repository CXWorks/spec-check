3.12.4.3 PROTOCOL_ATTRIBUTES command
               Returns the implementation details associated with this protocol.
               This command is mandatory.
               3.12.4.3.1 Interface
               3.12.4.3.1.1   Input values
        Name                           Register     Bits        Type        Description
        message_id                     —            —           UInt32      Message ID, value 0x1
        protocol_id                    —            —           UInt32      Protocol ID, value 0x1B
               3.12.4.3.1.2   Output values
        Name                           Register     Bits        Type        Description
        status                         —            31:0        Int32       Command return status. See Section 3.1.4 for status code definitions.
        de_num                         —            31:0        UInt32      Total number of Data Events (DEs) supported by this protocol
        groups_num                     —            31:0        UInt32      Total number of event groups supported by this protocol
        de_implementation_rev_dword0   —            31:0        UInt32      Bits[31:0] of the primary 128-bit DE implementation revision. See Section 3.12.2.2 for more information about the DE implementation revision.
        de_implementation_rev_dword1   —            31:0        UInt32      Bits[63:32] of the primary 128-bit DE implementation revision
        de_implementation_rev_dword2   —            31:0        UInt32      Bits[95:64] of the primary 128-bit DE implementation revision
        de_implementation_rev_dword3   —            31:0        UInt32      Bits[127:96] of the primary 128-bit DE implementation revision
        attributes_1                   —            31          UInt32      Single-sample asynchronous read support. 1: the protocol supports single-sample asynchronous telemetry DE reads through the TELEMETRY_CONFIG_SET command, and the platform indicates data availability through the TELEMETRY_READING_COMPLETE delayed response. 0: single-sample asynchronous reads are not supported.
                                       —            30                      Continuous update notification support. 1: the protocol supports continuous update notifications, and the platform sends the TELEMETRY_UPDATE notification at the configured sampling interval when new data samples are available over the telemetry interface. 0: continuous update notifications are not supported.
                                       —            29:19                   Reserved, must be zero
                                       —            18                      Event group specific sampling rate and collection support. 1: each event group can be configured with its own sampling rate and collection mode using the TELEMETRY_CONFIG_SET command (Section 3.12.4.10), and all DEs that are not part of any event group must be configured with the same sampling rate and collection mode. 0: the same sampling rate and collection mode must be configured for all DEs and event groups across the platform using the TELEMETRY_CONFIG_SET command (Section 3.12.4.10).
                                       —            17                      Telemetry Reset support. 1: the platform supports a full reset of the telemetry infrastructure, which includes all configuration and accumulated DE data.
                                       —            16                      FastChannel support. 1: FastChannels are supported and at least one DE uses a FastChannel. 0: FastChannels are not supported.
                                       —            15:0                    Number of SHMTIs supported by this protocol
        default_blk_ts_rate            —            31:0        UInt32      Default clock rate in kHz used to generate block timestamps. This clock rate should not change. When the ID field of a block timestamp line is 0, the agent assumes that the block timestamp uses this clock rate.
               3.12.4.3.2 Failure conditions
               The PROTOCOL_ATTRIBUTES command does not define any failure conditions.
               3.12.4.3.2.1   Failure condition ordering
               The PROTOCOL_ATTRIBUTES command does not have any failure condition orderings.
               3.12.4.3.3 Success conditions
  ID                          Condition
  de_num                      post: de_num == NumDataEventsSupported()
  groups_num                  post: groups_num == NumEventGroupsSupported()
  de_impl_rev                 post: (de_implementation_rev_dword3 :: de_implementation_rev_dword2 :: de_implementation_rev_dword1 :: de_implementation_rev_dword0) == PrimaryDeImplementationRevision()
  async_read                  post: attributes_1[31] == SupportsSingleSampleAsyncRead()
  cont_update                 post: attributes_1[30] == SupportsContinuousUpdateNotification()
  reserved                    post: attributes_1[29:19] == 0
  group_sampling              post: attributes_1[18] == SupportsEventGroupSpecificSampling()
  telemetry_reset             post: attributes_1[17] == SupportsTelemetryReset()
  fastchannel                 post: attributes_1[16] == SupportsFastChannels()
  shmti_num                   post: attributes_1[15:0] == NumShmtisSupported()
  blk_ts_rate                 post: default_blk_ts_rate == DefaultBlockTimestampClockRateKhz()
               3.12.4.3.4 Footprint
               The PROTOCOL_ATTRIBUTES command does not define any state that it modifies.
