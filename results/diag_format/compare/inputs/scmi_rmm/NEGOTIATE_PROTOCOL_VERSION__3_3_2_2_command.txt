3.3.2.2 NEGOTIATE_PROTOCOL_VERSION command
               Negotiates the protocol version that the agent intends to use, if the agent does not support the version returned by the PROTOCOL_VERSION command. The command is optional, but platforms that intend to support agents compliant with older versions of this protocol are strongly recommended to implement it. The agent can attempt any number of negotiations. All commands, responses and notifications must comply with the protocol version that was last negotiated successfully. If the agent uses a protocol version that differs from the version returned by PROTOCOL_VERSION without a successful negotiation, the platform handles it on a best-effort basis and does not guarantee functionality.
               3.3.2.2.1 Interface
               3.3.2.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        message_id          Header       -           -                                     Message ID, value 0x10
        protocol_id         Header       -           -                                     Protocol ID, value 0x11
        version             Payload      31:0        uint32                                The negotiated protocol version the agent intends to use
               3.3.2.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        status              Payload      31:0        int32                                 Command return status. See Section 3.1.4 for status code definitions
               3.3.2.2.2 Failure conditions
  ID                          Condition
  version_supported           pre: !IsProtocolVersionSupported(version)
                              post: ResultEqual(status, NOT_SUPPORTED)
               3.3.2.2.2.1   Failure condition ordering
               The NEGOTIATE_PROTOCOL_VERSION command does not have any failure condition orderings.
               3.3.2.2.3 Success conditions
  ID                          Condition
  status                      post: ResultEqual(status, SUCCESS)
  negotiated_version          post: NegotiatedProtocolVersion() == version
