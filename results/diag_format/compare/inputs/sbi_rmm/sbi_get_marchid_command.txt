4.6 sbi_get_marchid command
               Returns a value that is legal for the marchid CSR.
               4.6.1 Interface
               4.6.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 —            —           —                                     FID, value 5
               4.6.1.2   Output values
        Name                Register     Bits        Type                                  Description
        value               —            —           struct sbiret                         A value that is legal for the marchid CSR
               4.6.2 Failure conditions
               The sbi_get_marchid command does not have any failure conditions.
               4.6.2.1   Failure condition ordering
               The sbi_get_marchid command does not have any failure condition orderings.
               4.6.3 Success conditions
  ID                          Condition
  marchid_legal               post: IsLegalMarchidValue(value)
               4.6.4 Footprint
               The sbi_get_marchid command does not modify any state.
