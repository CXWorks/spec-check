17.9 sbi_sse_register command

               Registers an event handler for a software event.

               17.9.1 Interface

               17.9.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 2
        event_id            a0           31:0        UInt32                                Event ID for which an event handler is being registered
        handler_entry_pc    a1           XLEN-1:0    Address                               ENTRY_PC event attribute of the software event. Must be 2-byte aligned.
        handler_entry_arg   a2           XLEN-1:0    UInt                                  ENTRY_ARG event attribute of the software event

               17.9.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              a0           XLEN-1:0    SbiErrorCode                          Command return status (sbiret.error)

               17.9.2 Failure conditions
  ID                          Condition
  event_invalid               pre: !IsValidEventId(event_id)
                              post: ResultEqual(result, SBI_ERR_INVALID_PARAM)
  entry_align                 pre: !IsAligned(handler_entry_pc, 2)
                              post: ResultEqual(result, SBI_ERR_INVALID_PARAM)
  event_support               pre: !PlatformSupportsEvent(event_id)
                              post: ResultEqual(result, SBI_ERR_NOT_SUPPORTED)
  event_state                 pre: (IsLocalEvent(event_id) && SseEvent(event_id, CallingHart()).state != UNUSED)
                                   || (IsGlobalEvent(event_id) && SseEvent(event_id).state != UNUSED)
                              post: ResultEqual(result, SBI_ERR_INVALID_STATE)

               17.9.2.1   Failure condition ordering
               [event_invalid] < [event_support]
               [event_invalid] < [event_state]

               17.9.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SBI_SUCCESS)
  event_state_local           post: IsLocalEvent(event_id) => SseEvent(event_id, CallingHart()).state == REGISTERED
  event_state_global          post: IsGlobalEvent(event_id) => SseEvent(event_id).state == REGISTERED
  entry_pc                    post: SseEvent(event_id).attr.ENTRY_PC == handler_entry_pc
  entry_arg                   post: SseEvent(event_id).attr.ENTRY_ARG == handler_entry_arg

               17.9.4 Footprint
    ID                        Value
    event_state               SseEvent(event_id).state
    entry_pc                  SseEvent(event_id).attr.ENTRY_PC
    entry_arg                 SseEvent(event_id).attr.ENTRY_ARG
