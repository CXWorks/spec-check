11.6 sbi_pmu_num_counters command
               Returns the number of counters, counting both hardware and firmware counters.
               11.6.1 Interface
               11.6.1.1   Input values
        Name                Register        Bits        Type            Description
        fid                 —               —           UInt            FID, value 0
               11.6.1.2   Output values
        Name                Register        Bits        Type            Description
        error               sbiret.error    —           SbiReturnCode   Command return status
        value               sbiret.value    —           UInt            Number of counters (hardware and firmware)
               11.6.2 Failure conditions
               The sbi_pmu_num_counters command does not have any failure conditions.
               11.6.2.1   Failure condition ordering
               The sbi_pmu_num_counters command does not have any failure condition orderings.
               11.6.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(error, SBI_SUCCESS)
  num_counters                post: value == NumHardwareCounters() + NumFirmwareCounters()
               11.6.4 Footprint
               The sbi_pmu_num_counters command does not modify any state.
