17.15 sbi_sse_hart_unmask command
               Unmasks software events on the calling hart, so that the hart is ready to receive software events from the SBI implementation. Software events start out masked on all harts. Supervisor software must unmask them on the relevant harts at boot time.
               17.15.1 Interface
               17.15.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 8
               17.15.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              a0           XLEN-1:0    SbiErrorCode                          Command return status (sbiret.error)
               17.15.2 Failure conditions
  ID                          Condition
  already_started             pre: !SseEventsMaskedOnHart(CallingHart())
                              post: ResultEqual(result, SBI_ERR_ALREADY_STARTED)
  failed                      pre: RequestFailedForUnspecifiedReason()
                              post: ResultEqual(result, SBI_ERR_FAILED)
               17.15.2.1   Failure condition ordering
               The sbi_sse_hart_unmask command does not have any failure condition orderings.
               17.15.3 Success conditions
  ID                          Condition
  success                     post: ResultEqual(result, SBI_SUCCESS)
  hart_unmasked               post: !SseEventsMaskedOnHart(CallingHart())
               17.15.4 Footprint
    ID                        Value
    hart_unmasked             SseEventsMaskedOnHart(CallingHart())
