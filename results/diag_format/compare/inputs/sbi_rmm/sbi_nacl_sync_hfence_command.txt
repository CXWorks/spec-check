15.8 sbi_nacl_sync_hfence command

               Synchronizes HFENCEs in the nested acceleration shared memory. This is an optional function. It is available only if the SBI_NACL_FEAT_SYNC_HFENCE feature is available.

               15.8.1 Interface

               15.8.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 3
        entry_index         a0           XLEN-1:0    UInt                                  Set of nested HFENCE entries to synchronize. All-ones bitwise selects all entries. A value < (3840 / XLEN) selects the single entry at that index.

               15.8.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           XLEN-1:0    SbiErrorCode                          Command return status (sbiret.error)

               15.8.2 Failure conditions
  ID                          Condition
  feat_sync_hfence            pre: !NaclFeatureAvailable(SBI_NACL_FEAT_SYNC_HFENCE)
                              post: ResultEqual(error, SBI_ERR_NOT_SUPPORTED)
  entry_index_range           pre: !IsAllOnes(entry_index) && entry_index >= (3840 / XLEN)
                              post: ResultEqual(error, SBI_ERR_INVALID_PARAM)
  shmem                       pre: !NaclSharedMemoryAvailable()
                              post: ResultEqual(error, SBI_ERR_NO_SHMEM)

               15.8.2.1   Failure condition ordering
               The sbi_nacl_sync_hfence command does not have any failure condition orderings.

               15.8.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(error, SBI_SUCCESS)
  sync_all                    pre: IsAllOnes(entry_index)
                              post: All nested HFENCE entries are synchronized as described in Section 15.2
  sync_single                 pre: entry_index < (3840 / XLEN)
                              post: The nested HFENCE entry at entry_index is synchronized as described in Section 15.2

               15.8.4 Footprint
    ID                        Value
    hfence_entries            NaclShmemHfenceEntries(entry_index)
