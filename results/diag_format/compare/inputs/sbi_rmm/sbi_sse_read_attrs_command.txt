17.7 sbi_sse_read_attrs command
               Reads a range of event attribute values from a software event.
               17.7.1 Interface
               17.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 -            -           UInt                                  FID, value 0
        event_id            -            31:0        UInt32                                Software event ID
        base_attr_id        -            31:0        UInt32                                ID of the first event attribute in the range
        attr_count          -            31:0        UInt32                                Number of event attributes in the range
        output_phys_lo      -            XLEN-1:0    Address                               Lower part of the physical address of the output shared memory
        output_phys_hi      -            XLEN-1:0    Address                               Upper part of the physical address of the output shared memory
               17.7.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              -            XLEN-1:0    SbiErrorCode                          Error code (struct sbiret error)
               17.7.2 Failure conditions
  ID                          Condition
  event_unsupported           pre: IsValidEventId(event_id) && !IsReservedEventId(event_id)
                                   && !PlatformSupportsEvent(event_id)
                              post: ResultEqual(result, SBI_ERR_NOT_SUPPORTED)
  event_invalid               pre: !IsValidEventId(event_id)
                              post: ResultEqual(result, SBI_ERR_INVALID_PARAM)
  attr_count_zero             pre: attr_count == 0
                              post: ResultEqual(result, SBI_ERR_INVALID_PARAM)
  attr_range                  pre: Exists(i, 0 <= i < attr_count,
                                   IsReservedAttrId(base_attr_id + i))
                              post: ResultEqual(result, SBI_ERR_BAD_RANGE)
  output_mem                  pre: !SatisfiesSharedMemoryRequirements(output_phys_lo, output_phys_hi,
                                   (XLEN / 8) * attr_count)
                              post: ResultEqual(result, SBI_ERR_INVALID_ADDRESS)
  read_failed                 pre: ReadFailedForOtherReason()
                              post: ResultEqual(result, SBI_ERR_FAILED)
               17.7.2.1   Failure condition ordering
               The sbi_sse_read_attrs command does not have any failure condition orderings.
               17.7.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SBI_SUCCESS)
  attr_values                 post: ForAll(i, 0 <= i < attr_count,
                                   SharedMemoryAt(OutputPhysAddr(output_phys_lo, output_phys_hi)
                                   + (XLEN / 8) * (base_attr_id + i))
                                   == EventAttr(event_id, base_attr_id + i))
               17.7.4 Footprint
    ID                        Value
    attr_values               ForAll(i, 0 <= i < attr_count,
                              SharedMemoryAt(OutputPhysAddr(output_phys_lo, output_phys_hi)
                              + (XLEN / 8) * (base_attr_id + i)))
