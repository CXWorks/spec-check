18.2 sbi_fwft_get command
               Gets the configuration value of a firmware feature.
               18.2.1 Interface
               18.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                              -           -                                     FID, value 1
        feature                          31:0        uint32_t                              Firmware feature ID
               18.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              sbiret.error -           -                                     Command return status
        value               sbiret.value -           -                                     Firmware feature configuration value (see Table 93)
               18.2.2 Failure conditions
  ID                          Condition
  feat_unsupported            pre: !IsReservedFeature(feature)
                                   && IsValidFeature(feature)
                                   && !PlatformSupportsFeature(feature)
                              post: ResultEqual(result, SBI_ERR_NOT_SUPPORTED)
                                    && value == 0
  feat_denied                 pre: IsReservedFeature(feature)
                                   || (IsPlatformSpecificFeature(feature)
                                       && !IsImplementedFeature(feature))
                              post: ResultEqual(result, SBI_ERR_DENIED)
                                    && value == 0
  get_failed                  pre: FeatureGetFailed(feature)
                              post: ResultEqual(result, SBI_ERR_FAILED)
                                    && value == 0
               18.2.2.1   Failure condition ordering
               The sbi_fwft_get command does not have any failure condition orderings.
               18.2.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SBI_SUCCESS)
  feat_value                  post: value == FeatureConfigValue(feature)
               18.2.4 Footprint
               The sbi_fwft_get command does not have a footprint.
