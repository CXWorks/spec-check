18.1 sbi_fwft_set command

               Sets a firmware feature according to the value and flags parameters.

               18.1.1 Interface

               18.1.1.1   Input values
        Name                Register        Bits            Type                Description
        fid                 Not specified   Not specified   FID                 FID, value #0 (Firmware Features Set)
        feature             Not specified   31:0            uint32_t            Identifier of the firmware feature to set
        value               Not specified   XLEN-1:0        unsigned long       Requested feature value; the supported values for each feature are given in Table 93
        flags               Not specified   XLEN-1:0        unsigned long       Set flags (Table 94):
                                                                                BIT[0] LOCK: if set, the feature value can no longer be modified until hart reset (local-scope feature) or system reset (global-scope feature)
                                                                                BIT[XLEN-1:1]: reserved for future use and must be zero

               18.1.1.2   Output values
        Name                Register        Bits            Type                Description
        result              Not specified   Not specified   struct sbiret       Command return status

               18.1.2 Failure conditions

               This section does not name any error return codes, so no failure conditions can be listed.

               18.1.2.1   Failure condition ordering

               The sbi_fwft_set command does not have any failure condition orderings.

               18.1.3 Success conditions
  ID                          Condition
  success                     post: IsSuccessfulReturn(result)
  feat_value                  post: FeatureValue(feature) == value
  feat_lock                   pre: FlagIsSet(flags, LOCK)
                              post: FeatureIsLocked(feature)
  feat_same_value             pre: FeatureValue(feature) == value
                              post: IsSuccessfulReturn(result)

               18.1.4 Footprint
    ID                        Value
    feat_value                FeatureValue(feature)
    feat_lock                 FeatureIsLocked(feature)
