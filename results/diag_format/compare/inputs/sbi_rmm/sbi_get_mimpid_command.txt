4.7 sbi_get_mimpid command
               Returns the machine implementation ID.
               4.7.1 Interface
               4.7.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 —            —           UInt                                  FID, value 6
               4.7.1.2   Output values
        Name                Register     Bits        Type                                  Description
        value               —            —           struct sbiret                         A value that is legal for the mimpid CSR
               4.7.2 Failure conditions
               The sbi_get_mimpid command does not have any failure conditions.
               4.7.2.1   Failure condition ordering
               The sbi_get_mimpid command does not have any failure condition orderings.
               4.7.3 Success conditions
  ID                          Condition
  mimpid_legal                post: IsLegalMimpidValue(value)
               4.7.4 Footprint
               The sbi_get_mimpid command does not modify any state.
