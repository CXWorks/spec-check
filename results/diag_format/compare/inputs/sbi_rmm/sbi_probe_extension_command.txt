4.4 sbi_probe_extension command
               Probes whether an SBI extension is available.
               4.4.1 Interface
               4.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 —            —           —                                     FID, value 3
        extension_id        —            —           long                                  SBI extension ID (EID) to probe
               4.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        ret                 —            —           struct sbiret                         0 if the extension is not available; 1, or another implementation-defined non-zero value, if it is available
               4.4.2 Failure conditions
               The sbi_probe_extension command does not have any failure conditions.
               4.4.2.1   Failure condition ordering
               The sbi_probe_extension command does not have any failure condition orderings.
               4.4.3 Success conditions
  ID                          Condition
  ext_unavail                 pre: !IsExtensionAvailable(extension_id)
                              post: ret == 0
  ext_avail                   pre: IsExtensionAvailable(extension_id)
                              post: (ret == 1) || (ret != 0 && IsImplementationDefinedProbeValue(ret))
               4.4.4 Footprint
               The sbi_probe_extension command does not modify any state.
