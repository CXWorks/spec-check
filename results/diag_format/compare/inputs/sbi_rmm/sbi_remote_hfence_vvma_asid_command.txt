8.6 sbi_remote_hfence_vvma_asid command
               Tells the remote harts to execute one or more HFENCE.VVMA instructions. These cover the guest virtual addresses from start_addr to start_addr + size for the given ASID and the current VMID.
               8.6.1 Interface
               8.6.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 —            —           —                                     FID, value 5
        hart_mask           —            —           unsigned long                         Mask of the target remote harts
        hart_mask_base      —            —           unsigned long                         Base hart ID that hart_mask is relative to
        start_addr          —            —           unsigned long                         Start of the guest virtual address range
        size                —            —           unsigned long                         Size of the guest virtual address range
        asid                —            —           unsigned long                         ASID that the fence covers
               8.6.1.2   Output values
        Name                Register     Bits        Type                                  Description
        ret                 —            —           struct sbiret                         Return value of the call
               8.6.2 Failure conditions
               The section does not list any failure conditions for sbi_remote_hfence_vvma_asid.
               8.6.2.1   Failure condition ordering
               The sbi_remote_hfence_vvma_asid command does not have any failure condition orderings.
               8.6.3 Success conditions
  ID                          Condition
  hfence_exec                 post: ForAll(hart in HartsSelectedBy(hart_mask, hart_mask_base)):
                                      ExecutedHfenceVvma(hart, start_addr, start_addr + size, asid, CurrentVmid())
               8.6.4 Footprint
