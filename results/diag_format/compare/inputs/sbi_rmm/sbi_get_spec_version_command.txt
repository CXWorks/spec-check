4.1 sbi_get_spec_version command
               Returns the current SBI specification version.
               4.1.1 Interface
               4.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 —            —           UInt                                  FID, value 0
               4.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        ret                 —            —           struct sbiret                         Current SBI specification version
        ret.minor           —            23:0        UInt24                                Minor number of the SBI specification
        ret.major           —            30:24       UInt7                                 Major number of the SBI specification
        ret.reserved        —            31          Bit                                   Reserved for future expansion, must be 0
        ret.reserved_hi     —            XLEN-1:32   Bits                                  Reserved when XLEN > 32, must be 0
               4.1.2 Failure conditions
               The sbi_get_spec_version command does not have any failure conditions. This function must always succeed.
               4.1.2.1   Failure condition ordering
               The sbi_get_spec_version command does not have any failure condition orderings.
               4.1.3 Success conditions
  ID                          Condition
  minor                       post: ret[23:0] == CurrentSbiSpecMinorVersion()
  major                       post: ret[30:24] == CurrentSbiSpecMajorVersion()
  rsvd_31                     post: ret[31] == 0
  rsvd_hi                     post: (XLEN > 32) ==> (ret[XLEN-1:32] == 0)
               4.1.4 Footprint
               The sbi_get_spec_version command does not have a footprint.
