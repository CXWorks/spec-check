17.14 sbi_sse_inject command

               Injects a software event.

               17.14.1 Interface

               17.14.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 7
        event_id            a0           31:0        UInt32                                ID of the event to be injected
        hart_id             a1           XLEN-1:0    unsigned long                         For local events: the hart on which the event is to be injected. For global events: ignored

               17.14.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           XLEN-1:0    SbiReturnCode                         Command return status

               17.14.2 Failure conditions
               The section does not list any error codes, so no failure conditions are given here.

               17.14.2.1   Failure condition ordering
               The sbi_sse_inject command does not have any failure condition orderings.

               17.14.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(error, SBI_SUCCESS)
  inject_allowed              post: EventInjectAllowedByAttribute(event_id)
  inject_local                post: IsLocalEvent(event_id) ==> EventInjected(event_id, hart_id)
  inject_global               post: IsGlobalEvent(event_id) ==> EventInjected(event_id)
  preempt                     post: InSseHandler() && EventReady(event_id) && EventPriority(event_id) > EventPriority(CurrentEvent())
                                    ==> EventHandledImmediately(event_id)
  defer                       post: InSseHandler() && EventReady(event_id) && EventPriority(event_id) < EventPriority(CurrentEvent())
                                    ==> EventRunsAfterCompletion(event_id, CurrentEvent())

               17.14.4 Footprint
    ID                        Value
    inject_local              EventAt(event_id, hart_id).injected
    inject_global             EventAt(event_id).injected
