11.13 sbi_pmu_snapshot_set_shmem command
               Sets and enables the PMU snapshot shared memory on the calling hart, or clears and disables it.
               11.13.1 Interface
               11.13.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 7
        shmem_phys_lo       a0           XLEN-1:0    unsigned long                         Lower XLEN bits of the snapshot shared memory physical base address. All-ones bitwise (together with shmem_phys_hi) means clear and disable
        shmem_phys_hi       a1           XLEN-1:0    unsigned long                         Upper XLEN bits of the snapshot shared memory physical base address. All-ones bitwise (together with shmem_phys_lo) means clear and disable
        flags               a2           XLEN-1:0    unsigned long                         Flags
               11.13.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           XLEN-1:0    long                                  sbiret.error: command return status
        value               a1           XLEN-1:0    long                                  sbiret.value
               11.13.2 Failure conditions
               The section names no error return codes, so no failure conditions are listed here. It does say that when the shared memory is being set, shmem_phys_lo MUST be 4096-byte (page) aligned (AddrIsPageAligned(shmem_phys_lo)). It does not say which error code is returned if that is not true.
               11.13.2.1   Failure condition ordering
               The sbi_pmu_snapshot_set_shmem command does not have any failure condition orderings.
               11.13.3 Success conditions
  ID                          Condition
  shmem_set_base              pre: !(IsAllOnes(shmem_phys_lo) && IsAllOnes(shmem_phys_hi))
                              post: PmuSnapshotShmem(CurrentHart()).base == ((shmem_phys_hi << XLEN) | shmem_phys_lo)
  shmem_set_size              pre: !(IsAllOnes(shmem_phys_lo) && IsAllOnes(shmem_phys_hi))
                              post: PmuSnapshotShmem(CurrentHart()).size == 4096
  shmem_set_enabled           pre: !(IsAllOnes(shmem_phys_lo) && IsAllOnes(shmem_phys_hi))
                              post: PmuSnapshotShmem(CurrentHart()).enabled == TRUE
  shmem_clear                 pre: IsAllOnes(shmem_phys_lo) && IsAllOnes(shmem_phys_hi)
                              post: PmuSnapshotShmem(CurrentHart()).cleared == TRUE
  shmem_disable               pre: IsAllOnes(shmem_phys_lo) && IsAllOnes(shmem_phys_hi)
                              post: PmuSnapshotShmem(CurrentHart()).enabled == FALSE
               11.13.4 Footprint
    ID                        Value
    shmem_base                PmuSnapshotShmem(CurrentHart()).base
    shmem_enabled             PmuSnapshotShmem(CurrentHart()).enabled
