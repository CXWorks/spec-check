9.1 sbi_hart_start command
               Requests the SBI implementation to start executing the target hart in supervisor-mode, at the address given by start_addr.
               9.1.1 Interface
               9.1.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 a6           XLEN-1:0    UInt                                  FID, value 0
        hartid              a0           XLEN-1:0    UInt (unsigned long)                  Identifier of the target hart
        start_addr          a1           XLEN-1:0    Address (unsigned long)               Address at which the target hart starts executing in supervisor-mode
        opaque              a2           XLEN-1:0    UInt (unsigned long)                  Opaque value
               9.1.1.2   Output values
        Name                Register     Bits        Type                                  Description
        error               a0           XLEN-1:0    struct sbiret.error                   Command return status
        value               a1           XLEN-1:0    struct sbiret.value                   Return value
               9.1.2 Failure conditions
               The section does not define any failure conditions for sbi_hart_start.
               9.1.2.1   Failure condition ordering
               The sbi_hart_start command does not have any failure condition orderings.
               9.1.3 Success conditions
  ID                          Condition
  hart_start                  post: HartStartRequested(hartid, start_addr, opaque)
               9.1.4 Footprint
    ID                        Value
    hart_state                HartAt(hartid).state
