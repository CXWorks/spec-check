8.2 sbi_remote_sfence_vma command
               Instructs the remote harts to execute one or more SFENCE.VMA instructions, covering the range of virtual addresses between start_addr and start_addr + size.
               8.2.1 Interface
               8.2.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 —            —           unsigned long                         FID, value 1
        hart_mask           —            —           unsigned long                         Mask of the targeted harts
        hart_mask_base      —            —           unsigned long                         Base of the targeted-hart mask
        start_addr          —            —           unsigned long                         Start of the virtual address range
        size                —            —           unsigned long                         Size of the virtual address range
               8.2.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              —            —           sbiret.error                          Command return status
               8.2.2 Failure conditions
  ID                          Condition
  addr_range                  pre: !IsValidStartAddr(start_addr) || !IsValidSize(size)
                              post: ResultEqual(result, SBI_ERR_INVALID_ADDRESS)
               8.2.2.1   Failure condition ordering
               The sbi_remote_sfence_vma command does not have any failure condition orderings.
               8.2.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SBI_SUCCESS)
  ipi_sent                    post: IpiSentToAll(TargetHarts(hart_mask, hart_mask_base))
  sfence_vma                  post: forall hart in TargetHarts(hart_mask, hart_mask_base):
                                    SfenceVmaExecuted(hart, start_addr, start_addr + size)
               8.2.4 Footprint
    ID                        Value
    sfence_vma                AddressTranslationState(hart, start_addr, start_addr + size)
                              for hart in TargetHarts(hart_mask, hart_mask_base)
