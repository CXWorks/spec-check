6.5.1 DRTM_DYNAMIC_LAUNCH command
               Requests a dynamic launch. This section gives only the hardware-backed requirements for DRTM_DYNAMIC_LAUNCH (Table 68). It does not define the full command interface.
               6.5.1.1 Interface
               6.5.1.1.1   Input values
               This section does not specify the input values of the DRTM_DYNAMIC_LAUNCH command.
               6.5.1.1.2   Output values
               This section does not specify the output values of the DRTM_DYNAMIC_LAUNCH command.
               6.5.1.2 Failure conditions
               This section does not specify any failure conditions or error return codes for the DRTM_DYNAMIC_LAUNCH command.
               6.5.1.2.1   Failure condition ordering
               This section does not specify any failure condition ordering for the DRTM_DYNAMIC_LAUNCH command.
               6.5.1.3 Success conditions
  ID                          Condition
  dcrtm_proxy                 post: DynamicLaunchRequestProxiedToCoprocessorDcrtm()
                              (R65000. The method is implementation-specific.)
  dma_protect                 post: CallerDmaProtectionsBlock(NONSECURE_DEVICES) && CallerDmaProtectionsBlock(SECURE_DEVICES)
                              (R65010)
               This section does not specify a success return code.
               6.5.1.4 Footprint
