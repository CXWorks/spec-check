3.8 DRTM_SET_ERROR command
               Sets a DRTM error code indicating that a dynamic launch has failed.
               3.8.1 Interface
               3.8.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 W0           31:0        UInt32                                FID, value 0xC4000117
        error_code          X1           63:0        Int64                                 64-bit error code describing the reason for a dynamic launch failure. See error encoding in section 3.12
               3.8.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 Command return status
               3.8.2 Failure conditions
  ID                          Condition
  drtm_support                pre: !IsDrtmSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
  error_set                   pre: IsDrtmErrorSet()
                              post: ResultEqual(result, DENIED)
               This function may return other error codes as defined in section 3.18.
               3.8.2.1   Failure condition ordering
               The DRTM_SET_ERROR command does not have any failure condition orderings.
               3.8.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SUCCESS)
  error_set                   post: IsDrtmErrorSet()
  error_dce                   pre: !IsDlmePhase()
                              post: StoredDrtmError() == error_code
  error_dlme_phase            pre: IsDlmePhase()
                              post: StoredDrtmError()[2:0] == DLME
  error_dlme_code             pre: IsDlmePhase()
                              post: StoredDrtmError()[10:3] == 0xFF
  error_dlme_upper            pre: IsDlmePhase()
                              post: StoredDrtmError()[63:11] == error_code[63:11]
               The DRTM error code is persisted in a non-volatile location that the Normal world cannot access, so that DRTM_GET_ERROR can return it after the system reset.
               3.8.4 Footprint
    ID                        Value
    error_stored              StoredDrtmError()
    error_set                 IsDrtmErrorSet()
