B4.3.61 RMI_VDEV_UNLOCK command
               Unlock a VDEV.
               B4.3.61.1 Interface
               B4.3.61.1.1   Input values
        Name                 Register    Bits         Type                                 Description
        fid                  X0          63:0         UInt64                               FID, value 0xC400018A
        rd                   X1          63:0         Address                              PA of the RD
        vdev_ptr             X2          63:0         Address                              PA of the VDEV
               B4.3.61.1.2   Context
               The RMI_VDEV_UNLOCK command operates on the following context.
        Name                 Type                       Value                                      Before   Description
        realm                RmmRealm                   RealmAt(rd)                                false    Realm
        vdev                 RmmVdev                    VdevAt(vdev_ptr)                           false    VDEV
               B4.3.61.1.3   Output values
        Name                 Register    Bits         Type                                 Description
        result               X0          63:0         RmiCommandReturnCode                 Command return status
               B4.3.61.2 Failure conditions
(da_supp) If ImplFeatures().feat_da != FEATURE_TRUE, then ResultEqual(result, RMI_ERROR_NOT_SUPPORTED).
(rd_align) If !AddrIsGranuleAligned(rd), then ResultEqual(result, RMI_ERROR_INPUT).
(rd_bound) If !PaIsDelegable(rd), then ResultEqual(result, RMI_ERROR_INPUT).
(rd_state) If GranuleAt(rd).state != RD, then ResultEqual(result, RMI_ERROR_INPUT).
(vdev_align) If !AddrIsGranuleAligned(vdev_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(vdev_bound) If !PaIsDelegable(vdev_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(vdev_gran_state) If GranuleAt(vdev_ptr).state != VDEV, then ResultEqual(result, RMI_ERROR_INPUT).
(vdev_realm) If vdev.realm != rd, then ResultEqual(result, RMI_ERROR_INPUT).
(vdev_state) If (vdev.vdev_state != VDEV_LOCKED
                                          && vdev.vdev_state != VDEV_STARTED
        && vdev.vdev_state != VDEV_ERROR), then ResultEqual(result, RMI_ERROR_DEVICE).
(comm_state) If vdev.comm_state != DEV_COMM_IDLE, then ResultEqual(result, RMI_ERROR_DEVICE).
(num_map) If vdev.num_map != 0, then ResultEqual(result, RMI_ERROR_DEVICE).
               B4.3.61.2.1     Failure condition ordering
               [rd_bound, rd_state, vdev_bound, vdev_gran_state] < [vdev_realm]
               [da_supp] < [rd_bound, rd_state, vdev_align, vdev_bound,
                    vdev_gran_state, vdev_realm]
               [vdev_gran_state] < [vdev_state, comm_state, num_map]
                                                                            da_supp
                                                                    RMI_ERROR_NOT _SUPPORT ED
                    rd_align   vdev_align   vdev_bound   rd_state          rd_bound             vdev_gran_state
                                                                          vdev_realm                                      num_map   comm_state    vdev_state
                                                                                                                                                 RMI_ERROR_DEVICE
                                                                                                        RMI_ERROR_INPUT
               B4.3.61.3 Success conditions
(dma_state) On success, vdev.dma_state == VDEV_DMA_DISABLED.
(op) On success, vdev.op == VDEV_OP_UNLOCK.
(comm_state) On success, vdev.comm_state == DEV_COMM_PENDING.
