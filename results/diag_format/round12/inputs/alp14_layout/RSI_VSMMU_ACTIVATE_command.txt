B5.3.21 RSI_VSMMU_ACTIVATE command
                Activate a VSMMU.
                B5.3.21.1 Interface
                B5.3.21.1.1   Input values
         Name                 Register    Bits        Type                                  Description
         fid                  X0          63:0        UInt64                                FID, value 0xC400019B
         base                 X1          63:0        Address                               Base of target IPA region
         top                  X2          63:0        Address                               Top of target IPA region
                B5.3.21.1.2   Context
                The RSI_VSMMU_ACTIVATE command operates on the following context.
         Name                 Type                       Value                                      Before    Description
         realm                RmmRealm                   CurrentRealm()                             false     Current Realm
         walk                 RmmRttWalkResult           RttWalk(                                   false     RTT walk result
                                                             realm, base,
                                                             RMM_RTT_PAGE_LEVEL,
                                                             RMM_RTT_TREE_PRIMARY)
         vsmmu                RmmVsmmu                   VsmmuAt(walk.rtte.addr)                    false     VSMMU
                B5.3.21.1.3   Output values
         Name                 Register    Bits        Type                                  Description
         result               X0          63:0        RsiCommandReturnCode                  Command return status
         new_base             X1          63:0        Address                               Base of IPA region which was not
                                                                                            modified by the command
                B5.3.21.2 Failure conditions
(base_align) If !AddrIsGranuleAligned(base), then result == RSI_ERROR_INPUT.
(top_align) If !AddrIsGranuleAligned(top), then result == RSI_ERROR_INPUT.
(size_valid) If UInt(top) <= UInt(base), then result == RSI_ERROR_INPUT.
(rgn_bound) If !AddrRangeIsProtected(base, top, realm), then result == RSI_ERROR_INPUT.
(rtte_state) If walk.rtte.state != ASSIGNED_VSMMU, then result == RSI_ERROR_INPUT.
               B5.3.21.2.1   Failure condition ordering
               The RSI_VSMMU_ACTIVATE command does not have any failure condition orderings.
               B5.3.21.3 Success conditions
(ripas) RIPAS of address range [base, new_base) is equal to DEV.
(start) If (base == vsmmu.reg_base && new_base != vsmmu.reg_top), then vsmmu.state == VSMMU_ACTIVATING.
(complete) If new_base == vsmmu.reg_top, then vsmmu.state == VSMMU_ACTIVE.
               B5.3.21.4 Footprint
               The RSI_VSMMU_ACTIVATE command does not have any footprint.
