B4.3.30 RMI_REC_ENTER command
              Enter a REC.
              B4.3.30.1 Interface
              B4.3.30.1.1    Input values
        Name                 Register    Bits        Type                                  Description
        fid                  X0          63:0        UInt64                                FID, value 0xC400015C
        rec_ptr              X1          63:0        Address                               PA of the target REC
        run_ptr              X2          63:0        Address                               PA of RecRun object
              The number of GICv3 List Register values which can be provided by the Host in RmiRecEnter, and which are
              returned in RmiRecExit, is reported by the RMI_FEATURES command.
              B4.3.30.1.2    Context
              The RMI_REC_ENTER command operates on the following context.
        Name                 Type                       Value                                      Before   Description
        run                  RmiRecRun                  RmiRecRunAt(run_ptr)                       false    RecRun object
        rec                  RmmRec                     RecAt(rec_ptr)                             false    REC
        realm                RmmRealm                   RealmAt(rec.owner)                         false    Realm
              B4.3.30.1.3    Output values
        Name                 Register    Bits        Type                                  Description
        result               X0          63:0        RmiCommandReturnCode                  Command return status
              B4.3.30.2 Failure conditions
  (run_align) If !AddrIsGranuleAligned(run_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
  (run_pas) If !GranuleAccessPermitted(run_ptr, PAS_NS), then ResultEqual(result, RMI_ERROR_INPUT).
  (rec_align) If !AddrIsGranuleAligned(rec_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
  (rec_bound) If !PaIsDelegable(rec_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
  (rec_gran_state) If GranuleAt(rec_ptr).state != REC, then ResultEqual(result, RMI_ERROR_INPUT).
  (realm_new) If realm.state == REALM_NEW, then ResultEqual(result, RMI_ERROR_REALM, 0).
  (system_off) If realm.state == REALM_SYSTEM_OFF, then ResultEqual(result, RMI_ERROR_REALM, 1).
  (rec_state) If rec.state == REC_RUNNING, then ResultEqual(result, RMI_ERROR_REC).
  (rec_runnable) If rec.flags.runnable == NOT_RUNNABLE, then ResultEqual(result, RMI_ERROR_REC).
  (rec_mmio) If (run.enter.flags.emul_mmio == RMI_EMULATED_MMIO && rec.emulatable_abort != EMULATABLE_ABORT), then ResultEqual(result, RMI_ERROR_REC).
  (rec_gicv3) If !Gicv3ConfigIsValid(run.enter.gicv3_hcr, run.enter.gicv3_lrs), then ResultEqual(result, RMI_ERROR_REC).
  (rec_pending) If rec.pending != REC_PENDING_NONE, then ResultEqual(result, RMI_ERROR_REC).
               B4.3.30.2.1   Failure condition ordering
               [rec_align, rec_bound, rec_gran_state, run_pas, run_align] <
                    [rec_state, rec_runnable, rec_mmio, realm_new, system_off,
                    rec_gicv3, rec_pending]

               B4.3.30.3 Success conditions
  (rec_exit) On success, run.exit contains Realm exit syndrome information.
  (rec_emul_abt) On success, rec.emulatable_abort is updated.
