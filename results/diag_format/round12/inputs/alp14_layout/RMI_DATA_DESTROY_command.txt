B4.3.3 RMI_DATA_DESTROY command
               Destroys a Data Granule.
               B4.3.3.1 Interface
               B4.3.3.1.1   Input values
        Name                Register      Bits       Type                                  Description
        fid                 X0            63:0       UInt64                                FID, value 0xC4000155
        rd                  X1            63:0       Address                               PA of the RD which owns the target Data
        ipa                 X2            63:0       Address                               IPA at which the Granule is mapped in
                                                                                           the target Realm
               B4.3.3.1.2   Context
               The RMI_DATA_DESTROY command operates on the following context.
        Name                Type                        Value                                      Before   Description
        realm               RmmRealm                    RealmAt(rd)                                false    Realm
        walk                RmmRttWalkResult            RttWalk(                                   false    RTT walk result
                                                            realm, ipa,
                                                            RMM_RTT_PAGE_LEVEL,
                                                            RMM_RTT_TREE_PRIMARY)
        entry_idx           UInt64                      RttEntryIndex(                             false    RTTE index
                                                            ipa, walk.level)
        walk_top            Address                     RttSkipNonLiveEntries(                     false    Top IPA of non-live
                                                            RttAt(walk.rtt_addr),                           RTT entries, from
                                                            walk.level,                                     entry at which the
                                                            ipa)                                            RTT walk terminated
               B4.3.3.1.3   Output values
        Name                Register      Bits       Type                                  Description
        result              X0            63:0       RmiCommandReturnCode                  Command return status
        data                X1            63:0       Address                               PA of the Data Granule which was
                                                                                           destroyed
        top                 X2            63:0       Address                               Top IPA of non-live RTT entries, from
                                                                                           entry at which the RTT walk terminated
               The data output value is valid only when the command result is RMI_SUCCESS.
                The values of the result and top output values for different command outcomes are summarized in the following
                table.
            Scenario                            result                                 top           walk.rtte.state
            ipa is mapped as a page and         RMI_SUCCESS                            > ipa         Before execution: ASSIGNED
            RIPAS is RAM                                                                             and RIPAS is RAM
                                                                                                     After execution: UNASSIGNED
                                                                                                     and RIPAS is DESTROYED
            ipa is mapped as a page and         RMI_SUCCESS                            > ipa         Before execution: ASSIGNED
            RIPAS is not RAM                                                                         and RIPAS is not RAM
                                                                                                     After execution: UNASSIGNED
                                                                                                     and RIPAS is unchanged
            ipa is not mapped                   (RMI_ERROR_RTT, <= 3)                  > ipa         UNASSIGNED
            ipa is mapped as a block            (RMI_ERROR_RTT, 0                      == ipa        ASSIGNED
                                                0 < level < 3)
            RTT walk was not performed,         Another error code                     0             Unknown
            due to any other command failure
                B4.3.3.2 Failure conditions

(rd_align) If !AddrIsGranuleAligned(rd), then ResultEqual(result, RMI_ERROR_INPUT).

(rd_bound) If !PaIsDelegable(rd), then ResultEqual(result, RMI_ERROR_INPUT).

(rd_state) If GranuleAt(rd).state != RD, then ResultEqual(result, RMI_ERROR_INPUT).

(ipa_align) If !AddrIsGranuleAligned(ipa), then ResultEqual(result, RMI_ERROR_INPUT).

(ipa_bound) If !AddrIsProtected(ipa, realm), then ResultEqual(result, RMI_ERROR_INPUT).

(rtt_walk) If walk.level < RMM_RTT_PAGE_LEVEL, then (ResultEqual(result, RMI_ERROR_RTT, walk.level) && (top == walk_top)).

(rtte_state) If walk.rtte.state != ASSIGNED, then (ResultEqual(result, RMI_ERROR_RTT, walk.level) && (top == walk_top)).

(aux_live) If AddrIsAuxLive(ipa, realm), then ResultEqual(result, RMI_ERROR_RTT_AUX, 0).

                B4.3.3.2.1   Failure condition ordering
                [rd_bound, rd_state] < [rtt_walk, rtte_state, aux_live]
                [ipa_bound] < [rtt_walk, rtte_state, aux_live]
                        ipa_align           rd_align            ipa_bound              rd_state          rd_bound
                                                                                                        RMI_ERROR_INPUT
                                           aux_live               rtte_state            rtt_walk
                                      RMI_ERROR_RT T _AUX                            RMI_ERROR_RT

               B4.3.3.3 Success conditions

(data_state) On success, GranuleAt(walk.rtte.addr).state == DELEGATED.

(rtte_state) On success, walk.rtte.state == UNASSIGNED.

(ripas_ram) If walk.rtte.ripas == RAM, then walk.rtte.ripas == DESTROYED.

(data) On success, data == walk.rtte.addr.

(top) On success, top == walk_top.
               B4.3.3.4 Footprint
    ID                        Value
    data_state                GranuleAt(walk.rtte.addr).state
    rtte                      RttEntryAt(RttAt(walk.rtt_addr), entry_idx)
