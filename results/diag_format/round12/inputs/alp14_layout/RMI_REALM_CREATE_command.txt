B4.3.25 RMI_REALM_CREATE command
              Creates a Realm.
              B4.3.25.1 Interface
              B4.3.25.1.1   Input values
        Name                Register    Bits        Type                                  Description
        fid                 X0          63:0        UInt64                                FID, value 0xC4000158
        rd                  X1          63:0        Address                               PA of the RD
        params_ptr          X2          63:0        Address                               PA of Realm parameters
              B4.3.25.1.2   Context
              The RMI_REALM_CREATE command operates on the following context.
        Name                Type                       Value                                      Before   Description
        params              RmiRealmParams             RmiRealmParamsAt(                          false    Realm parameters
                                                           params_ptr)
        realm               RmmRealm                   RealmAt(rd)                                false    Realm
        mec_members_pre UInt64                         MecMembers(params.mecid)                   true     Number of Realms
                                                                                                           which are members of
                                                                                                           the Realm’s MEC
        mec_state_pre       RmmMecState                MecState(params.mecid)                     true     MECID state
              B4.3.25.1.3   Output values
        Name                Register    Bits        Type                                  Description
        result              X0          63:0        RmiCommandReturnCode                  Command return status
              B4.3.25.2 Failure conditions

(params_align) If !AddrIsGranuleAligned(params_ptr), then ResultEqual(result, RMI_ERROR_INPUT).

(params_pas) If !GranuleAccessPermitted(params_ptr, PAS_NS), then ResultEqual(result, RMI_ERROR_INPUT).

(params_valid) If !RmiRealmParamsIsValid(params_ptr), then ResultEqual(result, RMI_ERROR_INPUT).

(params_supp) If !RealmParamsSupported(params), then ResultEqual(result, RMI_ERROR_INPUT).

(alias) If AddrInRange(rd, params.rtt_base, (params.rtt_num_start - 1) * RMM_GRANULE_SIZE), then ResultEqual(result, RMI_ERROR_INPUT).

(rd_align) If !AddrIsGranuleAligned(rd), then ResultEqual(result, RMI_ERROR_INPUT).

(rd_bound) If !PaIsDelegableDram(rd), then ResultEqual(result, RMI_ERROR_INPUT).

(rd_state) If GranuleAt(rd).state != DELEGATED, then ResultEqual(result, RMI_ERROR_INPUT).

(rtt_align) If !AddrIsAligned(params.rtt_base, params.rtt_num_start * RMM_GRANULE_SIZE), then ResultEqual(result, RMI_ERROR_INPUT).

(rtt_num_level) If !RttConfigIsValid( params.s2sz, params.rtt_level_start, params.rtt_num_start), then ResultEqual(result, RMI_ERROR_INPUT).

(rtt_state) If !RttsStateEqual( params.rtt_base, params.rtt_num_start, DELEGATED), then ResultEqual(result, RMI_ERROR_INPUT).

(vmid_valid) If (!VmidsAreValid(params.vmid, params.aux_vmid) || !VmidsAreFree(params.vmid, params.aux_vmid)), then ResultEqual(result, RMI_ERROR_INPUT).

(mecid_bound) If UInt(params.mecid) > UInt(ImplFeatures().max_mecid), then ResultEqual(result, RMI_ERROR_INPUT).

(mecid_state) If MecState(params.mecid) == MEC_STATE_PRIVATE_ASSIGNED, then ResultEqual(result, RMI_ERROR_INPUT).

                B4.3.25.2.1   Failure condition ordering
                The RMI_REALM_CREATE command does not have any failure condition orderings.

                B4.3.25.3 Success conditions

(rd_state) On success, GranuleAt(rd).state == RD.

(realm_state) On success, realm.state == REALM_NEW.

(rec_index) On success, realm.rec_index == 0.

(rtt_base) On success, RealmRttBaseEqual( realm, params.rtt_base, params.aux_rtt_base).

(rtt_state) On success, RttsStateEqual( realm.rtt_base[[0]], realm.rtt_num_start, RTT).

(rtte_p_states) On success, RttsAllProtectedEntriesState( realm.rtt_base[[0]], realm.rtt_num_start, UNASSIGNED).

(rtte_up_states) On success, RttsAllUnprotectedEntriesState( realm.rtt_base[[0]], realm.rtt_num_start, UNASSIGNED_NS).

(rtte_ripas) On success, RttsAllProtectedEntriesRipas( realm.rtt_base[[0]], realm.rtt_num_start, EMPTY).

(lpa2) On success, Equal(realm.feat_lpa2, params.flags0.lpa2).

(ipa_width) On success, realm.ipa_width == params.s2sz.

(hash_algo) On success, Equal(realm.hash_algo, params.hash_algo).

(rim) On success, realm.measurements[[0]] == RimInit( realm.hash_algo, params).

(rem) On success, (realm.measurements[[1]] == Zeros( RMM_REALM_MEASUREMENT_WIDTH) && realm.measurements[[2]] == Zeros( RMM_REALM_MEASUREMENT_WIDTH) && realm.measurements[[3]] == Zeros( RMM_REALM_MEASUREMENT_WIDTH) && realm.measurements[[4]] == Zeros( RMM_REALM_MEASUREMENT_WIDTH)).

(rtt_level) On success, realm.rtt_level_start == params.rtt_level_start.

(rtt_num) On success, realm.rtt_num_start == params.rtt_num_start.

(vmid) On success, RealmVmidEqual( realm, params.vmid, params.aux_vmid).

(rpv) On success, realm.rpv == params.rpv.

(da) On success, Equal(realm.feat_da, params.flags0.da).

(ats) On success, Equal(realm.feat_ats, params.flags1.ats).

(ats_plane) On success, realm.ats_plane == params.ats_plane.

(rtt_tree_per_plane) On success, Equal(realm.rtt_tree_per_plane, params.flags1.rtt_tree_per_plane).

(num_aux_planes) On success, realm.num_aux_planes == params.num_aux_planes.

(rtt_s2ap_encoding) On success, Equal(realm.rtt_s2ap_encoding, params.flags1.rtt_s2ap_encoding).

(lfa_policy) On success, Equal(realm.lfa_policy, params.flags0.lfa_policy).

(mecid) On success, realm.mecid == params.mecid.

(mec_policy) On success, realm.mec_policy == MecPolicy(realm.mecid).

(mecid_private) If mec_state_pre == MEC_STATE_PRIVATE_UNASSIGNED, then on success MecState(params.mecid) == MEC_STATE_PRIVATE_ASSIGNED.

(mec_members) If mec_state_pre == MEC_STATE_SHARED, then on success MecMembers(params.mecid) == mec_members_pre + 1.

(num_recs) On success, realm.num_recs == 0.

(num_vdevs) On success, realm.num_vdevs == 0.

(num_vsmmus) On success, realm.num_vsmmus == 0.

                B4.3.25.4 RMI_REALM_CREATE initialization of RIM
                On successful execution of RMI_REALM_CREATE, the initial RIM value of the target Realm is calculated by the
                RMM as follows:
                  1. Allocate a zero-filled RmiRealmParams data structure to hold the measured Realm parameters.
                  2. Copy the following attributes from the Host-provided RmiRealmParams data structure into the measured
                     Realm parameters data structure:
                   • flags0
                   • s2sz
                   • sve_vl
                   • num_bps
                   • num_wps
                   • pmu_num_ctrs
                   • hash_algo
                  3. Using the RHA of the target Realm, compute the hash of the measured Realm parameters data structure. Set
                     the RIM of the target Realm to this value, zero filling upper bytes if the RHA output is smaller than the size
                     of the RIM.
