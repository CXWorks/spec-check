B4.3.38 RMI_RTT_CREATE command
                Creates a primary RTT.
                B4.3.38.1 Interface
                B4.3.38.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC400015D
        rd                    X1          63:0        Address                               PA of the RD for the target Realm
        rtt                   X2          63:0        Address                               PA of the target RTT
        ipa                   X3          63:0        Address                               Base of the IPA range described by the
                                                                                            RTT
        level                 X4          63:0        Int64                                 RTT level
                B4.3.38.1.2   Context
                The RMI_RTT_CREATE command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   RealmAt(rd)                                false    Realm
        walk                  RmmRttWalkResult           RttWalk(                                   false    RTT walk result
                                                             realm, ipa,
                                                             level - 1,
                                                             RMM_RTT_TREE_PRIMARY)
        entry_idx             UInt64                     RttEntryIndex(                             false    RTTE index
                                                             ipa, walk.level)
        walk_pre              RmmRttWalkResult           RttWalk(                                   true     RTT walk result
                                                             realm, ipa,                                     before command
                                                             level - 1,                                      execution
                                                             RMM_RTT_TREE_PRIMARY)
        rtte_pre              RmmRttEntry                walk_pre.rtte                              true     RTTE before
                                                                                                             command execution
                B4.3.38.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
               B4.3.38.2 Failure conditions
(rd_align) If !AddrIsGranuleAligned(rd), then ResultEqual(result, RMI_ERROR_INPUT).
(rd_bound) If !PaIsDelegable(rd), then ResultEqual(result, RMI_ERROR_INPUT).
(rd_state) If GranuleAt(rd).state != RD, then ResultEqual(result, RMI_ERROR_INPUT).
(level_bound) If (!RttLevelIsValid(realm, level) || RttLevelIsStarting(realm, level)), then ResultEqual(result, RMI_ERROR_INPUT).
(ipa_align) If !AddrIsRttLevelAligned(ipa, level - 1), then ResultEqual(result, RMI_ERROR_INPUT).
(ipa_bound) If UInt(ipa) >= (2 ^ realm.ipa_width), then ResultEqual(result, RMI_ERROR_INPUT).
(rtt_align) If !AddrIsGranuleAligned(rtt), then ResultEqual(result, RMI_ERROR_INPUT).
(rtt_bound) If !PaIsDelegableDram(rtt), then ResultEqual(result, RMI_ERROR_INPUT).
(rtt_state) If GranuleAt(rtt).state != DELEGATED, then ResultEqual(result, RMI_ERROR_INPUT).
(rtt_bound2) If ((realm.feat_lpa2 == FEATURE_FALSE) && (UInt(rtt) >= 2^48)), then ResultEqual(result, RMI_ERROR_INPUT).
(rtt_walk) If walk.level < level - 1, then ResultEqual(result, RMI_ERROR_RTT, walk.level).
(rtte_state) If walk.rtte.state == TABLE, then ResultEqual(result, RMI_ERROR_RTT, walk.level).
               B4.3.38.2.1       Failure condition ordering
               [rd_bound, rd_state] < [rtt_walk, rtte_state]
               [level_bound, ipa_bound] < [rtt_walk, rtte_state]
                    rtt_bound2     rtt_state   rtt_bound   rtt_align   ipa_align   rd_align   ipa_bound   level_bound       rd_state       rd_bound
                                                                                                                                          RMI_ERROR_INPUT
                                                                                                            rtte_state     rtt_walk
                                                                                                                         RMI_ERROR_RT
               B4.3.38.3 Success conditions
(rtt_state) On success, GranuleAt(rtt).state == RTT.
(rtte_state) On success, walk.rtte.state == TABLE.
(rtte_addr) On success, walk.rtte.addr == rtt.
(rtte_c_ripas) If AddrIsProtected(ipa, realm), then RttAllEntriesRipas(RttAt(rtt), rtte_pre.ripas).
(rtte_c_state) On success, RttAllEntriesState(RttAt(rtt), rtte_pre.state).
(rtte_c_addr) If (rtte_pre.state != UNASSIGNED && rtte_pre.state != UNASSIGNED_NS), then RttAllEntriesContiguous(RttAt(rtt), rtte_pre.addr, level).
                 B4.3.38.4 Footprint
    ID                        Value
    rtt_state                 GranuleAt(rtt).state
    rtte                      RttEntryAt(RttAt(walk.rtt_addr), entry_idx)
