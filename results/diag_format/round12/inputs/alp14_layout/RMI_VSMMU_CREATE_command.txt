B4.3.65 RMI_VSMMU_CREATE command
              Create a VSMMU.
              B4.3.65.1 Interface
              B4.3.65.1.1   Input values
        Name                Register    Bits        Type                                  Description
        fid                 X0          63:0        UInt64                                FID, value 0xC400016A
        rd                  X1          63:0        Address                               PA of the RD
        vsmmu_ptr           X2          63:0        Address                               PA of the VSMMU
        params_ptr          X3          63:0        Address                               PA of VSMMU parameters
              B4.3.65.1.2   Context
              The RMI_VSMMU_CREATE command operates on the following context.
        Name                Type                       Value                                      Before   Description
        realm_pre           RmmRealm                   RealmAt(rd)                                true     Realm
        realm               RmmRealm                   RealmAt(rd)                                false    Realm
        vsmmu               RmmVsmmu                   VsmmuAt(vsmmu_ptr)                         false    VSMMU
        params              RmiVsmmuParams             RmiVsmmuParamsAt(                          false    VSMMU parameters
                                                           params_ptr)
              B4.3.65.1.3   Output values
        Name                Register    Bits        Type                                  Description
        result              X0          63:0        RmiCommandReturnCode                  Command return status
              B4.3.65.2 Failure conditions
(da_supp) If ImplFeatures().feat_da != FEATURE_TRUE, then ResultEqual(result, RMI_ERROR_NOT_SUPPORTED).
(rd_align) If !AddrIsGranuleAligned(rd), then ResultEqual(result, RMI_ERROR_INPUT).
(rd_bound) If !PaIsDelegable(rd), then ResultEqual(result, RMI_ERROR_INPUT).
(rd_state) If GranuleAt(rd).state != RD, then ResultEqual(result, RMI_ERROR_INPUT).
(realm_state) If realm.state != REALM_NEW, then ResultEqual(result, RMI_ERROR_INPUT).
(vsmmu_align) If !AddrIsGranuleAligned(vsmmu_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(vsmmu_bound) If !PaIsDelegableDram(vsmmu_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(vsmmu_state) If GranuleAt(vsmmu_ptr).state != DELEGATED, then ResultEqual(result, RMI_ERROR_INPUT).
(params_align) If !AddrIsGranuleAligned(params_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(params_pas) If !GranuleAccessPermitted(params_ptr, PAS_NS), then ResultEqual(result, RMI_ERROR_INPUT).
(params_valid) If !RmiVsmmuParamsIsValid(params_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(reg_base_align) If (!AddrIsGranuleAligned(params.reg_base)
    || !AddrIsGranuleAligned(params.reg_top)), then ResultEqual(result, RMI_ERROR_INPUT).
(reg_base_bound) If (!AddrIsProtected(params.reg_base, realm)
                                                 || !AddrIsProtected(params.reg_top, realm)
    || UInt(params.reg_top) <= UInt(params.reg_base)), then ResultEqual(result, RMI_ERROR_INPUT).
                B4.3.65.2.1           Failure condition ordering
                [rd_bound, rd_state] < [realm_state]
                [da_supp] < [rd_align, rd_bound, rd_state, vsmmu_align, vsmmu_bound,
                     vsmmu_state, params_align, params_pas, params_valid,
                     reg_base_align, reg_base_bound]
                                                                                                                                                      da_supp
                                                                                                                                              RMI_ERROR_NOT _SUPPORT ED
                     reg_base_bound     reg_base_align   params_valid   params_pas   params_align   vsmmu_state   vsmmu_bound   vsmmu_align           rd_align            rd_state    rd_bound
                                                                                                                                                                                     realm_state
                                                                                                                                                                                      RMI_ERROR_INPUT
                B4.3.65.3 Success conditions
(gran_state) On success, GranuleAt(vsmmu_ptr).state == VSMMU.
(state) On success, vsmmu.state == VSMMU_INACTIVE.
(realm) On success, vsmmu.realm == rd.
(reg_base) On success, vsmmu.reg_base == params.reg_base.
(reg_top) On success, vsmmu.reg_top == params.reg_top.
(aidr) On success, vsmmu.aidr == params.aidr.
(idr) On success, (vsmmu.idr[[0]] == params.idr[[0]]
                                      && vsmmu.idr[[1]] == params.idr[[1]]
                                      && vsmmu.idr[[2]] == params.idr[[2]]
                                      && vsmmu.idr[[3]] == params.idr[[3]]
                                      && vsmmu.idr[[4]] == params.idr[[4]]
                                      && vsmmu.idr[[5]] == params.idr[[5]]
    && vsmmu.idr[[6]] == params.idr[[6]]).
(num_vsmmus) On success, realm.num_vsmmus == realm_pre.num_vsmmus + 1.
