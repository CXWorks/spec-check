B4.3.63 RMI_VDEV_VALIDATE_MAPPING command
               Completes a request made by the Realm to validate mappings to device memory from a target IPA range.
     Issue     In RMI_VDEV_VALIDATE_MAPPING, consider how to combine:
                  • Modification of a range of RTT entries in a single command, and
                  • Checking of output address and HIPAS values against rec.ripas_dev_pa.
               B4.3.63.1 Interface
               B4.3.63.1.1   Input values
        Name                 Register    Bits        Type                                  Description
        fid                  X0          63:0        UInt64                                FID, value 0xC4000163
        rd                   X1          63:0        Address                               PA of the RD for the target Realm
        rec_ptr              X2          63:0        Address                               PA of the target REC
        pdev_ptr             X3          63:0        Address                               PA of the PDEV
        vdev_ptr             X4          63:0        Address                               PA of the VDEV
        base                 X5          63:0        Address                               Base of target IPA region
        top                  X6          63:0        Address                               Top of target IPA region
               B4.3.63.1.2   Context
               The RMI_VDEV_VALIDATE_MAPPING command operates on the following context.
        Name                 Type                       Value                                      Before    Description
        realm                RmmRealm                   RealmAt(rd)                                false     Realm
        realm_pre            RmmRealm                   RealmAt(rd)                                true      Realm
        rec                  RmmRec                     RecAt(rec_ptr)                             false     REC
        pdev                 RmmPdev                    PdevAt(pdev_ptr)                           false     PDEV
        vdev                 RmmVdev                    VdevAt(vdev_ptr)                           false     VDEV
        pa_pre               Address                    rec.dev_mem_pa                             true      Output base address
        walk                 RmmRttWalkResult           RttWalk(                                   false     RTT walk result
                                                            realm, base,
                                                            RMM_RTT_PAGE_LEVEL,
                                                            RMM_RTT_TREE_PRIMARY)
        walk_top_pre         Address                    RttSkipEntriesWithRipas(                   true      Top IPA of entries
                                                            RttAt(walk.rtt_addr),                            which have associated
                                                            walk.level,                                      RIPAS values,
                                                            base, top,                                       starting from entry at
                                                            FALSE)                                           which the RTT walk
                                                                                                             terminated
               B4.3.63.1.3   Output values
        Name                 Register    Bits        Type                                  Description
        result               X0          63:0        RmiCommandReturnCode                  Command return status
        out_top              X1          63:0        Address                               Top IPA of range whose RIPAS was
                                                                                           modified
               The out_top output value is valid only when the command result is RMI_SUCCESS.
               B4.3.63.2 Failure conditions
(rd_align) If !AddrIsGranuleAligned(rd), then ResultEqual(result, RMI_ERROR_INPUT).
(rd_bound) If !PaIsDelegable(rd), then ResultEqual(result, RMI_ERROR_INPUT).
(rd_state) If GranuleAt(rd).state != RD, then ResultEqual(result, RMI_ERROR_INPUT).
(rec_align) If !AddrIsGranuleAligned(rec_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(rec_bound) If !PaIsDelegable(rec_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(rec_gran_state) If GranuleAt(rec_ptr).state != REC, then ResultEqual(result, RMI_ERROR_INPUT).
(rec_state) If rec.state == REC_RUNNING, then ResultEqual(result, RMI_ERROR_REC).
(rec_owner) If rec.owner != rd, then ResultEqual(result, RMI_ERROR_REC).
(pdev_align) If !AddrIsGranuleAligned(pdev_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(pdev_bound) If !PaIsDelegable(pdev_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(pdev_gran_state) If GranuleAt(pdev_ptr).state != PDEV, then ResultEqual(result, RMI_ERROR_INPUT).
(vdev_align) If !AddrIsGranuleAligned(vdev_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(vdev_bound) If !PaIsDelegable(vdev_ptr), then ResultEqual(result, RMI_ERROR_INPUT).
(vdev_gran_state) If GranuleAt(vdev_ptr).state != VDEV, then ResultEqual(result, RMI_ERROR_INPUT).
(vdev_pdev) If vdev.pdev != pdev_ptr, then ResultEqual(result, RMI_ERROR_DEVICE).
(size_valid) If UInt(top) <= UInt(base), then ResultEqual(result, RMI_ERROR_INPUT).
(base_bound) If base != rec.dev_mem_addr, then ResultEqual(result, RMI_ERROR_INPUT).
(top_bound) If UInt(top) > UInt(rec.dev_mem_top), then ResultEqual(result, RMI_ERROR_INPUT).
(base_align) If !AddrIsRttLevelAligned(base, walk.level), then ResultEqual(result, RMI_ERROR_RTT, walk.level).
(top_gran_align) If !AddrIsGranuleAligned(top), then ResultEqual(result, RMI_ERROR_INPUT).
(no_progress) If UInt(base) == UInt(walk_top_pre), then ResultEqual(result, RMI_ERROR_RTT, walk.level).
(ncoh_attr) If (rec.dev_mem_flags.coh == DEV_MEM_NON_COHERENT
                                        && !RttEntriesInRangeMemAttr(
                                                           RttAt(walk.rtt_addr),
                                                           walk.level,
                                                           base, walk_top_pre,
                                            MEMATTR_NON_CACHEABLE)), then ResultEqual(result, RMI_ERROR_RTT, walk.level).
(ncoh_pa) If (rec.dev_mem_flags.coh == DEV_MEM_NON_COHERENT
                                        && !RttEntriesInRangeNonCohDevMem(
                                                           RttAt(walk.rtt_addr),
                                                           walk.level,
                                            base, walk_top_pre)), then ResultEqual(result, RMI_ERROR_RTT, walk.level).
(coh_attr) If (rec.dev_mem_flags.coh == DEV_MEM_COHERENT
                                        && !RttEntriesInRangeMemAttr(
                                                           RttAt(walk.rtt_addr),
                                                           walk.level,
                                                           base, walk_top_pre,
                                            MEMATTR_PASSTHROUGH)), then ResultEqual(result, RMI_ERROR_RTT, walk.level).
(coh_pa) If (rec.dev_mem_flags.coh == DEV_MEM_COHERENT
                                        && !RttEntriesInRangeCohDevMem(
                                                           RttAt(walk.rtt_addr),
                                                           walk.level,
                                            base, walk_top_pre)), then ResultEqual(result, RMI_ERROR_RTT, walk.level).
(linear_map) If !RttEntriesInRangeOutputContiguous(
                                                           RttAt(walk.rtt_addr),
                                                           walk.level,
                                                           base, walk_top_pre,
                                        rec.dev_mem_pa), then ResultEqual(result, RMI_ERROR_RTT, walk.level).
(aux_live) If AddrRangeIsAuxLive(base, top, realm_pre), then ResultEqual(result, RMI_ERROR_RTT, walk.level).

               B4.3.63.3 Success conditions
(rtte_ripas) On success, RttEntriesInRangeRipas(
                                                           RttAt(walk.rtt_addr),
                                                           walk.level,
                                                           base, walk_top_pre,
                                                           DEV).
(dev_mem_addr) On success, rec.dev_mem_addr == MinAddress(top, walk_top_pre).
(dev_mem_pa) On success, rec.dev_mem_pa == ToAddress(
                                                           UInt(pa_pre) + (UInt(walk_top_pre) - UInt(base))).
(out_top) On success, out_top == MinAddress(top, walk_top_pre).
