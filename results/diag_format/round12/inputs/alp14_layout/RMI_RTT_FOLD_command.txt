B4.3.40 RMI_RTT_FOLD command
                Destroys a homogeneous primary RTT.
                B4.3.40.1 Interface
                B4.3.40.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000166
        rd                    X1          63:0        Address                               PA of the RD for the target Realm
        ipa                   X2          63:0        Address                               Base of the IPA range described by the
                                                                                            RTT
        level                 X3          63:0        Int64                                 RTT level
                B4.3.40.1.2   Context
                The RMI_RTT_FOLD command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   RealmAt(rd)                                false    Realm
        walk                  RmmRttWalkResult           RttWalk(                                   false    RTT walk result
                                                             realm, ipa,
                                                             level - 1,
                                                             RMM_RTT_TREE_PRIMARY)
        entry_idx             UInt64                     RttEntryIndex(                             false    RTTE index
                                                             ipa, walk.level)
        fold_pre              RmmRttEntry                RttFold(                                   true     Result of folding RTT
                                                             RttAt(walk.rtte.addr))
                B4.3.40.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
        rtt                   X1          63:0        Address                               PA of the RTT which was destroyed
                The rtt output value is valid only when the command result is RMI_SUCCESS.
                B4.3.40.2 Failure conditions

(rd_align) If !AddrIsGranuleAligned(rd), then ResultEqual(result, RMI_ERROR_INPUT).

(rd_bound) If !PaIsDelegable(rd), then ResultEqual(result, RMI_ERROR_INPUT).

(rd_state) If GranuleAt(rd).state != RD, then ResultEqual(result, RMI_ERROR_INPUT).

(level_bound) If (!RttLevelIsValid(realm, level) || RttLevelIsStarting(realm, level)), then ResultEqual(result, RMI_ERROR_INPUT).

(ipa_align) If !AddrIsRttLevelAligned(ipa, level - 1), then ResultEqual(result, RMI_ERROR_INPUT).

(ipa_bound) If UInt(ipa) >= (2 ^ realm.ipa_width), then ResultEqual(result, RMI_ERROR_INPUT).

(rtt_walk) If walk.level < level - 1, then ResultEqual(result, RMI_ERROR_RTT, walk.level).

(rtte_state) If walk.rtte.state != TABLE, then ResultEqual(result, RMI_ERROR_RTT, walk.level).

(rtt_homo) If !RttIsHomogeneous(RttAt(walk.rtte.addr)), then ResultEqual(result, RMI_ERROR_RTT, level).

(aux_ref) If AddrIsAuxRef(ipa, realm), then ResultEqual(result, RMI_ERROR_RTT, walk.level).

               B4.3.40.2.1   Failure condition ordering
               [rd_bound, rd_state] < [rtt_walk, rtte_state, rtt_homo, aux_ref]
               [level_bound, ipa_bound] < [rtt_walk, rtte_state]
                       ipa_align       rd_align        ipa_bound           level_bound          rd_state        rd_bound
                                                                                                               RMI_ERROR_INPUT
                                            aux_ref        rtt_homo          rtte_state        rtt_walk
                                                                                              RMI_ERROR_RT

               B4.3.40.3 Success conditions

(rtte_state) On success, walk.rtte.state == fold_pre.state.

(rtte_addr) If (fold_pre.state != UNASSIGNED && fold_pre.state != UNASSIGNED_NS), then walk.rtte.addr == fold_pre.addr.

(rtte_attr_prot) If fold_pre.state == ASSIGNED, then (RttMemAttrEqual(walk.rtte, fold_pre, RTT_PROTECTED) && RttS2APEqual(walk.rtte, fold_pre, S2AP_INDIRECT)).

(rtte_attr_unprot) If fold_pre.state == ASSIGNED_NS, then (RttMemAttrEqual(walk.rtte, fold_pre, RTT_UNPROTECTED) && RttS2APEqual(walk.rtte, fold_pre, realm.rtt_s2ap_encoding)).

(rtte_ripas) If AddrIsProtected(ipa, realm), then walk.rtte.ripas == fold_pre.ripas.

(rtt_state) On success, GranuleAt(walk.rtte.addr).state == DELEGATED.

(rtt) On success, rtt == walk.rtte.addr.
                    B4.3.40.4 Footprint
        ID                       Value
        rtt_state                GranuleAt(walk.rtte.addr).state
        rtte                     RttEntryAt(RttAt(walk.rtt_addr), entry_idx)
