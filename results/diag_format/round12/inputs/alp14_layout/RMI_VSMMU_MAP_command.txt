B4.3.67 RMI_VSMMU_MAP command
                Create a VSMMU mapping.
                B4.3.67.1 Interface
                B4.3.67.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC400016C
        rd                    X1          63:0        Address                               PA of the RD
        vsmmu_ptr             X2          63:0        Address                               PA of the VSMMU
        ipa                   X3          63:0        Address                               IPA at which to create the mapping
        level                 X4          63:0        Int64                                 RTT level
                B4.3.67.1.2   Context
                The RMI_VSMMU_MAP command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   RealmAt(rd)                                false    Realm
        vsmmu                 RmmVsmmu                   VsmmuAt(vsmmu_ptr)                         false    VSMMU
        walk                  RmmRttWalkResult           RttWalk(                                   false    RTT walk result
                                                             realm, ipa, level,
                                                             RMM_RTT_TREE_PRIMARY)
        entry_idx             UInt64                     RttEntryIndex(                             false    RTTE index
                                                             ipa, walk.level)
                B4.3.67.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.67.2 Failure conditions

(da_supp) If ImplFeatures().feat_da != FEATURE_TRUE, then ResultEqual(result, RMI_ERROR_NOT_SUPPORTED).

(rd_align) If !AddrIsGranuleAligned(rd), then ResultEqual(result, RMI_ERROR_INPUT).

(rd_bound) If !PaIsDelegable(rd), then ResultEqual(result, RMI_ERROR_INPUT).

(rd_state) If GranuleAt(rd).state != RD, then ResultEqual(result, RMI_ERROR_INPUT).

(level_bound) If (!RttLevelIsValid(realm, level) || level < 2), then ResultEqual(result, RMI_ERROR_INPUT).

(realm_state) If realm.state != REALM_NEW, then ResultEqual(result, RMI_ERROR_INPUT).

(vsmmu_align) If !AddrIsGranuleAligned(vsmmu_ptr), then ResultEqual(result, RMI_ERROR_INPUT).

(vsmmu_bound) If !PaIsDelegable(vsmmu_ptr), then ResultEqual(result, RMI_ERROR_INPUT).

(vsmmu_state) If GranuleAt(vsmmu_ptr).state != VSMMU, then ResultEqual(result, RMI_ERROR_INPUT).

(ipa_align) If !AddrIsRttLevelAligned(ipa, level), then ResultEqual(result, RMI_ERROR_INPUT).

(ipa_bound) If UInt(ipa) < UInt(vsmmu.reg_base), then ResultEqual(result, RMI_ERROR_INPUT).

(rtt_walk) If walk.level < level, then ResultEqual(result, RMI_ERROR_RTT, walk.level).

(rtte_state) If walk.rtte.state != UNASSIGNED, then ResultEqual(result, RMI_ERROR_RTT, walk.level).

(rtte_ripas) If walk.rtte.ripas != EMPTY, then ResultEqual(result, RMI_ERROR_RTT, walk.level).

(rtte_bound) If (UInt(ipa) + (RttLevelSize(walk.level) - 1) >= UInt(vsmmu.reg_top)), then ResultEqual(result, RMI_ERROR_RTT, walk.level).

                B4.3.67.2.1          Failure condition ordering
                [rd_bound, rd_state] < [realm_state]
                [rd_bound, rd_state] < [rtt_walk, rtte_state, rtte_ripas, rtte_bound]
                [vsmmu_state] < [rtte_bound]
                [da_supp] < [vsmmu_align, vsmmu_bound, vsmmu_state]
                                                                                                                    da_supp
                                                                                                            RMI_ERROR_NOT _SUPPORT ED
                    ipa_bound   ipa_align   level_bound   rd_align   rd_state    rd_bound     vsmmu_bound        vsmmu_align            vsmmu_state
                                                                                realm_state                                                                  rtte_ripas   rtte_state   rtt_walk   rtte_bound
                                                                                                                                           RMI_ERROR_INPUT                                         RMI_ERROR_RT

                B4.3.67.3 Success conditions

(rtte_state) On success, walk.rtte.state == ASSIGNED_VSMMU.

(rtte_addr) On success, walk.rtte.addr == vsmmu_ptr.
              B4.3.67.4 Footprint
    ID                        Value
    rtte                      RttEntryAt(RttAt(walk.rtt_addr), entry_idx)
