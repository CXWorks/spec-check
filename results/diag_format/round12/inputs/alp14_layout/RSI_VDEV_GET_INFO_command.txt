B5.3.17 RSI_VDEV_GET_INFO command
                Get information for a device.
                Device configuration information, including digests of attestation evidence for the device are written to an
                RsiVdevInfo structure, at an address specified by the caller. Digests are calculated using the PDEV Hash
                Algorithm.
                B5.3.17.1 Interface
                B5.3.17.1.1    Input values
         Name                 Register     Bits        Type                                  Description
         fid                  X0           63:0        UInt64                                FID, value 0xC400019D
         vdev_id              X1           63:0        Bits64                                Realm device identifier
         addr                 X2           63:0        Address                               IPA to which the configuration data will
                                                                                             be written
                B5.3.17.1.2    Context
                The RSI_VDEV_GET_INFO command operates on the following context.
         Name                 Type                        Value                                      Before    Description
         realm                RmmRealm                    CurrentRealm()                             false     Current Realm
         vdev                 RmmVdev                     VdevFromVdevId(                            false     Realm device
                                                              realm,
                                                              vdev_id)
         pdev                 RmmPdev                     PdevAt(vdev.pdev)                          false     Physical device
         cfg                  RsiVdevInfo                 RsiVdevInfoAt(addr)                        false     Device configuration
         walk                 RmmRttWalkResult            RttWalk(                                   false     RTT walk result
                                                              realm, addr,
                                                              RMM_RTT_PAGE_LEVEL,
                                                              RMM_RTT_TREE_PRIMARY)
                B5.3.17.1.3    Output values
         Name                 Register     Bits        Type                                  Description
         result               X0           63:0        RsiCommandReturnCode                  Command return status
                B5.3.17.2 Failure conditions
(da_en) If realm.feat_da != FEATURE_TRUE, then result == RSI_ERROR_STATE.
(vdev_id) If VdevIdIsFree(realm, vdev_id), then result == RSI_ERROR_INPUT.
(addr_align) If !AddrIsAligned(addr, 512), then result == RSI_ERROR_INPUT.
(addr_bound) If !AddrIsProtected(addr, realm), then result == RSI_ERROR_INPUT.
(addr_empty) If walk.rtte.ripas == EMPTY, then result == RSI_ERROR_INPUT.
                B5.3.17.2.1   Failure condition ordering
                [da_en] < [vdev_id, addr_align, addr_bound]
                                                                                                              da_en
                                                                                                           RSI_ERROR_STAT E
                              addr_empty                addr_bound                  addr_align               vdev_id
                                                                                                           RSI_ERROR_INPUT
                B5.3.17.3 Success conditions
(hash_algo) On success, Equal(cfg.hash_algo, pdev.hash_algo).
(p2p_enabled) On success, Equal(cfg.flags.p2p_enabled, pdev.p2p_enabled).
(p2p_bound) On success, Equal(cfg.flags.p2p_bound, vdev.p2p_bound).
(p2p_peer) On success, cfg.p2p_peer == vdev.p2p_peer.
(attest_info) On success, VdevAttestInfoEqual(
                                         cfg.lock_nonce,
                                         cfg.meas_nonce,
                                         cfg.report_nonce,
                                         vdev.attest_info).
(vca_digest) On success, cfg.vca_digest == pdev.vca_digest.
(meas_digest) On success, cfg.meas_digest == vdev.meas_digest.
(report_digest) On success, cfg.report_digest == vdev.report_digest.
(state) On success, Equal(cfg.state, vdev.vdev_state).
             B5.3.17.4 Footprint
             The RSI_VDEV_GET_INFO command does not have any footprint.
