B5.3.10 VCI_MEM_SET_PERM_INDEX

B5.3.10.1 Intended use
VCI_MEM_SET_PERM_INDEX sets the overlay permission index for a specified LBA range.

The command operates on the current Vault and the current WORKER. These are the Vault and WORKER from which the command is called.

B5.3.10.2 Parameters
The caller passes the following input values:
• fid, passed in R0 (bits 63:0), is the function identifier. Its value is 0xC40001A1.
• base, passed in R1 (bits 63:0), is the base of the target LBA region.
• top, passed in R2 (bits 63:0), is the top of the target LBA region.
• perm_index, passed in R3 (bits 63:0), is the permission index.
• cookie, passed in R4 (bits 63:0), is the cookie value.

B5.3.10.3 Return values
The command returns the following output values:
• result, returned in R0 (bits 63:0), is the command return status.
• new_base, returned in R1 (bits 63:0), is the base of the LBA region that the command did not modify.
• response, returned in R2 (bit 0), shows whether the Host accepted or rejected the request.
• new_cookie, returned in R3 (bits 63:0), is the new cookie value.

The unused bits of the output values, R2[63:1], must be zero.

B5.3.10.4 Caller responsibilities
VCI_MEM_SET_PERM_INDEX can return the following errors:
• VCI_ERROR_INPUT is returned if base is not aligned to the size of a Extent.
• VCI_ERROR_INPUT is returned if top is not aligned to the size of a Extent.
• VCI_ERROR_INPUT is returned if top is less than or equal to base, with both values compared as unsigned integers.
• VCI_ERROR_INPUT is returned if the address range from base to top is not entirely within the Protected LBA space of the Vault.
• VCI_ERROR_INPUT is returned if perm_index is greater than or equal to KEEPER_NUM_PERM_OVERLAY_INDICES.
• VCI_ERROR_INPUT is returned if the cookie is invalid.

There is no required order among these failure conditions.

B5.3.10.5 Implementation responsibilities
When VCI_MEM_SET_PERM_INDEX succeeds, the implementation must ensure that:
• The Vault's overlay lock state for permission index perm_index is MEM_PERM_LOCKED.
• new_base equals the stage 2 access permission address recorded in the WORKER (xap_addr).
• response is the WORKER's stage 2 access permission response, converted to its VCI encoding.
• A new cookie is generated.

The only state that VCI_MEM_SET_PERM_INDEX may modify is the Vault's overlay lock state for permission index perm_index.
