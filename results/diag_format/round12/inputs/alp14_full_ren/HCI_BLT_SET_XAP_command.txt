B4.3.45 HCI_BLT_SET_XAP

B4.3.45.1 Intended use
HCI_BLT_SET_XAP completes a request made by the Vault to change the XAP of a target LBA range.

The command operates on the Vault described by vd and on the WORKER at worker_ptr. It also uses the result of a walk of the Blts of that Vault over the range from base to top, to BLT level KEEPER_BLT_PAGE_LEVEL. This walk returns any BLT entry that is not aligned to page level. In this section, that entry is called the unaligned BLT entry.

B4.3.45.2 Parameters
The caller passes the following input values:
•  fid is passed in R0. It is the function identifier and has the value 0xC400018B.
•  vd is passed in R1. It is the physical address of the VD for the target Vault.
•  worker_ptr is passed in R2. It is the physical address of the target WORKER.
•  base is passed in R3. It is the base of the target LBA region.
•  top is passed in R4. It is the top of the target LBA region.

B4.3.45.3 Return values
The implementation returns the following output values:
•  result is returned in R0. It is the command return status.
•  out_top is returned in R1. It is the top LBA of the range whose XAP was modified.
•  blt_tree is returned in R2. It is the index of the BLT tree in which the base alignment check failed.

If result is HCI_ERROR_BLT or HCI_ERROR_BLT_AUX, then:
•  out_top is the LBA of the BLTE at which the base alignment check failed.
•  blt_tree is the index of the BLT in which the base alignment check failed.

B4.3.45.4 Caller responsibilities
HCI_BLT_SET_XAP can return the following errors:
•  HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.
•  HCI_ERROR_INPUT is returned if vd is not a enrollable physical address.
•  HCI_ERROR_INPUT is returned if the state of the Extent at vd is not VD.
•  HCI_ERROR_INPUT is returned if worker_ptr is not aligned to the size of a Extent.
•  HCI_ERROR_INPUT is returned if worker_ptr is not a enrollable physical address.
•  HCI_ERROR_INPUT is returned if the state of the Extent at worker_ptr is not WORKER.
•  HCI_ERROR_WORKER is returned if the state of the WORKER is WORKER_RUNNING.
•  HCI_ERROR_WORKER is returned if the WORKER is not owned by the Vault described by vd.
•  HCI_ERROR_INPUT is returned if top, read as an unsigned value, is less than or equal to base.
•  HCI_ERROR_INPUT is returned if base is not the same as the WORKER's xap_addr value.
•  HCI_ERROR_INPUT is returned if top, read as an unsigned value, is greater than the WORKER's xap_top value.
•  HCI_ERROR_INPUT is returned if top is not aligned to the size of a Extent.
•  HCI_ERROR_BLT is returned, together with the BLT level of the entry, if all of the following are true for the unaligned BLT entry:
   –  The unaligned BLT entry is valid (KEEPER_TRUE).
   –  The range from base to top is not within the address range of that entry. This address range runs from the entry's address aligned down to the entry's BLT level, to the entry's address aligned up to that level.
   –  The entry is in the primary BLT tree (KEEPER_BLT_TREE_PRIMARY).
   –  The entry's stage 2 access permission overlay index is not the same as the WORKER's xap_overlay_index.
•  HCI_ERROR_BLT_AUX is returned, together with the BLT level of the entry, if all of the following are true for the unaligned BLT entry:
   –  The unaligned BLT entry is valid (KEEPER_TRUE).
   –  The range from base to top is not within the address range of that entry. This address range runs from the entry's address aligned down to the entry's BLT level, to the entry's address aligned up to that level.
   –  The entry is not in the primary BLT tree (KEEPER_BLT_TREE_PRIMARY), which means that it is in an auxiliary BLT tree.
   –  The entry's stage 2 access permission overlay index is not the same as the WORKER's xap_overlay_index.

HCI_BLT_SET_XAP has no defined ordering between these failure conditions.

B4.3.45.5 Implementation responsibilities
If the command succeeds, the implementation sets the WORKER's xap_addr to the value of out_top.

The only state that HCI_BLT_SET_XAP can modify is the xap_addr value of the WORKER at worker_ptr.
