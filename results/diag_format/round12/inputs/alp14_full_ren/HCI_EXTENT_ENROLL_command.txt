B4.3.5 HCI_EXTENT_ENROLL

B4.3.5.1 Intended use
HCI_EXTENT_ENROLL enrolls a Extent. The caller passes the physical address of the target Extent, and the KEEPER moves that Extent from the UNENROLLED state to the ENROLLED state.

B4.3.5.2 Parameters
HCI_EXTENT_ENROLL takes the following input values:
•  fid, passed in R0 (bits 63:0). This is the function identifier, and its value is 0xC4000151.
•  addr, passed in R1 (bits 63:0). This is the physical address (DPA) of the target Extent.

B4.3.5.3 Return values
HCI_EXTENT_ENROLL returns the following output value:
•  result, returned in R0 (bits 63:0). This is the command return status.

HCI_EXTENT_ENROLL can return the following errors:
•  HCI_ERROR_INPUT is returned if addr is not aligned to the size of a Extent.
•  HCI_ERROR_INPUT is returned if addr is not a physical address that can be enrolled.
•  HCI_ERROR_INPUT is returned if the Extent at addr is not in the UNENROLLED state.

HCI_EXTENT_ENROLL does not define any ordering between these failure conditions.

B4.3.5.4 Implementation responsibilities
If the command succeeds, the KEEPER must make sure that:
•  The Extent at addr is in the ENROLLED state.
•  The Extent Protection Table entry for the Extent at addr is GUARDMAP_VAULT.

HCI_EXTENT_ENROLL can modify only the following state:
•  The Extent Protection Table entry of the Extent at addr.
•  The state of the Extent at addr.
