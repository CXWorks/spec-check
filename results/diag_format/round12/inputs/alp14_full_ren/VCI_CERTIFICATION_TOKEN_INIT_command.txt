B5.3.2 VCI_CERTIFICATION_TOKEN_INIT

B5.3.2.1 Intended use
VCI_CERTIFICATION_TOKEN_INIT starts the process of retrieving an certification token. When a Vault needs an certification token, it calls this command and provides a challenge value.

The command acts on the Vault that makes the call and on the WORKER that makes the call.

B5.3.2.2 Parameters
VCI_CERTIFICATION_TOKEN_INIT takes the following input values:
• fid is passed in R0. It is the function identifier, and its value is 0xC4000194.
• challenge_0 is passed in R1. It is doubleword 0 of the challenge value.
• challenge_1 is passed in R2. It is doubleword 1 of the challenge value.
• challenge_2 is passed in R3. It is doubleword 2 of the challenge value.
• challenge_3 is passed in R4. It is doubleword 3 of the challenge value.
• challenge_4 is passed in R5. It is doubleword 4 of the challenge value.
• challenge_5 is passed in R6. It is doubleword 5 of the challenge value.
• challenge_6 is passed in R7. It is doubleword 6 of the challenge value.
• challenge_7 is passed in R8. It is doubleword 7 of the challenge value.

B5.3.2.3 Return values
VCI_CERTIFICATION_TOKEN_INIT returns the following output values:
• result is returned in R0. It is the command return status.
• size is returned in R1. It is an upper bound, in bytes, on the size of the certification token.

VCI_CERTIFICATION_TOKEN_INIT has no failure conditions. Because there are no failure conditions, there is no ordering between them.

B5.3.2.4 Implementation responsibilities
After a successful call to VCI_CERTIFICATION_TOKEN_INIT, the implementation must make sure that:
• The certification state of the WORKER is CERTIFY_IN_PROGRESS.
• The certification challenge of the WORKER is challenge_0, challenge_1, challenge_2, challenge_3, challenge_4, challenge_5, challenge_6 and challenge_7 joined together in that order, starting with challenge_0.
• size is the maximum size of the certification token for the Vault.

VCI_CERTIFICATION_TOKEN_INIT can change only these items of state:
• The certification state of the WORKER.
• The certification challenge of the WORKER.
