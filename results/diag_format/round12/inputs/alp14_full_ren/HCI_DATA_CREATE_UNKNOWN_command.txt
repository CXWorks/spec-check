B4.3.2 HCI_DATA_CREATE_UNKNOWN

B4.3.2.1 Intended use
HCI_DATA_CREATE_UNKNOWN creates a Data Extent with unknown contents. The Host calls this command with three inputs: a Extent that is in the ENROLLED state, the VD of the target Vault, and the LBA in the target Vault at which the Extent will be mapped.

The command acts on the Vault that the VD at vd describes. It walks the Blts of that Vault for lba, to the page level of the primary BLT tree. The BLT entry it uses is the entry for lba at the level where this walk ends.

B4.3.2.2 Parameters
The function ID and input values are passed as follows:
• fid is passed in R0. It is the function ID of HCI_DATA_CREATE_UNKNOWN and has the value 0xC4000154.
• vd is passed in R1. It is the physical address of the VD for the target Vault.
• data is passed in R2. It is the physical address of the target Data Extent.
• lba is passed in R3. It is the LBA at which the Extent will be mapped in the target Vault.

B4.3.2.3 Return values
The output value is returned as follows:
• result is returned in R0. It is the command return status.

HCI_DATA_CREATE_UNKNOWN can return the following errors:
• HCI_ERROR_INPUT is returned if data is not aligned to the size of a Extent.
• HCI_ERROR_INPUT is returned if data is not a enrollable physical address in DRAM.
• HCI_ERROR_INPUT is returned if the Extent at data is not in the ENROLLED state.
• HCI_ERROR_INPUT is returned if the Vault does not support BIGADDR (its feat_bigaddr attribute is FEATURE_FALSE) and data is equal to or greater than 2^48.
• HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.
• HCI_ERROR_INPUT is returned if vd is not a enrollable physical address.
• HCI_ERROR_INPUT is returned if the Extent at vd is not in the VD state.
• HCI_ERROR_INPUT is returned if lba is not aligned to the size of a Extent.
• HCI_ERROR_INPUT is returned if lba is not within the Protected LBA space of the Vault.
• HCI_ERROR_BLT is returned if the BLT walk for lba ends at a level above the page level. The error is returned together with the level at which the walk ended.
• HCI_ERROR_BLT is returned if the BLT entry found by the BLT walk for lba is not in the UNASSIGNED state. The error is returned together with the level at which the walk ended.

The failure conditions are checked in the following order:
• Two HCI_ERROR_BLT checks depend on earlier checks. The first is that the BLT walk reaches the page level. The second is that the BLT entry is in the UNASSIGNED state.
• The check that vd is a enrollable physical address is made before both HCI_ERROR_BLT checks.
• The check that the Extent at vd is in the VD state is made before both HCI_ERROR_BLT checks.
• The check that lba is within the Protected LBA space of the Vault is made before both HCI_ERROR_BLT checks.

B4.3.2.4 Implementation responsibilities
When HCI_DATA_CREATE_UNKNOWN succeeds, the implementation must ensure the following:
• The Extent at data is in the DATA state.
• The contents of the target Extent are wiped.
• The BLT entry found by the BLT walk for lba is in the ASSIGNED state.
• The output address of that BLT entry is data.
• The memory attribute of that BLT entry is MEMATTR_CACHEABLE.
• The shareability of that BLT entry is SHAREABILITY_INNER.

HCI_DATA_CREATE_UNKNOWN can modify only the following state:
• The state of the Extent at data.
• The BLT entry for lba. This is the entry in the BLT at which the BLT walk for lba ended.
