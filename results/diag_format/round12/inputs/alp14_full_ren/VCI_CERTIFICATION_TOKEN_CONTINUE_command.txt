B5.3.1 VCI_CERTIFICATION_TOKEN_CONTINUE

B5.3.1.1 Intended use
VCI_CERTIFICATION_TOKEN_CONTINUE continues the operation to retrieve an certification token. The Vault calls it on the current WORKER and provides the LBA of a Extent, plus an offset and size that describe a buffer within that Extent. The KEEPER writes part of the certification token into that buffer.

The command acts on the current Vault and the current WORKER. To locate the Extent at addr, the KEEPER walks the primary BLT of the current Vault at page level, using addr as the address.

B5.3.1.2 Parameters
The caller provides these input values:
•  fid is passed in R0. It is the function identifier, and its value is 0xC4000195.
•  addr is passed in R1. It is the LBA of the Extent that the token is written to.
•  offset is passed in R2. It is the offset in bytes from the start of the Extent to the start of the buffer.
•  size is passed in R3. It is the size of the buffer in bytes.

B5.3.1.3 Return values
The command returns these output values:
•  result is returned in R0. It is the command return status.
•  len is returned in R1. It is the number of bytes written to the buffer.

B5.3.1.4 Caller responsibilities
Before calling VCI_CERTIFICATION_TOKEN_CONTINUE, the caller must make sure that:
•  addr is aligned to the size of a Extent.
•  addr is a Protected LBA of the Vault, and the LBAMODE of the Vault LBA addr is not EMPTY.
•  offset is less than KEEPER_EXTENT_SIZE.
•  Adding size to offset does not overflow, and offset plus size is not greater than KEEPER_EXTENT_SIZE.
•  The certification state of the calling WORKER is CERTIFY_IN_PROGRESS.

VCI_CERTIFICATION_TOKEN_CONTINUE can return these errors:
•  VCI_ERROR_INPUT is returned if addr is not aligned to the size of a Extent.
•  VCI_ERROR_INPUT is returned if addr is not a Protected LBA of the Vault.
•  VCI_ERROR_INPUT is returned if the LBAMODE of the Vault LBA addr is EMPTY.
•  VCI_ERROR_INPUT is returned if offset is greater than or equal to KEEPER_EXTENT_SIZE.
•  VCI_ERROR_INPUT is returned if adding size to offset overflows, so that the sum is smaller than offset.
•  VCI_ERROR_INPUT is returned if offset plus size is greater than KEEPER_EXTENT_SIZE.
•  VCI_ERROR_STATE is returned if the certification state of the calling WORKER is not CERTIFY_IN_PROGRESS.
•  VCI_ERROR_UNKNOWN is returned if token generation failed for an unknown or IMPLEMENTATION DEFINED reason.

These failure conditions have no defined order.

B5.3.1.5 Implementation responsibilities
On success, VCI_CERTIFICATION_TOKEN_CONTINUE must:
•  Write bytes of the certification token to the Extent at addr, starting at offset and writing no more than size bytes. It returns the number of bytes written in len.
•  Return VCI_INCOMPLETE if token generation is not complete.
•  Change the certification state of the calling WORKER to NO_CERTIFY_IN_PROGRESS if token generation is complete.

The only state this command may modify is the certification state of the calling WORKER.
