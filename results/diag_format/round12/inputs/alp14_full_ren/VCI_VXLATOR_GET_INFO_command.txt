B5.3.22 VCI_VXLATOR_GET_INFO

B5.3.22.1 Intended use
VCI_VXLATOR_GET_INFO gets information about a VXLATOR. A Vault calls VCI_VXLATOR_GET_INFO with the base LBA of a VXLATOR, and the command returns the top LBA of that VXLATOR.

The command operates on the current Vault, which is the Vault that makes the call. The BLT entry the command checks is the entry found by walking the current Vault's primary BLT tree to addr, at page level.

B5.3.22.2 Parameters
The input values are:
• fid, passed in R0. This is the function identifier for VCI_VXLATOR_GET_INFO. Its value is 0xC400019A.
• addr, passed in R1. This is the base LBA of the VXLATOR.

B5.3.22.3 Return values
The output values are:
• result, returned in R0. This is the command return status.
• top, returned in R1. This is the top LBA of the VXLATOR.

VCI_VXLATOR_GET_INFO can return the following errors:
• VCI_ERROR_INPUT is returned if addr is not aligned to the size of a Extent.
• VCI_ERROR_INPUT is returned if addr is not a Protected LBA of the Vault.
• VCI_ERROR_INPUT is returned if the BLT entry found by walking the Vault's BLT to addr is not in the ASSIGNED_VXLATOR state.
• VCI_ERROR_INPUT is returned if addr is not the register base address of the VXLATOR that the BLT entry found by walking the Vault's BLT to addr refers to.

There is no required order between these failure conditions.

If the command succeeds, top is the register top address of the VXLATOR that the BLT entry found by walking the Vault's BLT to addr refers to.

B5.3.22.4 Implementation responsibilities
VCI_VXLATOR_GET_INFO has no footprint. The command does not modify any state.
