B4.3.37 RMI_RTT_AUX_UNMAP_UNPROTECTED

B4.3.37.1 Intended use
RMI_RTT_AUX_UNMAP_UNPROTECTED removes a valid descriptor or a table descriptor at an Unprotected IPA from the starting level of an auxiliary RTT.

The Host passes the RD of the target Realm, an IPA in that Realm, and the index of an RTT tree. The command walks the auxiliary RTT tree that index identifies. The walk starts at the Realm's starting RTT level and goes towards ipa. The command acts on the RTT entry where the walk ends. That entry is the entry in the RTT that the walk reached, at the index that ipa selects at the level where the walk ended.

The command also reports the top IPA of non-live RTT entries in the starting level RTT. The command finds this value by starting at the entry where the RTT walk ended and skipping the non-live entries that follow it in that RTT.

B4.3.37.2 Parameters
The RMI_RTT_AUX_UNMAP_UNPROTECTED command takes the following input values:
•  fid, passed in X0, bits 63:0, is the function identifier. Its value is 0xC4000184.
•  rd, passed in X1, bits 63:0, is the physical address of the RD for the target Realm.
•  ipa, passed in X2, bits 63:0, is an IPA in the target Realm.
•  index, passed in X3, bits 63:0, is the RTT tree index.

B4.3.37.3 Return values
The RMI_RTT_AUX_UNMAP_UNPROTECTED command returns the following output values:
•  result, returned in X0, bits 63:0, is the command return status.
•  top, returned in X1, bits 63:0, is the top IPA of non-live RTT entries in the starting level RTT, counted from the entry where the RTT walk ended.

B4.3.37.4 Caller responsibilities
RMI_RTT_AUX_UNMAP_UNPROTECTED can return the following errors:
•  RMI_ERROR_INPUT is returned if rd is not aligned to the size of a Granule.
•  RMI_ERROR_INPUT is returned if rd is not a physical address that can be delegated.
•  RMI_ERROR_INPUT is returned if the Granule at rd is not in the RD state.
•  RMI_ERROR_INPUT is returned if ipa is not aligned to the size of the address range that one RTT entry maps at the Realm's starting RTT level.
•  RMI_ERROR_INPUT is returned if either of the following is true:
   –  ipa is equal to or greater than 2 to the power of the Realm's IPA width.
   –  ipa is a Protected IPA of the Realm.
•  RMI_ERROR_INPUT is returned if any of the following is true:
   –  The Realm does not use a separate RTT tree for each Plane. That is, its rtt_tree_per_plane value is FEATURE_FALSE.
   –  index is RMM_RTT_TREE_PRIMARY.
   –  index is greater than the Realm's number of auxiliary Planes.

These failure conditions have no defined order among them.

B4.3.37.5 Implementation responsibilities
When the command succeeds:
•  The RTT entry that the RTT walk reaches is in the UNASSIGNED_NS state.
•  The output value top is equal to the top IPA of non-live RTT entries that the RTT walk produces.

The command may modify only the RTT entry where the RTT walk ended, which is the entry at the index that ipa selects in the RTT that the walk reached.
