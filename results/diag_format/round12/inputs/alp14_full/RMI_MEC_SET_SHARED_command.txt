B4.3.8 RMI_MEC_SET_SHARED

B4.3.8.1 Intended use
RMI_MEC_SET_SHARED is used to change the state of a MEC to Shared.

B4.3.8.2 Parameters
RMI_MEC_SET_SHARED takes the following input values:
•  fid, passed in X0. This is the function identifier, and its value is 0xC400018C.
•  mecid, passed in X1. This is the MECID of the MEC whose state is to be changed. It is a 64-bit value.

B4.3.8.3 Return values
RMI_MEC_SET_SHARED returns the following output value:
•  result, returned in X0. This is the command return status.

B4.3.8.4 Caller responsibilities
RMI_MEC_SET_SHARED can return the following errors:
•  RMI_ERROR_INPUT is returned if mecid is greater than the maximum MECID that the implementation supports.
•  RMI_ERROR_INPUT is returned if the MEC state of mecid is not MEC_STATE_PRIVATE_UNASSIGNED.

There is no required ordering between these failure conditions.

B4.3.8.5 Implementation responsibilities
On success, the MEC state of mecid is MEC_STATE_SHARED.

The only state that RMI_MEC_SET_SHARED may modify is the MEC state of mecid.
