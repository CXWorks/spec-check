B5.3.1 RSI_ATTESTATION_TOKEN_CONTINUE

B5.3.1.1 Intended use
RSI_ATTESTATION_TOKEN_CONTINUE continues the operation to retrieve an attestation token. The Realm calls it on the current REC and provides the IPA of a Granule, plus an offset and size that describe a buffer within that Granule. The RMM writes part of the attestation token into that buffer.

The command acts on the current Realm and the current REC. To locate the Granule at addr, the RMM walks the primary RTT of the current Realm at page level, using addr as the address.

B5.3.1.2 Parameters
The caller provides these input values:
•  fid is passed in X0. It is the function identifier, and its value is 0xC4000195.
•  addr is passed in X1. It is the IPA of the Granule that the token is written to.
•  offset is passed in X2. It is the offset in bytes from the start of the Granule to the start of the buffer.
•  size is passed in X3. It is the size of the buffer in bytes.

B5.3.1.3 Return values
The command returns these output values:
•  result is returned in X0. It is the command return status.
•  len is returned in X1. It is the number of bytes written to the buffer.

B5.3.1.4 Caller responsibilities
Before calling RSI_ATTESTATION_TOKEN_CONTINUE, the caller must make sure that:
•  addr is aligned to the size of a Granule.
•  addr is a Protected IPA of the Realm, and the RIPAS of the Realm IPA addr is not EMPTY.
•  offset is less than RMM_GRANULE_SIZE.
•  Adding size to offset does not overflow, and offset plus size is not greater than RMM_GRANULE_SIZE.
•  The attestation state of the calling REC is ATTEST_IN_PROGRESS.

RSI_ATTESTATION_TOKEN_CONTINUE can return these errors:
•  RSI_ERROR_INPUT is returned if addr is not aligned to the size of a Granule.
•  RSI_ERROR_INPUT is returned if addr is not a Protected IPA of the Realm.
•  RSI_ERROR_INPUT is returned if the RIPAS of the Realm IPA addr is EMPTY.
•  RSI_ERROR_INPUT is returned if offset is greater than or equal to RMM_GRANULE_SIZE.
•  RSI_ERROR_INPUT is returned if adding size to offset overflows, so that the sum is smaller than offset.
•  RSI_ERROR_INPUT is returned if offset plus size is greater than RMM_GRANULE_SIZE.
•  RSI_ERROR_STATE is returned if the attestation state of the calling REC is not ATTEST_IN_PROGRESS.
•  RSI_ERROR_UNKNOWN is returned if token generation failed for an unknown or IMPLEMENTATION DEFINED reason.

These failure conditions have no defined order.

B5.3.1.5 Implementation responsibilities
On success, RSI_ATTESTATION_TOKEN_CONTINUE must:
•  Write bytes of the attestation token to the Granule at addr, starting at offset and writing no more than size bytes. It returns the number of bytes written in len.
•  Return RSI_INCOMPLETE if token generation is not complete.
•  Change the attestation state of the calling REC to NO_ATTEST_IN_PROGRESS if token generation is complete.

The only state this command may modify is the attestation state of the calling REC.
