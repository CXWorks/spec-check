B5.3.10 RSI_MEM_SET_PERM_INDEX

B5.3.10.1 Intended use
RSI_MEM_SET_PERM_INDEX sets the overlay permission index for a specified IPA range.

The command operates on the current Realm and the current REC. These are the Realm and REC from which the command is called.

B5.3.10.2 Parameters
The caller passes the following input values:
• fid, passed in X0 (bits 63:0), is the function identifier. Its value is 0xC40001A1.
• base, passed in X1 (bits 63:0), is the base of the target IPA region.
• top, passed in X2 (bits 63:0), is the top of the target IPA region.
• perm_index, passed in X3 (bits 63:0), is the permission index.
• cookie, passed in X4 (bits 63:0), is the cookie value.

B5.3.10.3 Return values
The command returns the following output values:
• result, returned in X0 (bits 63:0), is the command return status.
• new_base, returned in X1 (bits 63:0), is the base of the IPA region that the command did not modify.
• response, returned in X2 (bit 0), shows whether the Host accepted or rejected the request.
• new_cookie, returned in X3 (bits 63:0), is the new cookie value.

The unused bits of the output values, X2[63:1], must be zero.

B5.3.10.4 Caller responsibilities
RSI_MEM_SET_PERM_INDEX can return the following errors:
• RSI_ERROR_INPUT is returned if base is not aligned to the size of a Granule.
• RSI_ERROR_INPUT is returned if top is not aligned to the size of a Granule.
• RSI_ERROR_INPUT is returned if top is less than or equal to base, with both values compared as unsigned integers.
• RSI_ERROR_INPUT is returned if the address range from base to top is not entirely within the Protected IPA space of the Realm.
• RSI_ERROR_INPUT is returned if perm_index is greater than or equal to RMM_NUM_PERM_OVERLAY_INDICES.
• RSI_ERROR_INPUT is returned if the cookie is invalid.

There is no required order among these failure conditions.

B5.3.10.5 Implementation responsibilities
When RSI_MEM_SET_PERM_INDEX succeeds, the implementation must ensure that:
• The Realm's overlay lock state for permission index perm_index is MEM_PERM_LOCKED.
• new_base equals the stage 2 access permission address recorded in the REC (s2ap_addr).
• response is the REC's stage 2 access permission response, converted to its RSI encoding.
• A new cookie is generated.

The only state that RSI_MEM_SET_PERM_INDEX may modify is the Realm's overlay lock state for permission index perm_index.
