B5.3.5 RSI_IPA_STATE_GET

B5.3.5.1 Intended use
RSI_IPA_STATE_GET is intended for a Realm to get the RIPAS of a target IPA range. The Realm calls the RSI_IPA_STATE_GET function with the base and the end of the target IPA region. The command operates on the current Realm, which is the Realm that issues the call.

The implementation returns a RIPAS value and the top of the IPA region that has the reported RIPAS value.

Note: The RIPAS of a Protected IPA can change to DESTROYED at any time, without the Realm taking any action.

B5.3.5.2 Parameters
The caller passes the following input values:
• fid is passed in X0. It is the function identifier, with value 0xC4000198.
• base is passed in X1. It is the base of the target IPA region.
• top is passed in X2. It is the end of the target IPA region.

B5.3.5.3 Return values
The implementation returns the following output values:
• result is returned in X0. It is the command return status.
• out_top is returned in X1. It is the top of the IPA region that has the reported RIPAS value.
• ripas is returned in bits [7:0] of X2. It is the RIPAS value.

Bits [63:8] of X2 are unused and must be zero.

B5.3.5.4 Caller responsibilities
Before an RSI_IPA_STATE_GET call, the caller must make sure that:
• base is aligned to the size of a Granule.
• top is aligned to the size of a Granule.
• top is greater than base, when both are read as unsigned integers.
• The whole address range from base to top is inside the protected address range of the Realm.

RSI_IPA_STATE_GET can return the following errors:
• RSI_ERROR_INPUT is returned if base is not aligned to the size of a Granule.
• RSI_ERROR_INPUT is returned if top is not aligned to the size of a Granule.
• RSI_ERROR_INPUT is returned if top is less than or equal to base, when both are read as unsigned integers.
• RSI_ERROR_INPUT is returned if any part of the address range from base to top is outside the protected address range of the Realm.

No ordering is defined between these failure conditions.

B5.3.5.5 Implementation responsibilities
If result is RSI_SUCCESS, all of the following are true:
• out_top is greater than base.
• out_top is less than or equal to top.
• Every address from base up to, but not including, out_top has the RIPAS value returned in ripas.

RSI_IPA_STATE_GET does not modify any state.
