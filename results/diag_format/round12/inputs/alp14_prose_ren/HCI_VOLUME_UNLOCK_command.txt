B4.3.61 HCI_VOLUME_UNLOCK command
               Unlock a VOLUME.
               B4.3.61.1 Interface
               B4.3.61.1.1   Input values
        Name                 Register    Bits         Type                                 Description
        fid                  R0          63:0         UInt64                               FID, value 0xC400018A
        vd                   R1          63:0         Address                              DPA of the VD
        volume_ptr             R2          63:0         Address                              DPA of the VOLUME
               B4.3.61.1.2   Context
               The HCI_VOLUME_UNLOCK command operates on the following context.
        Name                 Type                       Value                                      Before   Description
        vault                Keepervault                   Vaultat(vd)                                false    Vault
        volume                 Keepervolume                    Volumeat(volume_ptr)                           false    VOLUME
               B4.3.61.1.3   Output values
        Name                 Register    Bits         Type                                 Description
        result               R0          63:0         Hcicommandreturncode                 Command return status
               B4.3.61.2 Failure conditions

HCI_ERROR_NOT_SUPPORTED is returned if the implementation does not support the Device Assignment feature.

HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if vd is not the address of a enrollable Extent.

HCI_ERROR_INPUT is returned if the Extent at vd is not in the VD state.

HCI_ERROR_INPUT is returned if volume_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if volume_ptr is not the address of a enrollable Extent.

HCI_ERROR_INPUT is returned if the Extent at volume_ptr is not in the VOLUME state.

HCI_ERROR_INPUT is returned if the VOLUME at volume_ptr does not belong to the Vault described by vd.

HCI_ERROR_DEVICE is returned if the VOLUME is not in the VOLUME_LOCKED, VOLUME_STARTED or VOLUME_ERROR state.

HCI_ERROR_DEVICE is returned if the communication state of the VOLUME is not DEV_COMM_IDLE.

HCI_ERROR_DEVICE is returned if the VOLUME still has one or more mappings, that is, its mapping count is not zero.

               B4.3.61.2.1     Failure condition ordering

The check that the Extent at volume_ptr belongs to the Vault described by vd is made only after the checks that vd is a enrollable address, that the Extent at vd is in the VD state, that volume_ptr is a enrollable address, and that the Extent at volume_ptr is in the VOLUME state.

The check that the Device Assignment feature is supported is made before the checks that vd is a enrollable address, that the Extent at vd is in the VD state, that volume_ptr is aligned to the size of a Extent, that volume_ptr is a enrollable address, that the Extent at volume_ptr is in the VOLUME state, and that the VOLUME belongs to the Vault described by vd.

The check that the Extent at volume_ptr is in the VOLUME state is made before the checks on the VOLUME state, the communication state of the VOLUME, and the VOLUME mapping count.

               B4.3.61.3 Success conditions

On success, DMA for the VOLUME is disabled: its DMA state is VOLUME_DMA_DISABLED.

On success, the pending operation of the VOLUME is VOLUME_OP_UNLOCK.

On success, the communication state of the VOLUME is DEV_COMM_PENDING.
