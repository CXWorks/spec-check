B5.3.2 VCI_CERTIFICATION_TOKEN_INIT command
                Initialize the operation to retrieve an certification token.
                B5.3.2.1 Interface
                B5.3.2.1.1    Input values
         Name                  Register     Bits        Type                                  Description
         fid                   R0           63:0        UInt64                                FID, value 0xC4000194
         challenge_0           R1           63:0        Bits64                                Doubleword 0 of the challenge value
         challenge_1           R2           63:0        Bits64                                Doubleword 1 of the challenge value
         challenge_2           R3           63:0        Bits64                                Doubleword 2 of the challenge value
         challenge_3           R4           63:0        Bits64                                Doubleword 3 of the challenge value
         challenge_4           R5           63:0        Bits64                                Doubleword 4 of the challenge value
         challenge_5           R6           63:0        Bits64                                Doubleword 5 of the challenge value
         challenge_6           R7           63:0        Bits64                                Doubleword 6 of the challenge value
         challenge_7           R8           63:0        Bits64                                Doubleword 7 of the challenge value
                B5.3.2.1.2    Context
                The VCI_CERTIFICATION_TOKEN_INIT command operates on the following context.
         Name                  Type                        Value                                      Before    Description
         vault                 Keepervault                    Currentvault()                             false     Current Vault
         worker                   Keeperworker                      Currentworker()                               false     Current WORKER
                B5.3.2.1.3    Output values
         Name                  Register     Bits        Type                                  Description
         result                R0           63:0        Vcicommandreturncode                  Command return status
         size                  R1           63:0        UInt64                                Upper bound on certification token size in
                                                                                              bytes
                B5.3.2.2 Failure conditions
                The VCI_CERTIFICATION_TOKEN_INIT command does not have any failure conditions.
                B5.3.2.3 Success conditions
After a successful call, the WORKER's certification state is CERTIFY_IN_PROGRESS.

After a successful call, the WORKER's certification challenge is the concatenation of challenge_0, challenge_1, challenge_2, challenge_3, challenge_4, challenge_5, challenge_6 and challenge_7, in that order, starting with challenge_0.

After a successful call, size is the maximum size of the certification token for the Vault.
