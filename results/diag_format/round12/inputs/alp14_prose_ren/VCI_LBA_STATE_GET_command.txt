B5.3.5 VCI_LBA_STATE_GET command
                 Get LBAMODE of a target LBA range.
                 B5.3.5.1 Interface
                 B5.3.5.1.1   Input values
         Name                 Register     Bits        Type                                  Description
         fid                  R0           63:0        UInt64                                FID, value 0xC4000198
         base                 R1           63:0        Address                               Base of target LBA region
         top                  R2           63:0        Address                               End of target LBA region
                 B5.3.5.1.2   Context
                 The VCI_LBA_STATE_GET command operates on the following context.
         Name                 Type                        Value                                      Before    Description
         vault                Keepervault                    Currentvault()                             false     Current Vault
                 B5.3.5.1.3   Output values
         Name                 Register     Bits        Type                                  Description
         result               R0           63:0        Vcicommandreturncode                  Command return status
         out_top              R1           63:0        Address                               Top of LBA region which has the
                                                                                             reported LBAMODE value
         lbamode                R2           7:0         Vcilbamode                              LBAMODE value
                 The following unused bits of VCI_LBA_STATE_GET output values MBZ: R2[63:8].
                 If result == VCI_SUCCESS then all of the following are true:
                    • out_top > base
                    • out_top <= top
                    • All addresses within the range [base, out_top) have the LBAMODE value lbamode.
                 Note that the LBAMODE of a Protected LBA can change at any time to DESTROYED without the Vault taking any
                 action.
                 B5.3.5.2 Failure conditions

VCI_ERROR_INPUT is returned if base is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if top is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if top is less than or equal to base, when both are read as unsigned integers.

VCI_ERROR_INPUT is returned if any part of the address range from base to top is outside the protected address range of the Vault.

               B5.3.5.2.1   Failure condition ordering

               The VCI_LBA_STATE_GET command does not have any failure condition orderings.

               B5.3.5.3 Success conditions

On success, out_top is set so that every address from base up to, but not including, out_top has a LBAMODE equal to the value returned in lbamode.
               B5.3.5.4 Footprint
               The VCI_LBA_STATE_GET command does not have any footprint.
