B5.3.8 VCI_MEASUREMENT_READ command
               Read measurement for the current Vault.
               B5.3.8.1 Interface
               B5.3.8.1.1   Input values
         Name               Register     Bits        Type                                  Description
         fid                R0           63:0        UInt64                                FID, value 0xC4000192
         index              R1           63:0        UInt64                                Measurement index
               index 0 selects the IFP. An index of 1 or greater selects the corresponding REM.
               B5.3.8.1.2   Context
               The VCI_MEASUREMENT_READ command operates on the following context.
         Name               Type                        Value                                      Before   Description
         vault              Keepervault                    Currentvault()                             false    Current Vault
         meas               Keepervaultmeasurement vault.measurements[[index]]                        false    Measurement
               B5.3.8.1.3   Output values
         Name               Register     Bits        Type                                  Description
         result             R0           63:0        Vcicommandreturncode                  Command return status
         value_0            R1           63:0        Bits64                                Doubleword 0 of the Vault
                                                                                           measurement identified by “index”
         value_1            R2           63:0        Bits64                                Doubleword 1 of the Vault
                                                                                           measurement identified by “index”
         value_2            R3           63:0        Bits64                                Doubleword 2 of the Vault
                                                                                           measurement identified by “index”
         value_3            R4           63:0        Bits64                                Doubleword 3 of the Vault
                                                                                           measurement identified by “index”
         value_4            R5           63:0        Bits64                                Doubleword 4 of the Vault
                                                                                           measurement identified by “index”
         value_5            R6           63:0        Bits64                                Doubleword 5 of the Vault
                                                                                           measurement identified by “index”
         value_6            R7           63:0        Bits64                                Doubleword 6 of the Vault
                                                                                           measurement identified by “index”
         Name              Register     Bits        Type                                  Description
         value_7           R8           63:0        Bits64                                Doubleword 7 of the Vault
                                                                                          measurement identified by “index”
             If the size of the measurement value is smaller than 512 bits, the output values are padded with zeroes.
             B5.3.8.2 Failure conditions

VCI_ERROR_INPUT is returned if index is greater than 4.

             B5.3.8.3 Success conditions

If the Vault's hash algorithm is SHA-256, then:
- value_0 to value_3 hold the first through fourth 64-bit words of the encoded value of the Vault measurement selected by index, in that order.
- value_4 to value_7 are all zero.

If the Vault's hash algorithm is SHA-512, then value_0 to value_7 hold the first through eighth 64-bit words of the encoded value of the Vault measurement selected by index, in that order.
             B5.3.8.4 Footprint
             The VCI_MEASUREMENT_READ command does not have any footprint.
