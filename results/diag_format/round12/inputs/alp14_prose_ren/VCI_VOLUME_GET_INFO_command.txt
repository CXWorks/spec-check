B5.3.17 VCI_VOLUME_GET_INFO command
                Get information for a device.
                Device configuration information, including digests of certification evidence for the device are written to an
                Vcivolumeinfo structure, at an address specified by the caller. Digests are calculated using the DRIVE Hash
                Algorithm.
                B5.3.17.1 Interface
                B5.3.17.1.1    Input values
         Name                 Register     Bits        Type                                  Description
         fid                  R0           63:0        UInt64                                FID, value 0xC400019D
         volume_id              R1           63:0        Bits64                                Vault device identifier
         addr                 R2           63:0        Address                               LBA to which the configuration data will
                                                                                             be written
                B5.3.17.1.2    Context
                The VCI_VOLUME_GET_INFO command operates on the following context.
         Name                 Type                        Value                                      Before    Description
         vault                Keepervault                    Currentvault()                             false     Current Vault
         volume                 Keepervolume                     Volumefromvolumeid(                            false     Vault device
                                                              vault,
                                                              volume_id)
         drive                 Keeperdrive                     Driveat(volume.drive)                          false     Physical device
         cfg                  Vcivolumeinfo                 Vcivolumeinfoat(addr)                        false     Device configuration
         walk                 Keeperbltwalkresult            Bltwalk(                                   false     BLT walk result
                                                              vault, addr,
                                                              KEEPER_BLT_PAGE_LEVEL,
                                                              KEEPER_BLT_TREE_PRIMARY)
                B5.3.17.1.3    Output values
         Name                 Register     Bits        Type                                  Description
         result               R0           63:0        Vcicommandreturncode                  Command return status
                B5.3.17.2 Failure conditions

VCI_ERROR_STATE is returned if the Vault was not created with the device assignment feature enabled.

VCI_ERROR_INPUT is returned if volume_id does not identify a VOLUME that is assigned to the Vault.

VCI_ERROR_INPUT is returned if addr is not aligned to 512 bytes.

VCI_ERROR_INPUT is returned if addr is not within the protected LBA space of the Vault.

VCI_ERROR_INPUT is returned if the LBAMODE of the LBA at addr is EMPTY.

                B5.3.17.2.1   Failure condition ordering

The check that the device assignment feature is enabled for the Vault comes before the volume_id check, the addr alignment check and the check that addr is within the protected LBA space. So if the feature is not enabled, VCI_ERROR_STATE is returned even if one of those three checks would also fail. No ordering is defined between the check that the LBAMODE at addr is EMPTY and any other failure condition.

                B5.3.17.3 Success conditions

The device configuration structure written to addr contains the following values:

- The hash algorithm is the hash algorithm of the DRIVE.
- The p2p_enabled flag shows whether peer-to-peer communication is enabled for the DRIVE.
- The p2p_bound flag shows whether the VOLUME is bound to a peer-to-peer peer.
- The p2p_peer field identifies the peer-to-peer peer of the VOLUME.
- The lock nonce, measurement nonce and report nonce match the certification information of the VOLUME.
- The PCA digest is the PCA digest of the DRIVE.
- The measurement digest is the measurement digest of the VOLUME.
- The report digest is the report digest of the VOLUME.
- The state field is the current state of the VOLUME.
             B5.3.17.4 Footprint
             The VCI_VOLUME_GET_INFO command does not have any footprint.
