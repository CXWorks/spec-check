B5.3.15 VCI_VAULT_CONFIG command
                Read configuration for the current Vault.
                B5.3.15.1 Interface
                B5.3.15.1.1   Input values
         Name                 Register    Bits        Type                                  Description
         fid                  R0          63:0        UInt64                                FID, value 0xC4000196
         addr                 R1          63:0        Address                               LBA of the Extent to which the
                                                                                            configuration data will be written
                B5.3.15.1.2   Context
                The VCI_VAULT_CONFIG command operates on the following context.
         Name                 Type                       Value                                      Before    Description
         vault                Keepervault                   Currentvault()                             false     Current Vault
         cfg                  Vcivaultconfig             Vcivaultconfigat(addr)                     false     Vault configuration
         walk                 Keeperbltwalkresult           Bltwalk(                                   false     BLT walk result
                                                             vault, addr,
                                                             KEEPER_BLT_PAGE_LEVEL,
                                                             KEEPER_BLT_TREE_PRIMARY)
                B5.3.15.1.3   Output values
         Name                 Register    Bits        Type                                  Description
         result               R0          63:0        Vcicommandreturncode                  Command return status
                B5.3.15.2 Failure conditions
VCI_ERROR_INPUT is returned if addr is not aligned to the size of a Extent.
VCI_ERROR_INPUT is returned if addr is not a Protected LBA of the Vault.
VCI_ERROR_INPUT is returned if the LBAMODE of the page at addr is EMPTY.
                B5.3.15.2.1   Failure condition ordering
                The VCI_VAULT_CONFIG command does not have any failure condition orderings.
              B5.3.15.3 Success conditions
On success, the lba_width field of the Vault configuration written to addr equals the LBA width of the Vault.
On success, the hash_algo field of the Vault configuration written to addr matches the hash algorithm of the Vault.
On success, the num_aux_tiers field of the Vault configuration written to addr equals the number of auxiliary Tiers of the Vault.
On success, the xlc_tier field of the Vault configuration written to addr equals the XLC Tier setting of the Vault.
              B5.3.15.4 Footprint
              The VCI_VAULT_CONFIG command does not have any footprint.
