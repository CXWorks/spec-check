              B4.3.58.2 Failure conditions

HCI_ERROR_NOT_SUPPORTED is returned if the implementation does not support the Device Assignment feature (feat_dx is not FEATURE_TRUE).

HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if vd is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at vd is not in the VD state.

HCI_ERROR_INPUT is returned if worker_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if worker_ptr is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at worker_ptr is not in the WORKER state.

HCI_ERROR_WORKER is returned if the WORKER at worker_ptr is in the WORKER_RUNNING state.

HCI_ERROR_WORKER is returned if the WORKER at worker_ptr is not owned by the Vault described by vd.

HCI_ERROR_INPUT is returned if stream_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if stream_ptr is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at stream_ptr is not in the P2P_STREAM state.

HCI_ERROR_INPUT is returned if drive_1_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if drive_1_ptr is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at drive_1_ptr is not in the DRIVE state.

HCI_ERROR_INPUT is returned if the DRIVE at drive_1_ptr does not have a valid P2P stream (its p2p_stream_valid attribute is not KEEPER_TRUE), or if its P2P stream is not the one at stream_ptr.

HCI_ERROR_INPUT is returned if drive_2_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if drive_2_ptr is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at drive_2_ptr is not in the DRIVE state.

HCI_ERROR_INPUT is returned if the DRIVE at drive_2_ptr does not have a valid P2P stream (its p2p_stream_valid attribute is not KEEPER_TRUE), or if its P2P stream is not the one at stream_ptr.

HCI_ERROR_INPUT is returned if volume_1_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if volume_1_ptr is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at volume_1_ptr is not in the VOLUME state.

HCI_ERROR_INPUT is returned if the VOLUME at volume_1_ptr does not belong to the Vault described by vd.

HCI_ERROR_INPUT is returned if the VOLUME at volume_1_ptr is not associated with the DRIVE at drive_1_ptr.

HCI_ERROR_DEVICE is returned if the communication state of the VOLUME at volume_1_ptr is not DEV_COMM_IDLE.

HCI_ERROR_DEVICE is returned if the certification information of the VOLUME at volume_1_ptr does not match the first VOLUME certification information held by the WORKER at worker_ptr (volume_certify_info_1).

HCI_ERROR_DEVICE is returned if the p2p_bound attribute of the VOLUME at volume_1_ptr is not FEATURE_FALSE.

HCI_ERROR_INPUT is returned if volume_2_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if volume_2_ptr is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at volume_2_ptr is not in the VOLUME state.

HCI_ERROR_INPUT is returned if the VOLUME at volume_2_ptr does not belong to the Vault described by vd.

HCI_ERROR_INPUT is returned if the VOLUME at volume_2_ptr is not associated with the DRIVE at drive_2_ptr.

HCI_ERROR_DEVICE is returned if the communication state of the VOLUME at volume_2_ptr is not DEV_COMM_IDLE.

HCI_ERROR_DEVICE is returned if the certification information of the VOLUME at volume_2_ptr does not match the second VOLUME certification information held by the WORKER at worker_ptr (volume_certify_info_2).

HCI_ERROR_DEVICE is returned if the p2p_bound attribute of the VOLUME at volume_2_ptr is not FEATURE_FALSE.

             B4.3.58.2.1                                                          Failure condition ordering

The check for Device Assignment support comes before every other failure condition. If the feature is not supported, HCI_ERROR_NOT_SUPPORTED is returned, even if any of the other failure conditions also apply. No ordering is defined among the remaining failure conditions. These cover vd, worker_ptr, stream_ptr, drive_1_ptr, drive_2_ptr, volume_1_ptr and volume_2_ptr, and they return HCI_ERROR_INPUT, HCI_ERROR_WORKER or HCI_ERROR_DEVICE.

             B4.3.58.3 Success conditions

The operation of the VOLUME at volume_1_ptr is set to VOLUME_OP_P2P_BIND.

The communication state of the VOLUME at volume_1_ptr is set to DEV_COMM_PENDING.

The p2p_bound attribute of the VOLUME at volume_1_ptr is set to FEATURE_TRUE.

The P2P stream of the VOLUME at volume_1_ptr is set to the P2P stream at stream_ptr.

The P2P peer of the VOLUME at volume_1_ptr is set to the VOLUME identifier of the VOLUME at volume_2_ptr.

The operation of the VOLUME at volume_2_ptr is set to VOLUME_OP_P2P_BIND.

The communication state of the VOLUME at volume_2_ptr is set to DEV_COMM_PENDING.

The p2p_bound attribute of the VOLUME at volume_2_ptr is set to FEATURE_TRUE.

The P2P stream of the VOLUME at volume_2_ptr is set to the P2P stream at stream_ptr.

The P2P peer of the VOLUME at volume_2_ptr is set to the VOLUME identifier of the VOLUME at volume_1_ptr.
