B5.3.19 VCI_VOLUME_VALIDATE_MAPPING command
                 Validate Vault device memory mappings.
                 B5.3.19.1 Interface
                 B5.3.19.1.1   Input values
         Name                  Register    Bits        Type                                  Description
         fid                   R0          63:0        UInt64                                FID, value 0xC400019F
         volume_id               R1          63:0        Bits64                                Vault device identifier
         lba_base              R2          63:0        Address                               Base of target LBA region
         lba_top               R3          63:0        Address                               Top of target LBA region
         dpa_base               R4          63:0        Address                               Base of target DPA region
         flags                 R5          63:0        Vcidevmemflags                        Flags
         lock_nonce            R6          63:0        UInt64                                Nonce generated on most recent
                                                                                             transition to LOCKED state
         meas_nonce            R7          63:0        UInt64                                GET_MEASUREMENT request
                                                                                             sequence number
         report_nonce          R8          63:0        UInt64                                GET_INTERFACE_REPORT request
                                                                                             sequence number
                 B5.3.19.1.2   Context
                 The VCI_VOLUME_VALIDATE_MAPPING command operates on the following context.
         Name                  Type                       Value                                      Before    Description
         vault                 Keepervault                   Currentvault()                             false     Current Vault
         worker                   Keeperworker                     Currentworker()                               false     Current WORKER
         volume                  Keepervolume                    Volumefromvolumeid(                            false     Vault device
                                                              vault,
                                                              volume_id)
                 B5.3.19.1.3   Output values
         Name                  Register    Bits        Type                                  Description
         result                R0          63:0        Vcicommandreturncode                  Command return status
         new_lba_base          R1          63:0        Address                               Base of LBA region which was not
                                                                                             modified by the command
         response              R2          0:0         Vciresponse                           Whether the Host accepted or rejected
                                                                                             the request
                The following unused bits of VCI_VOLUME_VALIDATE_MAPPING output values MBZ: R2[63:1].
                B5.3.19.2 Failure conditions

VCI_ERROR_STATE is returned if the Device Assignment feature is not enabled for the Vault.

VCI_ERROR_INPUT is returned if volume_id does not identify a VOLUME that is in use by the Vault.

VCI_ERROR_INPUT is returned if the state of the VOLUME is neither VOLUME_LOCKED nor VOLUME_STARTED.

VCI_ERROR_INPUT is returned if lba_base is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if lba_top is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if dpa_base is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if lba_top is less than or equal to lba_base.

VCI_ERROR_INPUT is returned if the LBA range from lba_base to lba_top is not entirely within the protected LBA space of the Vault.

VCI_ERROR_DEVICE is returned if lock_nonce, meas_nonce and report_nonce do not match the certification information recorded for the VOLUME.

                B5.3.19.2.1       Failure condition ordering

The check that the Device Assignment feature is enabled for the Vault is made before the check that volume_id identifies a VOLUME in use by the Vault.

                B5.3.19.3 Success conditions

new_lba_base is equal to the device memory address recorded in the WORKER.

response is the device memory response recorded in the WORKER, converted to its VCI encoding.
             B5.3.19.4 Footprint
             The VCI_VOLUME_VALIDATE_MAPPING command does not have any footprint.
