B5.3.10 VCI_MEM_SET_PERM_INDEX command
                Set overlay permission index for a specified LBA range.
                B5.3.10.1 Interface
                B5.3.10.1.1   Input values
         Name                 Register    Bits        Type                                  Description
         fid                  R0          63:0        UInt64                                FID, value 0xC40001A1
         base                 R1          63:0        Address                               Base of target LBA region
         top                  R2          63:0        Address                               Top of target LBA region
         perm_index           R3          63:0        UInt64                                Permission index
         cookie               R4          63:0        Bits64                                Cookie value
                B5.3.10.1.2   Context
                The VCI_MEM_SET_PERM_INDEX command operates on the following context.
         Name                 Type                       Value                                      Before     Description
         vault                Keepervault                   Currentvault()                             false      Current Vault
         worker                  Keeperworker                     Currentworker()                               false      Current WORKER
                B5.3.10.1.3   Output values
         Name                 Register    Bits        Type                                  Description
         result               R0          63:0        Vcicommandreturncode                  Command return status
         new_base             R1          63:0        Address                               Base of LBA region which was not
                                                                                            modified by the command
         response             R2          0:0         Vciresponse                           Whether the Host accepted or rejected
                                                                                            the request
         new_cookie           R3          63:0        Bits64                                New cookie value
                The following unused bits of VCI_MEM_SET_PERM_INDEX output values MBZ: R2[63:1].
                B5.3.10.2 Failure conditions

VCI_ERROR_INPUT is returned if base is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if top is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if top is less than or equal to base, with both values compared as unsigned integers.

VCI_ERROR_INPUT is returned if the address range from base to top is not entirely within the Protected LBA space of the Vault.

VCI_ERROR_INPUT is returned if perm_index is greater than or equal to KEEPER_NUM_PERM_OVERLAY_INDICES.

VCI_ERROR_INPUT is returned if the cookie is invalid.

               B5.3.10.2.1   Failure condition ordering

               The VCI_MEM_SET_PERM_INDEX command does not have any failure condition orderings.

               B5.3.10.3 Success conditions

On success, the Vault's overlay lock state for permission index perm_index is MEM_PERM_LOCKED.

On success, new_base is equal to the stage 2 access permission address recorded in the WORKER (xap_addr).

On success, response is the WORKER's stage 2 access permission response, converted to its VCI encoding.

On success, a new cookie is generated.
