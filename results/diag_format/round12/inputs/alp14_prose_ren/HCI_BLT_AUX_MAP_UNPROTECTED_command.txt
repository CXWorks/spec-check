B4.3.35 HCI_BLT_AUX_MAP_UNPROTECTED command
              Copies a valid or table descriptor at an Unprotected LBA from the starting level of the primary BLT to an auxiliary
              BLT.

              B4.3.35.2 Failure conditions

HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if vd is not a physical address that can be enrolled.

HCI_ERROR_INPUT is returned if the Extent at vd is not in the VD state.

HCI_ERROR_INPUT is returned if lba is not aligned to the size of the address range that one BLT entry maps at the starting BLT level of the Vault.

HCI_ERROR_INPUT is returned if lba is outside the Vault's LBA space, that is, lba is greater than or equal to 2 to the power of the Vault's LBA width. It is also returned if lba is a Protected address in the Vault.

HCI_ERROR_INPUT is returned if any of these is true:
- the Vault does not use a separate BLT tree for each Tier (its per-Tier BLT tree setting is FEATURE_FALSE)
- index identifies the primary BLT tree (KEEPER_BLT_TREE_PRIMARY)
- index is greater than the number of auxiliary Tiers in the Vault

HCI_ERROR_BLT is returned if the BLT entry for lba in the primary BLT tree is in the UNASSIGNED_PUB state. The returned value also includes the BLT level at which the walk of the primary BLT tree ended.

               B4.3.35.2.1   Failure condition ordering

The check that vd is a physical address that can be enrolled is done before the check on the state of the primary BLT entry. The check that the Extent at vd is in the VD state is also done before that check.

The check that lba is inside the Vault's LBA space and is not a Protected address is done before the check on the state of the primary BLT entry. The check on index is also done before that check.

               B4.3.35.3 Success conditions

The state of the BLT entry for lba in the auxiliary BLT tree selected by index matches the state of the BLT entry for lba in the primary BLT tree.

The memory attributes of the auxiliary BLT entry match those of the primary BLT entry, compared as Unprotected entries. The stage 2 access permissions of the two entries also match, compared with the Vault's stage 2 access permission encoding.

The output address in the auxiliary BLT entry matches the output address in the primary BLT entry.
