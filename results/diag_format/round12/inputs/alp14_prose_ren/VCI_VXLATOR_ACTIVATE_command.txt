B5.3.21 VCI_VXLATOR_ACTIVATE command
                Activate a VXLATOR.
                B5.3.21.1 Interface
                B5.3.21.1.1   Input values
         Name                 Register    Bits        Type                                  Description
         fid                  R0          63:0        UInt64                                FID, value 0xC400019B
         base                 R1          63:0        Address                               Base of target LBA region
         top                  R2          63:0        Address                               Top of target LBA region
                B5.3.21.1.2   Context
                The VCI_VXLATOR_ACTIVATE command operates on the following context.
         Name                 Type                       Value                                      Before    Description
         vault                Keepervault                   Currentvault()                             false     Current Vault
         walk                 Keeperbltwalkresult           Bltwalk(                                   false     BLT walk result
                                                             vault, base,
                                                             KEEPER_BLT_PAGE_LEVEL,
                                                             KEEPER_BLT_TREE_PRIMARY)
         vxlator                Keepervxlator                   Vxlatorat(walk.blte.addr)                    false     VXLATOR
                B5.3.21.1.3   Output values
         Name                 Register    Bits        Type                                  Description
         result               R0          63:0        Vcicommandreturncode                  Command return status
         new_base             R1          63:0        Address                               Base of LBA region which was not
                                                                                            modified by the command
                B5.3.21.2 Failure conditions

VCI_ERROR_INPUT is returned if base is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if top is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if top is less than or equal to base, compared as unsigned integers.

VCI_ERROR_INPUT is returned if the address range from base up to, but not including, top is not entirely within the Protected LBA space of the Vault.

VCI_ERROR_INPUT is returned if the BLT entry reached by the BLT walk is not in the ASSIGNED_VXLATOR state.

               B5.3.21.2.1   Failure condition ordering

               The VCI_VXLATOR_ACTIVATE command does not have any failure condition orderings.

               B5.3.21.3 Success conditions

On success, the LBAMODE of the address range from base up to, but not including, new_base is DEV.

If base is equal to the base address of the VXLATOR register region, and new_base is not equal to the top address of that region, the VXLATOR state is VXLATOR_ACTIVATING.

If new_base is equal to the top address of the VXLATOR register region, the VXLATOR state is VXLATOR_ACTIVE.
               B5.3.21.4 Footprint
               The VCI_VXLATOR_ACTIVATE command does not have any footprint.
