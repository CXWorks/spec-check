B6.3.2 PWRCTL_CPU_OFF command
               Power down the calling core.
               This command causes a WORKER exit due to PWRCTL.
               B6.3.2.1 Interface
               B6.3.2.1.1   Input values
         Name                                 Register    Bits        Type                 Description
         fid                                  R0          63:0        UInt64               FID, value 0xC4000002
               B6.3.2.1.2   Context
               The PWRCTL_CPU_OFF command operates on the following context.
         Name               Type                         Value                                     Before   Description
         worker                Keeperworker                       Currentworker()                              false    Current WORKER
               B6.3.2.1.3   Output values
               The PWRCTL_CPU_OFF command does not have any output values.
               Following execution of PWRCTL_CPU_OFF, control does not return to the caller.
               B6.3.2.2 Failure conditions
               The PWRCTL_CPU_OFF command does not have any failure conditions.
               B6.3.2.3 Success conditions
               The PWRCTL_CPU_OFF command does not have any success conditions.
               Following execution of PWRCTL_CPU_OFF, control does not return to the caller.
               B6.3.2.4 Footprint
               The PWRCTL_CPU_OFF command does not have any footprint.
