B4.3.8 HCI_ZONE_SET_SHARED command
                Change state of a ZONE to Shared.
                B4.3.8.1 Interface
                B4.3.8.1.1   Input values
          Name               Register     Bits        Type                                  Description
          fid                R0           63:0        UInt64                                FID, value 0xC400018C
          zoneid              R1           63:0        Bits64                                ZONEID
                B4.3.8.1.2   Output values
          Name               Register     Bits        Type                                  Description
          result             R0           63:0        Hcicommandreturncode                  Command return status
                B4.3.8.2 Failure conditions
HCI_ERROR_INPUT is returned if zoneid is greater than the maximum ZONEID that the implementation supports.
HCI_ERROR_INPUT is returned if the ZONE state of zoneid is not ZONE_STATE_PRIVATE_UNASSIGNED.
                B4.3.8.2.1   Failure condition ordering
                The HCI_ZONE_SET_SHARED command does not have any failure condition orderings.
                B4.3.8.3 Success conditions
On success, the ZONE state of zoneid is ZONE_STATE_SHARED.
                B4.3.8.4 Footprint
    ID                            Value
    zone_state                     Zonestate(zoneid)
