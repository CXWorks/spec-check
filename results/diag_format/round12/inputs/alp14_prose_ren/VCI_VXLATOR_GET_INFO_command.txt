B5.3.22 VCI_VXLATOR_GET_INFO command
                Get information of a VXLATOR.
                B5.3.22.1 Interface
                B5.3.22.1.1   Input values
         Name                 Register    Bits        Type                                  Description
         fid                  R0          63:0        UInt64                                FID, value 0xC400019A
         addr                 R1          63:0        Address                               Base LBA of the VXLATOR
                B5.3.22.1.2   Context
                The VCI_VXLATOR_GET_INFO command operates on the following context.
         Name                 Type                       Value                                      Before   Description
         vault                Keepervault                   Currentvault()                             false    Current Vault
         walk                 Keeperbltwalkresult           Bltwalk(                                   false    BLT walk result
                                                             vault, addr,
                                                             KEEPER_BLT_PAGE_LEVEL,
                                                             KEEPER_BLT_TREE_PRIMARY)
                B5.3.22.1.3   Output values
         Name                 Register    Bits        Type                                  Description
         result               R0          63:0        Vcicommandreturncode                  Command return status
         top                  R1          63:0        Address                               Top LBA of the VXLATOR
                B5.3.22.2 Failure conditions
VCI_ERROR_INPUT is returned if addr is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if addr is not a Protected LBA of the Vault.

VCI_ERROR_INPUT is returned if the BLT entry found by walking the Vault's BLT to addr is not in the ASSIGNED_VXLATOR state.

VCI_ERROR_INPUT is returned if addr is not the register base address of the VXLATOR referenced by the BLT entry found by walking the Vault's BLT to addr.
             B5.3.22.2.1    Failure condition ordering
             The VCI_VXLATOR_GET_INFO command does not have any failure condition orderings.
             B5.3.22.3 Success conditions
On success, top is the register top address of the VXLATOR referenced by the BLT entry found by walking the Vault's BLT to addr.
             B5.3.22.4 Footprint
             The VCI_VXLATOR_GET_INFO command does not have any footprint.
