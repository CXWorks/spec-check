B4.3.1 HCI_DATA_CREATE command
                Creates a Data Extent, copying contents from a Non-secure Extent provided by the caller.
                B4.3.1.1 Interface
                B4.3.1.1.1   Input values
        Name                 Register     Bits        Type                                  Description
        fid                  R0           63:0        UInt64                                FID, value 0xC4000153
        vd                   R1           63:0        Address                               DPA of the VD for the target Vault
        data                 R2           63:0        Address                               DPA of the target Data
        lba                  R3           63:0        Address                               LBA at which the Extent will be
                                                                                            mapped in the target Vault
        src                  R4           63:0        Address                               DPA of the source Extent
        flags                R5           63:0        Hcidataflags                          Flags
                B4.3.1.1.2   Context
                The HCI_DATA_CREATE command operates on the following context.
        Name                 Type                        Value                                      Before    Description
        vault_pre            Keepervault                    Vaultat(vd)                                true      Vault
        vault                Keepervault                    Vaultat(vd)                                false     Vault
        walk                 Keeperbltwalkresult            Bltwalk(                                   false     BLT walk result
                                                             vault, lba,
                                                             KEEPER_BLT_PAGE_LEVEL,
                                                             KEEPER_BLT_TREE_PRIMARY)
        entry_idx            UInt64                      Bltentryindex(                             false     BLTE index
                                                             lba, walk.level)
                B4.3.1.1.3   Output values
        Name                 Register     Bits        Type                                  Description
        result               R0           63:0        Hcicommandreturncode                  Command return status
                B4.3.1.2 Failure conditions

HCI_ERROR_INPUT is returned if src is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if the Extent at src cannot be accessed from the Non-secure physical address space.

HCI_ERROR_INPUT is returned if data is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if data is not the physical address of DRAM that can be enrolled.

HCI_ERROR_INPUT is returned if the Extent at data is not in the ENROLLED state.

HCI_ERROR_INPUT is returned if data is 2^48 or greater and the target Vault does not support BIGADDR, which means its feat_bigaddr attribute is FEATURE_FALSE.

HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if vd is not a physical address that can be enrolled.

HCI_ERROR_INPUT is returned if the Extent at vd is not in the VD state.

HCI_ERROR_INPUT is returned if lba is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if, before the command runs, lba is not in the protected LBA space of the target Vault.

HCI_ERROR_VAULT is returned if, before the command runs, the target Vault is not in the VAULT_NEW state.

HCI_ERROR_BLT is returned, together with the BLT level that the walk reached, if the BLT walk for lba stops before it reaches the page level, KEEPER_BLT_PAGE_LEVEL.

HCI_ERROR_BLT is returned, together with the BLT level that the walk reached, if the BLT entry found by the walk for lba is not in the UNASSIGNED state.

                B4.3.1.2.1       Failure condition ordering

The KEEPER checks that vd can be enrolled and that the Extent at vd is in the VD state before it checks whether the target Vault is in the VAULT_NEW state.

The KEEPER checks that vd can be enrolled and that the Extent at vd is in the VD state before it checks the BLT walk level and the state of the BLT entry for lba.

The KEEPER checks that lba is in the protected LBA space of the target Vault before it checks the BLT walk level and the state of the BLT entry for lba.

                B4.3.1.3 Success conditions

The Extent at data is in the DATA state.

The contents of the source Extent at src are copied into the target Extent at data.

The BLT entry for lba is in the ASSIGNED state.

The LBAMODE of the BLT entry for lba is RAM.

The output address of the BLT entry for lba is data.

The memory attribute of the BLT entry for lba is MEMATTR_CACHEABLE.

The shareability of the BLT entry for lba is SHAREABILITY_INNER.

The IFP of the target Vault is updated: the first measurement of the Vault becomes the value calculated from the Vault's state before the command, lba, data and flags, as described in B4.3.1.4.

               B4.3.1.4 HCI_DATA_CREATE extension of IFP
               On successful execution of HCI_DATA_CREATE, the KEEPER calculates the new IFP value of the target Vault as follows:
                 1. If the measure field of flags is HCI_MEASURE_CONTENT, compute the hash of the contents of the DATA Extent using the VHA of the target Vault.
                 2. Allocate an Keepermeasurementdescriptordata data structure.
                 3. Populate the measurement descriptor:
                  • Set the desc_type field to the descriptor type.
                  • Set the len field to the descriptor length.
                  • Set the ifp field to the current IFP value of the target Vault.
                  • Set the lba field to the LBA at which the DATA Extent is mapped in the target Vault.
                  • Set the flags field to the flags provided by the Host.
                  • If the measure field of flags is HCI_MEASURE_CONTENT, set the content field to the hash of the contents of the DATA Extent. If it is not, set the content field to zero.
                 4. Compute the hash of the measurement descriptor using the VHA of the target Vault, and set the IFP of the target Vault to this value. If the VHA output is smaller than the IFP, fill the upper bytes with zeros.
