B5.3.1 VCI_CERTIFICATION_TOKEN_CONTINUE command
                Continue the operation to retrieve an certification token.
                B5.3.1.1 Interface
                B5.3.1.1.1   Input values
         Name                 Register     Bits        Type                                  Description
         fid                  R0           63:0        UInt64                                FID, value 0xC4000195
         addr                 R1           63:0        Address                               LBA of the Extent to which the token
                                                                                             will be written
         offset               R2           63:0        UInt64                                Offset within Extent to start of buffer
                                                                                             in bytes
         size                 R3           63:0        UInt64                                Size of buffer in bytes
                B5.3.1.1.2   Context
                The VCI_CERTIFICATION_TOKEN_CONTINUE command operates on the following context.
         Name                 Type                        Value                                      Before     Description
         vault                Keepervault                    Currentvault()                             false      Current Vault
         worker                  Keeperworker                      Currentworker()                               false      Current WORKER
         walk                 Keeperbltwalkresult            Bltwalk(                                   false      BLT walk result
                                                              vault, addr,
                                                              KEEPER_BLT_PAGE_LEVEL,
                                                              KEEPER_BLT_TREE_PRIMARY)
                B5.3.1.1.3   Output values
         Name                 Register     Bits        Type                                  Description
         result               R0           63:0        Vcicommandreturncode                  Command return status
         len                  R1           63:0        UInt64                                Number of bytes written to buffer
                B5.3.1.2 Failure conditions

VCI_ERROR_INPUT is returned if addr is not aligned to the size of a Extent.

VCI_ERROR_INPUT is returned if addr is not a Protected LBA of the Vault.

VCI_ERROR_INPUT is returned if the LBAMODE of the Vault LBA addr is EMPTY.

VCI_ERROR_INPUT is returned if offset is greater than or equal to KEEPER_EXTENT_SIZE.

VCI_ERROR_INPUT is returned if adding size to offset overflows, so that the sum is smaller than offset.

VCI_ERROR_INPUT is returned if offset plus size is greater than KEEPER_EXTENT_SIZE.

VCI_ERROR_STATE is returned if the certification state of the calling WORKER is not CERTIFY_IN_PROGRESS.

VCI_ERROR_UNKNOWN is returned if token generation failed for an unknown or IMPLEMENTATION DEFINED reason.

               B5.3.1.2.1   Failure condition ordering

               The VCI_CERTIFICATION_TOKEN_CONTINUE command does not have any failure condition orderings.

               B5.3.1.3 Success conditions

The output len is the number of bytes of the certification token written to the Extent at addr, starting at offset and limited to size bytes.

VCI_INCOMPLETE is returned if token generation is not complete.

If token generation is complete, the certification state of the calling WORKER becomes NO_CERTIFY_IN_PROGRESS.
