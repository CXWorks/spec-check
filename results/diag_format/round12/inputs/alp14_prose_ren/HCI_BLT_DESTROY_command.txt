               B4.3.39.2 Failure conditions

HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if vd is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at vd is not in the VD state.

HCI_ERROR_INPUT is returned if level is not a valid BLT level for the Vault, or if level is the starting level of the Vault's BLT.

HCI_ERROR_INPUT is returned if lba is not aligned to the size of the address range that an BLT entry maps at the level one less than level.

HCI_ERROR_INPUT is returned if lba is outside the Vault's LBA space. This means lba is greater than or equal to 2 raised to the power of the Vault's LBA width.

HCI_ERROR_BLT is returned if the BLT walk to lba stops at a level lower than one less than level. The error index is the level at which the walk stopped, and the output top is set to walk_top.

HCI_ERROR_BLT is returned if the BLT entry that the walk reaches is not in the TABLE state. The error index is the level at which the walk stopped, and the output top is set to walk_top.

HCI_ERROR_BLT is returned if the BLT that this BLT entry points to is live. The error index is level, and the output top is set to lba.

HCI_ERROR_BLT is returned if lba is referenced by an auxiliary BLT of the Vault. The error index is the level at which the walk stopped.

                    B4.3.39.2.1   Failure condition ordering

The check that vd is a enrollable physical address and the check that the Extent at vd is in the VD state are both made before two other checks. The first is the check that the BLT walk reaches the level one less than level. The second is the check that the BLT entry reached is in the TABLE state.

The check that level is valid and is not the starting level, and the check that lba is within the Vault's LBA space, are also both made before those two BLT walk checks.

The check that the BLT entry reached is in the TABLE state is made before two later checks. One is the check that the BLT it points to is not live. The other is the check that lba is not referenced by an auxiliary BLT.

                    B4.3.39.3 Success conditions

If lba is a Protected address, the BLT entry reached by the walk is in the UNASSIGNED state.

If lba is a Protected address, the LBAMODE of the BLT entry reached by the walk is DESTROYED.

If lba is not a Protected address, the BLT entry reached by the walk is in the UNASSIGNED_PUB state.

The Extent that held the destroyed BLT, which is the one at the address in the BLT entry, is in the ENROLLED state.

The output blt is the address of the destroyed BLT, as held in the BLT entry.

The output top is set to walk_top.
