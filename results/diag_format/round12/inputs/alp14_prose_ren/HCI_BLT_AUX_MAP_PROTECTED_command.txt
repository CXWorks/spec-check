              B4.3.34.2 Failure conditions

HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if vd is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at vd is not in the VD state.

HCI_ERROR_INPUT is returned if lba is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if lba is not a Protected LBA of the Vault.

HCI_ERROR_INPUT is returned if any of the following is true:
- the Vault does not use a separate BLT tree for each Tier, meaning blt_tree_per_tier is FEATURE_FALSE
- index is KEEPER_BLT_TREE_PRIMARY
- index is greater than the number of auxiliary Tiers of the Vault

HCI_ERROR_BLT is returned if the primary BLT entry at lba is not in the ASSIGNED, ASSIGNED_DEV or ASSIGNED_VXLATOR state. The error carries the level of that primary BLT entry. state is set to the state of the primary BLT entry, and lbamode is set to the LBAMODE of the primary BLT entry.

HCI_ERROR_BLT is returned if the primary BLT entry at lba is in the ASSIGNED state and its LBAMODE is not RAM. The error carries the level of that primary BLT entry. state is set to the state of the primary BLT entry, and lbamode is set to the LBAMODE of the primary BLT entry.

HCI_ERROR_BLT is returned if the primary BLT entry at lba is in the ASSIGNED_DEV state and its LBAMODE is not DEV. The error carries the level of that primary BLT entry. state is set to the state of the primary BLT entry, and lbamode is set to the LBAMODE of the primary BLT entry.

HCI_ERROR_BLT_AUX is returned if the auxiliary BLT entry at lba, in the BLT tree selected by index, is in the AUX_DESTROYED state. The error carries the level of that auxiliary BLT entry. state is set to the state of the auxiliary BLT entry, and lbamode is set to the LBAMODE of the primary BLT entry.

HCI_ERROR_BLT_AUX is returned if the walk of the auxiliary BLT at lba ends at a lower-numbered level than the walk of the primary BLT. In that case the auxiliary entry covers a larger region than the primary entry. The error carries the level of the auxiliary BLT entry. state is set to the state of the auxiliary BLT entry, and lbamode is set to the LBAMODE of the primary BLT entry.

              B4.3.34.2.1   Failure condition ordering

The checks that vd is a enrollable address and that the Extent at vd is in the VD state are made before any of the checks on the primary BLT entry (its state, its LBAMODE in the ASSIGNED state and its LBAMODE in the ASSIGNED_DEV state) and before the checks on the auxiliary BLT entry (the AUX_DESTROYED state and the walk level).

The checks that lba is a Protected LBA and that index is valid are also made before all of those primary and auxiliary BLT entry checks.

               B4.3.34.3 Success conditions

On success, the auxiliary BLT entry at lba is in the ASSIGNED state.

On success, the auxiliary BLT entry at lba has the same protection attributes as the primary BLT entry.

On success, the auxiliary BLT entry at lba has the same shareability attribute as the primary BLT entry.

On success, the output address of the auxiliary BLT entry is calculated from the output address of the primary BLT entry. The primary entry may cover a region made up of several auxiliary-level entries. The auxiliary entry's address is the primary entry's address plus this entry's position in that region multiplied by the size of the region mapped by one entry at the auxiliary BLT entry's level.
