B4.3.53 HCI_VOLUME_GET_INTERFACE_REPORT command
               Get VOLUME interface report.
               B4.3.53.1 Interface
               B4.3.53.1.1   Input values
        Name                 Register    Bits        Type                                  Description
        fid                  R0          63:0        UInt64                                FID, value 0xC40001D0
        vd                   R1          63:0        Address                               DPA of the VD
        volume_ptr             R2          63:0        Address                               DPA of the VOLUME
               B4.3.53.1.2   Context
               The HCI_VOLUME_GET_INTERFACE_REPORT command operates on the following context.
        Name                 Type                       Value                                      Before   Description
        vault                Keepervault                   Vaultat(vd)                                false    Vault
        volume                 Keepervolume                    Volumeat(volume_ptr)                           false    VOLUME
               B4.3.53.1.3   Output values
        Name                 Register    Bits        Type                                  Description
        result               R0          63:0        Hcicommandreturncode                  Command return status
               B4.3.53.2 Failure conditions

HCI_ERROR_NOT_SUPPORTED is returned if the implementation does not support the Device Assignment feature.

HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if vd is not a physical address that can be enrolled.

HCI_ERROR_INPUT is returned if the Extent at vd is not in the VD state.

HCI_ERROR_INPUT is returned if volume_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if volume_ptr is not a physical address that can be enrolled.

HCI_ERROR_INPUT is returned if the Extent at volume_ptr is not in the VOLUME state.

HCI_ERROR_INPUT is returned if the VOLUME at volume_ptr does not belong to the Vault described by vd.

HCI_ERROR_DEVICE is returned if the VOLUME is in neither the VOLUME_LOCKED state nor the VOLUME_STARTED state.

HCI_ERROR_DEVICE is returned if the communication state of the VOLUME is not DEV_COMM_IDLE.

               B4.3.53.2.1     Failure condition ordering

Before the check that the VOLUME belongs to the Vault described by vd, the command checks that vd can be enrolled, that the Extent at vd is in the VD state, that volume_ptr can be enrolled, and that the Extent at volume_ptr is in the VOLUME state.

The check that the implementation supports Device Assignment comes before these checks: vd can be enrolled, the Extent at vd is in the VD state, volume_ptr is aligned to the size of a Extent, volume_ptr can be enrolled, the Extent at volume_ptr is in the VOLUME state, and the VOLUME belongs to the Vault described by vd.

The check that the Extent at volume_ptr is in the VOLUME state comes before the check of the VOLUME state and the check of the VOLUME communication state.

               B4.3.53.3 Success conditions

The pending operation of the VOLUME is VOLUME_OP_GET_REPORT.

The communication state of the VOLUME is DEV_COMM_PENDING.
