B4.3.43 HCI_BLT_READ_ENTRY command
                Reads an entry from a primary BLT.
                B4.3.43.1 Interface
                B4.3.43.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   R0          63:0        UInt64                                FID, value 0xC4000161
        vd                    R1          63:0        Address                               DPA of the VD for the target Vault
        lba                   R2          63:0        Address                               Vault Address for which to read the
                                                                                            BLTE
        level                 R3          63:0        Int64                                 BLT level at which to read the BLTE
                B4.3.43.1.2   Context
                The HCI_BLT_READ_ENTRY command operates on the following context.
        Name                  Type                       Value                                      Before    Description
        vault                 Keepervault                   Vaultat(vd)                                false     Vault
        walk                  Keeperbltwalkresult           Bltwalk(                                   false     BLT walk result
                                                             vault, lba, level,
                                                             KEEPER_BLT_TREE_PRIMARY)
        blte                  Keeperbltentry                Bltdescriptordecode(                       false     BLT entry value
                                                             desc,                                            returned to Host
                                                             vault.blt_xap_encoding
                                                         )
                B4.3.43.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                R0          63:0        Hcicommandreturncode                  Command return status
        walk_level            R1          63:0        UInt64                                BLT level reached by the BLT walk
        state                 R2          7:0         Hcibltentrystate                      State of BLTE reached by the walk
        desc                  R3          63:0        Bits64                                BLTE descriptor
        lbamode                 R4          7:0         Hcilbamode                              LBAMODE of BLTE reached by the walk
                The following unused bits of HCI_BLT_READ_ENTRY output values MBZ: R2[63:8], R4[63:8].
                The layout and encoding of fields in the desc output value match “Attribute fields in stage 2 Xmsa8-64 Block
                and Page descriptors” in Acme Architecture Reference Manual for A-Profile architecture [3].
               B4.3.43.2 Failure conditions

HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if vd is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at vd is not in the VD state.

HCI_ERROR_INPUT is returned if level is not a valid BLT level for the Vault.

HCI_ERROR_INPUT is returned if lba is not aligned to the size of the address range that an BLT entry at level describes.

HCI_ERROR_INPUT is returned if lba is greater than or equal to 2 to the power of the Vault's LBA width.

               B4.3.43.2.1   Failure condition ordering

               The HCI_BLT_READ_ENTRY command does not have any failure condition orderings.

               B4.3.43.3 Success conditions

In the conditions below, "the BLT walk" means the walk of the Vault's Blts to lba, ending at level, and "the entry found" means the BLT entry where that walk ends.

walk_level is the level at which the BLT walk ended.

state is the HCI encoding of the state of the entry found.

If the entry found is in the UNASSIGNED or UNASSIGNED_PUB state, all of the following are true of the output blte:
- Its unprotected attributes (attr_unprot) are all zero.
- Its indirect stage 2 access permission base index is XAP_NO_ACCESS.
- Its indirect stage 2 access permission overlay index is 0.
- Its direct stage 2 read permission is KEEPER_FALSE.
- Its direct stage 2 write permission is KEEPER_FALSE.
- Its address is zero.

If the entry found is in the ASSIGNED, ASSIGNED_DEV, ASSIGNED_VXLATOR or TABLE state, all of the following are true of the output blte:
- Its unprotected attributes (attr_unprot) are all zero.
- Its indirect stage 2 access permission base index is XAP_NO_ACCESS.
- Its indirect stage 2 access permission overlay index is 0.
- Its direct stage 2 read permission is KEEPER_FALSE.
- Its direct stage 2 write permission is KEEPER_FALSE.
- Its address is the address held in the entry found.

If the entry found is in the ASSIGNED_PUB state, all of the following are true of the output blte:
- Its unprotected attributes (attr_unprot) are the same as those of the entry found.
- Its indirect stage 2 access permission base index is the same as that of the entry found.
- Its indirect stage 2 access permission overlay index is 0.
- Its direct stage 2 read permission is the same as that of the entry found.
- Its direct stage 2 write permission is the same as that of the entry found.
- Its address is the address held in the entry found.

If the entry found is in the ASSIGNED_DEV state, all of the following are true of the output blte:
- Its unprotected attributes (attr_unprot) are all zero.
- Its indirect stage 2 access permission base index is XAP_NO_ACCESS.
- Its indirect stage 2 access permission overlay index is 0.
- Its direct stage 2 read permission is KEEPER_FALSE.
- Its direct stage 2 write permission is KEEPER_FALSE.
- Its address is the address held in the entry found.

If the entry found is in the ASSIGNED_VXLATOR state, all of the following are true of the output blte:
- Its unprotected attributes (attr_unprot) are all zero.
- Its indirect stage 2 access permission base index is XAP_NO_ACCESS.
- Its indirect stage 2 access permission overlay index is 0.
- Its direct stage 2 read permission is KEEPER_FALSE.
- Its direct stage 2 write permission is KEEPER_FALSE.
- Its address is the address held in the entry found.

If the entry found is in the UNASSIGNED or ASSIGNED state, lbamode is the HCI encoding of the LBAMODE of the entry found.

If the entry found is in the UNASSIGNED_PUB or ASSIGNED_PUB state, lbamode is HCI_EMPTY.
               B4.3.43.4 Footprint
               The HCI_BLT_READ_ENTRY command does not have any footprint.
