B6.3.8 PWRCTL_VERSION command
               Query the version of PWRCTL implemented.
               B6.3.8.1 Interface
               B6.3.8.1.1   Input values
         Name                                Register     Bits        Type                 Description
         fid                                 R0           63:0        UInt64               FID, value 0xC4000000
               B6.3.8.1.2   Output values
         Name                                Register     Bits        Type                 Description
         result                              R0           63:0        Pwrctlinterfaceversioninterface version
               B6.3.8.2 Failure conditions
               The PWRCTL_VERSION command does not have any failure conditions.
               B6.3.8.3 Success conditions
The command returns the version of the PWRCTL interface that is implemented.
               B6.3.8.4 Footprint
               The PWRCTL_VERSION command does not have any footprint.
