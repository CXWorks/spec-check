B4.3.55 HCI_VOLUME_GET_STATE command
                Get state of a VOLUME.
                B4.3.55.1 Interface
                B4.3.55.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   R0          63:0        UInt64                                FID, value 0xC4000189
        volume_ptr              R1          63:0        Address                               DPA of the VOLUME
                B4.3.55.1.2   Context
                The HCI_VOLUME_GET_STATE command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        volume                  Keepervolume                    Volumeat(volume_ptr)                           false    VOLUME
                B4.3.55.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                R0          63:0        Hcicommandreturncode                  Command return status
        state                 R1          7:0         Hcivolumestate                          VOLUME state
                The following unused bits of HCI_VOLUME_GET_STATE output values MBZ: R1[63:8].
                B4.3.55.2 Failure conditions

HCI_ERROR_NOT_SUPPORTED is returned if the implementation does not support the Device Assignment feature.

HCI_ERROR_INPUT is returned if volume_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if volume_ptr is not a physical address that can be enrolled.

HCI_ERROR_INPUT is returned if the Extent at volume_ptr is not in the VOLUME state.

             B4.3.55.2.1   Failure condition ordering

The check for Device Assignment support comes before all other checks. If Device Assignment is not supported, HCI_ERROR_NOT_SUPPORTED is returned even when volume_ptr is also invalid. The three HCI_ERROR_INPUT checks have no defined order among themselves: the alignment of volume_ptr, whether volume_ptr can be enrolled, and whether the Extent at volume_ptr is in the VOLUME state.

             B4.3.55.3 Success conditions

The output argument state equals the current state of the VOLUME object at volume_ptr.
             B4.3.55.4 Footprint
             The HCI_VOLUME_GET_STATE command does not have any footprint.
