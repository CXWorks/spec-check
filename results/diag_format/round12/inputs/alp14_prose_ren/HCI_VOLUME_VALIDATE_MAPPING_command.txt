B4.3.63 HCI_VOLUME_VALIDATE_MAPPING command
               Completes a request made by the Vault to validate mappings to device memory from a target LBA range.
     Issue     In HCI_VOLUME_VALIDATE_MAPPING, consider how to combine:
                  • Modification of a range of BLT entries in a single command, and
                  • Checking of output address and HOSTMODE values against worker.lbamode_dev_dpa.

               B4.3.63.2 Failure conditions

In the conditions below, "the BLT walk" means the walk of the Vault's Blts from base. "The walked range" is the address range that starts at base and ends at the top of the address range described by the BLT that the BLT walk reaches. The walked range is determined from the state before the command runs. Where HCI_ERROR_BLT is returned, the level reached by the BLT walk is returned with it.

HCI_ERROR_INPUT is returned if vd is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if vd is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at vd is not in the VD state.

HCI_ERROR_INPUT is returned if worker_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if worker_ptr is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at worker_ptr is not in the WORKER state.

HCI_ERROR_WORKER is returned if the WORKER is in the WORKER_RUNNING state.

HCI_ERROR_WORKER is returned if the WORKER is not owned by the Vault described by vd.

HCI_ERROR_INPUT is returned if drive_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if drive_ptr is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at drive_ptr is not in the DRIVE state.

HCI_ERROR_INPUT is returned if volume_ptr is not aligned to the size of a Extent.

HCI_ERROR_INPUT is returned if volume_ptr is not a enrollable physical address.

HCI_ERROR_INPUT is returned if the Extent at volume_ptr is not in the VOLUME state.

HCI_ERROR_DEVICE is returned if the VOLUME is not associated with the DRIVE at drive_ptr.

HCI_ERROR_INPUT is returned if top is less than or equal to base.

HCI_ERROR_INPUT is returned if base is not equal to the device memory address recorded in the WORKER (dev_mem_addr).

HCI_ERROR_INPUT is returned if top is greater than the device memory top address recorded in the WORKER (dev_mem_top).

HCI_ERROR_BLT is returned if base is not aligned to the size of the address range that an BLT entry describes at the level reached by the BLT walk.

HCI_ERROR_INPUT is returned if top is not aligned to the size of a Extent.

HCI_ERROR_BLT is returned if base is equal to the top of the walked range, so the command cannot make progress.

HCI_ERROR_BLT is returned if the device memory flags in the WORKER mark the memory as DEV_MEM_NON_COHERENT, and not every BLT entry in the walked range has the memory attribute MEMATTR_NON_CACHEABLE.

HCI_ERROR_BLT is returned if the device memory flags in the WORKER mark the memory as DEV_MEM_NON_COHERENT, and not every BLT entry in the walked range maps non-coherent device memory.

HCI_ERROR_BLT is returned if the device memory flags in the WORKER mark the memory as DEV_MEM_COHERENT, and not every BLT entry in the walked range has the memory attribute MEMATTR_PASSTHROUGH.

HCI_ERROR_BLT is returned if the device memory flags in the WORKER mark the memory as DEV_MEM_COHERENT, and not every BLT entry in the walked range maps coherent device memory.

HCI_ERROR_BLT is returned if the output addresses of the BLT entries in the walked range are not contiguous, starting from the device memory physical address recorded in the WORKER (dev_mem_dpa).

HCI_ERROR_BLT is returned if any address in the range from base to top is live in an auxiliary BLT of the Vault, as evaluated before the command runs.

               B4.3.63.2.1   Failure condition ordering

The checks that vd is a enrollable physical address and that the Extent at vd is in the VD state are made before the check that base is aligned to the BLT walk level.

The checks that vd is a enrollable physical address and that the Extent at vd is in the VD state are made before the check that base is not equal to the top of the walked range.

The checks that worker_ptr is a enrollable physical address and that the Extent at worker_ptr is in the WORKER state are made before the checks that the WORKER is not in the WORKER_RUNNING state and that the WORKER is owned by the Vault described by vd.

The checks that drive_ptr is a enrollable physical address, that the Extent at drive_ptr is in the DRIVE state, that volume_ptr is a enrollable physical address, and that the Extent at volume_ptr is in the VOLUME state are made before the check that the VOLUME is associated with the DRIVE at drive_ptr.

The check that base is equal to the device memory address recorded in the WORKER is made before the check that base is aligned to the BLT walk level.

The check that top is aligned to the size of a Extent is made before the check that base is not equal to the top of the walked range.

               B4.3.63.3 Success conditions

The LBAMODE of every BLT entry in the walked range is DEV.

The device memory address recorded in the WORKER (dev_mem_addr) is set to the lower of top and the top of the walked range.

The device memory physical address recorded in the WORKER (dev_mem_dpa) is set to its value before the command, plus the size of the range from base to the top of the walked range.

out_top is set to the lower of top and the top of the walked range.
