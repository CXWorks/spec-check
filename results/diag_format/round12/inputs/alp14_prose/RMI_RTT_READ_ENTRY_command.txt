B4.3.43 RMI_RTT_READ_ENTRY command
                Reads an entry from a primary RTT.
                B4.3.43.1 Interface
                B4.3.43.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000161
        rd                    X1          63:0        Address                               PA of the RD for the target Realm
        ipa                   X2          63:0        Address                               Realm Address for which to read the
                                                                                            RTTE
        level                 X3          63:0        Int64                                 RTT level at which to read the RTTE
                B4.3.43.1.2   Context
                The RMI_RTT_READ_ENTRY command operates on the following context.
        Name                  Type                       Value                                      Before    Description
        realm                 RmmRealm                   RealmAt(rd)                                false     Realm
        walk                  RmmRttWalkResult           RttWalk(                                   false     RTT walk result
                                                             realm, ipa, level,
                                                             RMM_RTT_TREE_PRIMARY)
        rtte                  RmmRttEntry                RttDescriptorDecode(                       false     RTT entry value
                                                             desc,                                            returned to Host
                                                             realm.rtt_s2ap_encoding
                                                         )
                B4.3.43.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
        walk_level            X1          63:0        UInt64                                RTT level reached by the RTT walk
        state                 X2          7:0         RmiRttEntryState                      State of RTTE reached by the walk
        desc                  X3          63:0        Bits64                                RTTE descriptor
        ripas                 X4          7:0         RmiRipas                              RIPAS of RTTE reached by the walk
                The following unused bits of RMI_RTT_READ_ENTRY output values MBZ: X2[63:8], X4[63:8].
                The layout and encoding of fields in the desc output value match “Attribute fields in stage 2 VMSAv8-64 Block
                and Page descriptors” in Arm Architecture Reference Manual for A-Profile architecture [3].
               B4.3.43.2 Failure conditions

RMI_ERROR_INPUT is returned if rd is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rd is not a delegable physical address.

RMI_ERROR_INPUT is returned if the Granule at rd is not in the RD state.

RMI_ERROR_INPUT is returned if level is not a valid RTT level for the Realm.

RMI_ERROR_INPUT is returned if ipa is not aligned to the size of the address range that an RTT entry at level describes.

RMI_ERROR_INPUT is returned if ipa is greater than or equal to 2 to the power of the Realm's IPA width.

               B4.3.43.2.1   Failure condition ordering

               The RMI_RTT_READ_ENTRY command does not have any failure condition orderings.

               B4.3.43.3 Success conditions

In the conditions below, "the RTT walk" means the walk of the Realm's RTTs to ipa, ending at level, and "the entry found" means the RTT entry where that walk ends.

walk_level is the level at which the RTT walk ended.

state is the RMI encoding of the state of the entry found.

If the entry found is in the UNASSIGNED or UNASSIGNED_NS state, all of the following are true of the output rtte:
- Its unprotected attributes (attr_unprot) are all zero.
- Its indirect stage 2 access permission base index is S2AP_NO_ACCESS.
- Its indirect stage 2 access permission overlay index is 0.
- Its direct stage 2 read permission is RMM_FALSE.
- Its direct stage 2 write permission is RMM_FALSE.
- Its address is zero.

If the entry found is in the ASSIGNED, ASSIGNED_DEV, ASSIGNED_VSMMU or TABLE state, all of the following are true of the output rtte:
- Its unprotected attributes (attr_unprot) are all zero.
- Its indirect stage 2 access permission base index is S2AP_NO_ACCESS.
- Its indirect stage 2 access permission overlay index is 0.
- Its direct stage 2 read permission is RMM_FALSE.
- Its direct stage 2 write permission is RMM_FALSE.
- Its address is the address held in the entry found.

If the entry found is in the ASSIGNED_NS state, all of the following are true of the output rtte:
- Its unprotected attributes (attr_unprot) are the same as those of the entry found.
- Its indirect stage 2 access permission base index is the same as that of the entry found.
- Its indirect stage 2 access permission overlay index is 0.
- Its direct stage 2 read permission is the same as that of the entry found.
- Its direct stage 2 write permission is the same as that of the entry found.
- Its address is the address held in the entry found.

If the entry found is in the ASSIGNED_DEV state, all of the following are true of the output rtte:
- Its unprotected attributes (attr_unprot) are all zero.
- Its indirect stage 2 access permission base index is S2AP_NO_ACCESS.
- Its indirect stage 2 access permission overlay index is 0.
- Its direct stage 2 read permission is RMM_FALSE.
- Its direct stage 2 write permission is RMM_FALSE.
- Its address is the address held in the entry found.

If the entry found is in the ASSIGNED_VSMMU state, all of the following are true of the output rtte:
- Its unprotected attributes (attr_unprot) are all zero.
- Its indirect stage 2 access permission base index is S2AP_NO_ACCESS.
- Its indirect stage 2 access permission overlay index is 0.
- Its direct stage 2 read permission is RMM_FALSE.
- Its direct stage 2 write permission is RMM_FALSE.
- Its address is the address held in the entry found.

If the entry found is in the UNASSIGNED or ASSIGNED state, ripas is the RMI encoding of the RIPAS of the entry found.

If the entry found is in the UNASSIGNED_NS or ASSIGNED_NS state, ripas is RMI_EMPTY.
               B4.3.43.4 Footprint
               The RMI_RTT_READ_ENTRY command does not have any footprint.
