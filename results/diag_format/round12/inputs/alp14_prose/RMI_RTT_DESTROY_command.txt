B4.3.39 RMI_RTT_DESTROY command
                Destroys a primary RTT.
                B4.3.39.1 Interface
                B4.3.39.1.1   Input values

               B4.3.39.2 Failure conditions

RMI_ERROR_INPUT is returned if rd is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rd is not a delegable physical address.

RMI_ERROR_INPUT is returned if the Granule at rd is not in the RD state.

RMI_ERROR_INPUT is returned if level is not a valid RTT level for the Realm, or if level is the starting level of the Realm's RTT.

RMI_ERROR_INPUT is returned if ipa is not aligned to the size of the address range that an RTT entry maps at the level one less than level.

RMI_ERROR_INPUT is returned if ipa is outside the Realm's IPA space. This means ipa is greater than or equal to 2 raised to the power of the Realm's IPA width.

RMI_ERROR_RTT is returned if the RTT walk to ipa stops at a level lower than one less than level. The error index is the level at which the walk stopped, and the output top is set to walk_top.

RMI_ERROR_RTT is returned if the RTT entry that the walk reaches is not in the TABLE state. The error index is the level at which the walk stopped, and the output top is set to walk_top.

RMI_ERROR_RTT is returned if the RTT that this RTT entry points to is live. The error index is level, and the output top is set to ipa.

RMI_ERROR_RTT is returned if ipa is referenced by an auxiliary RTT of the Realm. The error index is the level at which the walk stopped.

                    B4.3.39.2.1   Failure condition ordering

The check that rd is a delegable physical address and the check that the Granule at rd is in the RD state are both made before two other checks. The first is the check that the RTT walk reaches the level one less than level. The second is the check that the RTT entry reached is in the TABLE state.

The check that level is valid and is not the starting level, and the check that ipa is within the Realm's IPA space, are also both made before those two RTT walk checks.

The check that the RTT entry reached is in the TABLE state is made before two later checks. One is the check that the RTT it points to is not live. The other is the check that ipa is not referenced by an auxiliary RTT.

                    B4.3.39.3 Success conditions

If ipa is a Protected address, the RTT entry reached by the walk is in the UNASSIGNED state.

If ipa is a Protected address, the RIPAS of the RTT entry reached by the walk is DESTROYED.

If ipa is not a Protected address, the RTT entry reached by the walk is in the UNASSIGNED_NS state.

The Granule that held the destroyed RTT, which is the one at the address in the RTT entry, is in the DELEGATED state.

The output rtt is the address of the destroyed RTT, as held in the RTT entry.

The output top is set to walk_top.
