B5.3.19 RSI_VDEV_VALIDATE_MAPPING command
                 Validate Realm device memory mappings.
                 B5.3.19.1 Interface
                 B5.3.19.1.1   Input values
         Name                  Register    Bits        Type                                  Description
         fid                   X0          63:0        UInt64                                FID, value 0xC400019F
         vdev_id               X1          63:0        Bits64                                Realm device identifier
         ipa_base              X2          63:0        Address                               Base of target IPA region
         ipa_top               X3          63:0        Address                               Top of target IPA region
         pa_base               X4          63:0        Address                               Base of target PA region
         flags                 X5          63:0        RsiDevMemFlags                        Flags
         lock_nonce            X6          63:0        UInt64                                Nonce generated on most recent
                                                                                             transition to LOCKED state
         meas_nonce            X7          63:0        UInt64                                GET_MEASUREMENT request
                                                                                             sequence number
         report_nonce          X8          63:0        UInt64                                GET_INTERFACE_REPORT request
                                                                                             sequence number
                 B5.3.19.1.2   Context
                 The RSI_VDEV_VALIDATE_MAPPING command operates on the following context.
         Name                  Type                       Value                                      Before    Description
         realm                 RmmRealm                   CurrentRealm()                             false     Current Realm
         rec                   RmmRec                     CurrentRec()                               false     Current REC
         vdev                  RmmVdev                    VdevFromVdevId(                            false     Realm device
                                                              realm,
                                                              vdev_id)
                 B5.3.19.1.3   Output values
         Name                  Register    Bits        Type                                  Description
         result                X0          63:0        RsiCommandReturnCode                  Command return status
         new_ipa_base          X1          63:0        Address                               Base of IPA region which was not
                                                                                             modified by the command
         response              X2          0:0         RsiResponse                           Whether the Host accepted or rejected
                                                                                             the request
                The following unused bits of RSI_VDEV_VALIDATE_MAPPING output values MBZ: X2[63:1].
                B5.3.19.2 Failure conditions

RSI_ERROR_STATE is returned if the Device Assignment feature is not enabled for the Realm.

RSI_ERROR_INPUT is returned if vdev_id does not identify a VDEV that is in use by the Realm.

RSI_ERROR_INPUT is returned if the state of the VDEV is neither VDEV_LOCKED nor VDEV_STARTED.

RSI_ERROR_INPUT is returned if ipa_base is not aligned to the size of a Granule.

RSI_ERROR_INPUT is returned if ipa_top is not aligned to the size of a Granule.

RSI_ERROR_INPUT is returned if pa_base is not aligned to the size of a Granule.

RSI_ERROR_INPUT is returned if ipa_top is less than or equal to ipa_base.

RSI_ERROR_INPUT is returned if the IPA range from ipa_base to ipa_top is not entirely within the protected IPA space of the Realm.

RSI_ERROR_DEVICE is returned if lock_nonce, meas_nonce and report_nonce do not match the attestation information recorded for the VDEV.

                B5.3.19.2.1       Failure condition ordering

The check that the Device Assignment feature is enabled for the Realm is made before the check that vdev_id identifies a VDEV in use by the Realm.

                B5.3.19.3 Success conditions

new_ipa_base is equal to the device memory address recorded in the REC.

response is the device memory response recorded in the REC, converted to its RSI encoding.
             B5.3.19.4 Footprint
             The RSI_VDEV_VALIDATE_MAPPING command does not have any footprint.
