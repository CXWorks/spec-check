B4.3.19 RMI_PDEV_SET_PUBKEY command
               Provide public key associated with a PDEV.
               B4.3.19.1 Interface
               B4.3.19.1.1   Input values
        Name                 Register    Bits        Type                                  Description
        fid                  X0          63:0        UInt64                                FID, value 0xC400017B
        pdev_ptr             X1          63:0        Address                               PA of the PDEV
        params_ptr           X2          63:0        Address                               PA of the key parameters
               B4.3.19.1.2   Context
               The RMI_PDEV_SET_PUBKEY command operates on the following context.
        Name                 Type                       Value                                      Before   Description
        pdev                 RmmPdev                    PdevAt(pdev_ptr)                           false    PDEV
        params               RmiPublicKeyParams         RmiPublicKeyParamsAt(                      false    Public key parameters
                                                            params_ptr)
               B4.3.19.1.3   Output values
        Name                 Register    Bits        Type                                  Description
        result               X0          63:0        RmiCommandReturnCode                  Command return status
               B4.3.19.2 Failure conditions

RMI_ERROR_NOT_SUPPORTED is returned if the implementation does not support the Device Assignment feature.

RMI_ERROR_INPUT is returned if pdev_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if pdev_ptr is not a delegable physical address.

RMI_ERROR_INPUT is returned if the Granule at pdev_ptr is not in the PDEV state.

RMI_ERROR_INPUT is returned if params_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if the Granule at params_ptr cannot be accessed in the Non-secure physical address space.

RMI_ERROR_INPUT is returned if the key length given in the parameters at params_ptr is greater than 1024.

RMI_ERROR_INPUT is returned if the metadata length given in the parameters at params_ptr is greater than 1024.

RMI_ERROR_INPUT is returned if the key is invalid. For example, the key length may be invalid for the specified signature algorithm.

RMI_ERROR_INPUT is returned if the metadata is invalid. For example, the metadata length may be invalid for the specified signature algorithm.

RMI_ERROR_DEVICE is returned if the PDEV is not in the PDEV_NEEDS_KEY state.

                B4.3.19.2.1              Failure condition ordering

The check for Device Assignment support is made before these checks: pdev_ptr alignment, whether pdev_ptr is delegable, the state of the Granule at pdev_ptr, params_ptr alignment, whether the Granule at params_ptr can be accessed in the Non-secure physical address space, the key length limit, key validity, the metadata length limit, and metadata validity. So if Device Assignment is not supported, RMI_ERROR_NOT_SUPPORTED is returned and none of these checks is made.

The check that the Granule at pdev_ptr is in the PDEV state is made before the check that the PDEV is in the PDEV_NEEDS_KEY state. So if the Granule is not in the PDEV state, RMI_ERROR_INPUT is returned, not RMI_ERROR_DEVICE.

                B4.3.19.3 Success conditions

On success, the PDEV moves to the PDEV_HAS_KEY state.

On success, the communication state of the PDEV is DEV_COMM_PENDING.
