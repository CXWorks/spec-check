B4.3.29 RMI_REC_DESTROY command
              Destroys a REC.
              B4.3.29.1 Interface
              B4.3.29.1.1   Input values
        Name                Register    Bits        Type                                  Description
        fid                 X0          63:0        UInt64                                FID, value 0xC400015B
        rec_ptr             X1          63:0        Address                               PA of the target REC
              B4.3.29.1.2   Context
              The RMI_REC_DESTROY command operates on the following context.
        Name                Type                       Value                                      Before   Description
        rd_pre              Address                    RecAt(rec_ptr).owner                       true     RD address
        realm_pre           RmmRealm                   RealmAt(rd_pre)                            true     Realm
        realm               RmmRealm                   RealmAt(rd_pre)                            false    Realm
        rec_pre             RmmRec                     RecAt(rec_ptr)                             true     REC
        rec                 RmmRec                     RecAt(rec_ptr)                             false    REC
              B4.3.29.1.3   Output values
        Name                Register    Bits        Type                                  Description
        result              X0          63:0        RmiCommandReturnCode                  Command return status
              B4.3.29.2 Failure conditions

RMI_ERROR_INPUT is returned if rec_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rec_ptr is not a physical address that can be delegated.

RMI_ERROR_INPUT is returned if the Granule at rec_ptr is not in the REC state.

RMI_ERROR_REC is returned if the REC is in the REC_RUNNING state.

                B4.3.29.2.1   Failure condition ordering

The RMM checks that rec_ptr can be delegated, and that the Granule at rec_ptr is in the REC state, before it checks whether the REC is in the REC_RUNNING state. If rec_ptr fails either of the first two checks, RMI_ERROR_INPUT is returned, not RMI_ERROR_REC. This ordering does not cover the check that rec_ptr is Granule-aligned.

                B4.3.29.3 Success conditions

The Granule at rec_ptr is in the DELEGATED state.

Each auxiliary Granule of the REC is in the DELEGATED state. These are the auxiliary Granules the REC had before the command ran. Their number is the REC auxiliary Granule count for the owning Realm, as it was before the command ran.

The Realm's REC count, num_recs, is one less than it was before the command ran.
