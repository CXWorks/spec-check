B5.3.22 RSI_VSMMU_GET_INFO command
                Get information of a VSMMU.
                B5.3.22.1 Interface
                B5.3.22.1.1   Input values
         Name                 Register    Bits        Type                                  Description
         fid                  X0          63:0        UInt64                                FID, value 0xC400019A
         addr                 X1          63:0        Address                               Base IPA of the VSMMU
                B5.3.22.1.2   Context
                The RSI_VSMMU_GET_INFO command operates on the following context.
         Name                 Type                       Value                                      Before   Description
         realm                RmmRealm                   CurrentRealm()                             false    Current Realm
         walk                 RmmRttWalkResult           RttWalk(                                   false    RTT walk result
                                                             realm, addr,
                                                             RMM_RTT_PAGE_LEVEL,
                                                             RMM_RTT_TREE_PRIMARY)
                B5.3.22.1.3   Output values
         Name                 Register    Bits        Type                                  Description
         result               X0          63:0        RsiCommandReturnCode                  Command return status
         top                  X1          63:0        Address                               Top IPA of the VSMMU
                B5.3.22.2 Failure conditions
RSI_ERROR_INPUT is returned if addr is not aligned to the size of a Granule.

RSI_ERROR_INPUT is returned if addr is not a Protected IPA of the Realm.

RSI_ERROR_INPUT is returned if the RTT entry found by walking the Realm's RTT to addr is not in the ASSIGNED_VSMMU state.

RSI_ERROR_INPUT is returned if addr is not the register base address of the VSMMU referenced by the RTT entry found by walking the Realm's RTT to addr.
             B5.3.22.2.1    Failure condition ordering
             The RSI_VSMMU_GET_INFO command does not have any failure condition orderings.
             B5.3.22.3 Success conditions
On success, top is the register top address of the VSMMU referenced by the RTT entry found by walking the Realm's RTT to addr.
             B5.3.22.4 Footprint
             The RSI_VSMMU_GET_INFO command does not have any footprint.
