B4.3.63 RMI_VDEV_VALIDATE_MAPPING command
               Completes a request made by the Realm to validate mappings to device memory from a target IPA range.
     Issue     In RMI_VDEV_VALIDATE_MAPPING, consider how to combine:
                  • Modification of a range of RTT entries in a single command, and
                  • Checking of output address and HIPAS values against rec.ripas_dev_pa.

               B4.3.63.2 Failure conditions

In the conditions below, "the RTT walk" means the walk of the Realm's RTTs from base. "The walked range" is the address range that starts at base and ends at the top of the address range described by the RTT that the RTT walk reaches. The walked range is determined from the state before the command runs. Where RMI_ERROR_RTT is returned, the level reached by the RTT walk is returned with it.

RMI_ERROR_INPUT is returned if rd is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rd is not a delegable physical address.

RMI_ERROR_INPUT is returned if the Granule at rd is not in the RD state.

RMI_ERROR_INPUT is returned if rec_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rec_ptr is not a delegable physical address.

RMI_ERROR_INPUT is returned if the Granule at rec_ptr is not in the REC state.

RMI_ERROR_REC is returned if the REC is in the REC_RUNNING state.

RMI_ERROR_REC is returned if the REC is not owned by the Realm described by rd.

RMI_ERROR_INPUT is returned if pdev_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if pdev_ptr is not a delegable physical address.

RMI_ERROR_INPUT is returned if the Granule at pdev_ptr is not in the PDEV state.

RMI_ERROR_INPUT is returned if vdev_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if vdev_ptr is not a delegable physical address.

RMI_ERROR_INPUT is returned if the Granule at vdev_ptr is not in the VDEV state.

RMI_ERROR_DEVICE is returned if the VDEV is not associated with the PDEV at pdev_ptr.

RMI_ERROR_INPUT is returned if top is less than or equal to base.

RMI_ERROR_INPUT is returned if base is not equal to the device memory address recorded in the REC (dev_mem_addr).

RMI_ERROR_INPUT is returned if top is greater than the device memory top address recorded in the REC (dev_mem_top).

RMI_ERROR_RTT is returned if base is not aligned to the size of the address range that an RTT entry describes at the level reached by the RTT walk.

RMI_ERROR_INPUT is returned if top is not aligned to the size of a Granule.

RMI_ERROR_RTT is returned if base is equal to the top of the walked range, so the command cannot make progress.

RMI_ERROR_RTT is returned if the device memory flags in the REC mark the memory as DEV_MEM_NON_COHERENT, and not every RTT entry in the walked range has the memory attribute MEMATTR_NON_CACHEABLE.

RMI_ERROR_RTT is returned if the device memory flags in the REC mark the memory as DEV_MEM_NON_COHERENT, and not every RTT entry in the walked range maps non-coherent device memory.

RMI_ERROR_RTT is returned if the device memory flags in the REC mark the memory as DEV_MEM_COHERENT, and not every RTT entry in the walked range has the memory attribute MEMATTR_PASSTHROUGH.

RMI_ERROR_RTT is returned if the device memory flags in the REC mark the memory as DEV_MEM_COHERENT, and not every RTT entry in the walked range maps coherent device memory.

RMI_ERROR_RTT is returned if the output addresses of the RTT entries in the walked range are not contiguous, starting from the device memory physical address recorded in the REC (dev_mem_pa).

RMI_ERROR_RTT is returned if any address in the range from base to top is live in an auxiliary RTT of the Realm, as evaluated before the command runs.

               B4.3.63.2.1   Failure condition ordering

The checks that rd is a delegable physical address and that the Granule at rd is in the RD state are made before the check that base is aligned to the RTT walk level.

The checks that rd is a delegable physical address and that the Granule at rd is in the RD state are made before the check that base is not equal to the top of the walked range.

The checks that rec_ptr is a delegable physical address and that the Granule at rec_ptr is in the REC state are made before the checks that the REC is not in the REC_RUNNING state and that the REC is owned by the Realm described by rd.

The checks that pdev_ptr is a delegable physical address, that the Granule at pdev_ptr is in the PDEV state, that vdev_ptr is a delegable physical address, and that the Granule at vdev_ptr is in the VDEV state are made before the check that the VDEV is associated with the PDEV at pdev_ptr.

The check that base is equal to the device memory address recorded in the REC is made before the check that base is aligned to the RTT walk level.

The check that top is aligned to the size of a Granule is made before the check that base is not equal to the top of the walked range.

               B4.3.63.3 Success conditions

The RIPAS of every RTT entry in the walked range is DEV.

The device memory address recorded in the REC (dev_mem_addr) is set to the lower of top and the top of the walked range.

The device memory physical address recorded in the REC (dev_mem_pa) is set to its value before the command, plus the size of the range from base to the top of the walked range.

out_top is set to the lower of top and the top of the walked range.
