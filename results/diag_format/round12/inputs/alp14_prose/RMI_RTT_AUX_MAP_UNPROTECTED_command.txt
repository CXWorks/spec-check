B4.3.35 RMI_RTT_AUX_MAP_UNPROTECTED command
              Copies a valid or table descriptor at an Unprotected IPA from the starting level of the primary RTT to an auxiliary
              RTT.
              B4.3.35.1 Interface
              B4.3.35.1.1    Input values

              B4.3.35.2 Failure conditions

RMI_ERROR_INPUT is returned if rd is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rd is not a physical address that can be delegated.

RMI_ERROR_INPUT is returned if the Granule at rd is not in the RD state.

RMI_ERROR_INPUT is returned if ipa is not aligned to the size of the address range that one RTT entry maps at the starting RTT level of the Realm.

RMI_ERROR_INPUT is returned if ipa is outside the Realm's IPA space, that is, ipa is greater than or equal to 2 to the power of the Realm's IPA width. It is also returned if ipa is a Protected address in the Realm.

RMI_ERROR_INPUT is returned if any of these is true:
- the Realm does not use a separate RTT tree for each Plane (its per-Plane RTT tree setting is FEATURE_FALSE)
- index identifies the primary RTT tree (RMM_RTT_TREE_PRIMARY)
- index is greater than the number of auxiliary Planes in the Realm

RMI_ERROR_RTT is returned if the RTT entry for ipa in the primary RTT tree is in the UNASSIGNED_NS state. The returned value also includes the RTT level at which the walk of the primary RTT tree ended.

               B4.3.35.2.1   Failure condition ordering

The check that rd is a physical address that can be delegated is done before the check on the state of the primary RTT entry. The check that the Granule at rd is in the RD state is also done before that check.

The check that ipa is inside the Realm's IPA space and is not a Protected address is done before the check on the state of the primary RTT entry. The check on index is also done before that check.

               B4.3.35.3 Success conditions

The state of the RTT entry for ipa in the auxiliary RTT tree selected by index matches the state of the RTT entry for ipa in the primary RTT tree.

The memory attributes of the auxiliary RTT entry match those of the primary RTT entry, compared as Unprotected entries. The stage 2 access permissions of the two entries also match, compared with the Realm's stage 2 access permission encoding.

The output address in the auxiliary RTT entry matches the output address in the primary RTT entry.
