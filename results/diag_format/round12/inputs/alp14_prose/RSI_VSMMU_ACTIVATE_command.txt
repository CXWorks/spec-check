B5.3.21 RSI_VSMMU_ACTIVATE command
                Activate a VSMMU.
                B5.3.21.1 Interface
                B5.3.21.1.1   Input values
         Name                 Register    Bits        Type                                  Description
         fid                  X0          63:0        UInt64                                FID, value 0xC400019B
         base                 X1          63:0        Address                               Base of target IPA region
         top                  X2          63:0        Address                               Top of target IPA region
                B5.3.21.1.2   Context
                The RSI_VSMMU_ACTIVATE command operates on the following context.
         Name                 Type                       Value                                      Before    Description
         realm                RmmRealm                   CurrentRealm()                             false     Current Realm
         walk                 RmmRttWalkResult           RttWalk(                                   false     RTT walk result
                                                             realm, base,
                                                             RMM_RTT_PAGE_LEVEL,
                                                             RMM_RTT_TREE_PRIMARY)
         vsmmu                RmmVsmmu                   VsmmuAt(walk.rtte.addr)                    false     VSMMU
                B5.3.21.1.3   Output values
         Name                 Register    Bits        Type                                  Description
         result               X0          63:0        RsiCommandReturnCode                  Command return status
         new_base             X1          63:0        Address                               Base of IPA region which was not
                                                                                            modified by the command
                B5.3.21.2 Failure conditions

RSI_ERROR_INPUT is returned if base is not aligned to the size of a Granule.

RSI_ERROR_INPUT is returned if top is not aligned to the size of a Granule.

RSI_ERROR_INPUT is returned if top is less than or equal to base, compared as unsigned integers.

RSI_ERROR_INPUT is returned if the address range from base up to, but not including, top is not entirely within the Protected IPA space of the Realm.

RSI_ERROR_INPUT is returned if the RTT entry reached by the RTT walk is not in the ASSIGNED_VSMMU state.

               B5.3.21.2.1   Failure condition ordering

               The RSI_VSMMU_ACTIVATE command does not have any failure condition orderings.

               B5.3.21.3 Success conditions

On success, the RIPAS of the address range from base up to, but not including, new_base is DEV.

If base is equal to the base address of the VSMMU register region, and new_base is not equal to the top address of that region, the VSMMU state is VSMMU_ACTIVATING.

If new_base is equal to the top address of the VSMMU register region, the VSMMU state is VSMMU_ACTIVE.
               B5.3.21.4 Footprint
               The RSI_VSMMU_ACTIVATE command does not have any footprint.
