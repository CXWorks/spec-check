              Create a VSMMU.
              B4.3.65.1 Interface
              B4.3.65.1.1   Input values

        params_ptr          X3          63:0        Address                               PA of VSMMU parameters

        Name                Register    Bits        Type                                  Description
        result              X0          63:0        RmiCommandReturnCode                  Command return status
              B4.3.65.2 Failure conditions

RMI_ERROR_NOT_SUPPORTED is returned if the implementation does not support the device assignment feature (feat_da).

RMI_ERROR_INPUT is returned if rd is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rd is not a physical address that can be delegated.

RMI_ERROR_INPUT is returned if the Granule at rd is not in the RD state.

RMI_ERROR_INPUT is returned if the state of the Realm described by rd is not REALM_NEW.

RMI_ERROR_INPUT is returned if vsmmu_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if vsmmu_ptr is not a DRAM physical address that can be delegated.

RMI_ERROR_INPUT is returned if the Granule at vsmmu_ptr is not in the DELEGATED state.

RMI_ERROR_INPUT is returned if params_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if the Granule at params_ptr cannot be accessed from the Non-secure physical address space.

RMI_ERROR_INPUT is returned if the VSMMU parameters at params_ptr are not valid.

RMI_ERROR_INPUT is returned if the reg_base or the reg_top value in the VSMMU parameters is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if the reg_base or the reg_top value in the VSMMU parameters is not a Protected address in the Realm, or if reg_top is not greater than reg_base.

                B4.3.65.2.1           Failure condition ordering

The checks that rd can be delegated and that the Granule at rd is in the RD state are made before the check of the Realm's state.

The check that the implementation supports the device assignment feature is made before every other check listed here except the Realm state check: the alignment, delegability and state checks on rd, the alignment, delegability and state checks on vsmmu_ptr, the alignment, access and validity checks on params_ptr, and the alignment and bounds checks on reg_base and reg_top.

                B4.3.65.3 Success conditions

The Granule at vsmmu_ptr is in the VSMMU state.

The VSMMU is in the VSMMU_INACTIVE state.

The VSMMU belongs to the Realm described by rd.

The reg_base value of the VSMMU equals the reg_base value in the VSMMU parameters.

The reg_top value of the VSMMU equals the reg_top value in the VSMMU parameters.

The aidr value of the VSMMU equals the aidr value in the VSMMU parameters.

Each of the idr values 0 to 6 of the VSMMU equals the matching idr value in the VSMMU parameters.

The Realm's count of VSMMUs (num_vsmmus) is one more than it was before the command.
