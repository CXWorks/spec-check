B5.3.17 RSI_VDEV_GET_INFO command
                Get information for a device.
                Device configuration information, including digests of attestation evidence for the device are written to an
                RsiVdevInfo structure, at an address specified by the caller. Digests are calculated using the PDEV Hash
                Algorithm.
                B5.3.17.1 Interface
                B5.3.17.1.1    Input values
         Name                 Register     Bits        Type                                  Description
         fid                  X0           63:0        UInt64                                FID, value 0xC400019D
         vdev_id              X1           63:0        Bits64                                Realm device identifier
         addr                 X2           63:0        Address                               IPA to which the configuration data will
                                                                                             be written
                B5.3.17.1.2    Context
                The RSI_VDEV_GET_INFO command operates on the following context.
         Name                 Type                        Value                                      Before    Description
         realm                RmmRealm                    CurrentRealm()                             false     Current Realm
         vdev                 RmmVdev                     VdevFromVdevId(                            false     Realm device
                                                              realm,
                                                              vdev_id)
         pdev                 RmmPdev                     PdevAt(vdev.pdev)                          false     Physical device
         cfg                  RsiVdevInfo                 RsiVdevInfoAt(addr)                        false     Device configuration
         walk                 RmmRttWalkResult            RttWalk(                                   false     RTT walk result
                                                              realm, addr,
                                                              RMM_RTT_PAGE_LEVEL,
                                                              RMM_RTT_TREE_PRIMARY)
                B5.3.17.1.3    Output values
         Name                 Register     Bits        Type                                  Description
         result               X0           63:0        RsiCommandReturnCode                  Command return status
                B5.3.17.2 Failure conditions

RSI_ERROR_STATE is returned if the Realm was not created with the device assignment feature enabled.

RSI_ERROR_INPUT is returned if vdev_id does not identify a VDEV that is assigned to the Realm.

RSI_ERROR_INPUT is returned if addr is not aligned to 512 bytes.

RSI_ERROR_INPUT is returned if addr is not within the protected IPA space of the Realm.

RSI_ERROR_INPUT is returned if the RIPAS of the IPA at addr is EMPTY.

                B5.3.17.2.1   Failure condition ordering

The check that the device assignment feature is enabled for the Realm comes before the vdev_id check, the addr alignment check and the check that addr is within the protected IPA space. So if the feature is not enabled, RSI_ERROR_STATE is returned even if one of those three checks would also fail. No ordering is defined between the check that the RIPAS at addr is EMPTY and any other failure condition.

                B5.3.17.3 Success conditions

The device configuration structure written to addr contains the following values:

- The hash algorithm is the hash algorithm of the PDEV.
- The p2p_enabled flag shows whether peer-to-peer communication is enabled for the PDEV.
- The p2p_bound flag shows whether the VDEV is bound to a peer-to-peer peer.
- The p2p_peer field identifies the peer-to-peer peer of the VDEV.
- The lock nonce, measurement nonce and report nonce match the attestation information of the VDEV.
- The VCA digest is the VCA digest of the PDEV.
- The measurement digest is the measurement digest of the VDEV.
- The report digest is the report digest of the VDEV.
- The state field is the current state of the VDEV.
             B5.3.17.4 Footprint
             The RSI_VDEV_GET_INFO command does not have any footprint.
