              B4.3.30.2 Failure conditions

RMI_ERROR_INPUT is returned if run_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if the Granule at run_ptr cannot be accessed in the Non-secure PAS.

RMI_ERROR_INPUT is returned if rec_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rec_ptr is not a delegable physical address.

RMI_ERROR_INPUT is returned if the state of the Granule at rec_ptr is not REC.

RMI_ERROR_REALM, with index 0, is returned if the state of the Realm that owns the REC is REALM_NEW.

RMI_ERROR_REALM, with index 1, is returned if the state of the Realm that owns the REC is REALM_SYSTEM_OFF.

RMI_ERROR_REC is returned if the state of the REC is REC_RUNNING.

RMI_ERROR_REC is returned if the REC is marked NOT_RUNNABLE.

RMI_ERROR_REC is returned if the Host requests MMIO emulation, meaning that the emul_mmio flag in the entry section of the RecRun object is RMI_EMULATED_MMIO, and the most recent REC exit was not caused by an emulatable abort, meaning that the emulatable_abort value of the REC is not EMULATABLE_ABORT.

RMI_ERROR_REC is returned if the gicv3_hcr and gicv3_lrs values in the entry section of the RecRun object do not describe a valid GICv3 configuration.

RMI_ERROR_REC is returned if the REC has a pending operation, meaning that its pending value is not REC_PENDING_NONE.

               B4.3.30.2.1   Failure condition ordering

These five checks are made before any of the remaining checks:
- that rec_ptr is aligned to the size of a Granule
- that rec_ptr is a delegable physical address
- that the state of the Granule at rec_ptr is REC
- that the Granule at run_ptr can be accessed in the Non-secure PAS
- that run_ptr is aligned to the size of a Granule

The remaining checks are made after all five of them:
- that the state of the REC is not REC_RUNNING
- that the REC is not marked NOT_RUNNABLE
- the check on the MMIO emulation request
- that the state of the Realm is not REALM_NEW
- that the state of the Realm is not REALM_SYSTEM_OFF
- that the GICv3 configuration is valid
- that the REC has no pending operation

No order is defined among the checks within either group.

As a result, an RMI_ERROR_INPUT failure is reported in preference to an RMI_ERROR_REALM or RMI_ERROR_REC failure.

               B4.3.30.3 Success conditions

The exit section of the RecRun object contains information about the Realm exit syndrome.

The emulatable_abort value of the REC is updated.
