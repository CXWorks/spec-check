B4.3.41 RMI_RTT_INIT_RIPAS command
               Set the RIPAS of a target IPA range to RAM, for a Realm in the REALM_NEW state.
               B4.3.41.1 Interface
               B4.3.41.1.1   Input values
        Name                 Register     Bits        Type                                  Description
        fid                  X0           63:0        UInt64                                FID, value 0xC4000168
        rd                   X1           63:0        Address                               PA of the RD for the target Realm
        base                 X2           63:0        Address                               Base of target IPA region
        top                  X3           63:0        Address                               Top of target IPA region
               B4.3.41.1.2   Context
               The RMI_RTT_INIT_RIPAS command operates on the following context.
        Name                 Type                        Value                                      Before    Description
        realm_pre            RmmRealm                    RealmAt(rd)                                true      Realm
        realm                RmmRealm                    RealmAt(rd)                                false     Realm
        walk                 RmmRttWalkResult            RttWalk(                                   false     RTT walk result
                                                             realm, base,
                                                             RMM_RTT_PAGE_LEVEL,
                                                             RMM_RTT_TREE_PRIMARY)
        walk_top             Address                     RttSkipEntriesIfNotState(                  false     Top IPA of
                                                             RttAt(walk.rtt_addr),                            UNASSIGNED
                                                             walk.level,                                      entries, starting from
                                                             base, top, UNASSIGNED)                           entry at which the
                                                                                                              RTT walk terminated
               B4.3.41.1.3   Output values
        Name                 Register     Bits        Type                                  Description
        result               X0           63:0        RmiCommandReturnCode                  Command return status
        out_top              X1           63:0        Address                               Top IPA of range whose RIPAS was
                                                                                            modified
               The out_top output value is valid only when the command result is RMI_SUCCESS.
               When the out_top output value is valid, it is aligned to the size of the address range described by the RTT entry
               at the level where the RTT walk terminated.
                B4.3.41.2 Failure conditions

RMI_ERROR_INPUT is returned if rd is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rd is not the address of a Granule that can be delegated.

RMI_ERROR_INPUT is returned if the Granule at rd is not in the RD state.

RMI_ERROR_INPUT is returned if top is less than or equal to base.

RMI_ERROR_INPUT is returned if the address one Granule below top is not a Protected IPA of the target Realm, as it was before the command ran.

RMI_ERROR_REALM is returned if the target Realm, as it was before the command ran, is not in the REALM_NEW state.

RMI_ERROR_RTT is returned, with the RTT walk level, if base is not aligned to the size of the address range that one RTT entry describes at the level reached by the RTT walk from base.

RMI_ERROR_RTT is returned, with the RTT walk level, if the RTT entry reached by the RTT walk from base is not in the UNASSIGNED state.

RMI_ERROR_INPUT is returned if top is not aligned to the size of a Granule.

RMI_ERROR_RTT is returned, with the RTT walk level, if base is equal to the top of the IPA range the command can process from base in the RTT reached by the walk. In that case, no RTT entries can be processed.

                B4.3.41.2.1   Failure condition ordering

The RMM checks failure conditions in the following order:

- The checks that rd is a Granule that can be delegated and that the Granule at rd is in the RD state come before the check that the Realm is in the REALM_NEW state.
- The checks that rd is a Granule that can be delegated and that the Granule at rd is in the RD state come before the checks that base is aligned to the RTT walk level and that the RTT entry is in the UNASSIGNED state.
- The checks that rd is a Granule that can be delegated and that the Granule at rd is in the RD state come before the check that the command can process at least one RTT entry.
- The check that top is aligned to the size of a Granule comes before the check that the command can process at least one RTT entry.

                B4.3.41.3 Success conditions

On success, every RTT entry in the RTT reached by the walk, at the walk level, in the IPA range from base up to the top of the processed range has RIPAS RAM.

On success, the RIM of the target Realm is extended as described in B4.3.41.4. The extension covers the IPA range from base up to the top of the processed range, at the RTT walk level, and starts from the state of the Realm before the command ran.

On success, out_top is the top of the IPA range that the command processed.

               B4.3.41.4 RMI_RTT_INIT_RIPAS extension of RIM

On successful execution of RMI_RTT_INIT_RIPAS, the new RIM value of the target Realm is calculated by the RMM as follows:

                 1. Allocate an RmmMeasurementDescriptorRipas data structure.
                 2. For each RTT entry in the range [base, top) described by the RMI_RTT_INIT_RIPAS input values:
                 a. Populate the measurement descriptor:
                  • Set the desc_type field to the descriptor type.
                  • Set the len field to the descriptor length.
                  • Set the base field to the IPA of the RTT entry.
      • Set the top field to the IPA of the RTT entry plus the size of the region it describes, or to the top input value, whichever is smaller. Here:
        – the IPA of the RTT entry is the start of its region
        – the size is the size in bytes of the IPA region that the RTT entry describes
        – the top input value is the top argument given to the command
   b. Use the RHA of the target Realm to hash the measurement descriptor. Set the RIM of the target Realm to this hash. If the RHA output is smaller than the RIM, fill the upper bytes with zeros.
