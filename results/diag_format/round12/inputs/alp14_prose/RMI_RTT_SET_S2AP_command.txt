B4.3.45 RMI_RTT_SET_S2AP command
               Completes a request made by the Realm to change the S2AP of a target IPA range.
               B4.3.45.1 Interface
               B4.3.45.1.1    Input values
        Name                 Register     Bits        Type                                  Description
        fid                  X0           63:0        UInt64                                FID, value 0xC400018B
        rd                   X1           63:0        Address                               PA of the RD for the target Realm
        rec_ptr              X2           63:0        Address                               PA of the target REC
        base                 X3           63:0        Address                               Base of target IPA region
        top                  X4           63:0        Address                               Top of target IPA region
               B4.3.45.1.2    Context
               The RMI_RTT_SET_S2AP command operates on the following context.
        Name                 Type                        Value                                      Before    Description
        realm                RmmRealm                    RealmAt(rd)                                false     Realm
        realm_pre            RmmRealm                    RealmAt(rd)                                true      Realm
        rec                  RmmRec                                                                 false     REC
                                                         RecAt(rec_ptr)
        not_aligned          RmmRttWalkNotAligned RttWalkAnyNotAligned(                             false     RTT walk result
                                                               realm, base, top,                              which is not aligned
                                                               RMM_RTT_PAGE_LEVEL)                            to page level
               B4.3.45.1.3    Output values
        Name                 Register     Bits        Type                                  Description
        result               X0           63:0        RmiCommandReturnCode                  Command return status
        out_top              X1           63:0        Address                               Top IPA of range whose S2AP was
                                                                                            modified
        rtt_tree             X2           63:0        UInt64                                Index of RTT tree in which base
                                                                                            alignment check failed
               If result is RMI_ERROR_RTT or RMI_ERROR_RTT_AUX then the following are true:
                   • out_top is the IPA of the RTTE at which the base alignment check failed.
                   • rtt_tree is the index of the RTT in which the base alignment check failed.
               B4.3.45.2 Failure conditions

RMI_ERROR_INPUT is returned if rd is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rd is not a delegable physical address.

RMI_ERROR_INPUT is returned if the state of the Granule at rd is not RD.

RMI_ERROR_INPUT is returned if rec_ptr is not aligned to the size of a Granule.

RMI_ERROR_INPUT is returned if rec_ptr is not a delegable physical address.

RMI_ERROR_INPUT is returned if the state of the Granule at rec_ptr is not REC.

RMI_ERROR_REC is returned if the state of the REC is REC_RUNNING.

RMI_ERROR_REC is returned if the REC is not owned by the Realm described by rd.

RMI_ERROR_INPUT is returned if top, read as an unsigned value, is less than or equal to base.

RMI_ERROR_INPUT is returned if base is not the same as the REC's s2ap_addr value.

RMI_ERROR_INPUT is returned if top, read as an unsigned value, is greater than the REC's s2ap_top value.

RMI_ERROR_INPUT is returned if top is not aligned to the size of a Granule.

RMI_ERROR_RTT is returned, together with the RTT level of the entry, if all of the following are true for the unaligned RTT entry (not_aligned):
- not_aligned is valid (RMM_TRUE).
- The range from base to top is not within the address range of that entry. This address range runs from the entry's address aligned down to the entry's RTT level, to the entry's address aligned up to that level.
- The entry is in the primary RTT tree (RMM_RTT_TREE_PRIMARY).
- The entry's stage 2 access permission overlay index is not the same as the REC's s2ap_overlay_index.

               B4.3.45.2 Failure conditions

RMI_ERROR_RTT_AUX is returned, together with the RTT level of the entry, if all of the following are true for the unaligned RTT entry (not_aligned):
- not_aligned is valid (RMM_TRUE).
- The range from base to top is not within the address range of that entry. This address range runs from the entry's address aligned down to the entry's RTT level, to the entry's address aligned up to that level.
- The entry is not in the primary RTT tree (RMM_RTT_TREE_PRIMARY), which means it is in an auxiliary RTT tree.
- The entry's stage 2 access permission overlay index is not the same as the REC's s2ap_overlay_index.

              B4.3.45.2.1   Failure condition ordering
              The RMI_RTT_SET_S2AP command does not have any failure condition orderings.

              B4.3.45.3 Success conditions

On success, the REC's s2ap_addr is set to the value of out_top.
