5.21 PSCI_SET_SUSPEND_MODE command
               Switches between the platform-coordinated and OS-initiated power state coordination modes.
               5.21.1 Interface
               5.21.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           63:0        UInt64                                FID
        mode                X1           63:0        UInt64                                Power state coordination mode to switch to. Valid values are 0 and 1
               5.21.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        PsciReturnCode                        Command return status
               5.21.2 Failure conditions
  ID                          Condition
  not_supported               pre: !PsciSetSuspendModeImplemented()
                              post: ResultEqual(result, NOT_SUPPORTED)
  mode_valid                  pre: (mode != 0) && (mode != 1)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  osi_core_state              pre: IsOsInitiatedMode(mode)
                                   && CurrentCoordinationMode() == PLATFORM_COORDINATED
                                   && ExistsCore(c, !IsRunning(c) && !IsOffViaCpuOffOrNotBooted(c)
                                                    && !IsSuspendedViaCpuDefaultSuspend(c))
                              post: ResultEqual(result, DENIED)
  osi_suspend_used            pre: IsOsInitiatedMode(mode)
                                   && CurrentCoordinationMode() == PLATFORM_COORDINATED
                                   && AnyCoreCalledCpuSuspendSinceLastModeChangeOrBoot()
                              post: ResultEqual(result, DENIED)
  pc_core_state               pre: IsPlatformCoordinatedMode(mode)
                                   && CurrentCoordinationMode() == OS_INITIATED
                                   && ExistsCore(c, c != CallingCore() && !IsOffViaCpuOffOrNotBooted(c))
                              post: ResultEqual(result, DENIED)
               5.21.2.1   Failure condition ordering
               The PSCI_SET_SUSPEND_MODE command does not have any failure condition orderings.
               5.21.3 Success conditions
  ID                          Condition
  coord_mode                  post: CurrentCoordinationMode() == mode
               5.21.4 Footprint
    ID                        Value
    coord_mode                CurrentCoordinationMode()
