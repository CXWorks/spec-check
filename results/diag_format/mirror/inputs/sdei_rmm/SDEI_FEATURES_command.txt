5.1.17 SDEI_FEATURES command
               Enumerates SDEI features.
               5.1.17.1 Interface
               5.1.17.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           31:0        UInt32                                FID, value 0xC4000030
        feature             X1           31:0        UInt32                                Feature being queried:
                                                                                           0: BIND_SLOTS
                                                                                           1: RELATIVE_MODE
                                                                                           All other values are reserved
               5.1.17.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 On success, the value of the queried feature. On error, an error code.
               5.1.17.2 Failure conditions
  ID                          Condition
  sdei_supp                   pre: !IsSdeiSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
  feature_valid               pre: !IsValidSdeiFeature(feature)
                              post: ResultEqual(result, INVALID_PARAMETERS)
               5.1.17.2.1   Failure condition ordering
               The SDEI_FEATURES command does not have any failure condition orderings.
               5.1.17.3 Success conditions
  ID                          Condition
  bind_rsvd                   pre: feature == BIND_SLOTS
                              post: result[63:32] == 0
  bind_shared                 pre: feature == BIND_SLOTS
                              post: result[31:16] == SharedEventSlotCount()
  bind_private                pre: feature == BIND_SLOTS
                              post: result[15:0] == PrivateEventSlotCount()
  rel_supp                    pre: feature == RELATIVE_MODE && IsRelativeModeSupported()
                              post: result == 1
  rel_unsupp                  pre: feature == RELATIVE_MODE && !IsRelativeModeSupported()
                              post: result == 0
               5.1.17.4 Footprint
               The SDEI_FEATURES command does not have any footprint.
