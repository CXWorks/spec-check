5.1.13 SDEI_PE_UNMASK command
               Unmask the PE to receive SDEI events.
               5.1.13.1 Interface
               5.1.13.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           31:0        UInt32                                Function ID, value 0xC400002C
               5.1.13.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 Command return status
               5.1.13.2 Failure conditions
  ID                          Condition
  sdei_support                pre: !SdeiIsSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
               5.1.13.2.1   Failure condition ordering
               The SDEI_PE_UNMASK command does not have any failure condition orderings.
               5.1.13.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SUCCESS)
  pe_unmask                   post: !PeIsMasked(client, CallingPe())
  pending_dispatch            post: PendingEventsDispatched(CallingPe())
               5.1.13.4 Footprint
    ID                        Value
    pe_unmask                 PeMaskState(client, CallingPe())
