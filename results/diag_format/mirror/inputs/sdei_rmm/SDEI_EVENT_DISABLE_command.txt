5.1.4 SDEI_EVENT_DISABLE command
               Disable the specified event.
               5.1.4.1 Interface
               5.1.4.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 X0           31:0        UInt32                                Function ID, value 0xC4000023
        event               X1           31:0        Int32                                 Event number
               5.1.4.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 Command return status
               5.1.4.2 Failure conditions
  ID                          Condition
  sdei_supp                   pre: !SdeiIsSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
  event_valid                 pre: !IsKnownEvent(event)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  event_reg                   pre: !EventIsRegisteredByClient(event)
                              post: ResultEqual(result, DENIED)
  handler_state               pre: EventHandlerState(event) == HANDLER_UNREGISTER_PENDING
                              post: ResultEqual(result, DENIED)
               5.1.4.2.1   Failure condition ordering
               The SDEI_EVENT_DISABLE command does not have any failure condition orderings.
               5.1.4.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SUCCESS)
  event_private               pre: EventIsPrivate(event)
                              post: !EventIsEnabledForPe(event, CallingPe())
  event_shared                pre: EventIsShared(event)
                              post: !EventIsEnabledForClient(event, CallingClient())
               5.1.4.4 Footprint
    ID                        Value
    event_private             EventEnableState(event, CallingPe())
    event_shared              EventEnableState(event, CallingClient())
