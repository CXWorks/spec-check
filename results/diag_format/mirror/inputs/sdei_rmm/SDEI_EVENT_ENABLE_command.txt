5.1.3 SDEI_EVENT_ENABLE command
               Enables the specified event.
               5.1.3.1 Interface
               5.1.3.1.1   Input values
        Name                Register     Bits        Type                                  Description
        fid                 W0           31:0        UInt32                                FID, value 0xC4000022
        event               W1           31:0        Int32                                 Event number
               5.1.3.1.2   Output values
        Name                Register     Bits        Type                                  Description
        result              X0           63:0        Int64                                 Command return status
               5.1.3.2 Failure conditions
  ID                          Condition
  sdei_support                pre: !SdeiIsSupported()
                              post: ResultEqual(result, NOT_SUPPORTED)
  event_valid                 pre: !IsKnownEvent(event)
                              post: ResultEqual(result, INVALID_PARAMETERS)
  event_reg                   pre: !IsEventRegisteredByClient(event)
                              post: ResultEqual(result, DENIED)
  handler_state               pre: EventHandlerState(event) == HANDLER_UNREGISTER_PENDING
                              post: ResultEqual(result, DENIED)
               5.1.3.2.1   Failure condition ordering
               The SDEI_EVENT_ENABLE command does not have any failure condition orderings.
               5.1.3.3 Success conditions
  ID                          Condition
  result                      post: ResultEqual(result, SUCCESS)
  event_private               pre: IsPrivateEvent(event)
                              post: IsEventEnabledForPe(event, CallingPe())
  event_shared                pre: IsSharedEvent(event)
                              post: IsEventEnabledForClient(event, CallingClient())
               5.1.3.4 Footprint
    ID                        Value
    event_private             EventEnableState(event, CallingPe())
    event_shared              EventEnableState(event, CallingClient())
