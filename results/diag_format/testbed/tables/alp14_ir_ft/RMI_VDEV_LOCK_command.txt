B4.3.56 RMI_VDEV_LOCK command
                Lock VDEV.
                B4.3.56.1 Interface
                B4.3.56.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC40001D2
        rd                    X1          63:0        Address                               PA of the RD
        vdev_ptr              X2          63:0        Address                               PA of the VDEV
                B4.3.56.1.2   Context
                The RMI_VDEV_LOCK command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   RealmAt(rd)                                false    Realm
        vdev                  RmmVdev                    VdevAt(vdev_ptr)                           false    VDEV
                B4.3.56.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.56.2 Failure conditions
  ID                           Condition
  da_feature                  pre: !ImplFeatures(s).feat_da
                               post: ResultEqual(result, RMI_ERROR_NOT_SUPPORTED)
  rd_align                    pre: !AddrIsGranuleAligned(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_delegable                pre: !PaIsDelegable(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_state                    pre: GranuleAt(rd).state != RD
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_ptr_align              pre: !AddrIsGranuleAligned(vdev_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_ptr_delegable          pre: !PaIsDelegable(vdev_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_ptr_state              pre: GranuleAt(vdev_ptr).state != VDEV
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_realm                  pre: VdevAt(vdev_ptr).realm != RealmAt(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_state                  pre: VdevAt(vdev_ptr).vdev_state != VDEV_UNLOCKED
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
  vdev_comm_state             pre: VdevAt(vdev_ptr).comm_state != DEV_COMM_IDLE
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
                B4.3.56.2.1   Failure condition ordering
                [da_feature] < [rd_delegable, rd_state, vdev_ptr_delegable, vdev_ptr_state, vdev_realm]
                [rd_delegable, rd_state, vdev_ptr_delegable, vdev_ptr_state] < [vdev_realm]
                [vdev_ptr_state] < [vdev_state, vdev_comm_state]
                                 da_feature                     rd_delegable                        rd_state                        vdev_ptr_delegable                        vdev_ptr_state
                                                                                           vdev_realm
                                                                                           vdev_state                        vdev_comm_state
                                                                                           RMI_ERROR_INPUT
                                                                                           RMI_ERROR_DEVICE
                                                                                           RMI_ERROR_DEVICE
                B4.3.56.3 Success conditions
  ID                           Condition
  vdev_op                     post: VdevAt(vdev_ptr).op == VDEV_OP_LOCK
  vdev_comm_state             post: VdevAt(vdev_ptr).comm_state == DEV_COMM_PENDING
                B4.3.56.4 Footprint
    ID                           Value
    vdev_op                     VdevAt(vdev_ptr).op
    vdev_comm_state             VdevAt(vdev_ptr).comm_state
