B4.3.37 RMI_RTT_AUX_UNMAP_UNPROTECTED command
                Removes a valid or table descriptor at an Unprotected IPA from the starting level of an auxiliary RTT.
                B4.3.37.1 Interface
                B4.3.37.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000184
        rd                    X1          63:0        Address                               PA of the RD for the target Realm
        ipa                   X2          63:0        Address                               IPA in the target Realm
        index                 X3          63:0        UInt64                                RTT tree index
                B4.3.37.1.2   Context
                The RMI_RTT_AUX_UNMAP_UNPROTECTED command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   RealmAt(rd)                                false    Realm
        walk                  RmmRttWalkResult           RttWalk(                                   false    Auxiliary RTT walk
                                  realm, ipa,
                                  realm.rtt_level_start,
                                  index)
        entry_idx             UInt64                     RttEntryIndex(                             false    RTTE index
                                  ipa, walk.level)
        walk_top              Address                    RttSkipNonLiveEntries(                     false    Top IPA of non-live
                                  RttAt(walk.rtt_addr),                           RTT entries, from
                                  walk.level,                                     entry at which the
                                  ipa)                                            RTT walk terminated
                B4.3.37.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
        top                   X1          63:0        Address                               Top IPA of non-live RTT entries, from
                                                                                starting level RTT
                B4.3.37.2 Failure conditions
  ID                           Condition
  rd_align                     pre: !AddrIsGranuleAligned(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_delegable                 pre: !PaIsDelegable(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_state                     pre: GranuleAt(rd).state != RD
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  ipa_aligned                  pre: !AddrIsAligned(ipa, pow2(RealmAt(rd).ipa_width))
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  ipa_range                    pre: !(ipa < pow2(RealmAt(rd).ipa_width))
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  ipa_protected                pre: AddrIsProtected(ipa, RealmAt(rd))
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rtt_tree_per_plane           pre: RealmAt(rd).rtt_tree_per_plane == FEATURE_FALSE
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  index_primary                pre: index == RMM_RTT_TREE_PRIMARY
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  index_too_high               pre: index > RealmAt(rd).num_aux_planes
                               post: ResultEqual(result, RMI_ERROR_INPUT)
                B4.3.37.2.1   Failure condition ordering
                The RMI_RTT_AUX_UNMAP_UNPROTECTED command does not have any failure condition orderings.
                B4.3.37.3 Success conditions
  rtte_state                  post: RttEntry(walk.rtt_addr, RttEntryIndex(ipa, walk.level)).state == UNASSIGNED_NS
  top                         post: top == RttSkipNonLiveEntries(RttAt(walk.rtt_addr), walk.level, ipa)
                B4.3.37.4 Footprint
    ID                          Value
    rtte                        RttEntry(walk.rtt_addr, entry_idx)
