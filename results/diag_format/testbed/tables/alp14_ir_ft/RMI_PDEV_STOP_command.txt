B4.3.20 RMI_PDEV_STOP command
                Stop a PDEV.
                B4.3.20.1 Interface
                B4.3.20.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC400017C
        pdev_ptr              X1          63:0        Address                               PA of the PDEV
                B4.3.20.1.2   Context
                The RMI_PDEV_STOP command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        pdev                  RmmPdev                    PdevAt(pdev_ptr)                           false    PDEV
                B4.3.20.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.20.2 Failure conditions
  ID                           Condition
  feature                      pre: !ImplFeatures(s).feat_da
                               post: ResultEqual(result, RMI_ERROR_NOT_SUPPORTED)
  pdev_ptr_align               pre: !AddrIsGranuleAligned(s, pdev_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  pdev_ptr_delegable           pre: !PaIsDelegable(s, pdev_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  pdev_ptr_state               pre: GranuleAt(s, pdev_ptr).state != PDEV
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  pdev_state                   pre: pdev.state != PDEV_STOPPING && pdev.state != PDEV_STOPPING && pdev.state != PDEV_STOPPED
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
  pdev_vdevs                   pre: pdev.num_vdevs != 0
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
                B4.3.20.2.1   Failure condition ordering
                [feature, pdev_ptr_align, pdev_ptr_delegable, pdev_ptr_state] < [pdev_state, pdev_vdevs]
                                 feature                      pdev_ptr_align                     pdev_ptr_delegable                     pdev_ptr_state
                                                                                           pdev_state                        pdev_vdevs
                B4.3.20.3 Success conditions
  ID                           Condition
  pdev_state                   post: pdev.state == PDEV_STOPPING
  pdev_comm_state              post: pdev.comm_state == DEV_COMM_PENDING
                B4.3.20.4 Footprint
    ID                          Value
    state                       pdev.state
    comm_state                  pdev.comm_state
