B5.3.19 RSI_VDEV_VALIDATE_MAPPING command
                Validate Realm device memory mappings.
                B5.3.19.1 Interface
                B5.3.19.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC400019F
        vdev_id               X1          63:0        Bits64                                Realm device identifier
        ipa_base              X2          63:0        Address                               Base of target IPA region
        ipa_top               X3          63:0        Address                               Top of target IPA region
        pa_base               X4          63:0        Address                               Base of target PA region
        flags                 X5          63:0        RsiDevMemFlags                        Flags
        lock_nonce            X6          63:0        UInt64                                Nonce generated on most recent
                                                                                 transition to LOCKED state
        meas_nonce            X7          63:0        UInt64                                GET_MEASUREMENT request
                                                                                 sequence number
        report_nonce          X8          63:0        UInt64                                GET_INTERFACE_REPORT request
                                                                                 sequence number
                B5.3.19.1.2   Context
                The RSI_VDEV_VALIDATE_MAPPING command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   CurrentRealm()                             false    Current Realm
        rec                   RmmRec                     CurrentRec()                               false    Current REC
        vdev                  RmmVdev                    VdevFromVdevId(                            false    Realm device
                                         realm,
                                         vdev_id)
                B5.3.19.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RsiCommandReturnCode                  Command return status
        new_ipa_base          X1          63:0        Address                               Base of IPA region which was not
                                                                                 modified by the command
        response              X2          0:0         RsiResponse                           Whether the Host accepted or rejected
                                                                                 the request
                B5.3.19.2 Failure conditions
  ID                           Condition
  device_assignment          pre: !CurrentRealm().feat_da
                               post: ResultEqual(result, RSI_ERROR_STATE)
  vdev_in_use                pre: !VdevFromVdevId(CurrentRealm(), vdev_id).vdev_state == VDEV_LOCKED && !VdevFromVdevId(CurrentRealm(), vdev_id).vdev_state == VDEV_STARTED
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  vdev_state                 pre: VdevFromVdevId(CurrentRealm(), vdev_id).vdev_state != VDEV_LOCKED && VdevFromVdevId(CurrentRealm(), vdev_id).vdev_state != VDEV_STARTED
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  ipa_base_aligned           pre: !AddrIsGranuleAligned(CurrentRealm(), ipa_base)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  ipa_top_aligned            pre: !AddrIsGranuleAligned(CurrentRealm(), ipa_top)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  pa_base_aligned            pre: !AddrIsGranuleAligned(CurrentRealm(), pa_base)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  ipa_top_le_ipa_base        pre: ipa_top <= ipa_base
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  ipa_range_protected        pre: !(ipa_base > CurrentRealm().rtt_base[0] && ipa_top < CurrentRealm().rtt_base[0] + pow2(10))
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  attestation_match          pre: VdevFromVdevId(CurrentRealm(), vdev_id).attest_info.lock_nonce != lock_nonce || VdevFromVdevId(CurrentRealm(), vdev_id).attest_info.meas_nonce != meas_nonce || VdevFromVdevId(CurrentRealm(), vdev_id).attest_info.report_nonce != report_nonce
                               post: ResultEqual(result, RSI_ERROR_DEVICE)
                B5.3.19.2.1   Failure condition ordering
                [device_assignment] < [vdev_in_use]
                                 vdev_state                 ipa_base_aligned            ipa_top_aligned            pa_base_aligned            ipa_top_le_ipa_base            ipa_range_protected            attestation_match
                                                                                           RSI_ERROR_INPUT
                                                                                           RSI_ERROR_INPUT
                                                                                           RSI_ERROR_INPUT
                                                                                           RSI_ERROR_INPUT
                                                                                           RSI_ERROR_INPUT
                                                                                           RSI_ERROR_INPUT
                                                                                           RSI_ERROR_DEVICE
                B5.3.19.3 Success conditions
  response                   post: response == RecDevMemResponseToRsi(CurrentRec())
  new_ipa_base               post: new_ipa_base == RecDevMemAddr(CurrentRec())
