B5.3.17 RSI_VDEV_GET_INFO command
                Get information for a device.
                B5.3.17.1 Interface
                B5.3.17.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC400019D
        vdev_id               X1          63:0        Bits64                                Realm device identifier
        addr                  X2          63:0        Address                               IPA to which the configuration data will
                                                                                be written
                B5.3.17.1.2   Context
                The RSI_VDEV_GET_INFO command operates on the following context.
        Name                  Type                        Value                                      Before   Description
        realm                 RmmRealm                    CurrentRealm()                             false    Current Realm
        vdev                  RmmVdev                     VdevFromVdevId(                            false    Realm device
                                         CurrentRealm(),
                                         vdev_id)
        pdev                  RmmPdev                     PdevAt(vdev.pdev)                          false    Physical device
        cfg                   RsiVdevInfo                 RsiVdevInfoAt(addr)                        false    Device configuration
        walk                  RmmRttWalkResult            RttWalk(                                   false    RTT walk result
                                         CurrentRealm(), addr,
                                         RMM_RTT_PAGE_LEVEL,
                                         RMM_RTT_TREE_PRIMARY)
                B5.3.17.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RsiCommandReturnCode                  Command return status
                B5.3.17.2 Failure conditions
  ID                           Condition
  realm_feature               pre: !CurrentRealm().feat_p2p
                               post: ResultEqual(result, RSI_ERROR_STATE)
  vdev_assigned               pre: !VdevFromVdevId(CurrentRealm(), vdev_id).pdev == PdevAt(VdevFromVdevId(CurrentRealm(), vdev_id).pdev).pdev_id
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  addr_aligned                pre: !AddrIsAligned(s, addr, 9)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  addr_protected              pre: !AddrIsProtected(s, addr, CurrentRealm())
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  ripas_empty                 pre: PdevAt(VdevFromVdevId(CurrentRealm(), vdev_id).pdev).ripas == RmmRipas::EMPTY
                               post: ResultEqual(result, RSI_ERROR_INPUT)
                B5.3.17.2.1   Failure condition ordering
                [realm_feature, vdev_assigned, addr_aligned, addr_protected] < [ripas_empty]
                                 realm_feature                     vdev_assigned                        addr_aligned
                                                                                           addr_protected
                                                                                           ripas_empty
                                                                                           RSI_ERROR_INPUT
                B5.3.17.3 Success conditions
  cfg_state                   post: cfg.state == VdevFromVdevId(CurrentRealm(), vdev_id).vdev_state
  cfg_p2p_enabled             post: cfg.p2p_enabled == PdevAt(VdevFromVdevId(CurrentRealm(), vdev_id).pdev).p2p_enabled
  cfg_p2p_bound               post: cfg.p2p_bound == VdevFromVdevId(CurrentRealm(), vdev_id).p2p_bound
  cfg_p2p_peer                post: cfg.p2p_peer == VdevFromVdevId(CurrentRealm(), vdev_id).p2p_peer
  cfg_lock_nonce              post: cfg.lock_nonce == VdevFromVdevId(CurrentRealm(), vdev_id).attest_info.lock_nonce
  cfg_meas_nonce              post: cfg.meas_nonce == VdevFromVdevId(CurrentRealm(), vdev_id).attest_info.meas_nonce
  cfg_report_nonce            post: cfg.report_nonce == VdevFromVdevId(CurrentRealm(), vdev_id).attest_info.report_nonce
  cfg_vca_digest              post: cfg.vca_digest == PdevAt(VdevFromVdevId(CurrentRealm(), vdev_id).pdev).vca_digest
  cfg_meas_digest             post: cfg.meas_digest == VdevFromVdevId(CurrentRealm(), vdev_id).meas_digest
  cfg_report_digest           post: cfg.report_digest == VdevFromVdevId(CurrentRealm(), vdev_id).report_digest
