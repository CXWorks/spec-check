B4.3.23 RMI_PSMMU_MSI_CONFIG command
                Programs the MSI configuration for the Realm side of the physical SMMU.
                B4.3.23.1 Interface
                B4.3.23.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC400016E
        psmmu                 X1          63:0        Address                               PA of PSMMU
        gerr_addr             X2          63:0        Address                               MSI address of the GERROR interrupt
        gerr_data             X3          63:0        Bits64                                MSI data of the GERROR interrupt
        eventq_addr           X4          63:0        Address                               MSI address of the EVENTQ interrupt
        eventq_data           X5          63:0        Bits64                                MSI data of the EVENTQ interrupt
        priq_addr             X6          63:0        Address                               MSI address of the PRIQ interrupt
        priq_data             X7          63:0        Bits64                                MSI data of the PRIQ interrupt
                B4.3.23.1.2   Context
                The RMI_PSMMU_MSI_CONFIG command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        psmmu                 RmmVsmmu                   VsmmuAt(psmmu)                              false    PSMMU
                B4.3.23.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.23.2 Failure conditions
  ID                           Condition
  psmmu_valid                 pre: !VsmmuIsLive(psmmu)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  psmmu_msi_support            pre: !VsmmuSupportsMsi(psmmu, gerr_addr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  gerr_addr_valid              pre: !MsiAddrIsValid(gerr_addr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  eventq_addr_valid            pre: !MsiAddrIsValid(eventq_addr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  priq_addr_valid              pre: !MsiAddrIsValid(priq_addr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
                B4.3.23.2.1   Failure condition ordering
                There is none.
                B4.3.23.3 Success conditions
  gerr_addr                   post: SMMU_R_GERROR_IRQ_CFG0(VsmmuAt(psmmu)) == gerr_addr
  gerr_data                   post: SMMU_R_GERROR_IRQ_CFG1(VsmmuAt(psmmu)) == gerr_data
  eventq_addr                 post: SMMU_R_EVENTQ_IRQ_CFG0(VsmmuAt(psmmu)) == eventq_addr
  eventq_data                 post: SMMU_R_EVENTQ_IRQ_CFG1(VsmmuAt(psmmu)) == eventq_data
  priq_addr                   post: SMMU_R_PRIQ_IRQ_CFG0(VsmmuAt(psmmu)) == priq_addr
  priq_data                   post: SMMU_R_PRIQ_IRQ_CFG1(VsmmuAt(psmmu)) == priq_data
                B4.3.23.4 Footprint
    ID                           Value
    psmmu                       VsmmuAt(psmmu)
    SMMU_R_GERROR_IRQ_CFG0(VsmmuAt(psmmu))
    SMMU_R_GERROR_IRQ_CFG1(VsmmuAt(psmmu))
    SMMU_R_EVENTQ_IRQ_CFG0(VsmmuAt(psmmu))
    SMMU_R_EVENTQ_IRQ_CFG1(VsmmuAt(psmmu))
    SMMU_R_PRIQ_IRQ_CFG0(VsmmuAt(psmmu))
    SMMU_R_PRIQ_IRQ_CFG1(VsmmuAt(psmmu))
