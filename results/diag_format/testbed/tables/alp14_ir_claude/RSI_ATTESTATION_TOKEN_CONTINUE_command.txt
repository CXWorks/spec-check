B5.3.1 RSI_ATTESTATION_TOKEN_CONTINUE command
                Continue the operation to retrieve an attestation token.
                B5.3.1.1 Interface
                B5.3.1.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000195
        addr                  X1          63:0        Address                               IPA of the Granule to which the token
                                                                                            will be written
        offset                X2          63:0        UInt64                                Offset within Granule to start of buffer
                                                                                            in bytes
        size                  X3          63:0        UInt64                                Size of buffer in bytes
                B5.3.1.1.2   Context
                The RSI_ATTESTATION_TOKEN_CONTINUE command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   CurrentRealm()                             false    Current Realm
        rec                   RmmRec                     CurrentRec()                               false    Current REC
        walk                  RmmRttWalkResult           RttWalk(                                   false    RTT walk result
                                                             realm, addr,
                                                             RMM_RTT_PAGE_LEVEL,
                                                             RMM_RTT_TREE_PRIMARY)
                B5.3.1.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RsiCommandReturnCode                  Command return status
        len                   X1          63:0        UInt64                                Number of bytes written to buffer
                B5.3.1.2 Failure conditions
  ID                           Condition
  addr_align                   pre: !AddrIsGranuleAligned(addr)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  addr_bound                   pre: !AddrIsProtected(addr, realm)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  addr_empty                   pre: walk.rtte.ripas == EMPTY
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  offset_bound                 pre: offset >= RMM_GRANULE_SIZE
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  size_overflow                pre: offset + size < offset
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  size_bound                   pre: offset + size > RMM_GRANULE_SIZE
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  rec_state                    pre: rec.attest_state != ATTEST_IN_PROGRESS
                               post: ResultEqual(result, RSI_ERROR_STATE)
  token_failed                 pre: AttestationTokenGenerationFailed(rec)
                               post: ResultEqual(result, RSI_ERROR_UNKNOWN)
                B5.3.1.2.1   Failure condition ordering
                The RSI_ATTESTATION_TOKEN_CONTINUE command does not have any failure condition orderings.
                B5.3.1.3 Success conditions
  ID                           Condition
  len                          post: len == AttestationTokenWrite(addr, offset, size)
  incomplete                   post: !AttestationTokenGenerationComplete(rec) ==> ResultEqual(result, RSI_INCOMPLETE)
  state                        post: AttestationTokenGenerationComplete(rec) ==> rec.attest_state == NO_ATTEST_IN_PROGRESS
                B5.3.1.4 Footprint
    ID                           Value
    state                        rec.attest_state
