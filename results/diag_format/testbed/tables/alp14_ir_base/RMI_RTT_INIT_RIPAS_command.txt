B4.3.41 RMI_RTT_INIT_RIPAS command
                Sets the RIPAS of a target IPA range to RAM, for a Realm in the REALM_NEW state.
                B4.3.41.1 Interface
                B4.3.41.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000168
        rd                    X1          63:0        Address                               PA of the RD for the target Realm
        base                  X2          63:0        Address                               Base of target IPA region
        top                   X3          63:0        Address                               Top of target IPA region
                B4.3.41.1.2   Context
                The RMI_RTT_INIT_RIPAS command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm_pre             RmmRealm                   RealmAt(rd)                                true      Realm
        realm                 RmmRealm                   RealmAt(rd)                                false     Realm
        walk                  RmmRttWalkResult           RttWalk(realm, base, RMM_RTT_PAGE_LEVEL, RMM_RTT_TREE_PRIMARY)  false     RTT walk result
        walk_top              Address                    RttSkipEntriesIfNotState(RttAt(walk.rtt_addr), walk.level, base, top, UNASSIGNED)  false     Top IPA of entries, starting from entry at which the RTT walk terminated
                B4.3.41.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
        out_top               X1          63:0        Address                               Top IPA of range whose RIPAS was modified
                B4.3.41.2 Failure conditions
  ID                           Condition
  rd_align                     pre: !AddrIsGranuleAligned(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_delegable                 pre: !PaIsDelegable(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_state                     pre: GranuleAt(rd).state != RD
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  realm_state                  pre: realm_pre.state != REALM_NEW
                               post: ResultEqual(result, RMI_ERROR_REALM)
  base_top_order               pre: top <= base
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  top_above_protected          pre: !AddrIsProtected(RttAt(walk.rtt_addr), top - RttLevelSize(walk.level), realm_pre)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  base_rtt_align               pre: !AddrIsRttLevelAligned(base, walk.level)
                               post: ResultEqual(result, RMI_ERROR_RTT(walk.level))
  base_rtt_unassigned          pre: RttEntryAt(RttAt(walk.rtt_addr), RttEntryIndex(RttAt(walk.rtt_addr), base, walk.level)).state != UNASSIGNED
                               post: ResultEqual(result, RMI_ERROR_RTT(walk.level))
  top_align                    pre: !AddrIsGranuleAligned(top)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  base_max_range               pre: base == RttSkipEntriesUnlessState(RttAt(walk.rtt_addr), walk.level, base, top, UNASSIGNED)
                               post: ResultEqual(result, RMI_ERROR_RTT(walk.level))
                B4.3.41.2.1   Failure condition ordering
                [rd_delegable, rd_state] < [realm_state]
                [rd_delegable, rd_state] < [base_rtt_align, base_rtt_unassigned]
                [rd_delegable, rd_state] < [base_max_range]
                [top_align] < [base_max_range]
                                 rd_delegable                     rd_state                        realm_state
                                                                                           RMI_ERROR_INPUT
                                                                                           realm_state
                                 base_rtt_align                     base_rtt_unassigned
                                                                                           RMI_ERROR_RTT
                                 top_align
                                                                                           RMI_ERROR_INPUT
                                 base_max_range
                                                                                           RMI_ERROR_RTT
                B4.3.41.3 Success conditions

  rim_extended                post: RimExtend(realm, base, walk_top, RMM_RTT_PAGE_LEVEL) == realm.measurements[[0]]
  out_top_valid                post: out_top == walk_top
