B4.3.8 RMI_MEC_SET_SHARED command
                Change state of a MEC to Shared.
                B4.3.8.1 Interface
                B4.3.8.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC400018C
        mecid                 X1          63:0        Bits64                                MECID
                B4.3.8.1.2   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.8.2 Failure conditions
  ID                           Condition
  mecid_max                    pre: mecid > MaxMecid()
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  mecid_state                  pre: MecState(mecid) != MEC_STATE_PRIVATE_UNASSIGNED
                               post: ResultEqual(result, RMI_ERROR_INPUT)
                B4.3.8.2.1   Failure condition ordering
                [mecid_max, mecid_state] < [mecid_max]
                                 mecid_max                     mecid_state
                                                                                           RMI_ERROR_INPUT
                                                                                           mecid_state
                B4.3.8.3 Success conditions
  ID                           Condition
  mecid_state                  post: MecState(mecid) == MEC_STATE_SHARED
                B4.3.8.4 Footprint
    ID                            Value
    mec_state                     MecState(mecid)
