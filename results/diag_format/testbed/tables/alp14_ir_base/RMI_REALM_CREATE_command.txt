B4.3.25 RMI_REALM_CREATE command
                Creates a Realm.
                B4.3.25.1 Interface
                B4.3.25.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000158
        rd                    X1          63:0        Address                               PA of the RD
        params_ptr            X2          63:0        Address                               PA of Realm parameters
                B4.3.25.1.2   Context
                The RMI_REALM_CREATE command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        params                RmiRealmParams             RmiRealmParamsAt(params_ptr)              false    Realm parameters
        realm                 RmmRealm                   RealmAt(rd)                               false    Realm
        mec_members_pre       UInt64                         MecMembers(params.mecid)                  true     Number of Realms which are members of the Realm's MEC
        mec_state_pre         RmmMecState                MecState(params.mecid)                    true     MECID state
                B4.3.25.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.25.2 Failure conditions
  ID                           Condition
  params_ptr_align            pre: !AddrIsGranuleAligned(params_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  params_ptr_access           pre: !AddrIsProtected(params_ptr, PAS_NS)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  params_ptr_valid            pre: !RmiRealmParamsIsValid(params_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  params_supported            pre: !RealmParamsSupported(ImplFeatures(), params)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_rtt_overlap              pre: AddrIsWithin(rd, params.rtt_base, pow2(params.rtt_num_start - 1) * RMM_GRANULE_SIZE)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_align                    pre: !AddrIsGranuleAligned(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_delegable                pre: !PaIsDelegable(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_state                    pre: GranuleAt(rd).state != RD
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rtt_base_align              pre: !AddrIsGranuleAligned(params.rtt_base)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rtt_config_valid            pre: !RttConfigIsValid(params.s2sz, params.rtt_level_start, params.rtt_num_start)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rtt_state                   pre: !RttsGranuleState(params.rtt_base, params.rtt_num_start)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vmid_valid                  pre: !VmidsAreValid(params.vmid, params.aux_vmid)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  mecid_max                   pre: params.mecid > ImplFeatures().max_mecid
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  mec_state                   pre: mec_state_pre == MEC_STATE_PRIVATE_ASSIGNED
                               post: ResultEqual(result, RMI_ERROR_INPUT)
                B4.3.25.2.1   Failure condition ordering
                [None]
                B4.3.25.3 Success conditions
  ID                           Condition
  rd_state                     post: GranuleAt(rd).state == RD
  realm_state                  post: realm.state == REALM_NEW
  rec_index                    post: realm.rec_index == 0
  rtt_base                     post: realm.rtt_base == params.rtt_base
  rtt_base_aux                 post: forall i: 0..3 | realm.rtt_base[i] == params.aux_rtt_base[i]
  rtt_state                    post: RttsGranuleState(realm.rtt_base, realm.rtt_num_start)
  rtt_unassigned_prot          post: forall i: 0..realm.rtt_num_start | forall j: 0..RttLevelSize(i) | RttEntryAt(RttAt(realm.rtt_base[i]), j).state == UNASSIGNED ==> RttEntryAt(RttAt(realm.rtt_base[i]), j).attr_prot == RTT_PROTECTED
  rtt_unassigned_unprot        post: forall i: 0..realm.rtt_num_start | forall j: 0..RttLevelSize(i) | RttEntryAt(RttAt(realm.rtt_base[i]), j).state == UNASSIGNED ==> RttEntryAt(RttAt(realm.rtt_base[i]), j).attr_unprot == RTT_UNPROTECTED
  rtt_ripas_empty              post: forall i: 0..realm.rtt_num_start | forall j: 0..RttLevelSize(i) | RttEntryAt(RttAt(realm.rtt_base[i]), j).attr_prot == RTT_PROTECTED ==> RttEntryAt(RttAt(realm.rtt_base[i]), j).s2ap_direct.read == RMM_FALSE && RttEntryAt(RttAt(realm.rtt_base[i]), j).s2ap_direct.write == RMM_FALSE
  feat_lpa2                    post: realm.feat_lpa2 == params.flags0.lpa2
  ipa_width                    post: realm.ipa_width == params.s2sz
  hash_algo                    post: realm.hash_algo == params.hash_algo
  rim_0                        post: realm.measurements[0] == RimInit(RealmHashAlgorithm(realm), params)
  rem_0_3                      post: forall i: 1..4 | realm.measurements[i] == [0; 64]
  rtt_level_start              post: realm.rtt_level_start == params.rtt_level_start
  rtt_num_start                post: realm.rtt_num_start == params.rtt_num_start
  vmids                        post: realm.vmid[0] == params.vmid && realm.vmid[1] == params.aux_vmid[0] && realm.vmid[2] == params.aux_vmid[1] && realm.vmid[3] == params.aux_vmid[2]
  rpv                          post: forall i: 0..7 | realm.rpv[i] == params.rpv[i]
  feat_da                      post: realm.feat_da == params.flags0.da
  feat_ats                     post: realm.feat_ats == params.flags1.ats
  ats_plane                    post: realm.ats_plane == params.ats_plane
  rtt_tree_per_plane           post: realm.rtt_tree_per_plane == params.flags1.rtt_tree_per_plane
  num_aux_planes               post: realm.num_aux_planes == params.num_aux_planes
  rtt_s2ap_encoding            post: realm.rtt_s2ap_encoding == params.flags1.rtt_s2ap_encoding
  lfa_policy                   post: realm.lfa_policy == params.flags0.lfa_policy
  mecid                        post: realm.mecid == params.mecid
  mec_policy                   post: realm.mec_policy == MecState(params.mecid)
  mec_members_post             post: If mec_state_pre == MEC_STATE_PRIVATE_UNASSIGNED | Then mec_members_pre + 1 Else If mec_state_pre == MEC_STATE_SHARED | Then mec_members_pre + 1 Else mec_members_pre
  recs                         post: realm.num_recs == 0
  vdevs                        post: realm.num_vdevs == 0
  vsmmus                       post: realm.num_vsmmus == 0

                B4.3.25.5 RIM initialization
                On successful execution, the initial RIM value of the target Realm is calculated by the RMM as follows:
                  1. Allocate a zero-filled RmiRealmParams data structure to hold the measured Realm parameters.
  2. Copy the following attributes from the Host-provided RmiRealmParams data structure into the measured Realm parameters data structure:
                   • flags0
                   • s2sz
                   • sve_vl
                   • num_bps
                   • num_wps
                   • pmu_num_ctrs
                   • hash_algo
  3. Using the RHA of the target Realm, compute the hash of the measured Realm parameters data structure. Set the RIM of the target Realm to this value, zero filling upper bytes if the RHA output is smaller than the size of the RIM.
