B4.3.16 RMI_PDEV_IDE_RESET command
                Resets non-coherent IDE connection between the Root Port and the endpoint device.
                B4.3.16.1 Interface
                B4.3.16.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000179
        pdev_ptr              X1          63:0        Address                               PA of the PDEV
                B4.3.16.1.2   Context
                The RMI_PDEV_IDE_RESET command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        pdev                  RmmPdev                    PdevAt(pdev_ptr)
                B4.3.16.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.16.2 Failure conditions
  ID                           Condition
  fid_value                    pre: fid != 0xC4000179
                               post: ResultEqual(result, RMI_ERROR_NOT_SUPPORTED)
  pdev_ptr_align               pre: !AddrIsGranuleAligned(pdev_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  pdev_ptr_delegable           pre: !PaIsDelegable(pdev_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  pdev_ptr_state               pre: GranuleAt(pdev_ptr).state != PDEV
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  pdev_ncoh_ide                pre: pdev.ncoh_ide != IDE_TRUE
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
  pdev_state                   pre: pdev.state != PDEV_READY
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
                B4.3.16.2.1   Failure condition ordering
                [fid_value] < [pdev_ptr_align, pdev_ptr_delegable, pdev_ptr_state]
                [pdev_ptr_state] < [pdev_ncoh_ide, pdev_state]
                                                                                           fid_value
                                                                                           pdev_ptr_align
                                                                                           pdev_ptr_delegable
                                                                                           pdev_ptr_state
                                                                                           pdev_ncoh_ide
                                                                                           pdev_state
                                                                                           RMI_ERROR_NOT_SUPPORTED
                                                                                           RMI_ERROR_INPUT
                                                                                           RMI_ERROR_DEVICE
                B4.3.16.3 Success conditions
  ID                           Condition
  pdev_state                   post: pdev.state == PDEV_IDE_RESETTING
  pdev_comm_state              post: pdev.comm_state == DEV_COMM_PENDING
                B4.3.16.4 Footprint
    ID                          Value
    pdev_state                  pdev.state
    pdev_comm_state             pdev.comm_state
