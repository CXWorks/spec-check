B4.3.39 RMI_RTT_DESTROY command
                Destroys a primary RTT.
                B4.3.39.1 Interface
                B4.3.39.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC400015E
        rd                    X1          63:0        Address                               PA of the RD for the target Realm
        ipa                   X2          63:0        Address                               Base of the IPA range described by the RTT
        level                 X3          63:0        Int64                                 RTT level
                B4.3.39.1.2   Context
                The RMI_RTT_DESTROY command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   RealmAt(rd)                                false    Realm
        walk                  RmmRttWalkResult           RttWalk(realm, ipa, level - 1, RMM_RTT_TREE_PRIMARY) false    RTT walk result
        entry_idx             UInt64                     RttEntryIndex(ipa, walk.level)             false    RTTE index
        walk_top              Address                    RttSkipNonLiveEntries(RttAt(walk.rtt_addr), walk.level, ipa) false    Top IPA of non-live RTT entries, from entry at which the RTT walk terminated
                B4.3.39.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
        rtt                   X1          63:0        Address                               PA of the RTT which was destroyed
        top                   X2          63:0        Address                               Top IPA of non-live RTT entries, from entry at which the RTT walk terminated
                B4.3.39.2 Failure conditions
  ID                           Condition
  rd_align                     pre: !AddrIsGranuleAligned(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_delegable                 pre: !PaIsDelegable(rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_state                     pre: GranuleAt(rd).state != RD
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  level_valid                  pre: !RttLevelIsValid(realm, level) || RttLevelIsStarting(realm, level)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  ipa_aligned                  pre: !AddrIsAligned(ipa, pow2(RttLevelSize(level - 1)))
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  ipa_in_range                 pre: ipa >= pow2(realm.ipa_width)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  walk_level                   pre: walk.level < level - 1
                               post: ResultEqual(result, RMI_ERROR_RTT)
  walk_entry_state             pre: walk.rtte.state != TABLE
                               post: ResultEqual(result, RMI_ERROR_RTT)
  walk_target_live             pre: walk.rtte.state == TABLE && GranuleAt(walk.rtte.addr).state != DELEGATED
                               post: ResultEqual(result, RMI_ERROR_RTT)
  walk_aux_ref                 pre: walk.rtte.state == TABLE && AuxAlias32(RttAt(walk.rtt_addr), walk.rtte.addr, 32, 1)
                               post: ResultEqual(result, RMI_ERROR_RTT)
                B4.3.39.2.1   Failure condition ordering
                [rd_delegable, rd_state] < [level_valid, ipa_in_range] < [walk_level, walk_entry_state] < [walk_target_live, walk_aux_ref]
  rd_delegable                 rd_state                        level_valid                     ipa_in_range
  rd_state                     level_valid                     ipa_in_range                    walk_level                     walk_entry_state
  level_valid                  ipa_in_range                    walk_level                      walk_entry_state               walk_target_live               walk_aux_ref
  ipa_in_range                 walk_level                      walk_entry_state                walk_target_live               walk_aux_ref
  walk_level                   walk_entry_state                walk_target_live                walk_aux_ref
  walk_entry_state             walk_target_live                walk_aux_ref
  walk_target_live             walk_aux_ref
                B4.3.39.3 Success conditions
  ipa_protected                post: walk.rtte.state == UNASSIGNED && walk.rtte.ripas == DESTROYED
  ipa_not_protected            post: walk.rtte.state == UNASSIGNED_NS
  granule_state                post: GranuleAt(walk.rtte.addr).state == DELEGATED
  rtt_value                    post: rtt == walk.rtte.addr
  top_value                    post: top == walk_top
                B4.3.39.4 Footprint
    ID                           Value
    rtt_state                   GranuleAt(walk.rtte.addr).state
    rtte                        RttEntryAt(RttAt(walk.rtt_addr), entry_idx)
