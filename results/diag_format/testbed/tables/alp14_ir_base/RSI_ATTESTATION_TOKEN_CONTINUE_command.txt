B5.3.1 RSI_ATTESTATION_TOKEN_CONTINUE command
                Continue the operation to retrieve an attestation token.
                B5.3.1.1 Interface
                B5.3.1.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000195
        addr                  X1          63:0        Address                               IPA of the Granule to which the token will be written
        offset                X2          63:0        UInt64                                Offset within Granule to start of buffer in bytes
        size                  X3          63:0        UInt64                                Size of buffer in bytes
                B5.3.1.1.2   Context
                The RSI_ATTESTATION_TOKEN_CONTINUE command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                    CurrentRealm()                             false    Current Realm
        rec                   RmmRec                      CurrentRec()                               false    Current REC
        walk                  RmmRttWalkResult            RttWalk(realm, addr, RMM_RTT_PAGE_LEVEL, RMM_RTT_TREE_PRIMARY)  false    RTT walk result
                B5.3.1.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RsiCommandReturnCode                  Command return status
        len                   X1          63:0        UInt64                                Number of bytes written to buffer
                B5.3.1.2 Failure conditions
  ID                           Condition
  addr_align                  pre: !AddrIsGranuleAligned(s, addr)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  addr_protected              pre: !AddrIsProtected(s, addr, realm)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  ripas_empty                 pre: GranuleAt(s, addr).state == RMM_GRANULE_EMPTY
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  offset_too_large            pre: offset >= RMM_GRANULE_SIZE
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  overflow                    pre: offset + size < offset
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  range_exceeds               pre: offset + size > RMM_GRANULE_SIZE
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  rec_attest_state            pre: rec.attest_state != ATTEST_IN_PROGRESS
                               post: ResultEqual(result, RSI_ERROR_STATE)
  token_gen_failed            pre: token_generation_failed_for_unknown_or_impl_defined_reason
                               post: ResultEqual(result, RSI_ERROR_UNKNOWN)
                B5.3.1.2.1   Failure condition ordering
                [addr_align, addr_protected, ripas_empty, offset_too_large, overflow, range_exceeds] < [rec_attest_state] < [token_gen_failed]
                                 addr_align                     addr_protected                    ripas_empty
                                                                                           offset_too_large
                                                                                           overflow
                                                                                           range_exceeds
                                                                                           rec_attest_state
                                                                                           token_gen_failed
                                                                                           RSI_ERROR_INPUT
                                                                                           RSI_ERROR_STATE
                                                                                           RSI_ERROR_UNKNOWN
                B5.3.1.3 Success conditions
  ID                           Condition
  len_value                   post: len == min(size, bytes_written_to_granule_at_addr_starting_at_offset)
  rec_attest_state            post: rec.attest_state == NO_ATTEST_IN_PROGRESS
  result_success              post: ResultEqual(result, RSI_INCOMPLETE)
                B5.3.1.4 Footprint
    ID                          Value
    rec_attest_state            rec.attest_state
    granule_content             GranuleAt(s, addr).content (partial update)
    len                         len (output register)
    result                      result (output register)
