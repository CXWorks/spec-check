B5.3.20 RSI_VERSION command
                Returns RSI version.
                B5.3.20.1 Interface
                B5.3.20.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000190
        req                   X1          63:0        RsiInterfaceVersion                   Requested interface revision
                B5.3.20.1.2   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RsiCommandReturnCode                  Command return status
        lower                 X1          63:0        RsiInterfaceVersion                   Lower supported interface revision
        higher                X2          63:0        RsiInterfaceVersion                   Higher supported interface revision
                B5.3.20.2 Failure conditions
  ID                           Condition
  req_incompatible_lower       pre: !VersionCompatible(req, higher) && req > lower
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  req_incompatible_higher      pre: !VersionCompatible(req, higher) && req < higher
                               post: ResultEqual(result, RSI_ERROR_INPUT)
                B5.3.20.2.1   Failure condition ordering
                [req_incompatible_lower] < [req_incompatible_higher]
                                 req_incompatible_lower                     req_incompatible_higher
                                                                                           RSI_ERROR_INPUT
                                                                                           req_incompatible_higher
                B5.3.20.3 Success conditions
  ID                           Condition
  lower_eq_req                 post: lower == req
  higher_eq_max                post: higher == RsiVersionHighest(s)

    ID                           Value
    none                        -
