B5.3.21 RSI_VSMMU_ACTIVATE command
                Activate a VSMMU.
                B5.3.21.1 Interface
                B5.3.21.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC400019B
        base                  X1          63:0        Address                               Base of target IPA region
        top                   X2          63:0        Address                               Top of target IPA region
                B5.3.21.1.2   Context
                The RSI_VSMMU_ACTIVATE command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   CurrentRealm()                             false    Current Realm
        walk                  RmmRttWalkResult           RttWalk(realm, base, RMM_RTT_PAGE_LEVEL, RMM_RTT_TREE_PRIMARY)  false    RTT walk result
        vsmmu                 RmmVsmmu                   VsmmuAt(walk.rtte.addr)                    false    VSMMU
                B5.3.21.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RsiCommandReturnCode                  Command return status
        new_base              X1          63:0        Address                               Base of IPA region which was not modified by the command
                B5.3.21.2 Failure conditions
  ID                           Condition
  base_align                  pre: !AddrIsGranuleAligned(base)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  top_align                   pre: !AddrIsGranuleAligned(top)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  top_less_equal_base         pre: top <= base
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  range_not_protected         pre: !AddrRangeIsProtected(realm, base, top)
                               post: ResultEqual(result, RSI_ERROR_INPUT)
  rtt_entry_not_assigned_vsmmu pre: walk.rtte.state != ASSIGNED_VSMMU
                               post: ResultEqual(result, RSI_ERROR_INPUT)
                B5.3.21.2.1   Failure condition ordering
                [base_align, top_align, top_less_equal_base, range_not_protected] < [rtt_entry_not_assigned_vsmmu]
                                                                                           base_align                     top_align                     top_less_equal_base                     range_not_protected
                                                                                                                           rtt_entry_not_assigned_vsmmu
                B5.3.21.3 Success conditions
  ID                           Condition
  ripas_dev                   post: RipasToRmi(GranuleAt(base).state) == DEV && forall|addr: Address| AddrInRange(realm, addr, base, top) ==> RipasToRmi(GranuleAt(addr).state) == DEV
  vsmmu_state_activating      post: (base == VsmmuAt(walk.rtte.addr).reg_base) && (new_base != VsmmuAt(walk.rtte.addr).reg_top) ==> vsmmu.state == VSMMU_ACTIVATING
  vsmmu_state_active          post: new_base == VsmmuAt(walk.rtte.addr).reg_top ==> vsmmu.state == VSMMU_ACTIVE
