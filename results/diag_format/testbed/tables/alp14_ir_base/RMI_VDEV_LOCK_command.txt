B4.3.56 RMI_VDEV_LOCK command
                Lock VDEV.
                B4.3.56.1 Interface
                B4.3.56.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC40001D2
        rd                    X1          63:0        Address                               PA of the RD
        vdev_ptr              X2          63:0        Address                               PA of the VDEV
                B4.3.56.1.2   Context
                The RMI_VDEV_LOCK command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   RealmAt(rd)                                false    Realm
        vdev                  RmmVdev                    VdevAt(vdev_ptr)                           false    VDEV
                B4.3.56.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.56.2 Failure conditions
  ID                           Condition
  da_supported                 pre: !ImplFeatures(s).feat_da
                               post: ResultEqual(result, RMI_ERROR_NOT_SUPPORTED)
  rd_align                     pre: !AddrIsGranuleAligned(s, rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_bound                     pre: !PaIsDelegable(s, rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_state                     pre: GranuleAt(s, rd).state != RD
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_ptr_align               pre: !AddrIsGranuleAligned(s, vdev_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_ptr_bound               pre: !PaIsDelegable(s, vdev_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_state                   pre: GranuleAt(s, vdev_ptr).state != VDEV
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_realm                   pre: vdev.realm != realm
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_state_locked            pre: vdev.vdev_state != VDEV_UNLOCKED
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
  vdev_comm_idle               pre: vdev.comm_state != DEV_COMM_IDLE
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
                B4.3.56.2.1   Failure condition ordering
                [da_supported] < [rd_bound, rd_state] < [vdev_ptr_bound, vdev_ptr_align, vdev_state] < [vdev_realm] < [vdev_state_locked, vdev_comm_idle]
                                                                                           da_supported
                                                                                           rd_bound                     rd_state
                                                                                           vdev_ptr_bound               vdev_ptr_align               vdev_state
                                                                                                                           vdev_realm
                                                                                                                           vdev_state_locked               vdev_comm_idle
                B4.3.56.3 Success conditions
  ID                           Condition
  vdev_op                      post: vdev.op == VDEV_OP_LOCK
  vdev_comm_state              post: vdev.comm_state == DEV_COMM_PENDING
                B4.3.56.4 Footprint
    ID                            Value
    vdev_op                        vdev.op
    vdev_comm_state                vdev.comm_state
