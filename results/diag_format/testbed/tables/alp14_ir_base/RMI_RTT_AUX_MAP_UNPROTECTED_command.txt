B4.3.35 RMI_RTT_AUX_MAP_UNPROTECTED command
                Copies a valid or table descriptor at an Unprotected IPA from the starting level of the primary RTT to an auxiliary RTT.
                B4.3.35.1 Interface
                B4.3.35.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000181
        rd                    X1          63:0        Address                               PA of the RD for the target Realm
        ipa                   X2          63:0        Address                               IPA in the target Realm
        index                 X3          63:0        UInt64                                RTT tree index
                B4.3.35.1.2   Context
                The RMI_RTT_AUX_MAP_UNPROTECTED command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   RealmAt(rd)                                false    Realm
        walk_pri              RmmRttWalkResult           RttWalk(realm, ipa, realm.rtt_level_start, RMM_RTT_TREE_PRIMARY)  false    Primary RTT walk
        walk_aux              RmmRttWalkResult           RttWalk(realm, ipa, realm.rtt_level_start, index)                 false    Auxiliary RTT walk
        entry_idx             UInt64                     RttEntryIndex(ipa, walk_aux.level)                                   false    RTTE index
                B4.3.35.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.35.2 Failure conditions
  ID                           Condition
  rd_align                     pre: !AddrIsGranuleAligned(s, rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_delegable                 pre: !PaIsDelegable(s, rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_state                     pre: GranuleAt(s, rd).state != RD
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  ipa_aligned                  pre: !AddrIsAligned(s, ipa, pow2(realm.ipa_width))
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  ipa_in_range                 pre: ipa >= pow2(realm.ipa_width)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  ipa_protected                pre: AddrIsProtected(s, ipa, realm)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  realm_no_aux_trees           pre: realm.rtt_tree_per_plane == RMM_FEATURE_FALSE
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  index_primary                pre: index == RMM_RTT_TREE_PRIMARY
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  index_out_of_range           pre: index > realm.num_aux_planes
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  pri_entry_unassigned         pre: walk_pri.rtte.state == RMM_RTT_ENTRY_UNASSIGNED_NS
                               post: ResultEqual(result, RMI_ERROR_RTT)
                B4.3.35.2.1   Failure condition ordering
                [rd_delegable, rd_state] < [ip_in_range, ipa_protected] < [pri_entry_unassigned]
                                 rd_delegable                     rd_state                        ipa_in_range                     ipa_protected                     index_primary                     index_out_of_range                     realm_no_aux_trees
                                                                                           RMI_ERROR_INPUT
                                                                                           ipa_aligned
                                                                                           pri_entry_unassigned
                B4.3.35.3 Success conditions
  ID                           Condition
  rtte_state_match             post: walk_aux.rtte.state == walk_pri.rtte.state
  rtte_attr_match              post: RmmRttMemAttrEqual(walk_aux.rtte, walk_pri.rtte, RMM_RTT_PROTECTED)
  rtte_s2ap_match              post: RmmRttS2APEqual(walk_aux.rtte, walk_pri.rtte, realm.rtt_s2ap_encoding)
  rtte_out_addr_match          post: walk_aux.rtte.s2ap_direct.read == walk_pri.rtte.s2ap_direct.read && walk_aux.rtte.s2ap_direct.write == walk_pri.rtte.s2ap_direct.write
                B4.3.35.4 Footprint
    ID                           Value
    rtte                        RttEntry(walk_aux.rtt_addr, entry_idx)
