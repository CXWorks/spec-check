B4.3.53 RMI_VDEV_GET_INTERFACE_REPORT command
                Get VDEV interface report.
                B4.3.53.1 Interface
                B4.3.53.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC40001D0
        rd                    X1          63:0        Address                               PA of the RD
        vdev_ptr              X2          63:0        Address                               PA of the VDEV
                B4.3.53.1.2   Context
                The RMI_VDEV_GET_INTERFACE_REPORT command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        realm                 RmmRealm                   RealmAt(rd)                                false    Realm
        vdev                  RmmVdev                    VdevAt(vdev_ptr)                           false    VDEV
                B4.3.53.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.53.2 Failure conditions
  ID                           Condition
  feature_support             pre: !ImplFeatures(s).feat_da
                               post: ResultEqual(result, RMI_ERROR_NOT_SUPPORTED)
  rd_align                    pre: !AddrIsGranuleAligned(s, rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_delegable                pre: !PaIsDelegable(s, rd)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  rd_state                    pre: GranuleAt(s, rd).state != RD
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_ptr_align              pre: !AddrIsGranuleAligned(s, vdev_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_ptr_delegable          pre: !PaIsDelegable(s, vdev_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_ptr_state              pre: GranuleAt(s, vdev_ptr).state != VDEV
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_realm                  pre: !VdevAt(s, vdev_ptr).realm == realm
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  vdev_state                  pre: VdevAt(s, vdev_ptr).vdev_state != VDEV_LOCKED && VdevAt(s, vdev_ptr).vdev_state != VDEV_STARTED
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
  vdev_comm                   pre: VdevAt(s, vdev_ptr).comm_state != DEV_COMM_IDLE
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
                B4.3.53.2.1   Failure condition ordering
                [feature_support] < [rd_delegable, rd_state, vdev_ptr_align, vdev_ptr_delegable, vdev_ptr_state, vdev_realm] < [vdev_state, vdev_comm]
                                                                                           feature_support
                                                                                           rd_delegable                     rd_state                        vdev_ptr_align
                                                                                           vdev_ptr_delegable                   vdev_ptr_state                        vdev_realm
                                                                                                                           vdev_state                        vdev_comm
                B4.3.53.3 Success conditions
  ID                           Condition
  vdev_op                      post: VdevAt(s, vdev_ptr).op == VDEV_OP_GET_REPORT
  vdev_comm                    post: VdevAt(s, vdev_ptr).comm_state == DEV_COMM_PENDING
                B4.3.53.4 Footprint
    ID                            Value
    vdev_op                        vdev.op
    vdev_comm_state                vdev.comm_state
