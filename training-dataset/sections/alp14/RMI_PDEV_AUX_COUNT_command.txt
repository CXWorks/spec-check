B4.3.10 RMI_PDEV_AUX_COUNT command
                Get number of auxiliary Granules required for a PDEV.
                B4.3.10.1 Interface
                B4.3.10.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000156
        value                 X1          63:0        Bits64                                PDEV flags value
                B4.3.10.1.2   Context
                The RMI_PDEV_AUX_COUNT command operates on the following context.
        Name                  Type                       Value                                      Before     Description
        flags                 RmiPdevFlags               RmiPdevFlagsDecode(value)                  false      PDEV flags
                B4.3.10.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
        aux_count             X1          63:0        UInt64                                Number of auxiliary Granules required
                                                                                            for a PDEV
                B4.3.10.2 Failure conditions
  ID                           Condition
  da_supp                      pre: ImplFeatures().feat_da != FEATURE_TRUE
                               post: ResultEqual(result, RMI_ERROR_NOT_SUPPORTED)
  flags_supp                   pre: !RmiPdevFlagsSupported(flags)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
                B4.3.10.2.1   Failure condition ordering
                The RMI_PDEV_AUX_COUNT command does not have any failure condition orderings.
                B4.3.10.3 Success conditions
  ID                           Condition
  aux_count                    post: aux_count == PdevAuxCount(flags)
                B4.3.10.4 Footprint
                The RMI_PDEV_AUX_COUNT command does not have any footprint.
