B4.3.14 RMI_P2P_STREAM_REMOVE command
               Remove a PDEV from a P2P stream.
               B4.3.14.1 Interface
               B4.3.14.1.1   Input values
        Name                 Register    Bits        Type                                  Description
        fid                  X0          63:0        UInt64                                FID, value 0xC40001C3
        stream_ptr           X1          63:0        Address                               PA of the P2P_STREAM object
        pdev_ptr             X2          63:0        Address                               PA of the PDEV object
               B4.3.14.1.2   Context
               The RMI_P2P_STREAM_REMOVE command operates on the following context.
        Name                 Type                       Value                                      Before   Description
        stream_pre           RmmP2PStream               P2PStreamAt(stream_ptr)                    true     P2P stream
        stream               RmmP2PStream               P2PStreamAt(stream_ptr)                    false    P2P stream
        pdev                 RmmPdev                    PdevAt(pdev_ptr)                           false    PDEV
               B4.3.14.1.3   Output values
        Name                 Register    Bits        Type                                  Description
        result               X0          63:0        RmiCommandReturnCode                  Command return status
               B4.3.14.2 Failure conditions
  ID                          Condition
  da_supp                     pre: ImplFeatures().feat_da != FEATURE_TRUE
                              post: ResultEqual(result, RMI_ERROR_NOT_SUPPORTED)
  stream_align                pre: !AddrIsGranuleAligned(stream_ptr)
                              post: ResultEqual(result, RMI_ERROR_INPUT)
  stream_bound                pre: !PaIsDelegable(stream_ptr)
                              post: ResultEqual(result, RMI_ERROR_INPUT)
  stream_state                pre: GranuleAt(stream_ptr).state != P2P_STREAM
                              post: ResultEqual(result, RMI_ERROR_INPUT)
  pdev_align                  pre: !AddrIsGranuleAligned(pdev_ptr)
                              post: ResultEqual(result, RMI_ERROR_INPUT)
  ID                                 Condition
  pdev_bound                         pre: !PaIsDelegable(pdev_ptr)
                                     post: ResultEqual(result, RMI_ERROR_INPUT)
  pdev_gran_state                    pre: GranuleAt(pdev_ptr).state != PDEV
                                     post: ResultEqual(result, RMI_ERROR_INPUT)
  pdev_state                         pre: pdev.state != PDEV_READY
                                     post: ResultEqual(result, RMI_ERROR_INPUT)
  pdev_p2p_added                     pre: pdev.p2p_added == RMM_FALSE
                                     post: ResultEqual(result, RMI_ERROR_DEVICE)
  pdev_p2p_addr                      pre: pdev.p2p_addr != stream_ptr
                                     post: ResultEqual(result, RMI_ERROR_DEVICE)
               B4.3.14.2.1          Failure condition ordering
               [da_supp] < [stream_align, stream_bound, stream_state, pdev_align,
                    pdev_bound, pdev_gran_state, pdev_state, pdev_p2p_added,
                    pdev_p2p_addr]
                                                                                                                                                          da_supp
                                                                                                                                                     RMI_ERROR_NOT _SUPPORT ED
                    pdev_p2p_addr      pdev_p2p_added         pdev_state   pdev_gran_state   pdev_bound   pdev_align   stream_state   stream_bound      stream_align
                                           RMI_ERROR_DEVICE                                                                                               RMI_ERROR_INPUT
               B4.3.14.3 Success conditions
  ID                                 Condition
  num_pdevs                          stream.num_pdevs == stream_pre.num_pdevs - 1
  p2p_added                          pdev.p2p_added == RMM_FALSE
  pdev_state                         pdev.state == PDEV_COMMUNICATING
  comm_state                         pdev.comm_state == DEV_COMM_PENDING
               B4.3.14.4 Footprint
               The RMI_P2P_STREAM_REMOVE command does not have any footprint.
