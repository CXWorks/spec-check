B5.3.18 RSI_RDEV_GET_INTERFACE_REPORT command
                 Get Realm device interface report.
                 B5.3.18.1 Interface
                 B5.3.18.1.1   Input values
          Name                 Register    Bits        Type                                  Description
          fid                  X0          63:0        UInt64                                FID, value 0xC40001A6
          vdev_id              X1          63:0        Bits64                                Realm device identifier
          inst_id              X2          63:0        UInt64                                Device instance identifier
          version_max          X3          63:0        UInt64                                Maximum TDISP version accepted by
                                                                                             caller
                 B5.3.18.1.2   Context
                 The RSI_RDEV_GET_INTERFACE_REPORT command operates on the following context.
          Name                 Type                       Value                                      Before    Description
          realm                RmmRealm                   CurrentRealm()                             false     Current Realm
          vdev                 RmmVdev                    VdevFromInstId(                            false     Realm device
                                                              realm,
                                                              inst_id)
                 B5.3.18.1.3   Output values
          Name                 Register    Bits        Type                                  Description
          result               X0          63:0        RsiCommandReturnCode                  Command return status
          version              X1          63:0        UInt64                                TDISP version
                 B5.3.18.2 Failure conditions
  ID                            Condition
  da_en                         pre: realm.feat_da != FEATURE_TRUE
                                post: result == RSI_ERROR_STATE
  vdev_id                       pre: !VdevIdsAreValid(realm, vdev_id, inst_id)
                                post: result == RSI_ERROR_INPUT
  version                       pre: TDISP version is not supported.
                                post: result == RSI_ERROR_INPUT
  ID                         Condition
  state                      pre:  (vdev.rdev_state != RDEV_LOCKED
                                       && vdev.rdev_state != RDEV_STARTED)
                             post: result == RSI_ERROR_DEVICE
              B5.3.18.2.1   Failure condition ordering
              [da_en] < [vdev_id, version]
              [vdev_id] < [state]
                                                                                               da_en
                                                                                       RSI_ERROR_STAT E
                                                                version                      vdev_id

                                                                                         RSI_ERROR_DEVICE
              B5.3.18.3 Success conditions
  ID                         Condition
  locked                     pre: vdev.rdev_state == RDEV_LOCKED
                             post: vdev.rdev_state == RDEV_LOCKED_BUSY
  started                    pre: vdev.rdev_state == RDEV_STARTED
                             post: vdev.rdev_state == RDEV_STARTED_BUSY
  operation                  vdev.operation == RDEV_OP_GET_INTERFACE_REPORT
