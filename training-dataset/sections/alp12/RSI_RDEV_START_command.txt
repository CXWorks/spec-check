B5.3.23 RSI_RDEV_START command
                  Start a Realm device.
                  B5.3.23.1 Interface
                  B5.3.23.1.1   Input values
          Name                  Register    Bits        Type                                  Description
          fid                   X0          63:0        UInt64                                FID, value 0xC40001AA
          vdev_id               X1          63:0        Bits64                                Realm device identifier
          inst_id               X2          63:0        UInt64                                Device instance identifier
          flags                 X3          63:0        RsiDevStartFlags                      Flags
          non_ats_plane         X4          63:0        UInt64                                Plane whose stage 2 configuration
                                                                                              should be used if ATS is not enabled
                  B5.3.23.1.2   Context
                  The RSI_RDEV_START command operates on the following context.
          Name                  Type                       Value                                      Before    Description
          realm                 RmmRealm                   CurrentRealm()                             false     Current Realm
          vdev                  RmmVdev                    VdevFromInstId(                            false     Realm device
                                                               realm,
                                                               inst_id)
                  B5.3.23.1.3   Output values
          Name                  Register    Bits        Type                                  Description
          result                X0          63:0        RsiCommandReturnCode                  Command return status
                  B5.3.23.2 Failure conditions
  ID                             Condition
  da_en                          pre: realm.feat_da != FEATURE_TRUE
                                 post: result == RSI_ERROR_STATE
  vdev_id                        pre: !VdevIdsAreValid(realm, vdev_id, inst_id)
                                 post: result == RSI_ERROR_INPUT
  state                          pre: vdev.rdev_state != RDEV_LOCKED
                                 post: result == RSI_ERROR_DEVICE
              B5.3.23.2.1   Failure condition ordering
              [da_en] < [vdev_id]
              [vdev_id] < [state]
                                                                                               da_en

              B5.3.23.3 Success conditions
  ID                         Condition
  state                      vdev.rdev_state == RDEV_LOCKED_BUSY
  operation                  vdev.operation == RDEV_OP_START
