5.12  SYSTEM_RESET 

5.12.1 Intended use 
This function provides a method for performing a system cold reset. To the caller, the behavior is 
equivalent to a hardware power-cycle sequence. As detailed in section 4.4, the reset command applies 
to the machine view of the calling OS. 
5.12.2 Caller responsibilities 
Where possible, cores should be placed in a known state. No specific coordination is required between 
cores. Apart from the case when the response to the call is virtualized, when one core calls 
SYSTEM_RESET, the system power cycles.
