              3.10.3.13    POWERCAP_DOMAIN_NAME_GET
              This command returns the extended name associated with a specific power capping domain.
                  message_id: 0x8
                  protocol_id: 0x18
                  This command is mandatory only if extended power capping domain name is supported.
                  Extended power capping domain name is supported when Bit[28] of attributes field of
                  POWERCAP_DOMAIN_ATTRIBUTES command is set to 1. Refer to Section 3.10.3.5 for more details.
                  Parameters
                  Name
                                                              T0
                                                      Description
                  uint32 domain_id
                  Return values
                  Name
                                                BE    Identifier for the power capping domain.
                                                      Description
                  int32 status                        One of, but not limited to, the following:
                                                          • SUCCESS: if valid power capping domain extended name is returned.
                                                          • NOT_FOUND: if domain_id pertains to a non-existent domain.
                                                      See Section 3.1.4 for more status code definitions.
                  uint32 flags                        Bits[31:0]
                                                      Reserved, must be zero.
                  uint8 name[64]                      Null-terminated ASCII string of up to 64 bytes in length describing the power
                                                      capping domain extended name.
