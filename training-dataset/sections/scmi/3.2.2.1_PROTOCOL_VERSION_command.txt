                 3.2.2.1   PROTOCOL_VERSION
                                                                T0
                 This command returns the version of this protocol. For this version of the specification, the value that is returned must
                                                  BE
                 be 0x20001, which corresponds to version 2.1.
                    message_id: 0x0
                    protocol_id: 0x10
                    This command is mandatory.
                    Return values
                    Name                                Description
                    int32 status                        See Section 3.1.4 for status code definitions.
                    uint32 version                      For this revision of the specification, this value must be 0x20001.
