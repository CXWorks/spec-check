              3.8.2.1    PROTOCOL_VERSION
              On success, this command returns the version of this protocol. For this version of the specification, the value returned
              must be 0x30001, which corresponds to version 3.1.
                  message_id: 0x0
                  protocol_id: 0x16
                  This command is mandatory.
                  Return values
                  Name                                Description
                  int32 status                        See Section 3.1.4 for status code definitions.
                  uint32 version                      For this revision of the specification, this must be 0x30001.
