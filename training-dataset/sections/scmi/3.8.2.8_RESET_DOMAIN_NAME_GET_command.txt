              3.8.2.8    RESET_DOMAIN_NAME_GET
                                                              T0
              This command returns the extended name associated with a specific reset domain.
                  message_id: 0x6
                  protocol_id: 0x16
                                                BE
                  This command is mandatory only if extended reset domain name is supported.
                  Extended reset domain name is supported when Bit[29] of attributes field of RESET_DOMAIN_ATTRIBUTES
                  command is set to 1. Refer to Section 3.8.2.5 for more details.
                  Parameters
                  Name                                Description
                  uint32 domain_id                    Identifier for the reset domain.
                  Return values
                  Name                                Description
                  int32 status                        One of, but not limited to, the following:
                                                          • SUCCESS: if valid reset domain extended name is returned.
                                                          • NOT_FOUND: if domain_id pertains to a non-existent domain.
                                                      See Section 3.1.4 for more status code definitions.
                  uint32 flags                        Bits[31:0]
                                                      Reserved, must be zero.
                  uint8 name[64]                      Null-terminated ASCII string of up to 64 bytes in length describing the reset
                                                      domain extended name.
