                 3.5.6.4   PROTOCOL_MESSAGE_ATTRIBUTES
                 On success, this command returns the implementation details associated with a specific message in this protocol.
                 This command can be used to inquire if performance level or limit change notifications are supported by the platform.
                 This is achieved by passing message identifiers for the PERFORMANCE_NOTIFY_LEVEL or
                 PERFORMANCE_NOTIFY_LIMITS messages to the call. The platform then returns a status code of NOT_FOUND
                 to indicate that notifications are not implemented, or that they are not available to the calling agent. The notification
                 commands are described in Section 3.5.6.16 and Section 3.5.6.17. This command can also be used to discover if
                 FastChannels are supported for a command specified by message_id.
                    message_id: 0x2
                    protocol_id: 0x13
                    This command is mandatory.
                    Parameters
                    Name                                   Description
                    uint32 message_id                      message_id of the message.
                    Return values
                    Name                                   Description
                                                                                                      Arm® System Control and Management Interface
                    int32 status                           One of, but not limited to, the following:
                                                               • SUCCESS: in case the message is implemented and available to use.
                                                               • NOT_FOUND: if the message identified by message_id is invalid or not
                                                                 provided by this platform implementation.
                                                           See Section 3.1.4 for more status code definitions.
                    uint32 attributes                      Flags associated with a specific command in the protocol.
                                                           Bits[31:1]
                                                           Reserved, must be zero.
                                                           Bit[0]
                                                           FastChannel Support.
                                                                • Set to 1 if there is at least one dedicated FastChannel available for this
                                                                  message.
                                                                • Set to 0 if there are no FastChannels available for this message.
