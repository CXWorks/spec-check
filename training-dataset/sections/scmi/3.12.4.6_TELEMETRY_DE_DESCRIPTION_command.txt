              DE Descriptor
              The DE_DESC structure describes the DE properties, such as the unique identifier for the DE, timestamping support and
              other characteristics.
                  uint32 de_id                         Identifier for the DE. Each DE is identified by a unique 32-bit integer identifier.
                  uint32 group_id                      Event group identifier for the DE.
                                                       Set to 0xFFFFFFFF if this DE does not belong to any event group.
                  uint32 de_data_size                  Actual size of the DE data in bytes.
                                                       The space allocated for the DE data depends on the telemetry interface used,
                                                       and is a multiple of 8 bytes for SHMTI, and a multiple of 4 bytes for
                                                       FastChannels. The space allocated must be sufficient to accommodate the
                                                       maximum and minimum measurable DE values accounting for sign-extension.
                  uint32 de_attributes_1               Bit[31]
                                                       Named specified.
                                                            • If set to 1, the DE name is specified by the name field.
                                                            • If set to 0, the name field is not present. The DE name is not specified.
                                                       Bit[30]
                                                       FastChannel support.
                                                            • If this flag is set to 1, the DE values are returned using FastChannels.
                                                              The fields fastchannel_address_low, fastchannel_address_high and
                                                              fastchannel_address_size are present in this DE descriptor.
                                                            • If this flag is set to 0, no FastChannel is provisioned for this DE. The
                                                               T0
                                                              fields fastchannel_address_low, fastchannel_address_high and
                                                              fastchannel_address_size are not present in this DE descriptor.
                                                       Bits[29:22]
                                                 BE    DE type: The type of Data Event as described in Table 30.
                                                       Bit[21]
                                                       Persistent: The DE data values are persistent across all reboot cycles, except
                                                       cold reboot. In this case the DE ID must not change across reboot cycles
                                                       where the DE data value persists.
                                                       Bits[20:13]
                                                       DE unit Exponent: The power-of-10 multiplier in two's complement format that
                                                       is applied to the unit specified by the DE unit field.
                                                       Bits[12:5]
                                                       DE unit: The measurement system the DE implements, as described in
                                                       Table 19.
                                                       Bits[4:2]
                                                       Reserved, must be zero.
                                                       Bits[1:0]
                                                       Timestamp support:
                                                            • If this flag is set to 0, the DE cannot provide timestamped values.
                                                            • If this flag is set to 1, the DE provides timestamped values using its line
                                                              timestamp.
                                                            • If this flag is set to 2, the DE provides timestamped values using a
                                                              block timestamp line.
                                                              All other values are reserved and must not be used.
                                                       Timestamps should be derived from a monotonic time base. The selection of
                                                       a time base is beyond the scope of this specification and should be agreed
                                                       between the agent and the platform by other standard mechanisms.
                                                                                                 Arm® System Control and Management Interface
                  uint32 de_attributes_2              Bits[31:24]
                                                      DE Instance ID: Identifies DEs which measure the same DE unit, as specified
                                                      by Bits[12:5] of de_attributes_1 field, associated with the same Component
                                                      Instance. Component Instance is specified by Bits[23:8].
                                                      DE instance IDs are unsigned sequential integers starting from 0.
                                                      For example, if there are 3 DEs within the same CPU which measure
                                                      temperature at different locations within the CPU, their DE Instance IDs are 0,
                                                      1 and 2.
                                                      This field is set to 0 if there is only one instance of the DE within a component
                                                      ID.
                                                      Bits[23:8]
                                                      Component Instance: Instance of the component this DE is associated with.
                                                      Component Instances are sequential unsigned integers starting from 0.
                                                      For example if Bits[7:0] is set to 0x0, then this field identifies the CPU instance
                                                      this DE is associated with.
                                                      If the component type is a CPU, then this field is recommended to be ordered
                                                      according to the numeric order of the values read from the architecture
                                                      specific CPU identifier registers in the system. For example, MPIDR_EL1 is
                                                      the CPU identifier register in Arm A-Profile CPUs.
                                                      This field is set to 0 if there is only one instance of the component.
                                                      Bits[7:0]
                                                      Component Type: The component type this DE is associated with, as
                                                      described in Table 31.
