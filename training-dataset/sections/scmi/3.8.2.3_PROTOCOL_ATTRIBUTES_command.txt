              3.8.2.3    PROTOCOL_ATTRIBUTES
              This command returns the implementation details associated with this protocol.
                  message_id: 0x1
                  protocol_id: 0x16
                  This command is mandatory.
                  Return values
                  Name                                   Description
                  int32 status                           See Section 3.1.4 for status code definitions.
                  uint32 attributes                      Bits[31:16]
                                                         Reserved, must be zero.
                                                         Bits[15:0]
                                                         Number of reset domains.
