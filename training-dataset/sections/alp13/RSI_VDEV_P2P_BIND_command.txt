B5.3.18 RSI_VDEV_P2P_BIND command
                Creates a P2P binding between two VDEVs.
                B5.3.18.1 Interface
                B5.3.18.1.1   Input values
          Name                Register    Bits        Type                                  Description
          fid                 X0          63:0        UInt64                                FID, value 0xC400019E
          vdev_id_1           X1          63:0        Bits64                                Realm device identifier 1
          vdev_id_2           X2          63:0        Bits64                                Realm device identifier 2
                B5.3.18.1.2   Context
                The RSI_VDEV_P2P_BIND command operates on the following context.
          Name                Type                       Value                                      Before    Description
          realm               RmmRealm                   CurrentRealm()                             false     Current Realm
          vdev_1              RmmVdev                    VdevFromVdevId(                            false     Realm device 1
                                                             realm, vdev_id_1)
          pdev_1              RmmPdev                                                               false     Physical device 1
                                                         PdevAt(vdev_1.pdev)
          vdev_2              RmmVdev                    VdevFromVdevId(                            false     Realm device 2
                                                             realm, vdev_id_2)
          pdev_2              RmmPdev                    PdevAt(vdev_2.pdev)                        false     Physical device 2
                B5.3.18.1.3   Output values
          Name                Register    Bits        Type                                  Description
          result              X0          63:0        RsiCommandReturnCode                  Command return status
                B5.3.18.2 Failure conditions
  ID                           Condition
  da_en                        pre: realm.feat_da != FEATURE_TRUE
                               post: result == RSI_ERROR_STATE
  vdev_id_1                    pre: VdevIdIsFree(realm, vdev_id_1)
                               post: result == RSI_ERROR_INPUT
  vdev_id_2                    pre: VdevIdIsFree(realm, vdev_id_2)
                               post: result == RSI_ERROR_INPUT
  ID                         Condition
  p2p_added                  pre:  (pdev_1.p2p_added == RMM_FALSE
                                       || pdev_2.p2p_added == RMM_FALSE)
                             post: result == RSI_ERROR_INPUT
  p2p_addr                   pre: pdev_1.p2p_addr != pdev_2.p2p_addr
                             post: result == RSI_ERROR_INPUT
              B5.3.18.2.1   Failure condition ordering
              [da_en] < [vdev_id_1, vdev_id_2, p2p_added, p2p_addr]
                                                                                                            da_en
                                                                                                         RSI_ERROR_STAT E
                            p2p_addr               p2p_added                  vdev_id_2                   vdev_id_1
                                                                                                         RSI_ERROR_INPUT
              B5.3.18.3 Success conditions
              The RSI_VDEV_P2P_BIND command does not have any success conditions.
              B5.3.18.4 Footprint
              The RSI_VDEV_P2P_BIND command does not have any footprint.
