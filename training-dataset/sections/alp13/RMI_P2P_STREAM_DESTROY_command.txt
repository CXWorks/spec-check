B4.3.12 RMI_P2P_STREAM_DESTROY command
                Destroy a P2P stream.
                B4.3.12.1 Interface
                B4.3.12.1.1   Input values
        Name                  Register    Bits        Type                                  Description
        fid                   X0          63:0        UInt64                                FID, value 0xC4000182
        stream_ptr            X1          63:0        Address                               PA of the P2P_STREAM object
                B4.3.12.1.2   Context
                The RMI_P2P_STREAM_DESTROY command operates on the following context.
        Name                  Type                       Value                                      Before   Description
        stream                RmmP2PStream               P2PStreamAt(stream_ptr)                    false    P2P stream
                B4.3.12.1.3   Output values
        Name                  Register    Bits        Type                                  Description
        result                X0          63:0        RmiCommandReturnCode                  Command return status
                B4.3.12.2 Failure conditions
  ID                           Condition
  da_supp                      pre: ImplFeatures().feat_da != FEATURE_TRUE
                               post: ResultEqual(result, RMI_ERROR_NOT_SUPPORTED)
  stream_align                 pre: !AddrIsGranuleAligned(stream_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  stream_bound                 pre: !PaIsDelegable(stream_ptr)
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  stream_state                 pre: GranuleAt(stream_ptr).state != P2P_STREAM
                               post: ResultEqual(result, RMI_ERROR_INPUT)
  stream_live                  pre: stream.num_pdevs != 0
                               post: ResultEqual(result, RMI_ERROR_DEVICE)
               B4.3.12.2.1   Failure condition ordering
               [da_supp] < [stream_align, stream_bound, stream_state]
                                                                                 da_supp                 stream_live
                                                                        RMI_ERROR_NOT _SUPPORT ED        RMI_ERROR_DEVICE
                         stream_state              stream_bound               stream_align
                                                                                RMI_ERROR_INPUT
               B4.3.12.3 Success conditions
  ID                          Condition
  gran_state                  post: GranuleAt(stream_ptr).state == DELEGATED
               B4.3.12.4 Footprint
    ID                          Value
    state                       GranuleAt(stream_ptr).state
