B4.5.61 RMI_RTT_DATA_MAP command
                  Create mappings to conventional memory within a target Protected IPA range.
                  The RMI_RTT_DATA_MAP command may initiate a Stateful RMI Operation whose context is bound to the object
                  identified by rd.
