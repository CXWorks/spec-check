B5.2.2 Progress of long-running RSI operations
             The information returned to the caller regarding the amount of progress which has been made differs between
             long-running RSI operations. This section describes the patterns which are used for reporting this progress.
             B5.2.2.1 Long-running non-range RSI operation without separate initialization com-
             mand
IMVFZB       This pattern has the following characteristics:
                 • The operation is a non-range operation.
                 • The caller initiates the operation by calling an RSI command. The input values to this command fully describe
                   the requested operation.
                 • While the result of this command is RSI_INCOMPLETE, the caller continues the operation by calling the
                   command again.
                 • While the operation is incomplete, no changes in state are observable by the caller.
             The following pseudocode illustrate the programming model for this pattern.
             int rsi_long_running_non_range_wihout_init(
                 uint64_t in_value_1,
                 uint64_t in_value_2,

                   ...
                   uint64_t *out_value_1,
                   uint64_t *out_value_2,

                   int result = RSI_INCOMPLETE;

                       result = RSI_OPERATION(
                           in_value_1, in_value_2, ...,

INDRGM       This pattern has the following characteristics:

                   adjusting using the previous out_top as the new base value. This process is repeated until
                   out_top == top.

                   the out_top value.
