B4.5.74 RMI_RTT_UNPROT_UNMAP command
                  Removes mappings to conventional memory within a target Unprotected IPA range.
                  The RMI_RTT_UNPROT_UNMAP command may initiate a Stateful RMI Operation whose context is bound to
                  the object identified by rd.
