B4.5.65 RMI_RTT_DEV_MAP command
                  Create mappings to device memory within a target Protected IPA range.
                  The RMI_RTT_DEV_MAP command may initiate a Stateful RMI Operation whose context is bound to the object
                  identified by rd.
                  See also:
                     • A5.3.7 Create mappings from Protected IPA space to device memory
