B4.5.3 RMI_DPT_L0_DESTROY command
                 Destroy a Level 0 DPT.
                 The RMI_DPT_L0_DESTROY command may initiate a Stateful RMI Operation whose context is bound to the
                 current PE.
                 The RMI_DPT_L0_DESTROY command may initiate a memory-transferring RMI Operation.
