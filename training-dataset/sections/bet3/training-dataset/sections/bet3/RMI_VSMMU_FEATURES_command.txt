B4.5.91 RMI_VSMMU_FEATURES command
                 Returns VSMMU features supporte by the RMM.
                 B4.5.91.1 Interface
                 B4.5.91.1.1   Input values

           Name                Register     Bits       Type                                  Description

           fid                 X0           63:0       UInt64                                FID, value 0xC400020B
           features_ptr        X1           63:0       Address                               PA of the VSMMU features structure

                 B4.5.91.1.2   Context
                 The RMI_VSMMU_FEATURES command operates on the following context.

           Name                Type                       Value                                      Before   Description

           features            RmiVsmmuFeatures           VsmmuFeaturesAt(                           false    VSMMU features
                                                              features_ptr)

                 B4.5.91.1.3   Output values
                                                                     T
           Name                Register     Bits
                                                       AF
                                                       Type                                  Description

           result              X0           63:0
                                                   R   RmiResult                             Command result

                                          D
                 B4.5.91.2 Failure conditions

  ID                            Condition

  features_align                pre: !AddrIsAligned(features_ptr, 0x100)
                                post: result.status == RMI_ERROR_INPUT
  features_pas                  pre: !NonSecureAccessPermitted(features_ptr)
                                post: result.status == RMI_ERROR_INPUT

                 B4.5.91.2.1   Failure condition ordering
                 The RMI_VSMMU_FEATURES command does not have any failure condition orderings.
                 B4.5.91.3 Success conditions

  ID                            Condition

  features                      post: features is populated with VSMMU features supported by the RMM.
