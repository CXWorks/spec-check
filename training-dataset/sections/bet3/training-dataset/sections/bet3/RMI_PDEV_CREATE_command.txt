B4.5.20 RMI_PDEV_CREATE command
                 Create a PDEV.
                 The RMI_PDEV_CREATE command may initiate a Stateful RMI Operation whose context is bound to the object
                 identified by pdev_ptr.
                 The RMI_PDEV_CREATE command may initiate a memory-transferring RMI Operation.
                 See also:
                    • Chapter A9 Realm device assignment
                    • A9.2.2 Physical device invariants
                    • B4.3.4 Object creation and destruction
