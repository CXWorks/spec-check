B4.5.88 RMI_VSMMU_CREATE command
                 Create a VSMMU.
                 The RMI_VSMMU_CREATE command may initiate a Stateful RMI Operation whose context is bound to the
                 object identified by vsmmu_ptr.
                 The RMI_VSMMU_CREATE command may initiate a memory-transferring RMI Operation.
                 See also:
                    • A9.8 Virtual SMMU
                    • B4.3.4 Object creation and destruction
                    • B4.5.89 RMI_VSMMU_DESTROY command
