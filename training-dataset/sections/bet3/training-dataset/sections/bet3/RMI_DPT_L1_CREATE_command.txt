B4.5.4 RMI_DPT_L1_CREATE command
                 Create a Level 1 DPT.
                 The RMI_DPT_L1_CREATE command may initiate a Stateful RMI Operation whose context is bound to the
                 current PE.
                 The RMI_DPT_L1_CREATE command may initiate a memory-transferring RMI Operation.
                 See also:
                    • A9.7.5 Device Permission Table
