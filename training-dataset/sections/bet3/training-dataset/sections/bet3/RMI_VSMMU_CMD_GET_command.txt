B4.5.87 RMI_VSMMU_CMD_GET command
                 Get a command from the VSMMU.
                 See also:
                    • A9.8.6 Page Request Interface events
                    • B4.5.86 RMI_VSMMU_CMD_COMPLETE command
                 B4.5.87.1 Interface
                 B4.5.87.1.1   Input values

           Name                Register     Bits       Type                                  Description

           fid                 X0           63:0       UInt64                                FID, value 0xC400020C
