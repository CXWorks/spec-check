B4.5.9 RMI_GPT_L1_DESTROY command
                 Destroy a Level 1 GPT.
                 The RMI_GPT_L1_DESTROY command may initiate a Stateful RMI Operation whose context is bound to the
                 current PE.
                 The RMI_GPT_L1_DESTROY command may initiate a memory-transferring RMI Operation.
                 See also:
