B4.5.13 RMI_GRANULE_TRACKING_SET command
                 Set configuration of a Granule tracking region.
                 The RMI_GRANULE_TRACKING_SET command may initiate a Stateful RMI Operation whose context is bound
                 to the current PE.
                 The RMI_GRANULE_TRACKING_SET command may initiate a memory-transferring RMI Operation.
                 See also:
                    • A2.3.4 Granule tracking region
                    • B4.5.12 RMI_GRANULE_TRACKING_GET command
