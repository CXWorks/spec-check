B4.5.73 RMI_RTT_UNPROT_MAP command
                  Create mappings to conventional memory within a target Unprotected IPA range.
                  The RMI_RTT_UNPROT_MAP command may initiate a Stateful RMI Operation whose context is bound to the
                  object identified by rd.
                  See also:
                     • A5.3.11 Create mappings from Unprotected IPA space
                     • B4.5.74 RMI_RTT_UNPROT_UNMAP command
