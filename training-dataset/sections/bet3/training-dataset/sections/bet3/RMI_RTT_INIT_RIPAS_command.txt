               B4.5.69.4 RMI_RTT_INIT_RIPAS extension of RIM

                                                                        T
               Successful execution of RMI_RTT_INIT_RIPAS initiates a RIPAS initialization operation. The operation is
               complete when any of the following happens:

                                                          AF
                  • RMI_RTT_INIT_RIPAS returns RMI_SUCCESS.
                  • RMI_RTT_INIT_RIPAS returns RMI_INCOMPLETE, indicating that an SRO has been initialized.
                    Subsequent execution of RMI_OP_CONTINUE returns RMI_SUCCESS.

                                                    R
               On completion of the RIPAS initialization operation, the out_top output value indicates the top of the IPA range
               whose RIPAS was successfully initialized. If either of the following is true, out_top may be less than the top
               input value:
                                            D
                  • The SRO was cancelled by execution of RMI_OP_CANCEL.
                  • An RTT walk within the target IPA range terminated before reaching the level whose mapping size aligns
                    with top.
               On completion of the RIPAS initialization operation, the new RIM value of the target Realm is calculated by the
               RMM as follows:
                 1. Allocate an RmmMeasurementDescriptorRipas data structure.
                 2. Populate the measurement descriptor:
                  • Set the desc_type field to the descriptor type.
                  • Set the len field to the descriptor length.
                  • Set the rim field to the current RIM value of the target Realm.
                  • Set the base field to the base input value provided to RMI_RTT_INIT_RIPAS.
                  • Set the top field to the out_top output value returned from RMI_RTT_INIT_RIPAS.
                 3. Using the RHA of the target Realm, compute the hash of the measurement descriptor. Set the RIM of the
                    target Realm to this value, zero filling upper bytes if the RHA output is smaller than the size of the RIM.
               The above algorithm means that, if the RIPAS initialization operation completes with out_top < top, the final
               RIM may not match the value expected by a verifier. Because of this, the Host is expected to avoid such a partial
               completion of the RIPAS initialization operation.
