B4.5.10 RMI_GRANULE_RANGE_DELEGATE command
                 Delegates a range of Granules.
                 The RMI_GRANULE_RANGE_DELEGATE command may initiate a Stateful RMI Operation whose context is
                 bound to the current PE.
                 See also:
                    • A2.3.6.2 Granule delegation
                    • B4.3.5 Range RMI operations
                    • B4.5.11 RMI_GRANULE_RANGE_UNDELEGATE command
