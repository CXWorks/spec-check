B4.5.66 RMI_RTT_DEV_UNMAP command
                  Removes mappings to device memory within a target Protected IPA range.
                  The RMI_RTT_DEV_UNMAP command may initiate a Stateful RMI Operation whose context is bound to the
                  object identified by rd.
                  See also:
                     • A5.3.8 Remove mappings from Protected IPA space to device memory
