B4.5.12 RMI_GRANULE_TRACKING_GET command
                 Get Granule tracking configuration within a specified PA range.
                 See also:
                    • A2.3.4 Granule tracking region
                    • B4.5.13 RMI_GRANULE_TRACKING_SET command
                 B4.5.12.1 Interface
                 B4.5.12.1.1   Input values

           Name                Register     Bits        Type                                  Description

           fid                 X0           63:0        UInt64                                FID, value 0xC40001E1
           base                X1           63:0        Address                               Base PA of the target region
           top                 X2           63:0        Address                               Top PA of the target region

                 B4.5.12.1.2   Context
                 The RMI_GRANULE_TRACKING_GET command operates on the following context.

           Name                Type                        Value      T                               Before    Description

           rmm                 RmmGlobal                AF Rmm()                                      false     RMM global state

                 B4.5.12.1.3   Output values
                                                   R

                 B4.5.12.2 Failure conditions

                                post: result.status == RMI_ERROR_INPUT
