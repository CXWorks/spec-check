B4.5.33 RMI_PSMMU_DEACTIVATE command
                 Deactivate a PSMMU.
                 The RMI_PSMMU_DEACTIVATE command may initiate a Stateful RMI Operation whose context is bound to
                 the object identified by psmmu_ptr.
                 The RMI_PSMMU_DEACTIVATE command may initiate a memory-transferring RMI Operation.
                 See also:
