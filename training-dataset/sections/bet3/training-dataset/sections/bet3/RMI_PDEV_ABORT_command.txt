B4.5.18 RMI_PDEV_ABORT command
                 Abort device communication associated with a PDEV.
                 See also:
                    • Chapter A9 Realm device assignment
                 B4.5.18.1 Interface
                 B4.5.18.1.1   Input values

           Name                Register     Bits       Type                                  Description

           fid                 X0           63:0       UInt64                                FID, value 0xC4000174
           pdev_ptr            X1           63:0       Address                               PA of the PDEV

                 B4.5.18.1.2   Context
                 The RMI_PDEV_ABORT command operates on the following context.

           Name                Type                       Value                                      Before   Description

           pdev                RmmPdev                               T
                                                          PdevAt(pdev_ptr)                           false    PDEV

                 B4.5.18.1.3   Output values
                                                       AF
           Name                Register     Bits
                                                   R   Type                                  Description

           result              X0
                                          D 63:0

                 B4.5.18.2 Failure conditions
                                                       RmiResult                             Command result

  ID                            Condition

  feat                          pre: Rmm().static.feat_da != FEATURE_TRUE
                                post: result.status == RMI_ERROR_NOT_SUPPORTED
  pdev_align                    pre: !AddrIsRmiGranuleAligned(pdev_ptr)
                                post: result.status == RMI_ERROR_INPUT
  pdev_bound                    pre: !PaIsTracked(pdev_ptr)
                                post: result.status == RMI_ERROR_INPUT
  pdev_gran_state               pre: GranuleAt(pdev_ptr).state != GRAN_PDEV
                                post: result.status == RMI_ERROR_INPUT
  comm_state                    pre: pdev.comm_state == DEV_COMM_IDLE
                                post: result.status == RMI_ERROR_DEVICE
