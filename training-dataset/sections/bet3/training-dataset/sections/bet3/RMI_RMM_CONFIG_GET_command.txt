B4.5.47 RMI_RMM_CONFIG_GET command
                  Get the system configuration.
                  See also:
                      • A2.1 RMM
                  B4.5.47.1 Interface
                  B4.5.47.1.1   Input values

            Name                Register     Bits        Type                                  Description

            fid                 X0           63:0        UInt64                                FID, value 0xC40001EC
            cfg_ptr             X1           63:0        Address                               PA of configuration structure

                  B4.5.47.1.2   Context
                  The RMI_RMM_CONFIG_GET command operates on the following context.

            Name                Type                        Value                                      Before    Description

            rmm                 RmmGlobal                   Rmm()      T                               false     RMM global state
            cfg

                  B4.5.47.1.3
                                RmiRmmConfig

                                Output values
                                                         AF RmiRmmConfigAt(cfg_ptr)                    false     Configuration

            Name                Register     Bits
                                                    R    Type                                  Description

            result              X0
                                           D 63:0        RmiResult                             Command result

                  B4.5.47.2 Failure conditions

  ID                             Condition

  rmm_state                      pre:  !rmm.dynamic.state IN {
                                           RMM_STATE_INIT,
                                           RMM_STATE_ACTIVE
                                       }
                                 post: result.status == RMI_ERROR_GLOBAL
  cfg_align                      pre: !AddrIsRmiGranuleAligned(cfg_ptr)
                                 post: result.status == RMI_ERROR_INPUT
  cfg_pas                        pre: !NonSecureAccessPermitted(cfg_ptr)
                                 post: result.status == RMI_ERROR_INPUT

                  B4.5.47.2.1   Failure condition ordering
                  The RMI_RMM_CONFIG_GET command does not have any failure condition orderings.
