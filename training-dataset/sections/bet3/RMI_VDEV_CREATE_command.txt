B4.5.77 RMI_VDEV_CREATE command
                 Create a VDEV.
                 The RMI_VDEV_CREATE command may initiate a Stateful RMI Operation whose context is bound to the object
                 identified by vdev_ptr.
                 The RMI_VDEV_CREATE command may initiate a memory-transferring RMI Operation.
                 See also:
                    • Chapter A9 Realm device assignment
                    • A9.4.2 Virtual device invariants
                    • B4.3.4 Object creation and destruction
