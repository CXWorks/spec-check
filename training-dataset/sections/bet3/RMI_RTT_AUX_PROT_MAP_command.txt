B4.5.56 RMI_RTT_AUX_PROT_MAP command
                  Propagate mappings within a contiguous range of Protected IPA space from the primary RTT tree to an auxiliary
                  RTT tree.
                  The RMI_RTT_AUX_PROT_MAP command may initiate a Stateful RMI Operation whose context is bound to
                  the object identified by rd.
                  See also:
                     • A5.3.13 Create mappings within Protected IPA space in auxiliary RTT tree
                     • A10.3.1 Auxiliary RTT
                     • B4.5.57 RMI_RTT_AUX_PROT_UNMAP command
