B4.5.46 RMI_RMM_ACTIVATE command
                 Activate the RMM.
                 The RMI_RMM_ACTIVATE command may initiate a Stateful RMI Operation whose context is bound to the
                 current PE.
                 The RMI_RMM_ACTIVATE command may initiate a memory-transferring RMI Operation.
                 See also:

                    • B4.5.49 RMI_RMM_DEACTIVATE command
