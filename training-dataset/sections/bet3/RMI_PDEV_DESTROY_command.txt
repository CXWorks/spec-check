B4.5.21 RMI_PDEV_DESTROY command
                 Destroy a PDEV.
                 The RMI_PDEV_DESTROY command may initiate a Stateful RMI Operation whose context is bound to the
                 object identified by pdev_ptr.
                 The RMI_PDEV_DESTROY command may initiate a memory-transferring RMI Operation.
                 See also:
                    • Chapter A9 Realm device assignment
                    • B4.3.4 Object creation and destruction
