16.2 FFA_NOTIFICATION_BITMAP_DESTROY
           Description
               • This ABI is invoked by the Hypervisor at the Non-secure physical FF-A instance with the SMC conduit to
                 request the SPMC to destroy the SP and SPM framework notifications bitmap for the VM specified in the VM
                 ID input parameter. Also see 10.3 Notification bitmap setup.
               • Valid FF-A instances and conduits are listed in Table 16.7.
               • Syntax of this function is described in Table 16.8.
               • Returns FFA_SUCCESS without any further parameters on successful completion.
               • Encoding of error codes in the FFA_ERROR function is described in Table 16.9.
