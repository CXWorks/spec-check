15.2 FFA_MSG_SEND_DIRECT_REQ
           Description
               • Send a Partition or Framework message in parameter registers as a request to a Receiver endpoint, run the
                 endpoint and block until a response is available. Also see 8.3 Direct messaging.
               • Valid FF-A instances and conduits are listed in Table 15.6.
               • Syntax of this function is described in Table 15.7.
               • Successful completion of this function is indicated through an invocation of the following interfaces by the
                 callee:
                    – FFA_MSG_SEND_DIRECT_RESP to provide a response to the Direct request.
                    – FFA_INTERRUPT to indicate that the Direct request was interrupted and must be resumed through the
                       FFA_RUN interface.
                    – FFA_YIELD to indicate that the Receiver endpoint has transitioned to the blocked runtime state and must
                       be resumed through the FFA_RUN interface.
                    – FFA_SUCCESS to indicate completion of the Direct request without a corresponding Direct response.
                       All other parameter registers MBZ.
               • Encoding of error code in the FFA_ERROR function is described in Table 15.8.
