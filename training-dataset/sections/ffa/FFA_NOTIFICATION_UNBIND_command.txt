16.4 FFA_NOTIFICATION_UNBIND
            Description
                • This ABI is invoked by an endpoint at a virtual FF-A instance with the SMC, HVC or SVC conduits to
                  request the partition manager to unbind notifications specified in the Notification bitmap parameter from the
                  Sender endpoint. Also see 10.4.2 Notification binding.
                • This ABI is invoked by the Hypervisor at the Non-secure physical FF-A instance with the SMC conduit to
                  request the SPMC to unbind SP notifications specified in the Notification bitmap parameter from the SP
                  specified in the Sender endpoint ID parameter.
                • Valid FF-A instances and conduits are listed in Table 16.15.
                • Syntax of this function is described in Table 16.16.
                • Returns FFA_SUCCESS without any further parameters on successful completion.
                • Encoding of error codes in the FFA_ERROR function is described in Table 16.17.
                                                     Table 16.15: FFA_NOTIFICATION_UNBIND instances and conduits
           Config No.                  FF-A instance                                           Valid conduits
           1                           Non-secure virtual                                      SMC, HVC
           2                           Secure virtual                                          SMC, HVC, SVC
           3                           Non-secure physical                                     SMC
           4                           Secure physical                                         ERET
