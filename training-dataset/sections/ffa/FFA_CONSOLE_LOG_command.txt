13.12 FFA_CONSOLE_LOG
            Description
                • Allow an entity to provide debug logging to the console.
                • Valid FF-A instances and conduits are listed in Table 13.54.
                • Syntax of this function is described in Table 13.55.
                • Returns FFA_SUCCESS without any further parameters on successful completion.
                     – In this case, the characters are logged to the console in finite time.
                • Encoding of error codes in the FFA_ERROR function is described in Table 13.56.
                                                                Table 13.54: FFA_CONSOLE_LOG instances and conduits
            Config No.                  FF-A instance                                           Valid conduits
            1                           Secure physical                                         SMC
            2                           Secure virtual                                          SMC, HVC, SVC
