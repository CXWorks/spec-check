# 微调模型的迁移失败：域内完美，域外崩塌

> 把两份已有的实验结果放在同一把尺子下对照。
>
> - **域内**：[9B 结果 — pass 率与找 bug](9B结果-pass率与找bug.md) · RMM `alp14`，98 条命令，**有人工标准答案**
> - **域外**：[六份规范 — 两个 9B 完整实验报告](六份规范-两个9B-完整实验报告.md) · 6 份规范，316 条命令，**无标准答案**
>
> 两边用的是**同一个模型、同一个权重**（`sft3-2/final`，LoRA on Qwen3.5-9B），一个字节都没改。

---

## 一句话

**微调版在训练过的那份文档上，写得和人类专家一样好；换一份文档，它基本只会写「永远成立」。**

---

## 一、核心对照

同口径统计：**全部命令**的函数体是否字面等于 `true`（不是只看编译通过的那些）。

| | **alp14（域内）** | **六份规范（域外）** |
|---|---|---|
| 命令数 | 98 | 316 |
| 模型见过这份文档吗 | **训练数据就来自 RMM** | **一条都没见过** |
| **微调版空洞率** | **3/98 = 3%** | **73% – 95%** |
| **非空洞规范的子句中位数** | **20** | **1 – 5** |
| **人工标准答案对照** | **3/98 = 3%，子句中位 20** | 无 gold |

### 微调版在域内 = 人类专家

```
              空洞率      非空洞规范的子句中位数
微调版 9B      3/98          20
人工标准答案    3/98          20          ← 完全一致
```

而且**五种配置全部是 3/98**（不给字典 / 尾部200行 / 按需选取 / 尾部+改三轮 / 按需+改三轮），说明这不是某个配置的偶然。

那 3 条空洞是**对的**——文档在那几条命令上确实什么都没规定，**标准答案也是 `true`**。

### 同一个模型，换文档之后

| 文档 | 微调版空洞率 | 原始 9B 空洞率 |
|---|---|---|
| **alp14（域内）** | **3%** | — |
| PSCI | 95% | 0% |
| FFA | 92% | 15% |
| SDEI | 84% | 5% |
| SCMI | 82% | 12% |
| SBI | 82% | 15% |
| DRTM | 73% | 9% |

**从 3% 到 73–95%。**

## 二、这个 9B 是怎么训练出来的

要理解为什么泛化不了，得先看训练数据长什么样。

### 训练配置

| | |
|---|---|
| 底座 | `Qwen/Qwen3.5-9B`（bf16）|
| 方法 | **LoRA**（不动底座权重，只训练旁挂的一小组参数）|
| rank / alpha / dropout | 16 / 32 / 0.05 |
| 挂在哪些层 | `q, k, v, o, gate, up, down` 全挂 |
| 轮数 | 3 |
| 学习率 | 2e-4 |
| 单卡 batch / 梯度累积 | 1 / 4 |
| 最长序列 | 12288 token |
| 随机种子 | 42 |
| 硬件 | 单节点 8 × H100 |
| 产物 | `jisenli/spec-check-ckpt` 的 `sft3-2/final` |

### 训练数据：1266 条，**全部来自 RMM 一份规范**

```
训练 1266 条 / 验证 91 条 / 测试 49 条
```

版本分布（**六个版本，但都是同一份 RMM 规范**）：

```
eac5 121    rel0 122    alp11 255    alp12 261    alp13 252    alp14 255
```

### ⚠️ 关键：真正的任务样本只占 19%

1266 条训练样本里，**只有 249 条是「读文档 → 写规范」这个任务本身**：

| 样本类型 | 条数 | 占比 | 教什么 |
|---|---|---|---|
| `helper_stub` | **726** | **57%** | 词汇表里的辅助函数怎么用 |
| `type_definition` | **291** | **23%** | 词汇表里的类型长什么样 |
| **`command`** | **249** | **19%** | **真正的任务：文档章节 → Verus 规范** |

而且那 **249 条只覆盖 72 个不同的命令**——因为同一条命令在六个版本里反复出现，算作多条样本。

**一条训练样本长这样**（中位 1064 字符）：

```
system     任务说明 + 风格模板
user       词汇表 + 这条命令的章节文本
assistant  人工编写的 Verus 规范      ← 训练目标
```

### 这个数据构成解释了泛化失败

把上面几个数字连起来：

```
80% 的训练信号，教的是 RMM 这份文档的词汇表怎么用
   （RmiStatusCode 是什么、RttWalk 怎么调、RmiRealmState 有哪些取值……）
19% 才是真正的任务，而且只有 72 个不同命令，全部来自同一份文档
```

**模型学到的很可能主要是「RMM 的词汇和句式」，而不是「如何把规范文本翻译成形式化规范」。**

换一份文档之后：

- 那 80% 的词汇知识**全部失效**（SCMI 不认识 `RttWalk`，SBI 连架构都不是 Arm）
- 剩下 19% 学到的任务模式，在新文档的句式上对不上
- 模型退回到一个永远安全、永远编译通过的答案：**`true`**

这也和另一个已知现象吻合：**训练里明令禁止把「能编译」当作训练信号**，正因为 `true` 是编译通过率最高的答案。域内有标准答案压着，这个倾向看不出来；**域外一放开就暴露了**。

### 一句话

**这是一个在单一文档上、用 19% 任务样本训练出来的模型。它在那份文档上追平了人类专家，这件事本身是成立的——但没有理由期待它迁移，实测也确实没有迁移。**

## 三、这说明什么

### 1. 微调买到的能力是「这一份文档」的，不是「读规范」的

如果微调教会的是「如何把规范文本翻译成形式化规范」，换一份规范应该还能用。**实测不能。**

它更像是学会了 RMM 这份文档的**词汇、句式和套路**。离开这份文档，那套模式对不上，模型退回到一个永远安全的答案：`true`。

### 2. 空洞是最坏的失败方式，因为它看起来像成功

`true` 这条规范：

- **编译 100% 通过**
- **Z3 永远满足**
- **任何检查都不报错**
- **一个 bug 都找不到**

**如果只看「编译率」或「有没有报错」，域外的表现看起来毫无问题。** 只有专门数空洞才看得见。

这正是训练时明令禁止「拿编译成功当训练信号」的原因——`true` 是编译通过率最高的答案。域内有标准答案压着，这个倾向被掩盖了。

### 3. 原始模型没有这个问题，但有另一个问题

| | 微调版 | 原始 9B |
|---|---|---|
| 空洞率（域外） | **73–95%** | 0–15% |
| 用文档自己的返回码 | 很少 | **多得多**（SCMI 126/153）|
| 复读退化 | 几乎没有 | **有**（SCMI 18/153、SBI 11/72）|
| 输出长度 | 短而稳定 | 长，会撞 token 上限 |

**微调版稳定但空洞，原始模型有内容但控制不住。** 不是单方面更好。

### 4. 跨架构也成立

**SBI 是 RISC-V，不是 Arm**，和训练数据毫无关系——结论一样（微调版 82%，原始 15%）。所以这不是「Arm 文档之间的细微差异」，是**真正的域外失效**。

---

## 四、对论文主线的影响

之前有一个悬而未决的问题：**微调在域外究竟是「没帮上忙」还是「损害了泛化」？**

**现在有数据了：是后者。** 原始模型在同样的文档上空洞率 0–15%，微调版 73–95%。**微调让模型在域外变差了。**

这直接影响主线怎么定：

| 主线 | 这组数据的影响 |
|---|---|
| **流水线 + 可插拔生成器** | ✅ **支持**。生成器谁强用谁，域外可以换原始模型或通用模型 |
| **微调模型是核心贡献** | ❌ **硬伤**。域内 15–17/49 的好成绩不迁移，换文档就崩 |

**alp14 上那个「逐项追平标准答案」的结果依然成立**（见域内文档），但它的适用范围要说清楚：**那是 RMM 这一份文档上的结果。**

---

## 五、两边各自的限制

| | alp14（域内） | 六份规范（域外） |
|---|---|---|
| 有标准答案吗 | ✅ 有，所以能测**正确率** | ❌ 没有，**正确率测不了** |
| 能测什么 | 正确 / weaker / 编译 / 空洞 / 找 bug | 空洞 / 返回码命中 / 复读 |
| 主要弱点 | 只有一份文档 | 没有 gold，只能测「说了没说」，不能测「说得对不对」 |

**「原始模型空洞率低」不等于「原始模型写得对」**——它只是写了东西。内容对不对，这六份文档没有标准答案，判不了。
